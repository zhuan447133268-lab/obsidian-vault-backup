# 手搓夸克：候选开源项目调研（原料库）

> 目标：做一个类似"夸克网盘资源搜索"的工具——能搜到电影/电视剧分享资源。
> 结论：这不是单个项目，而是**三层拼装**的生态。以下为候选清单（2026-10-21 调研）。

## 三层模型

1. **资源搜索聚合**（"搜索框"）：爬/聚合 Telegram 公开频道 + 第三方插件，返回各网盘分享链接。
2. **夸克转存**（"存进夸克"）：封装夸克官方转存 API，把分享链接存进自己的夸克账号。
3. **AI agent 智能找片**（"智能版"）：用 agent 把 1+2 串起来，说片名自动搜→选→转存→追剧补集。

## 候选项目（按层）

### ① 搜索聚合
- **huanyu-a/panseek**（PanSeek）：Nuxt4 + Cloudflare Workers；TG 140+ 频道 + 68 插件源，覆盖夸克/阿里/百度/115/迅雷/123/磁力等 13 类；豆瓣榜单、链接失效检测、密码门。**最活跃最全，首选研究对象。**
- **wu529778790/panhub.shenzjd.com**（PanHub）：TG 80+ 频道 + 10+ 插件，极简 UI，Vercel/CF/Docker 一键部署。轻量入门。
- **usiyiymm/pan-search**：Go 后端 + 前端，高性能**搜索 API 服务**，多频道并发、结果排序、docker 前后端一体，有完整 API 文档。想自己接后端选它。
- **pansearch.me**（PanSearch）：现成在线搜索站点（未确认开源仓库）。

### ② 夸克转存 / API（核心底座）
- **Cp0204/quark-auto-save**（★3k+，Python，AGPL-3.0，Docker+WebUI）：签到、自动转存分享链接、正则整理文件名、Emby 刷新媒体库、接 Alist/rclone。**"手搓夸克"真正存进夸克账号的发动机**；作者声明仅封装官方 API，无破解。
- **H1d3rOne/QuarkManager**（FastAPI + Vue3）：更完整夸克网盘客户端——二维码登录、文件管理、分享转存、CLI。

### ③ AI agent 智能找片
- **fancydirty/mediary-scout**（巡影）：说片名 → AI 搜 → 择优 → 转存进网盘（夸克/115/光鸭/123/天翼）→ 校验 → 追剧自动补集；对接 Jellyfin/Emby/Plex。Docker + 桌面版。**最接近"手搓夸克"智能化形态**，本质用 agent 串起 ①②③。

### 客户端形态（参考 UI）
- **mcxiedidi/yingshipan**（影视盘，Flutter）：多网盘挂载 + TMDB 刮削 + 资源检索，GPL-3.0 非商用。

## 取舍判断
- 只做"能搜资源"：fork/参考 **PanSeek** 或 **pan-search**（已做完全网公开链接聚合，别从零爬 TG）。
- 必须"存进夸克"：**quark-auto-save** 是绕不开底座（封装的夸克官方转存 API 是全生态共同依赖）。
- 想一步体验智能版：**Mediary Scout** 直接 Docker 能跑（起 4 容器含 PanSou 搜索服务）。

## ⚠️ 合规/现实风险
- 聚合的是**用户公开分享链接**，作者均声明"只封装官方 API、不对内容负责"。
- 国内网盘自 2026-04 配合"剑网2025"已大规模清理未授权海外影视（夸克/阿里/115 均在肃清），项目可能因平台封禁分享/改 API 随时失效。
- 涉及版权与平台 ToS 风险：个人学习/管理自有内容可用，勿做公开分发或商业用途。
