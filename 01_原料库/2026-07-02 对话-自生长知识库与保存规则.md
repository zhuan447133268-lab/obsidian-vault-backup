# 2026-07-02 对话：自生长知识库 + 保存规则升级

## 一、触发

用户分享公众号文章《10分钟搭建自生长知识库》（链接：https://mp.weixin.qq.com/s/Fqel4MmeQSwGJH60CPlrNA），文章主张用 Obsidian + Codex 搭建四层闭环知识库：原料库、概念库、Skill 库、输出库。

## 二、文章核心观点

- 知识库不是收藏夹，而是消化系统：原料 → 消化 → 肌肉 → 反哺。
- 四层结构：
  - `01_原料库`：网页文章、截图、会议纪要、未处理信息
  - `02_概念库`：核心观点、案例、方法论、概念卡片
  - `03_Skill库`：选题判断、写作风格、周报模板、检查清单
  - `04_输出库`：文章、报告、方案、PPT
- 每次输出要回流进知识库，系统才会越用越懂你。
- 先用 10 分钟搭最小闭环，不要一开始就追求全自动。

## 三、结合用户现状的讨论

用户当前已使用 Obsidian 和 memory 系统，主要模式是：每次聊完让我把对话保存到 Obsidian。但存在的问题：

- 保存的多是原始对话，缺少消化和提炼。
- 确认过的事实、工作方法散在笔记里，无法被系统性调用。
- 每次新项目都要重新交代背景。

自生长的关键是：**让过去整理过的东西，自动参与未来的工作。**

## 四、用户决策

用户要求新增一条规则：

> 每次我说「存一下」时，保存对话后主动提取可以沉淀成 Skill 或概念卡的内容，列出来让我确认；或者自己提取后告诉我里面有哪些可沉淀。

该规则已写入 memory：`feedback_save_to_obsidian_extract_skill.md`。
