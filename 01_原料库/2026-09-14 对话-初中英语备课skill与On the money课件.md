## 三、核心讨论点

### 3.1 版本年级事故（最贵的一类错误）

- **错在哪**：把外研社九上当北师大七上，且"按年级推测版本"（默认"九年级就估外研社吧"的反向错误——这次是没核就按七年级压难度）。
- **代价**：整节课作废，从设计稿到课件教案练习演示全部重做。
- **修法必须是三层的，缺一层就还会犯**：
  1. **规则层**：铁律 1 写进 SKILL.md 最高优先级位，并写明事故代价作参照。
  2. **机器层**：查 5 核对"设计稿的教材版本行"与"教案的授课教材字段"是否一致；不一致直接 FAIL。
  3. **知识层**：`textbook_map.md` 删掉"按年级猜版本"的写法，改成取证优先级 + 判据速查表。
- **取证优先级**（有据可依的定义）：老师明说 > 老师给的教材页照片（页脚单元名/板块名/页码）> 老师平时用的课件文件名 > 教学设计里的"授课教材"字段 > 版本目录表命中。**任一缺失 → 先问，一次问完，不许猜。**

### 3.2 "太简单"的根因（后来才定位准）

老师最初只反馈"太简单了"。逐页比对老师课件后才定位到真正根因：

> **不是页数不够，是产出层级低一档。** 旧版停在"认规则 + 单句填空"，没有上升到"成段表达 + 自我评价"。

由此提炼出 `courseware_format.md` 的 **A 组硬性项**（缺任一即判"太简单"）：

1. **方法支架前置**（如"读句四步自查法"：找主谓 → 辨语义 → 定标点 → 查时态。先给工具再动笔）
2. **成篇产出任务 + Useful Expressions 句型支架**
3. **自评量表**（四维星级）
4. **范文示例**（把目标结构标出来）

### 3.3 跨板块对齐的口径

同单元不同板块**课型可以不同**（语法课 vs 读写课），但**环节骨架与难度标尺必须一致**。

- 比对方法：两份课件逐页 dump → 一一映射 → **映射不上的空位就是漏掉的环节**。
- 本次映射出的 4 个空位：方法支架 / 成篇产出 / 自评量表+范文 / 结束页。
- 练习形态差距：老师 5 种（填空/排序/结构图/问答/写作）vs 我 1 种（纯填空）。

### 3.4 演示的定位（两次返工才定）

- **第一次错**：做成点选填空 → "不还是练习题嘛"。
- **第二次定型**：演示是**讲解器**，不是练习题。硬机制：
  > **教师提问（台词）→ 学生先猜 → 点击验证 → 结论固化**
  每个模块标"对应课件 Pxx"，附一行"学生最常错"。
- **原则**："先问再点"——演示是验证工具，不是动画片。**不为演示而演示。**

### 3.5 配图风格的确立（先查实证再动手）

没有凭印象猜，先查了 2024 版外研社教材的多模态分析数据：

- 提供关系 90.7%（客观呈现，人物不看镜头）
- 近景 + 中景 89%
- 正面 78.8% / 平视 83.9%
- 高情态 68.6%（色彩丰富高对比）
- 另有对比研究指出新标准插图"更真实且具体" → **写实方向对、卡通夸张方向错**

据此定七条硬规格：**写实具体 / 正面平视 / 中近景 / 中央主体 / 明亮高对比 / 人物不看镜头 / 画面零文字**。

两个必做后处理：**裁掉生成图右下角平台水印**；**压成 JPG**（单张 2.3 MB → 约 280 KB，整套课件 4.36 MB → 2.23 MB）。

## 八、环境坑（本机，踩过的）

- **无 PowerPoint COM、无 LibreOffice** → `export_shots.py` 必失败，别死磕；走 `check_bounds.py` + `check_textfit.py` 双自查。
- **HTML 可以做真实截图验收**：`playwright install` 与已装 Chromium 版本对不上（要 1223 只有 1234）→ 用 `chromium.launch(channel='chrome')` 走系统 Chrome，可用；顺便查 `scrollWidth == clientWidth`（投屏最怕横向被切）。
- **ImageGen 出图右下角带平台水印**，必须裁（1024 宽裁 90px / 1536 宽裁 95px），再压 quality=88 JPG。
- **批量改 md 不要用 `python -c "..."` 内联串**：反引号会被 shell 当命令替换吞掉，把文件写坏 → 走 Edit / Write。
- **Edit 工具并发坑**：同一条消息里对同一文件的多次 Edit 可能静默不生效 → 拆开做，或整文件 Write。
- 偶发：Bash 的 PATH 会被 shell 环境破坏（`dirname: command not found`）→ 命令前加 `export PATH="/usr/bin:/bin:/c/Windows/System32"`。
