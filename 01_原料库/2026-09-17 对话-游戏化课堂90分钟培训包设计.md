# 2026-09-17 对话：游戏化课堂 90 分钟培训包设计（0 基础混合科目）

> 用途：「AI 辅助做游戏」培训课的**小学学段落地包**。沿用既有培训风格（实操演示 + 学员跟做卡），工具 = WorkBuddy（老师全员已装、自带电脑）。
> 成品物料：`C:\Users\dfjq\Desktop\游戏化课堂90分钟培训包\`（01 创意卡 / 02 跟做卡 / 03 讲师手册），可直接打印。
> 关联：[[2026-09-17 对话-2D像素小岛AI辅助开发(游戏培训课素材)]]（课程铁律出处）· 双 AI 分工法是其"WorkBuddy AI Coding 体验课"方法论支柱。

## 一、场景约束（设计前提）

| 约束 | 解法 |
|---|---|
| 小学老师 0 基础，混合科目 | **老师只出"题"，机制/代码/美术全部预制**；机制收敛为 3 种万能壳（答题闯关/配对分类/寻宝问答），不开放自由命题 |
| 初中老师混入 | 进阶卡三选一（加倒计时/加积分/换玩法）+ 混坐当同桌小助教 |
| 90 分钟、mostly 实操 | 实操 77/90 分钟；每步标 ⭐必做/▲选做 |
| 用户培训风格 | 讲师实操演示 + 学员跟做卡，每步写"做对了的样子" |

## 二、90 分钟流程总控

| 时间 | 环节 | 要点 |
|---|---|---|
| 0–8' | 开场演示 | WorkBuddy 现场"提示词→游戏→双击玩"；**样例提示词提前演练 3 遍** |
| 8–35' | 跟做① 统一样例 | 全场做"5 以内加法"跑通流程；助教重点盯：文件后缀 .html、复制不完整 |
| 35–65' | 跟做② 换自己内容 | 填模板 → 发送 → 保存 → 验收清单打钩；没备课的发题库急救包 |
| 65–80' | 同桌互玩互修 | 验收清单当评委卡，签名互评 |
| 80–90' | 展示收尾 | 展示"真实的"不选最好的；发"回去之后"卡 |

## 三、核心武器：填空式提示词模板

- 老师只改【】区：学科/标题/题目/答对答错语；**技术要求段锁死不许改**：
  - 单文件 HTML、零外部资源、不联网、双击可开（= 像素 demo 验证过的 file:// 路线）
  - 字号大按钮大（课堂投屏）、答错不判死可重答
  - 生成后让 AI 自报"怎么保存/怎么打开/改题改哪里"（0 基础老师的操作说明书由 AI 自己出）
- **通关验收清单 5 条**（能打开/题对/答对有反馈/答错能重答/有通关祝贺）——"机器可验证的完成标准"思路，与修黑屏时同源

## 四、风险预案（讲师手册里的干货）

1. WorkBuddy/网络现场挂 → U 盘离线降级：不发新提示词，改样例 HTML 文字（记事本查找替换），流程不破
2. 大范围生成失败 → 统一话术"新开对话重贴"，助教只处理重贴两次仍失败的
3. 创意卡提前一天回收，扫掉"想做联机/视频识别"等 90 分钟做不了的，沟通降级
4. 题库急救包：语/数/英/科各 3 套 ×5 题，已人工校对（语文"日加一笔"多解题已标口径）

## 五、课程铁律对齐

- 开场即产出 → 8 分钟内全场看到"提示词变游戏"
- 实操 ≥85% → 77/90 分钟
- 方法论进卡片 → 验收清单卡、进阶卡、"回去之后"卡
- 现场不现装环境 → WorkBuddy 预装 + U 盘离线兜底

## 六、待办（⚠️ 待校验）

- [ ] **用 WorkBuddy 实跑提示词模板**（跟做卡第 2 步样例段），验证产出质量；确认 WorkBuddy 能否直接生成/下载 HTML 文件（能则删掉手动复制保存的保底步骤）
- [ ] 培训前 3 天发创意卡，前一天回收并筛查做不了的需求
- [ ] 急救包题目正式打印前通读一遍（已在讲师手册标注多解风险点）

## 七、可复用模式（已提炼，见 [[游戏化课堂三件套设计法]]）

创意卡（收集内容）→ 跟做卡（统一样例跑流程 + 换内容 + 验收清单）→ 讲师手册（总控/预案/急救包）——不限于游戏培训，任何"0 基础 + AI 工具 + 90 分钟产出物"的培训都可套。
