# 2026-09-17 对话：2D 像素小岛 AI 辅助开发（游戏培训课素材）

> 用途：给「AI 辅助做游戏」培训课当**素材库**——不是照搬文章，而是按课程铁律（开场即产出 / 实操≥85% / 方法论进卡片）拆出可直接用的钩子。
> 系列共三篇：①搭世界（本篇）→ ②联机与服务器 → ③让 AI 走进来（AI 从对话框走进小岛）。

## 一、最值钱的 4 条（按"能不能直接进课"排序）

### 1. 双 AI 分工法 —— 课程方法论支柱
- 一个**强模型当架构师/advisor**（拆任务、定方案、审代码）+ 一个 **worker agent 写码**
- 推荐搭配：Opus / sol / fable 当架构师 + GLM 实际干活
- 没有两个也行：**开两个窗口**，一个写任务书、一个干活
- **进课角度**：这是"不会代码也能做游戏"的核心方法。可直接做一张「双窗口分工」实操卡片（方括号占位：[架构师窗口] 出任务书 → [worker 窗口] 写码 → 架构师审 → 改）。

### 2. 三条像素"基本法" + 踩坑清单 —— 学员最容易卡死区
"看着不对但说不出哪不对"的 bug 集合，做课素材金矿。
- **16px 网格制**：一切位置基于 `TILE=16`；角色/树/房子比格大（如 48×48 占三格）是常态。
- **Phaser 原点坑**：Sprite 默认原点在**中心**（origin 0.5,0.5），Image/Tile 才是左上角 → 角色要 `setOrigin(0.5, 1)` 钉到**脚底**，否则"偏半个身子"。
- **整数缩放**：ZOOM 必须 2/3/4，不能 1.5 → 像素糊/毛刺。
- **瓦片接缝闪线**：相机取整（每帧 `Math.round`）+ extruded tileset（边缘外扩 1px）。不知道原因能找一整天，还易误判成"贴图切错"。
- **NEAREST 过滤**：`pixelArt: true`；但 **RenderTexture 动态纹理要单独再设 NEAREST**（管不到）。
- **Mac 字体坑**：像素字体被系统抗锯齿弄圆 → CSS 关字体平滑。
- **进课角度**：做一张「像素世界基本法」自检卡（打勾式），配 1-2 个"为什么看起来不对"的反例截图。

### 3. 精灵图标定页 + 47-blob 自动瓦片 —— 实操技巧
- **标定页**：让 agent 做单个 HTML，精灵图放大 + 每格左上角叠帧号 → 截图给 agent 即知第几帧。比人肉数准，做一次全项目复用。帧号公式 `行×每行列数+列`。
- **47-blob**：不用 Godot 时人必须自己解决。搜 "47-blob tileset" 拿现成映射表；47 是去重后业界标准，作者项目 68 条（加了变体）。**选素材要看清**：3×3 九宫格包做不出完整自动瓦片。
- 现在模型有视觉 → 可让 agent 建初始映射 + 人肉校验（作者 2 月前无视觉才自己标定）。
- **进课角度**：把"标定页 + 47-blob"做成 agent 可执行的任务书片段，学员直接喂。

### 4. "先让世界有模样"节奏 —— 对应课程铁律
- 七层蛋糕叠地形（水/泥/浅草/深草/山/路/栅栏）做自然过渡。
- 不匀速动画帧（如 0-1-0-1-2-3）保留 GIF 重复帧节奏。
- 统一 `Interactable` 接口（作者重构过）：所有可交互物件实现同一接口，只暴露"我能被怎么操作"，加新物件不改交互系统。
- y-sort 一行：`sprite.setDepth(sprite.y)` 配合脚底 origin，世界"立起来"。
- **进课角度**：完美对齐"开场即产出、实操≥85%"——第 30 分钟看到小人在草地上跑，比先做 3 个系统强。把"先出模样再加层"写进实操卡片节奏说明。

## 二、技术栈结论（选 Phaser 的理由）
- **Phaser + TypeScript + Vite**：AI 助手几乎无认知盲区。
- 对比 Godot：拖拽能做的（地图编辑/碰撞可视化/动画预览）这里全用代码搓，但 AI 全代码协助得更好。
- 古法做游戏=学引擎太耗热情 → 直接用 Phaser（npm 包，不是软件；无编辑器/节点树/GDScript）。
- **进课角度**：选 Phaser 的决策依据直接写进课件"为什么这么选"页，消除学员"为什么不用 Unity/Godot"的疑虑。

## 三、世界"活起来"的配方（第 2 节素材）
| 效果 | 做法 | 关键点 |
|---|---|---|
| 昼夜 | 全屏半透明色块叠色，随游戏时钟平滑过渡 | 6点暖橙→8点透明→20点深蓝→2点蓝紫；一个全屏矩形 setAlpha+setFillStyle 每 tick 更新 |
| 四季 | 给草地/泥地/山丘叠 `setTint()` | 春绿/夏暖黄/秋枯褐/冬灰蓝；**水和栅栏不叠色**（水不会秋天变棕） |
| 雨 | 粒子系统，**两层雨**（近大快/远小慢）出纵深 | 雨天天暗一点+草地深一点，复用 tint |
| 雪 | 粒子慢落+随机横向+旋转，再叠正弦偏移 | 轻飘感 |
| 闪电 | 全屏遮罩瞬白 alpha≈0.6 再衰减 | 分叉用折线 |
| 天气决定 | 每天随机一次，按季节**权重表**控概率 | 春晴60/雨35/暴5；夏65/15/20；秋80/15/5；冬晴60/雪40。**雨天不用浇水**——这条让种田有策略 |
- **进课角度**：天气权重表+作物季节限制进数据表不硬编码 → 可做成"策略设计"小实操。

## 四、本篇结束时应达到的状态（验收锚点）
- 36×28 小岛：水围陆地、草地深浅过渡、石板路、几棵树、一片田、鸡牛溜达。
- 天有昼夜、四季变色、雨有两层。
- 角色能跑、被树挡、田边可交互。**单机、无存档、刷新即失**。
- 第 2 篇：加服务器/数据库/别人能连进来；第 3 篇：让 AI 走进来。

## 五、直接可用的"喂给 agent"任务书片段
1. "创建一个 Vite + TypeScript + Phaser 3 的项目。先搭一个能在浏览器看到空白画面的最简 Phaser 项目。"
2. "帮我设计统一交互接口。玩家走到物件附近按 E 交互，不同物件有不同交互效果，但交互触发逻辑统一（Interactable 接口）。"
3. "用 47-blob 方案做自动瓦片，先建初始映射再人工校验。"
4. "做一个精灵图标定页：单独 HTML 放大整张精灵图，每格左上角叠帧号。"
5. "给角色加 y-sort：sprite.setDepth(sprite.y)，origin 设 (0.5,1)。"

## 六、课程映射（对接我现有课体系）
- **WorkBuddy AI Coding 体验课**：双 AI 分工法 = "不会代码也能做"的方法论支柱。
- **课程铁律对齐**：
  - 开场即产出 → 第 30 分钟小人跑起来（对应"先出模样"）
  - 实操≥85% → 基本法自检卡 + 任务书片段，边喂边看
  - 方法论进卡片 → 双 AI 分工、像素基本法、47-blob 各一张卡
- **风险**：Phaser/TypeScript/Vite 对零基础学员仍偏技术 → 需预制标准 demo，讲师不现装环境（课程铁律"现场三不许"）。
