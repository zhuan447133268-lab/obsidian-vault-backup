# 搭建自生长知识库

## 适用场景

想让你的 Obsidian 从一个「存档夹」变成一个「越来越懂你」的工作系统。

## 工具组合

- **Obsidian**：本地 Markdown 知识底座
- **Claude Code**：读取、整理、执行、回流

## 最小搭建步骤（10 分钟）

### 第一步：新建 Vault 或复用现有 Vault

建议先别急着装一堆插件，先把文件结构跑通。

### 第二步：建四个文件夹

```
01_原料库/
02_概念库/
03_Skill库/
04_输出库/
```

### 第三步：写一份 README.md

放在 Vault 根目录，写清楚：

```markdown
# 我的自生长知识库

- 01_原料库：只放未处理信息
- 02_概念库：放 AI 整理后的结构化观点
- 03_Skill库：放可复用工作流
- 04_输出库：放最终文章、报告、方案

整理规则：
- 不要覆盖原始文件
- 新增内容注明来源和日期
- 能复用三次以上的方法，优先沉淀为 Skill
```

### 第四步：开始让信息进来

不要先整理历史包袱。从三种入口选一种：

1. **手动导入**：看到好文章、好观点，丢进 `01_原料库/`
2. **定期资讯**：让 Claude Code 每天/每周抓取信息源，生成结构化日报
3. **团队文档同步**：把飞书、Notion 里的重要内容转成 Markdown 进入 Obsidian

### 第五步：定期消化

固定任务示例：

> 请检查 `01_原料库/` 中最近 24 小时/7 天新增的内容。完成：
> 1. 去掉重复信息
> 2. 提炼值得长期保存的观点
> 3. 标出有用的数据、案例和链接
> 4. 找出可以变成选题或方案的内容
> 5. 把整理结果写入 `02_概念库/`

### 第六步：沉淀 Skill

反复出现三次以上的事，写成 Skill。常见类型：

- 周报 Skill
- 选题判断 Skill
- 写作风格 Skill
- 会议纪要 Skill
- 项目复盘 Skill
- 去 AI 味 Skill

### 第七步：输出并回流

输出时直接调用概念库和 Skill 库：

> 我要写一篇关于「经营分析看板」的文章，请从 `02_概念库/` 找素材，从 `03_Skill库/` 调用「公众号文风 Skill」，生成初稿。

输出完成后，把可复用部分拆回 `02_概念库/` 或 `03_Skill库/`。

## 四周启动计划

| 周次 | 任务 |
|---|---|
| 第一周 | 只做收集，每天把 3 条有用信息丢进 `01_原料库/` |
| 第二周 | 让 Claude Code 把本周信息整理成概念卡片，放进 `02_概念库/` |
| 第三周 | 沉淀第一个 Skill，从周报/选题/文风/去 AI 味里选一个 |
| 第四周 | 用知识库里的资料和 Skill，生成一次真实输出 |

## 三个常见坑

1. **一开始就追求全自动**：先手动跑通 10 条资料的小闭环，再考虑自动化。
2. **文件夹太复杂**：刚开始只需要四层，标签、双链、图谱以后再加。
3. **不写规则**：没有规则，AI 每次整理出来的格式都会漂。

## 安全提醒

不要把 API Key、客户隐私、账号密码、敏感合同放进会被自动同步的公开目录。
