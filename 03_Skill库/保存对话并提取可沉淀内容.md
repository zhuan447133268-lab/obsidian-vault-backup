# 保存对话并提取可沉淀内容

## 触发条件

用户说以下任意一种表达：
- 「存一下」
- 「保存到 Obsidian」
- 「把这次对话记下来」
- 类似含义

## 执行步骤

### 第一步：保存原始对话

1. 找到 Obsidian Vault 根目录下的 `01_原料库/`。
2. 新建文件，命名格式：`YYYY-MM-DD 对话-简短主题.md`。
3. 写入对话摘要：
   - 触发背景
   - 核心讨论点
   - 用户决策
   - 后续行动
4. 遵守 [[Obsidian笔记从旧到新排列]] 规则：追加内容放末尾，不 prepend。

### 第二步：提取可沉淀内容

从对话中识别以下内容：

| 类型 | 判定标准 | 去向 |
|---|---|---|
| 确认事实 / 业务口径 | 用户或业务方明确确认 | `02_概念库/` |
| 工作方法 / 流程 / 模板 | 重复出现三次以上，有固定步骤 | `03_Skill库/` |
| 项目状态 / 决策更新 | 已有项目笔记需要同步 | 更新已有笔记 |
| 新方法论 / 新概念 | 值得长期复用 | `02_概念库/` |

### 第三步：列出候选清单

向用户展示：
- 每条候选是什么
- 建议放到哪个文件夹
- 为什么值得沉淀

格式示例：

```
候选 1：概念卡 — 自生长知识库
- 内容：……
- 建议位置：02_概念库/自生长知识库.md
```

### 第四步：等用户确认后写入

- 用户说「都存」或明确指定编号后，再写入对应位置。
- 不要擅自写入。

## 注意事项

- 不要把 API Key、客户隐私、敏感合同写进会被自动同步的目录。
- 如果用户没有指定保存位置，默认存到 Vault 根目录的 `01_原料库/`。
- 提取时要区分：个人私活相关内容按 [[feedback_personal_work_excluded]] 规则处理，不入公司交付物。
