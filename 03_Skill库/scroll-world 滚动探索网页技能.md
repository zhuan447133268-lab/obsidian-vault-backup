# scroll-world：把品牌故事做成可滚动探索的网页

## 一句话定义

一个 AI skill：先让 AI 生成带镜头运动的视频，再用**网页滚动位置控制视频播放进度**——往下滚镜头推进，往回滚退回。本质是"视频 + 滚动 scrub"，**不是真 3D 实时场景**（不能自由旋转、换零件、改视角）。

## 它适合 / 不适合什么

- ✅ 适合：品牌故事页、产品发布、场景穿行（"先看到什么 → 为什么进下一处 → 停在哪"需提前设计）。
- ❌ 不适合：让用户自由转动产品、换零件、改观察角度的交互（需另做）。

## 关键事实（避坑）

- 仓库只给 **AI 工作流 + 提示模板 + 网页播放引擎**（`scrub-engine.js` / `index-template.html`），**不附视频素材**。
- 视频需另外用 **Monid（默认视频后端）/ Higgsfield（图像+备用视频路径）** 生成 → **付费**，且要登录、有额度、看模型能力。
- 本地依赖：**FFmpeg、Python/Pillow**（环境检查用 `monid --version`、`higgsfield workspace list`、`ffmpeg -version`、`python -c "from PIL import Image; print('Pillow OK')"`）。
- 费用**不写固定价**，取决于生成规格 / 片长 / 服务商 / 重做次数；仓库估算 ≠ 你账户当下报价。
- 原教程用虚构品牌"橙屿"做示例，**没真跑付费流水线**，配图是独立生成的概念图 + 仓库截图，不冒充成品实测 → "效果多炫"不能直接信。

## 八步流程（复现要点）

1. **装 skill**：Codex 用 `npx skills add oso95/scroll-world -a codex`；Claude Code 用 `/plugin marketplace add oso95/scroll-world` → `/plugin install scroll-world@scroll-world`。完成标准：AI 确认加载并能说明流程，≠ 素材工具已可用。
2. **查依赖与费用**：先让 AI 列已装/缺失工具、需登录的服务、可用生成路线、按三桌面场景估素材量/费用/重做余量，**未确认不生成**。
3. **拆品牌故事成 3 个场景**（例：果园 → 加工车间 → 街角饮品店），每站先定要表达的信息再排镜头；品牌文字留给网页排，**别烧进视频**（改一字可能重做素材）。
4. **先看静态场景图**统一风格（同材质/配色/光照/空间），确认后再批生成视频。
5. **生成镜头，重点查接缝**：用**实际渲染视频的首尾帧**做连接，别拿最初静态图接；慢慢滚过接缝再倒滚回去，查跳变/闪烁/折返。
6. **接入网页**：复制 `index-template.html` + `scrub-engine.js`，配 `sections`（still/clip/title/body）与 `connectors`；`diveScroll`/`connScroll` 调滚动距离；无手机素材就**不填虚构的 clipMobile**。
7. **本地预览验收**：`python -m http.server 8000 --bind 127.0.0.1` → 查五动作（顺滚看清 / 倒滚无跳 / 快滚不卡 / 导航对 / 按钮到联系）。空白先查网络面板 404，**别急着重生成**。
8. **手机版单独做**：宽屏裁到竖屏会丢主体；原生是另套 9:16 视频链 = 额外生成+费用，不是缩小桌面视频。

## 验收清单（可直接抄）

- [ ] AI 确认加载 skill 并说明流程与费用点
- [ ] 依赖清单 + 三场景预算已确认，未提交付费任务
- [ ] 三张静态图风格统一（材质/配色/光照一致、无多余肢体/变形/乱码文字）
- [ ] 接缝用实际帧、滚过去 + 倒滚回无突跳
- [ ] 本地预览五个动作全过，无 404
- [ ] 未填虚构的 mobile / 购买地址路径
- [ ] 本机预览 ≠ 可分享链接（部署后需重查线上加载）
