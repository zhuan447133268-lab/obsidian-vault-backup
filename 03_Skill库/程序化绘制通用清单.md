# 程序化绘制通用清单

> 从 moyu（正例）与 tangli（反例）的源码对照中提炼。用途：开工前判断、制作中对照、验收时打分。
> 源码锚点于 2026-11-27 核实，本地副本：`moyu-preview/` 与 `tangli/`（均在学习空间根目录下）。
> 注意：moyu 仓库没有 License。这里只引用思路与行号，不要整段复制代码用于分发。

## 心法一句话

**把「会变的东西」从像素里拆出来变成可计算的数据，再用一份环境状态同时驱动所有元素。**

「自然」不是某个特效，是每个元素都从同一份光照状态里读出自己的参数。

---

## 开工前：先做这个判断（不做完不开工）

列一张表：这个画面的哪些属性会随环境（天气 / 时段 / 镜头 / 交互）变化？

- 会变的 → 必须是数据，不能画进位图
- 不会变的 → 才可以做成素材

**验收问题**：随便挑一个会变的属性，问「改环境时它能自己跟着变吗？」答不上来就别开工。

## 八条清单

### 1. 形状用函数，不用描边图

- **要做的**：写一个 `widthAt(x, girth)` 这类函数——输入位置，输出宽度。改一个数字，整体体型跟着变。
- **正例**：`moyu-preview/art.js:30` `halfWidth(x, girth)`；吻部窄、胸鳍处最宽、尾柄收细。
- **反例**：tangli 用 AI 位图定轮廓，形状锁死在像素里（`assets.js:95` 注释直言「AI 图本身就是弯曲游动姿态，不需要逐片变形」）。
- **验收**：改一个参数，整条鱼/整个物体的体型能变。

### 2. 花纹用噪声 + seed

- **要做的**：噪声 = 随机但连续。同一噪声场配不同阈值就是不同花色；换 seed 出无限变体。
- **正例**：`art.js:12` `valueNoise(seed)`；`art.js:59` `patternFor(kind, seed)`；24 条鱼 24 种花色，零张素材图。
- **反例**：tangli 靠有限张 AI 位图，花色数量 = 出图数量。
- **验收**：换 seed 能出新变体，不用出新图。

### 3. 光单独存一层（核心）

- **要做的**：把素材拆成四份数据——`albedo` 底色 / `shade` 明暗 / `spec` 高光 / `fin` 半透明，最后才合成。
- **正例**：`art.js:84` 四个数组一次性声明；`art.js:91-169` 逐像素算光（把鱼身当圆柱体算受光、逐片鳞算阴影和亮带）；`art.js:204-217` 合成 `颜色 = 底色 × 明暗 + 高光`。
- **反例**：tangli 的高光和影子焊死在 AI 像素里——画亮了，到阴天还是那么亮。
- **验收**：同一个物体能渲染出晴天/阴天两个版本，**不是靠盖色雾**。

### 4. 影子从深度算，不写死

- **要做的**：深度同时决定影子的偏移、大小、锐度、透明度。
- **正例**：`scene.js:1264` —— 偏移 `(6 + (1-depth) × 30) × scale`；模糊 `(1-depth) × 1.1`；透明度 `0.72 - (1-depth) × 0.18`。贴底的影近、深、锐；浮面的影远、淡、糊。
- **反例**：`tangli/renderer/js/fish.js:230` `translate(x + 4, y + 7 + bob)` 固定偏移；`fish.js:70` depth 只影响透明度和大小。
- **验收**：把物体从水底移到水面，影子三个属性同时变化。

### 5. 环境参数集中成一张表

- **要做的**：天气/时段的所有参数写在一处；切换 = 换表，不改绘制代码。
- **正例**：`scene.js:122-131` `LOOKS` 表——sunny/cloudy/rain/snow 四份，每份含 sunK、caustic、glint、cloudCover、shadow、water、mist 等十几个参数；`lookFor()` 在表上做插值。
- **反例**：`tangli/renderer/js/pond.js:36-41` weather 表只有 dim/rain/snow 几个数；`pond.js:892-903` 靠全屏 `fillRect` 色雾调暗。
- **验收**：加一种新天气，只改表，不碰绘制函数。

### 6. 一个光照状态驱动所有元素

- **要做的**：同一份 `sun` / 云影状态，要被焦散、高光、鱼影、植物高光一起读取。
- **正例**：`gl.js:112` `sun = 1. - texture(uCloud, vUv).r`；`gl.js:233-239` 云影下 pond 整体转冷转灰、glint 一起衰减。注释写得很直白：「Caustics, glints, fish highlights and crisp shadows belong to sunlit water only」。
- **反例**：tangli 每层独立画完往上叠，雨只是整屏变暗（`pond.js:892-897`）。
- **验收**：云飘过时，鱼影、焦散、水色**同时**变，不是只有背景变。

### 7. 重活缓存，轻活每帧

- **要做的**：逐像素计算只做一次，每帧只做变形（弯曲、位移）。
- **正例**：`art.js:78` `layerCache`，`art.js:196` 上限 90 份按花色+seed+分辨率缓存；每帧只做脊柱弯曲。
- **反例**：tangli 每帧 `drawImage` 整张位图（`pond.js:799`）——性能是好，但无法二次加工。
- **验收**：缓存命中后逐像素计算不再执行；帧率不掉。

### 8. 缺了光，别用特效补

- **要做的**：先让统一光照成立，再谈雨丝、涟漪、粒子。
- **正例**：moyu 的雨打荷叶、漂浮花叶都接同一份 sun/wave。
- **反例**：`pond.js:743` 焦散 alpha 压到 `0.07` 几乎看不见，靠 `pond.js:867` 独立画雨丝撑气氛。
- **验收**：关掉所有特效后，画面仍然有统一光照。没有 → 回去补第 3、6 条。

## 反模式黑名单（看到就停）

| 反模式 | 出处 | 为什么危险 |
|---|---|---|
| AI 位图当主角 | `assets.js:95` | 好看的成品挡住了可计算的结构，高光/影子焊死 |
| 全局色雾盖全屏 | `pond.js:892-903` | 是滤镜不是光，所有元素不会各自响应 |
| 固定偏移椭圆影子 | `fish.js:230-236` | 不随深度、不随光照变 |
| 特效堆砌但光不统一 | `pond.js:743/867` | 越加越像贴纸，不像水 |
| 逐像素计算放进每帧循环 | — | 帧率崩盘，必须进缓存 |

## 迁移到视频

**结论：能用，而且比壁纸更放得开。** 视频是离线渲染，一帧可以算几秒，不用死守 60fps，所以光照能做得比 moyu 更细。

壁纸是**状态驱动**（天气/季节），视频是**状态 + 时间驱动**，多一层关键帧时间轴。内核完全不变：分层素材 + 统一光照。

| 壁纸概念 | 视频对应 |
|---|---|
| 环境参数表 `LOOKS` | 关键帧表：t0/t1/t2 各一份状态 |
| 天气切换 = 换表 | 帧插值 = 两张表之间线性/缓动过渡 |
| 实时 60fps | 离线逐帧渲染，无帧率上限 |
| 无限循环 | 有限时长 + 首尾帧 |

**视频专属的新规则**：

1. 变化写成**时间函数**，别散落在各处的 `if (状态)` 判断里——否则加长/缩短视频要改几十处。
2. 所有元素从同一个 `t` 读参数，保证「同一时刻全片同步」——这是壁纸统一光照的时间版。
3. 分镜切换只是换一张参数表，不要换一套绘制代码。
4. 先出低分辨率预览片确认节奏，再全分辨率渲染，别一上来就渲 4K。

**不适合的场景**：真人实拍、靠不可预测随机出效果的镜头、强叙事表演。这些用程序化反而束手束脚。

**成熟参照**：Manim（3Blue1Brown 所用）——本质就是「程序化绘制 + 时间轴」，跟 moyu 一个内核，只是目标从壁纸换成讲解视频。

## 最小启动路径（照着走）

1. **列变化表**：哪些属性随环境/时间变？会变的标红。
2. **定形状函数**：写 `widthAt(x)`，不要描边图。
3. **定噪声花纹**：一个函数 + seed，出无限变体。
4. **拆光层**：albedo / shade / spec / fin 分开存，最后合成。
5. **建参数表**：天气/时段/关键帧集中一处，所有元素从这里读。
6. **缓存起来**：逐像素只算一次。
7. **打分验收**：切一次天气（视频则拖一次时间轴），八条过几条？没过就别加特效，回去补光。
