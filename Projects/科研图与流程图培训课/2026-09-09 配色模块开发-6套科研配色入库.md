## 3 页设计

**第 10 页 `s-color-dict`** — 6 套色卡总览
2 列 × 3 行卡片，每卡 = 名称 + HEX 色块条 + 适用场景。底部金句「配色不是装饰，是编码」。

**第 11 页 `s-color-map`** — 图表 → 配色映射表（table 元素，7 行）
类型 / 配色的活儿 / 推荐方案 / 关键提醒。覆盖分类散点、热图、折线、双组对比、雷达、流程图网络图。
底部口诀：**分类用不同色，大小用深浅，重点用强调色**。

**第 12 页 `s-color-flow`** — 流程图配色 + 样式四件套
上半：5 节点流程示范（明确需求 → 选对路线 → 出图 → 核对数据 → 用出去），灰白底 + **只有最后一个节点用强调色**。
下半：线型 / 标记 / 透明度 / 渐变 四张卡。

> 流程图配色的核心：**中性底 + 一个强调色**，强调色只给关键节点，读者才知道往哪看。

## 技术沉淀：bento 课件怎么改

- 整个课件是**一个** `<script type="application/bento+json" id="bento-doc">` JSON 块，只改它，别重新生成文件
- JSON 内所有 `<` 必须转义成 `\u003c`（`>` 不用转）
- 元素只用三种类型就够：`text` / `shape(rect)` / `table`
  - 特殊符号（● ■ ▲ ◆ ★）用文本写，比画 shape 稳
  - 透明度色块 = 同 fill 不同 `opacity` 的 rect
- **morph**：连续同主题页共享元素 id（本例 `ck`/`ct`/`pg`）+ `transition:"morph"`，翻页时标题平滑变形 —— bento 的招牌动作
- 主题 token：背景 `#F4F1EA` / 墨色 `#1A1A18` / 强调色 `#002FA7`（IKB 克莱因蓝）；画布 1280×720，边距 96

### 必做的两条校验（插入后跑）

1. **id 去重**：同一页内元素 id 不能重复
   - 本次踩坑：循环生成 `so{k}` 与说明文字 `so1` 撞车，`sg{k}` 与 `sg1` 同理。命名时给说明类加 `_desc` 后缀
2. **边界检查**：`x+w ≤ 1280` 且 `y+h ≤ 720`

校验结果：15 页 / id 重复 0 / 越界 0。
