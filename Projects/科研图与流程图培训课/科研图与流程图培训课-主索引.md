# 科研图与流程图培训课 · 主索引

## 项目定位

面向**高校与中小学教师**的 AI 科研绘图实操课。核心主张：

> 科研图要的是 **准确 + 可复现 + 能改**，不是"好看就行"。

课程给老师一张"绘图地图"——按需求分成三条路线，各自解决不同问题：

| 路线 | 解决什么 | 典型场景 | 工具 |
|---|---|---|---|
| 路线1 · 结构化编辑图 | 画完还要改结构 | 流程图 / 架构图 / 关系图 / 层级图 | diagram-design（HTML+SVG，矢量可改） |
| 路线2 · 期刊级数据图 | 有真实数据要对比看趋势 | 柱状 / 折线 / 热力 / 散点 / 箱线 | SciencePlots + figures4papers（matplotlib） |
| 路线3 · 描述成文图 | 靠想象生成概念图 | 机理图 / 示意图 | PaperBanana 类多智能体（需 Gemini / OpenRouter key） |

选路口诀：**挑，不选填** —— 要改结构走 1，要画数据走 2，要想象走 3。

## 课程通用规范（跨路线）

配色是三条路线都要遵守的底层规范，不依附任何一条路线：

- **颜色是编码，不是装饰** —— 每一种颜色都要帮读者看懂数据
- 分类用**不同色**，大小用**深浅**，重点用**强调色**
- 类别 ≤ 8，别用彩虹色；0 值落在中性色
- 冗余编码：颜色之外再配线型 / 标记 / 透明度，保证黑白打印和色盲读者可读
