# 第 1 讲 · AI 怎么工作（2026 版）

> 上游：[[2026-11-18 6讲基础课-单课结构设计]]（§1.1 时间轴、§2.8 内容边界）
> 图上小字：推理模型 · 幻觉 · 上下文。课名不改字。
> 平台：Workbuddy（学生有积分，可自己跑完整任务）。
> 实操分两段：先跟做一个最小的，再换成本人自己的。

## 0. 这一讲讲什么

**一句话：它现在长什么样 → 里面有哪些零件 → 跑起来是一个什么循环。**

三条边界，写在最前面，防止又写偏：

| 讲 | 不讲 | 为什么 |
|---|---|---|
| 形态演进（从大语言模型到智能体） | 神经网络、参数、训练方法 | 学生要知道它现在能干什么，不需要知道它怎么算的 |
| 零件的名字与作用（上下文／工具／MCP／Skills／记忆） | 每个零件的技术规格 | 名字是用来对接世界的，不是用来考试的 |
| 一次运行的循环（想→做→看→再想） | 怎么拆任务、怎么逐步验收 | 那是第 ⑤ 讲的事，本讲只让学生**看见**这个循环 |

**本讲不承担"它会怎么出错"**。编造、漏约束、假报完成，在本次课里只作为**现象**露一面（演示中的反转、记录单里的一行），归因与防范放到第 ④、⑤ 讲。

## 1. 与第 5 讲的分工（2026-11-18 拍板）

| | 第 1 讲 | 第 5 讲 |
|---|---|---|
| 认领 | 它是什么、由哪些零件组成、跑起来什么样 | 怎么用它干活、怎么编排工作流 |
| 学生动作 | 看、认、记流水账 | 上手用、串流程、逐步验收 |
| 出口 | 《Agent 运行记录单》 | 《任务拆解卡》＋《委派验收单》 |

第 ⑤ 讲课名不动（"入门"仍然成立：学生第一次真上手），图上小字改为**「上手用 · 工作流编排」**。

## 2. 90′ 时间轴

| 时间 | 段 | 内容 | 出口 |
|---|---|---|---|
| 00–03 | 开场交流 | 问两句：用了哪些 AI／拿它干什么；点两三个人说，不写字、不发纸 | 黑板上有一列工具名 |
| 03–09 | 现场 | 同一句话：普通对话网页要你上传，Workbuddy 自己找到、改好、存回 | 每人一句"它多做了哪几件事" |
| 09–15 | 演进线 | 把黑板上那列名字摊成一条线：会接话 → 会先想 → 会查 → 会动手 → 连起来做完一件事 | 说得出"Agent 不是新一代模型" |
| 15–29 | 认零件 | 六个零件各一句话＋当场显形（讲 7′、学生点 7′） | 圈出"我最没听懂的那个" |
| 29–49 | 演示 | 从零造一个俄罗斯方块，20 分钟一句话不补 | 看见它写→跑→报错→改→交东西 |
| 49–71 | 实操 | 跟做 8′ 造一个猜数字；自主 14′ 换自己的 | 《运行记录单》五行 |
| 71–79 | 讲评 | 抽两份对照：它说的／实际发生的 | 补一行"我漏看了哪一步" |
| 79–90 | 收口 | 三个词、一句判断标准、下讲前置。末尾 5′ 留作缓冲：开机、账号、网络、慢班补做 | — |

**配比**：讲师开口约 50′（56%），学生动手与参与约 35′（39%），缓冲 5′。开口高出去的那部分几乎全在演示那 20′——它必须是讲师念、学生看。这一段是本讲的入场券，不砍，排在砍单最后一刀；补偿在认零件 7′ 与实操 22′ 都由学生自己动手。

## 3. 逐段脚本

### 3.1 开场交流（3′）· 你们都用了什么 AI，拿它干什么

**只问、只点人**。不发纸、不写字、不留东西到收口。这一段唯一的作用是让学生先说出自己平时怎么用，好接下一段那句"都是它给你一段字"。

**问两句（2′）**：

1. **「你们都用了哪些 AI？」** 学生报：豆包、DeepSeek、Kimi、通义、文心……讲师往黑板上写工具名，**只写一列，不分类**。
2. **「都拿它干什么？」** 写作业、改文案、查资料、翻译、让它写个 PPT 大纲。听两三个人说，**不追问、不点评**——这不是讨论，是取一句共同的话。

**过场一句（1′）**：

> 你们说的这些，都是它给你一段字。接下来六分钟，我让它干一件真事。

**出口**：黑板上有一列工具名；学生心里有一句"我平时就是这么用的"。

**备用**：一个人都不说话时，讲师先自报两个（"我每天用 A 改稿，用 B 查资料"），再点两名。报出来的工具只有一个也不要紧，一列名字就够接下一段。

### 3.2 现场（6′）· 同一句话，一个只能回你字，一个能自己去把事办了

接开场那句往下走。学生看两件事就够了：**它干不了，和它干成了**。

**那句话（课前定死，一个字不改）**：

> 把桌面上那个「报名表.xlsx」里重复的报名删掉，存成一个新文件。

| 时间 | 讲师做什么 | 屏幕上看什么 |
|---|---|---|
| 0–1′ | 说这句话，问一句"它能办吗" | 学生举手 |
| 1–3′ | 把这句**原样**打进一个普通对话网页（豆包／文心／DeepSeek 挑一个） | 它回"请把表格内容粘贴或上传给我"——它够不着电脑上的文件 |
| 3–5′ | 打开 Workbuddy，**一个字不改**，同一句打进去 | 它自己找到那张表、删掉 4 条重复、存出一个新文件 |
| 5–6′ | 收口 | — |

**出口**：每人一句——**第二次它多做了哪几件事**。

**收口原话（两句，不扩写）**：

> 同一句话，同一个模型。差别只有一个：这一次，允许它碰我的文件。
> 会不会自己动手去拿，就是聊天机器人和 Agent 的分界线。

**课前必做**：

- 报名表 30–50 行，埋 3–4 处重复（同一学号两次）、2 处错（手机号少一位）。这张表就是后面几讲的"脏表"原型，做一份能用一学期。
- 第一遍那个对话网页，课前确认它拿不到桌面文件：**讲师不点上传**，让它自己找，差别才成立。

**异常与备用**：

- Workbuddy 读不到讲师机桌面：把表放进一个共享目录，第 3 拍改说"把共享目录里那张表……"，开头那句话照样一个字不改。
- 两边都能读到文件：改用"把这三个文件合并成一份并去重"——对话网页要你一份份上传，Agent 自己扫目录。

### 3.3 演进线（6′）

从黑板上那一列工具名开始讲，不另起一套话：

> 黑板上这些名字，是它还只会说话的时候。中间隔着五步。

| 阶段 | 新学会的 | 学生能感到的差别 |
|---|---|---|
| 大语言模型 | 会接话、会写 | 像个很能写的秘书，但只会写字 |
| 推理模型 | 答之前先想一段 | 数学题、逻辑题突然做得对了 |
| 联网 | 会去查 | 问它新闻、问它价格，它知道今天的了 |
| 工具调用 | 会动手：读文件、跑代码、开浏览器 | 它开始改你电脑上的东西 |
| 智能体 | 把上面几样连起来，自己决定下一步 | 你说一句话，它自己跑完整个活 |

**落点句（这课最关键的一句）**：

> Agent 不是第五代模型，是这四样叠起来的一个跑法。

学生最容易把 Agent 当成"又出了一个更厉害的模型"，这句必须讲清，否则后面认零件全白认。

### 3.4 认零件（14′）

讲 7′、学生自己点 7′（两人一机）。每个零件只给一句话，配一个当场能看见的动作：

| 零件 | 一句话 | 当场怎么让它显形 |
|---|---|---|
| 模型本体 | 负责往下想的那个东西 | 问它一件它不该知道的事，看它答得多自信 |
| 上下文 | 这一轮它能看到的全部内容 | 新开一个对话，问它上一轮说过什么 |
| 工具 | 它能动手的方式：读文件、跑代码、搜网页 | 让它"读一下我桌面上那个文件" |
| MCP | 给"接工具"定的一套标准插口 | 同一个模型，换个软件就读不到你的文件——差别就是这个插口 |
| Skills | 把一套流程和资料打包，遇到这类活照包做 | 同一句话裸跑一次，再喂一份步骤跑一次，比结果 |
| 记忆 | 让它跨对话记得住你 | 隔一个对话再问同一个偏好 |

**要求**：学生点完，在自己纸上圈出"我最没听懂的那个零件"。讲评时先讲这三个被圈最多的。

> MCP 现场不好演示"插口"这个抽象物。台词用对比讲：同一个模型，在 A 里能读你的文件，在 B 网页里读不到——不是模型变了，是插口没接上。

### 3.5 演示（20′）· 从零造一个俄罗斯方块

**投屏的那句话（课前定死，现场照打）**：

> 做一个俄罗斯方块小游戏，单个 HTML 文件，双击就能在浏览器里打开玩。要求：方向键左右移动、上键旋转、下键加速下落；方块堆到底就消行并加分；游戏结束后能点一下重新开始。深色背景，七种方块用不同颜色。不要联网，不要用外部库。

| 时间 | 做什么 |
|---|---|
| 0–2 | 打这句话，打完收手："接下来十分钟我一个字都不打，你们看它怎么干。" |
| 2–12 | 它读要求 → 建文件 → 写 → 跑 → 报错 → 改。讲师只念它在做什么（"它在建文件""它跑了一下，报错了""它在改"），**不解释代码**。报错窗口停 5 秒，让全班看清 |
| 12–15 | 打开页面，叫一个学生上台玩，玩到消掉一行 |
| 15–18 | **反转**：翻回它中途那句"已完成"，对照现在这个页面还缺什么（旋转卡墙、消行没加分之类）。只落一句：**"它说的不算，它做的才算。"** |
| 18–20 | 三句落点，见下 |

**三句落点**：

1. 它刚才走了十几步，每一步都是它自己决定下一步干什么。
2. 中间它撞了一次墙，自己找到错、自己改好的——那一刻它是在判断，不是在背。
3. **你不需要会写。你需要会提要求，会验收。**

**课前必做**：

- 这句话跑 2–3 遍，挑一个"必然要改一两轮"的版本上台。一次就完美的题不用。
- 如果两遍都一次成功，现场加一条要求（"消行时要有动画和音效"），加需求必然引出问题。
- 全程录屏，断网可播。

### 3.6 实操（22′：跟做 8′ + 自主 14′）

**跟做（8′）**：全班同一句话，造一个最小的能跑的东西。

> 做一个猜数字小游戏，单个 HTML 文件，双击就能玩：电脑想一个 1 到 100 之间的数，我输入我猜的数，它告诉我大了还是小了，猜对的时候显示我猜了几次。

要求：8 分钟内让页面能打开、能玩。跑不起来就照实记在记录单上——**跑不起来也是一种结果，不是失败**。

**自主（14′）**：换成本人想造的东西。可以是游戏（贪吃蛇、打地鼠、记忆翻牌），也可以是专业里的小工具（绩点换算、单位换算、排班表）。定不出题的学生做加练版：给猜数字加"限时"或"历史最好成绩"。

**产出**：《Agent 运行记录单》五行以上。

### 3.7 讲评（8′）

抽两份记录单投屏对照：

- 一份记的是"它做了 9 步，第 6 步报错，改了两次才好；它中途说过一次已完成，其实没做完"——**记的是过程**。
- 一份记的是"做出来了，挺好用"——**只记了结果**。

讲师收两句：

1. 只记结果，你就没法知道它哪一步靠不住；下次它换个地方坏，你还是接不住。
2. 记录单上最值钱的一栏是"它自己怎么说的"——**它说的和实际发生的，对不上的地方就是你要盯的地方**。

每人回自己单子，补一行"我漏看了哪一步"。

### 3.8 收口（6′）

- 收记录单（拍照存共享目录，命名"学号_01_运行记录"）。
- 回到开场那句：那时候你说"它给我一段字"，今天它给了你一个能玩的东西——**差别不在它变聪明了，在它有手了**。
- 三个词带走：**Agent / 工具 / 上下文**。
- 一句判断标准：**看它做的，不看它说的。**
- 下讲前置：「今天你看见它会自己往下判断了。下一讲学怎么把这一屏喂对——你给它的东西，决定它写成什么。」

## 4. 学生带走物

《Agent 运行记录单》A4 一页，五栏：

| 第几步 | 它做了什么 | 成了没有 | 它自己怎么说的 | 我事后核对的结果 |
|---|---|---|---|---|

背面印三句：Agent 不是新模型，是叠起来的跑法｜它说的不算，它做的才算｜你不需要会写，你需要会提要求、会验收。

**这份单子在第 ⑤ 讲升级成《委派验收单》**——本讲记"发生了什么"，第 ⑤ 讲学"怎么逐步验"。

## 7. 超时砍单（顺序课前定死）

| 顺序 | 砍什么 | 代价 |
|---|---|---|
| 第一刀 | 现场第 2 拍（对话网页办不了）砍掉，改成一句问话"你们平时让它改表格，是不是都得先复制粘贴进去"（省 1.5′） | 少了对比，学生点头代替看见 |
| 第二刀 | 3.4 里"学生自己点一遍"改成讲师演示（省 5–7′） | 少一次亲手确认，讲评时多讲两个零件 |
| 第三刀 | 演示从俄罗斯方块降级为猜数字（省 6–8′） | 震撼打折，只在前面已经超 10′ 以上时用 |
| 不砍 | 现场第 3 拍（它自己把表改好了）、演示里那 3 分钟反转、讲评的两份对照 | 第 3 拍是整节课的起点，反转是第 ⑤ 讲的钩子，讲评是唯一一次把"记录"变成能力的机会 |

## 8. 讲评对照表（讲师当场判用）

| 学生记的 | 该记成什么样 | 要当场纠的 |
|---|---|---|
| "做出来了，挺好用" | 它走了几步、第几步报错、改了几次 | "好用不等于看得清，你下次换个任务还是瞎的" |
| "它很聪明，一次就做好了" | 哪一步是它自己改的 | "你把它改错的那一段跳过了，那才是它真在干活的地方" |
| "它说完成了" | 它说完之后页面实际缺什么 | "它说的和实际发生的，对不上的地方就是你要盯的地方" |
| "失败了，没做出来" | 停在第几步、报错说了什么 | "跑不起来也是结果，记清停在哪一步才有用" |

## 9. 待定

1. **Workbuddy 是终端还是浏览器**——决定 3.5 演示时"它能直接动你电脑上的文件"这句怎么讲。若是纯网页版，改成"它能自己动手做、自己看结果"。
2. **Workbuddy 能不能读讲师机桌面上的文件**——现场第 3 拍靠它。要授权就提前授好；读不到就把表挪进共享目录，台词改成"共享目录里那张表"，其余不动。
3. **积分额度**——每人够跑几个任务，决定自主段能不能让学生连做两版。
4. 机房浏览器版本能否打开生成的本地 HTML（双击打开这一步）。
