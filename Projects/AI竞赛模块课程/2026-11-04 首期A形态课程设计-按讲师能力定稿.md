# 首期 A 形态课程设计 · 按讲师能力定

> **决策（2026-11-04 用户定）**：本期按 **A 形态**落地——**一门课锚定一场赛事**（当前锁定视觉与信息设计类），不按年级分班；跑成熟后再按 **B 形态**拆成同期多门赛事选修课。
> ⚠️ **2026-11-04 晚修正**：原表述"一门课、**学生自选方向**"作废——首期不是让学生自选方向，而是**先定锚点赛事，再按该赛事的赛题与评分口径倒推设计课程**。学生要选的是"选不选这门课"，不是"选哪个方向"。详见 §9.2d。
> **设计约束（2026-11-04 用户追加）**：首期由用户本人主讲，**课程内容必须按讲师个人能力设计**，且必须保证**实用性、实操性**。
> 本文件只写首期怎么上，不写为什么不上 B（理由见 [[session-handoff-2026-11-03-校历页口径与待确认项]] 之后的讨论结论）。

## 0 一句话

**首期只把一条主赛道做深**——视觉与信息设计（校内赛 → 蓝桥杯视觉艺术设计赛），因为这正是讲师的方法库、评测工具、案例母本三者同时覆盖的区域；数据/平台赛做副线，只教"能读懂指标、能交、能自检"，不占课时深度。

## 1 讲师能力盘点（决定课程能讲多深）

### 1.1 可讲深的（有方法、有工具、有案例）

| 能力 | 证据来源 | 对应课程环节 |
|---|---|---|
| **交付工程**：材料自洽、官方机械要求、证据留痕、提交前验证 | `方法库/参赛通用价值手册.md` A / B / C / F 四类 | 第 1、4 课 |
| **视觉信息设计**：版式、信息层级、字号安全区、防漏读 | 手册 D 类 | 第 2、3 课 |
| **自动评测与门禁**：本地判官（overflow / 噎死检测 / 三键相对信号）、构建管线三检（OCR 文字朝向、必中串像素校验、逐图 diff） | 智擎杯科目三复盘「技术遗产」 | 第 2、4 课的实操工具 |
| **讲稿与演示**：时长控制、口播脚本、录屏 | 手册 E 类 | 第 3、4 课 |
| **培训交付**：把方法拆成可跟做的步骤 | `Projects/AI数字素养培训方案/` | 全局（每课的操作卡） |

### 1.2 讲不深的（首期明确不承诺）

- **算法 / 模型调优**：数据赛道只到"读懂指标、按规矩交件"，不教调参、不教特征工程。
- **商业路演 / 商业模式**：创新大赛、挑战杯一类不进首期（第 4 课的路演只做"3 分钟讲清你的交付件"，不做商业计划）。
- **大班运营**：首期限 1 个教学班，助教 1–2 人，不做并行多班。

### 1.3 案例资产（可用但要限定用法）

- 科目三 28 发全台账（终榜 81.3898 / 24 支第 18，**未晋级**）+ 五个根因 + 下次 SOP。用途：讲「本地分不可信」「按分值权重倒推投入」「最后一天才投大分值块」这三类真实翻车；**不做战绩宣传**，汇报页与招生文案里不出现个人名次。

## 2 主副赛道怎么分

| | 主线（做深） | 副线（做轻） |
|---|---|---|
| 方向 | 视觉与信息设计 | 数据 / 平台赛 |
| 首期锚定 | R0 校内赛（12-20）→ R1 蓝桥杯视觉艺术设计赛 / 数字科技创新赛（2027-04-26） | R0 同期天池类平台赛（自愿） |
| 讲师角色 | 讲透四步方法 + 门禁工具 | 只讲通用方法，助教跟队答疑 |
| 学生占比（预估） | 多数（跨专业友好、当天出图） | 少数（有兴趣/有基础者） |
| 与 B 形态的关系 | 第二期独立成一门课的首选 | 第二期独立成一门课的第二顺位 |

**为什么主线选视觉而不是数据**：方法库 D/E/F 三类正好压在这条线上；门禁与判官工具现成可用；案例母本是图像类；跨专业门槛最低；且 2027 春主锚（蓝桥杯视觉艺术设计赛）落点一致——首期讲的东西一期后直接接下一季赛事，不用换赛道重备。

## 2.1 校内赛赛题：一页信息图，但判据不在"图"

**赛题（2026-11-04 定）**：给一份素材包，输出**一页信息图**。

**已知疑虑（用户提出）**：对学生会不会过于简单——"把信息做成信息图，仅此而已"。

**这个疑虑成立的前提是"没有验收"**。任务本身不是难度来源，难度来源是约束。所以不改任务，改判据：

### 2.1.1 三条把"排版作业"变成"判断作业"的机制

| 机制 | 怎么做 | 学生必须做的动作 |
|---|---|---|
| **脏素材包** | 3–5 份来源里埋 ①一处数字口径冲突 ②一处已过期数据 ③一处看似相关实则无关的干扰项 | 先核查、再取舍——不核查就必错 |
| **图 + 证据表** | 交付物不是一个图片文件，而是「一页图 + 一张证据表」：图里每句主张，表里对一行来源 | 每个结论都要能被追问出处 |
| **机器当第二读者** | 图必须过 L1 门禁 + L2 判官；人看着好看但机器读不出 = 不及格 | 学会为"机器读者"改设计，而不只为好看 |

一句话改赛题措辞：不是"做一张信息图"，而是「**把这份材料压缩成一页，让机器和人都读得懂、每句话都能被追问出处**」。措辞决定学生的心智模型——说"信息图"，学生想到美工；说"压缩 + 可追问"，学生想到判断。

### 2.1.2 评分口径：照搬科目三，不自造第二套（2026-11-04 对齐）

校内赛直接用主锚赛事的机器评分表——**学生第 1 课学的评分表，和第 4 课交件时被判的评分表是同一张**。自造一套权重会让"课上学 A、比赛判 B"，且两套数字必然互相打架。

| 分块 | 分值 | 判据 |
|---|---|---|
| 关键对象 | 15 | 图中该有的核心对象是否出现、是否可识别 |
| 主要关系 | 20 | 主体—关系—客体三者全同才算命中 |
| 事件要素 | 10 | 主题 / 时间 / 地点 / 背景 |
| 表达重点 | 15 | 成句表述，覆盖要点即算 |
| 配图核验 | 40 | 逐条看图问答，最大单块 |

**四条封顶（硬规则，触发即压上限）**

| 触发条件 | 总分上限 |
|---|---|
| 缺关键视觉元素 | ≤ 25 |
| 宽 < 1920 或高 < 1080 | ≤ 30 |
| 内容与赛题完全无关 | ≤ 15 |
| 不同事件用同一张图 | 0 |

**证据表不在评分表里，在提交门槛里**——「图 + 证据表」齐交才算有效提交，缺表按未交处理。这样"证据可追溯"是及格线而不是加分项，也避免与官方评分表冲突。

**视觉怎么算**：机器评分里视觉质量只通过「配图核验 40」体现（图上元素读得到才拿得到这 40 分）；若校内赛另设专家环节，视觉表现按专家表独立计分（60 分制里占 16），与机器分并列、不混算。

**对外表述**：赛题页只写"视觉不是主体，机器读不懂的图等于没交"，不给百分比——写死一个 10%，学生会把它当成可以放弃的送分项。

### 2.1.3 同一赛题，三档交付尺度（解决一个班里水平差距）

| 档 | 交付要求 | 适合 |
|---|---|---|
| 能交 | 一页图 + 3 条信息 + 格式合规 | 零基础、大一 |
| 能获奖 | 上述 + 证据表 + 1 条**反直觉结论**（数据支持、与常识相反） | 有基础、大二 |
| 冲刺 | 上述 + 30 秒口播脚本 + 一次 A/B（只改一处并证明变化量） | 大三、大四、冲刺档 |

"太简单"和"太难"在同一张赛题上同时被解决：觉得简单的往高档走。

### 2.1.4 备课上真正难的地方

**素材包的"脏度"控制**——这是本课唯一的备课难点：太脏学生卡住、太干净就退化成排版。配比目标：1 处硬冲突 + 1 处过期 + 1 处干扰，且**三类都能在第 3 课的"证据来源"环节里被学生自己发现**。

> 素材包具体内容、评分表分档细则，**待学生选课、知道班级水平后再定**（2026-11-04 用户要求：先定课程，后续按选课情况做详细安排）。

## 3 四次课 = 科目三赛事的完整拆分（每次 90 分钟）

**结论：能。** 科目三的赛题形态是「1 篇事件文档 → 1 张 1920×1080 信息图」，天然可切成四段；每段产出一件，下一段在上一段产物上叠加，第四段结束就是**可提交件**。

### 3.0 递进链（一件套一件，不重做）

| 课 | 动作 | 当堂产出 | 四课后它变成 |
|---|---|---|---|
| 1 | 拆赛题 + 抽取 | **抽取表**（五块原料） | zip 里的内容底座 |
| 2 | 排版面 | **版面骨架 + 必画元素清单** | 图的骨架 |
| 3 | 落图 | **v1 成图 1920×1080** | `001.png` |
| 4 | 自检 + 提交 | **可提交包 + 参赛档案** | 提交件 |

学生全程只做**同一个事件**（一篇文档一张图），四节课是同一件作品的四次迭代——不是四个练习。

### 第 1 课 · 拆赛题与抽取（R0：11/22）
- **讲 25′**：五块分值（关键对象 15 / **主要关系 20** / 事件要素 10 / 表达重点 15 / **配图核验 40**）+ 四条封顶规则（缺关键视觉元素 ≤25、尺寸不足 1920×1080 ≤30、完全无关 ≤15、不同事件同一张图 0）；当场对照官方基准配图，讲清"它为什么拿得到分"。
- **实操 45′**：发 1 篇事件文档 → 填**抽取表**五栏：关键对象 / 关系三元组（主体＋关系＋客体）/ 事件要素（主题·时间·地点·背景）/ 表达重点（成句）/ 必须画进图的视觉元素。
- **验收 15′**：对照标准答案 JSON 现场算命中 → **obj / rel / elm / key 四块当堂出分**。
- **学生学到**：分值权重决定投入顺序；vfy 40 分是最大块，从第一课就要盯；什么会被封顶。
- **前置件**：1 篇事件文档 + 对应 truth（示例集 002 有官方文档与标准答案，可直接当课堂样例）。

### 第 2 课 · 排版面：把原料放进 1920×1080（R0：11/29）
- **讲 20′**：官方基准图的版面结构（大标题 / 元数据行 / 数字面板 / 主图 / 文字区块 / 时间轴）；信息密度原则——这是**一页情报简报，不是美术图**，文字量极大；机器怎么读图（OCR + 版面 + 元素识别）→ 引出"缺视觉元素直接封顶 ≤25"。
- **实操 50′**：把第 1 课的抽取表映射到 4 区骨架（只画线框、不放细节），逐个标注必画元素的位置 → 产出**骨架 + 元素清单**。
- **验收 20′**：拿骨架逐条核对元素清单（漏一个标红），并当场演示一次"缺元素"评分，让学生看见封顶怎么生效。
- **学生学到**：布局不是审美问题，是**元素覆盖率**问题。
- **复用**：科目三示例 002 基准配图 + 复盘的版面拆解。

### 第 3 课 · 落图：骨架变成能读的图（R0：12/6）
- **讲 15′**：字号安全区、对比度、信息层级、防漏读；渲染三检（OCR 文字朝向 / 必中串像素校验 / 相邻版本逐图 diff）；真实翻车案例——文字镜像潜伏多个版本，靠肉眼才发现。
- **实操 60′**：按骨架用**模板**出图 → 跑三检 → 出 v1（1920×1080）。
- **验收 15′**：三检全绿 + 必中串全部可检。
- **学生学到**：机器可读性是硬门槛，"人看着对"不算数。
- **前置件（最大阻塞）**：① 信息图模板（1920×1080、四区、可填空）② 出图工具（PPT / Figma / 代码，按机房条件定）③ 三检工具（网页版优先）。

### 第 4 课 · 自检与提交：像打榜一样交件（R0：12/13）
- **讲 15′**：按分值权重倒推投入比（先修 vfy 那块 40 分）；三档子弹（已验证 / 假设 / 彩票，70/20/10）；"本地分过线才交"；每日 3 次额度怎么花。
- **实操 50′**：跑 L1 评分器（对 truth 算命中）+ L2 判官（看图读回）→ **只改一处** → 再评 → 打包 `队伍编号.zip ├ 001.png` → 提交到校内赛。
- **收口 25′**：榜单公布（同班匿名排名 + 封顶命中情况）+ 每人写一条复盘。
- **验收**：包结构正确、尺寸合规、L1/L2 有分、榜单有名次。
- **学生学到**：**提交纪律造成的分差大于能力差**——28 发里大部分损失来自纪律，不是不会做。

### 3.5 怎么把"比赛的感觉"做出来（四个机制，不是模拟）

| 机制 | 课堂怎么落 |
|---|---|
| **榜单化** | 每课结束当场出分，匿名排名贴在教室（同班横向），像榜单一样实时更新 |
| **限次** | 第 4 课只给 **3 次**提交机会（照搬赛制），逼出"三档子弹"的取舍 |
| **硬规则** | 封顶规则原样搬进课堂：缺元素 ≤25、尺寸不对 ≤30、同图 0——规则是硬的，不讲情面 |
| **对手可见** | 公布块级均分（obj/rel/elm/key/vfy），学生自己找"我比别人差在哪一块" |

这四条比"模拟一次比赛流程"有效得多：**学生感受到的不是流程，是压力和取舍**。

### 3.6 合规与三个阻塞件（必须先解决）

- ⚠️ **原题授权**：直接用智擎杯科目三的赛题与数据做校内赛有授权风险。**建议自造同构赛题**——评分口径（五块 + 封顶规则）完全照搬，素材换成本校公开材料（校史 / 校园新闻 / 本地产业数据）；示例 002 的文档与标准答案仅作**教学样例**并标注来源。此事待确认。
- ⛔ **信息图模板**（1920×1080、四区、可填空）——没有它第 3 课 60 分钟出不了图。
- ⛔ **L1 评分器**（对 truth schema 算命中，不是让 VLM 看图猜）——第 1、4 课的分数由它出。

### 3.7 可行性压测：教师讲什么、学生做什么、哪里会卡

**总判断**：四节课能成立，但不靠"课程设计得好"，靠**四件实物**到位。缺任何一件，课堂立刻从"实操"退化成"听讲"。

| 实物 | 缺了会怎样 |
|---|---|
| 官方基准图 | 第 1、2 课只能念规则，学生判断不了"什么算好" |
| 事件文档 + truth | 第 1 课抽完不知道对错，当堂出不了分，直接掉信心 |
| **填空级**模板 | 第 3 课 60 分钟出不了图，变成看老师演示 |
| L1 评分器 | 第 4 课"本地分过线才交"执行不了，退回主观评分 |

#### 3.7.1 逐课压测（分钟账 + 卡点 + 兜底）

| 课 | 讲 | 做 | 走动答疑 | 教师手上真有货吗 | 最大卡点 | 兜底 |
|---|---|---|---|---|---|---|
| 1 | 25′ | 45′ | 8′ | 有：五块分值 8′ + 封顶 7′ + 基准图对照 10′ | 读文档 + 三元组概念首见 → 全班静默 20 分钟 | 示范样例（一篇文档→填好的表）+ 栏位定义卡 + 前 10 分钟领填第 1 栏 |
| 2 | 20′ | 50′ | 8′ | 有：基准图六区拆解 12′ + 信息密度 5′ + 机器读图 5′（**注意已 22′，要压到 20′**） | "4 区"没定义死 → 各组画法不可比、无法验收 | 发 1920×1080 空框底图 + 固定四区 + 元素清单勾选表 |
| 3 | 15′ | 60′ | 8′ | 有：三检 + 字号安全区 + 翻车案例（**案例只能讲 2 个，讲 3 个必超时**） | 零基础学生的排版决策太多（字号/对齐/留白） | 填空题模板（字号行距已定死，只替换文字和放图）+ 导出设置操作卡 |
| 4 | 15′ | 50′ | 8′ | 有：投入比 5′ + 三档子弹 6′ + 提交规范 4′ | 评分报告看不懂、zip 结构错、提交页不熟 | 分块报告（五块分别出分）+ 提交勾选卡（逐项打勾才许交） |

#### 3.7.2 单人讲师的容量上限（最硬的约束）

45 人班、50 分钟实操窗口：若每人提问 2 次 × 每次 2 分钟 = **180 人分钟**，而单讲师只有 50 分钟 → 只够 25 次交互，**必然有 20 人排队**。

所以规定：**提问率必须压到"每组 1 次"**——
- 4–5 人一组，共 9–11 组；
- 组内先互相解决，组答不了才举手（"组内三问制"）；
- 助教 1 人包 3–4 组，讲师走其余；
- 每课留 **8 分钟集中答疑窗口**，不许随时打断。

> 这条不写进课程设计，第一节课就会被提问淹没，实操时间被吃掉三分之一。

#### 3.7.3 三个必加的兜底机制

1. **每课一件示范样例**（最大杠杆）：第 1 课填好的抽取表、第 2 课画好的骨架、第 3 课出好的 v1 图、第 4 课打好的 zip。学生照做，提问量至少砍半。
2. **分段 checkpoint**：第 20 / 40 分钟各让全员抬头 3 分钟，看进度、统一纠错。防止跑到下课才发现全组方向错了。
3. **课前 5 分钟开机检查**：模板、文档、工具、登录、导出设置全部先打开。课堂里最浪费时间的不是内容难，是"等文件、等登录、找工具"。

#### 3.7.4 一个具体的隐形封顶来源（必须写进操作卡）

用 PPT 出图时，**默认导出常是 1280×720**，直接触发"尺寸不足 1920×1080 → 封顶 ≤30"。操作卡必须写明：幻灯片尺寸设 20×11.25 英寸，导出后跑一次尺寸检查。

> 这类坑不写进操作卡，就会有一半学生作品在评分前先被规则扣死——而他们以为是"内容不行"。

#### 3.7.5 如果备件时间不够，最小可行集是 6 件

示范样例 ×4（抽取表 / 骨架 / v1 图 / 提交包）+ 填空级模板 + L1 评分器。

其余（底图、勾选表、操作卡）可以课堂口头补；这 6 件不行——它们决定了学生是"做出来"还是"看老师做出来"。

### 课后节点（与校历一致）
12/17 双人复核门禁 → 12/20 交件 → 12/27 一页复盘。

## 4 保证"实用性 + 实操性"的四条硬约束

1. **讲 ≤ 25 分钟，动手 ≥ 45 分钟**，每课结束时手里必须有一个"能交的东西"（不是笔记、不是草稿）。
2. **每课一个机器可检验收**（L1 清单或工具输出）——讲师不凭印象给分，学生当场知道自己过没过。
3. **工具当场能跑**：预装镜像 / 一键脚本 / 网页版，三选一；**不留"回去自己配环境"**这种作业。
4. **课内完成度 ≥ 70%**：课后只做"完善"，不做"从零开始"。

> 这四条同时是**课程包的验收标准**：讲义、素材包、模板库、自检清单四件套，每件都要能对着这四条打分。

## 5 首期明确不做

- 不开数据 / 创意方向的独立课（副线只做轻量承接）。
- 不教算法调优、不教商业计划书。
- 不承诺获奖，招生文案不写"包获奖""冲国奖"。
- 不把讲师个人名次写进汇报页或招生材料。
- 不做多班并行（限 1 班）。

## 6 二期转 B 的接口（首期就必须留）

1. **选课后第一动作是选方向**，按方向组队、按方向交件。
2. **材料包第一天就分册做**（按提交物类型：图 / 数据 / 方案书 / Demo），不混编——混编的包拆不动。
3. **同一张评分表按方向设参数**，不写两套表。
4. **助教按方向配**，每方向 ≥ 1 人（第二期拆分的关键资产）。
5. **记录方向意向分布**（报名时选一个方向，不设配额）——这是拆分判据的证据。

拆分三条判据（同时满足才拆）：该方向意向人数 ≥ 开课下限 × 1.2；该方向助教 ≥ 2 人；该方向材料包已跑完一轮且有定稿样本与评分表。

报批措辞建议：《AI竞赛基础与项目实战》（含视觉设计、数据建模两个方向）——第二期做的是"分设"，不是"新开"，审批路径短得多。

## 8 算力与模型费用（须列为报批事项）

> 用户要求（2026-11-04）：赛事课会用到算力，**算力与模型费用要列为需要报批的事项**。本节把这件事拆成：到底用在哪、多少钱、谁来批、以及一条不能踩的合规红线。

### 8.1 先分清三种"算力"，钱花在哪完全不同

| 类型 | 用在哪一课 | 真实需求 | 费用量级（1 个班 45 人 / 一学期） |
|---|---|---|---|
| **A. LLM 文案与结构辅助** | 第 1、3、4 课 | 抽取、成句、自检建议；每次 2k–8k tokens | **¥5–30**（国产 API，¥1–2 / 百万 tokens） |
| **B. 文生图 / 图像模型** | 第 3 课（若做） | ¥0.1–0.3 / 张 × 10 张 / 人 | **¥45–135** |
| **C. 本地模型 / GPU** | 第 3 课（若要离线跑模型） | 45 人同时跑不现实，需排队或分组 | **租云 GPU ¥2–10/小时**，或学校机房现有 GPU |

**结论：课上真正的模型费用是百元量级，不是万元量级。** 需要报批的不是"钱多"，而是"**允不允许用付费 API、由谁付、额度多少**"——没有额度就得讲师垫付，这是最不该发生的事。

### 8.2 一条不能踩的合规红线（比预算更重要）

科目三赛制**明文禁止"付费 API / 外网 / 外部数据"**，参赛作品必须能离线复现（B 榜由主办方在封闭网络执行 `python main.py`）。

由此定两条纪律，必须写进课程设计：

1. **课堂环境 ≠ 参赛环境**。课堂可以用付费 API 与网页工具教学；**参赛作品不得依赖任何付费 API、外网服务或外部数据**。
2. **首期"出图"走模板渲染，不做文生图**。模板渲染是本地、可复现、零算力的；文生图既不满足离线要求，又需要 GPU。文生图放选修/进阶，不进主线。

> 这一条同时把算力需求压到最低：第 3 课的核心动作是"排版 + 校验"，不是"生成图像"，本来就不该依赖 GPU。

### 8.3 三档方案（按学校条件选，写进立项材料时三选一）

| 档 | 内容 | 单班一学期 | 前置条件 |
|---|---|---|---|
| **0 元档** | 只用免费额度 + 模板渲染 + 本地三检；不接付费 API | ¥0 | 学生用个人免费额度；课堂不统一采购 |
| **低预算档（建议）** | 讲师统一一个 API key，课内与自检用，按班核定 **¥500 封顶、按实报销** | ¥50–300 | 需走零星采购/报销流程，发票科目：云服务费 |
| **标准档** | 低预算档 + 云 GPU 租用（供冲刺档学生离线跑模型） | ¥1000–3000 | 需提前申请 GPU 资源或预算 |

**建议选低预算档**：金额小、审批层级低、能覆盖四节课的全部模型调用，且留了容错空间（学生个人额度经常中途用尽，课堂不能因此停摆）。

### 8.4 报批口径（写进立项材料的三句话）

1. **报什么**：赛事期与课堂演示所需的**模型调用额度**（API），不与课程建设费混列，单列"赛事期模型投入"。
2. **多少钱**：按班核定 **¥500 / 学期封顶、按实报销**；不含 GPU（GPU 若需要，另行申请资源，不折现）。
3. **谁批、何时批**：随课程立项一并提交（与"学分认定""师资协同"同批），**在 R0 开课前拿到额度**；否则讲师垫付或课堂降级到 0 元档。
