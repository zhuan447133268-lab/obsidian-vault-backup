# B站北航AI第一课 · 手法拆解单

> 来源：`D:\Users\dfjq\Desktop\【生成式人工智能应用实战（慕课版）】北航90后副教授何静带你走进新生小白人工智能的第一课.mp4`（18分钟 / 1080P / 30fps，用户 2026-11-20 下载）。**只抄手法，内容与画面全用第1讲自己的**，零版权雷。
> 方法：全局接触表（每60秒一格）+ 13 张关键帧精读。`breakdown.py` 逐帧拆解对这种「PPT翻页+真人讲解」视频不对症（慢且转场/运动指标无意义），已停用；手法靠抽帧读图提取。

## 0. 一句话结论

这个视频**赢在"把每个抽象概念都配一个生活比喻 + 一张结构化关系图"**，不在特效。真人站右侧讲解、PPT 占左侧约 2/3——**这恰恰是你第1讲"微课+现场讲解"形式的现成范本**：画面负责"看懂"，人负责"讲活"。

## 1. 画面形式：真人 + PPT 分屏

- 构图固定：讲师站画面右侧约 1/4，PPT 占左侧 2/3，全程不变。**镜头几乎不动**——不靠运镜，靠 PPT 每页的信息设计抓人。
- 底部一条白色字幕条，逐字跟口播。
- 讲师边讲边用手势指向 PPT——这正是"现场讲解"部分要抄的：**微课画面 + 人指向讲解**，跟你教案的"微课+现场讲解"完全同构。

## 2. 核心手法（这才是要抄的）

### 手法 A：一个概念 = 一个生活比喻（贯穿全片）
每个抽象概念都锁死一个日常场景，全片不换：

| 概念 | 视频用的比喻 | 怎么讲 |
|---|---|---|
| 大模型 | **超级学霸** | 学习三步：海量读书（训练）→ 接到问题 → 像"疯狂填词"一样逐字预测。还自嘲"有时也凭感觉答错题"讲幻觉 |
| AIGC | **画家学画画** | 看数万张猫照→提炼"猫的灵魂概念"→给它提示就能画出全新的猫；配卡通插图 |
| 具身智能 | **小孩学走路** | 摔倒→爬起→再摔倒→再爬起，四色圆点流程图；案例"六足机器人走沙滩" |
| 概念关系 | **森林/树/果实** | AI=整片森林，大模型=林中最大的树，AIGC=树结的果实，智能体=林中活跃的实体，具身智能=能跑能跳的动物 |

**抄法**：给你第1讲每个知识点配一个自己的比喻。注意——比喻必须**覆盖那个知识点的关键机制**，不是随便打个比方。（你有现成的：智能体=大脑+手脚+ReAct循环、"屋里聪明人/带目标实习生"，接着往下配）

### 手法 B：抽象关系画成"图"，不是色块
- **同心圆包含关系图**（"它们之间是什么关系呢？"）：AI(橙)⊃大模型(蓝)⊃智能体/AIGC(绿)⊃具身智能，一图讲清四个概念的层级——这是全片最高价值的一张图，直接可借鉴结构（内容换成我们的）。
- **四色圆点流程图**：小孩学走路 摔倒→爬起→再摔倒→再爬起，比文字箭头直观。
- **公式化一句话**：`具身智能 = AI大脑 + 感知五官 + 行动四肢`，把定义压成一个等式，学生记得住。

**抄法**：你的"会猜/会想/会查/会动手叠起来=智能体"正好可以做成一张"四层叠加图"或"同心圆能力图"——这就是你原来那版缺的视觉母题。

### 手法 C：每页一个大问句标题
`AI是什么？` / `大模型是什么？` / `大模型是如何工作的？` / `具身智能是什么？` / `它们之间是什么关系呢？` ——用问题驱动，不用陈述句。学生跟着问题往下走。

### 手法 D：三色语义分工（全片统一）
- 蓝色 = 概念框 / 步骤 / 输入
- 绿色 = 结果 / 正确 / 生成
- 橙红色 = 强调 / 挑战 / 关键点
一页不超过三色，配色稳定，看着不乱。

### 手法 E：信息密度高但分层清晰
每页结构是「一句话定义（浅色底框）→ 核心机制（2-3 个蓝框/表格）→ 底部一句总结（公式化）」。信息多但有层级，不是文字墙。

## 3. 跟你那版 film_v3 的关键差别

| | 你的 film_v3 | 北航这个 |
|---|---|---|
| 画面从哪来 | 一句话手搓一个画面，搓到抽象机制没东西画→退化成色块 | 每个概念先定一个具体比喻，再画成图，永远有东西可画 |
| 抽象的救法 | 无解，只能色块+字 | 比喻 + 关系图 + 公式等式，三件套 |
| 视觉一致性 | 蓝紫渐变+翻页卡（被 skill 判"AI味"） | 蓝/绿/橙三色语义分工，稳定 |
| 人的作用 | 无 | 真人指 PPT 讲解，画面看懂+人讲活 |

**病根确认**：你缺的不是画工，是"给每个抽象概念配比喻和关系图"这一步。这一步想清楚了，画面自然有东西可画。

## 4. 落地到我们第1讲（等知识点 A18/B28 定稿后执行）

1. 给 18/28 条里每条配一个自己的比喻（生活场景），覆盖其关键机制
2. 把"会猜/会想/会查/会动手=智能体"做成一张叠加图/同心圆图（抄手法 B）
3. 每幕标题改大问句（抄手法 C）
4. 全片锁三色语义分工（抄手法 D，用我们教案的绿红配色口径）
5. 画面 = SVG/代码精确渲染这些关系图（不用生成式，避免中文乱码）；人讲的部分保留现场
6. 走 `huashu-art-motion` 完整管线过 qa 门禁，别再手写 render.html

## 5. 边界（别越线）

- ❌ 不抄具体 PPT 画面、讲师形象、字幕样式
- ❌ 不抄它的比喻内容本身（超级学霸/森林/画家是它的）——手法抄，比喻我们自己想
- ✅ 抄：问句驱动、比喻+关系图+公式等式三件套、三色分工、人+画面分工的结构
