**核心工程文件（film_v3）**：
- `script.py` — 逐句台词（字幕从配音原文自动生成，硬校验逐字一致）
- `timeline.json` — 逐句配音真实时长累加出的时间轴
- `render.html` — 确定性渲染页：`renderAt(t)` 按全局时间 t 算出该帧画面+字幕，无 CSS 动画/定时器
- `gen_audio.py` — 逐句 TTS 合成 + 量时长 + 生成时间轴（含字幕逐字校验）
- `render_frames.py` / `mux.py` — 逐帧截图 + ffmpeg 合成混音
- 成片：`AI是怎么工作的_动画微课_全片_v3.mp4`

## 3. 关键架构决策（别再走回头路）

- **旁白是唯一主线，字幕和画面都挂在同一条时间轴上**：音、字、画共用 `timeline.json` 的同一份数据，物理上不可能错位。这是从 `film_v2`（录屏式，三条线各走各的）改出来的根因修复。
- **确定性逐帧渲染**：页面不自己播动画，暴露 `renderAt(t)`，第 i 帧时间 = i/fps，逐帧截图。不录屏。
- **字幕自动从配音原文生成**，只加高亮、不删字，配音脚本里加硬校验（字幕去标签后必须与配音逐字相等，否则报错）。修过 s21 因 flex 布局导致的换行错行（改 block）。
- **视觉**：明亮扁平科普风（奶油白→浅紫蓝渐变；紫=AI/橙=强调/青绿=成功），人物头像 + 小机器人头像，底部字幕条。**画面不加「第 X 幕」制作标签**（学生片里会像内部拆解）。

## 4. 被否过的做法（红线，按被否顺序）

| 做法 | 为什么被否 | 现在的做法 |
|---|---|---|
| 暗色发光球/抽象动画（huashu-art-motion 那版） | 暗、抽象、丑手图标，看不懂 | 改明亮扁平 + 真实软件/对话框场景 |
| ImageGen 生图配图 | 中文乱码、抽象，用户不理解 | 不靠生图，场景用 HTML/SVG 代码渲染 |
| `film_v2` 录屏式全片 | 字幕/配音/画面三条线各走各的，对不上、演示不到位 | 改成旁白主线 + 确定性逐帧渲染 |
| 全片抽象小图解（25 句旁白配示意图） | 丢掉了"对话框场景"的代入感，"跟样片基本没关系" | 以样片母版重做，每幕演成看得见的软件/对话框场景 |
| 画面加「第 X 幕」标签 | 学生片里像内部拆解 | 全部去掉 |
| 字幕手写精简版（删了配音里的字） | 字幕与配音逐字对不上 | 字幕从配音原文自动生成 + 硬校验 |
