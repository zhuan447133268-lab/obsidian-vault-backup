# 微课制作路线调研 · 三条路与推荐

> 起因：用户认可「专业部分提前做成微课 + 现场讲解 + 实操体验」的第1讲形式；但自建 `film_v3` 动画微课短片段可以、约1分钟以上效果很差。本文是调研结论 + 根因 + 选型，供拍板。**选型未定，别据此直接开工重做。**

## 1. 根因诊断（看了成片抽帧后确认，不是时长问题）

成片 `film_v3/AI是怎么工作的_动画微课_全片_v3.mp4` = 106 秒、26 句旁白、9 幕、TTS(晓晓) + 逐字字幕 + `renderAt(t)` 确定性逐帧渲染。

- **抽帧实证**：20s 帧（对话气泡逐字吐 + 候选字）画面完整像样；50s 帧退化为「紫方块+两条线」；80s 帧退化为「椭圆+四个小方块」。
- **真因**：架构是「一句话手搓一个画面」。前 6 句有具体软件场景（对话框）可画；后 20 句讲的是「会想/会查/自己决定下一步」等抽象机制，代码没有现成视觉母题，只能退化成色块+文字卡。句子越多越崩，**与时长无直接因果**。
- **第二个病**：画面是蓝紫渐变 + 翻页式卡片——正是本机 skill `huashu-art-motion` 明令禁止的两种「做坏方式」（翻页式PPT、一眼AI味·蓝紫渐变）。现行做法是绕开该 skill 手写 `render.html`，没吃到它的镜头表 / qa / deliver 门禁。

## 2. 决定性硬约束：生成式视频不能做知识讲解画面主体

多来源交叉验证结论：
- **画面内中文必乱码**：扩散模型不识字只会"画字"，视频需逐帧保持字形，笔画粘连丢字。带字界面/公式/图表不能靠生成。
- **事实不可靠**：Seedance 2.5 与 MiniMax H3 画勾股定理都画错三角形；柱子高度、分子结构、地图边界均会错。
- **正确分工**：文字/公式/界面 → 代码或矢量渲染；需要空间想象/氛围的场景 → 生成式视频；字幕配音 → 剪辑软件叠加。

## 3. 三条路线对比

| 路线 | 代表 | 优势 | 短板 | 成本 |
|---|---|---|---|---|
| **A. AI 生成视频** | 可灵 / 即梦 / 海螺 / Veo | 氛围写实、镜头运动、口型；国产中文提示词准 | 中文乱码 + 事实画错（硬伤）；只能做无字氛围镜头；废片率 30–60%，按成品 3–4 倍备生成量 | ¥0.2–3/秒；一条成片常 ¥80–200 |
| **B. 模板 MG 工具** | 万彩动画大师 / 来画 / 秀展网 | 模板拖拽、半天出片、自带配音字幕、PPT 转动画；教师向 | 风格受模板库约束；复杂动画吃配置；单画面单时间轴（来画） | 免费带水印；永久授权 万彩 ¥299 个人 / ¥399 教育 |
| **C. 混合工作流（推荐）** | 真实录屏 + 代码精确渲染 + 剪映；或本机 skill `huashu-art-motion` 完整管线 | 界面用真实录屏最可信；抽象机制用代码/SVG 精确控制；skill 门禁（镜头表/qa/deliver/独立审片）专治翻页PPT与蓝紫AI味 | 要写代码（用户具备）；MG 工具仍需人工校订素材错配 | 免费（剪映 + skill + 代码） |

辅助判断：
- 万彩易用性 4.2 / 来画 4.3（36氪企服点评），综合分一般 → 天花板存在，但做 60 秒科普够用。
- Manim（开源）适合数学/物理精确动画，本讲讲「AI 怎么工作」非公式推导，非必需。
- 数字人口播（有言 ¥49.8/月起 / 魔珐）适合概念定义、纯口播，不适合「看得见的软件场景」这条主线。

## 4. 推荐：第1讲专业段微课 = C 混合工作流，分两步走

1. **先定内容口径**（当前仍卡在这）：A 版 18 条 / B 版 28 条知识点待用户在 `film_v3` 同级 `资料_讲AI工作模式_*.html` 里拍板。按本文结论，选条目的同时要标每条的「视觉方法」：界面类→录屏，机制类→代码/矢量，氛围类→（可选）生成式。
2. **重做技术管线**（选 C 后执行）：
   - 可用的具体场景（对话逐字吐、读文件删重复）→ **真实录屏**，可信且与「现场三拍」口径一致；
   - 抽象机制（会想/会查/循环/叠起来）→ 用 `huashu-art-motion` 的 9 种解说动画语法 + 统一色板（**禁蓝紫**），走它的镜头表 → lint → 逐镜渲染 → qa → deliver 门禁；
   - 配音字幕仍在剪映收尾，保留逐字对齐；
   - 或省事版：万彩动画大师套科普模板半天出片，用于赶时间、不追求与现场演示同画面。

## 5. 下一步（等用户拍板其一）

- [ ] 用户选路线：A（不推荐）/ B（省事）/ C（推荐）
