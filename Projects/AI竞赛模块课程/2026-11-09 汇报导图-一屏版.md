## 0 用户的三轮要求

**第一轮**：出一版思维导图式的汇报版，把六个关键点梳理出来——培养目标、课程设置、培养哪些能力、参加的赛事、成果与认定、主讲老师能力要求。

**第二轮（当天下午，五条修正）**：
1. **"大一上的赛事初赛 11 月下旬截止，现在明显来不及"**——汇报方案出来后才去排课、招人、上课，赶不上 11 月的窗口。第一场要锚定**明年 3—4 月**的赛事。
2. **"你得写上大四自主参赛"**——上一版只画到第六学期。
3. **"不是 8 场赛事……是第一期暂定这些课程设置以及赛事安排，后续根据实际情况会再调整"**——别把场次写死，写进小字备注。
4. **"学分这部分先不要体现，让学校去定"**——全文去掉学分。
5. **"现阶段大一和大二、大三甚至可以参与一场赛事，后续再调整进阶设置"**——第一期不按年级锁死。

**第三轮**：师资块不要三级梯队，改成"根据上面赛事，梳理对任课教师的要求——就是什么样的教师可以上这个课"，并明确要求先梳理、不直接编辑。分档方式由用户在三个方案里选定"按课程类型分两档"。详见 4.1。

**第四轮（四条）**：①**去掉"汇报版"三个字**（页眉只留"通识教育选修课程模块 · 第一期"）；②**删掉"不要求会写代码、会训练模型"**；③**删掉"不要求获奖、创业经历或职称"**；④**课程卡片"8 学时"后补"（4 次课）"**；⑤**师资带加小标题**——原话"要加上一个小标题，让看的人知道需要老师具备的能力……只有我知道这个能力要求是要求谁的"。

## 1 判断：不做放射状思维导图

**理由**：6 门课 × 3 类信息（赛事、能力、成果）= 18 个叶子。放射状导图把 18 个叶子摊在圆周上，文字要么压到 8—10 字，要么挤成一圈，投影后后排看不清。更关键的是领导真想看的是**对应关系**——"这门课冲哪场比赛、练什么、能拿去交什么"——放射图会把横向对应变成交叉连线，反而更难指认。

**改法：横向导图**。中心在左，向右三级展开（场次 → 课程 → 赛事／能力／成果），文字全部水平，1920×1080 一屏装下。用户当场选定此方案。

### 4.1 师资块：三级梯队 → 按课型两档

**用户第三轮要求**（原话）："第一级课程负责人、第二级校内专任教师、第三级学生助教，此处不用写太细，只需要根据上面赛事对教师能力的培养，梳理一些对任课教师的要求即可。就是什么样的教师可以上这个课。"

上一版写的是**人事管理口径**——职责、产出、跟课路径、同批评分偏差 ≤ 5 分——回答的是"队伍怎么建"。用户要的是**任职资格**，回答"什么样的人能站上这个讲台"。

**倒推方法**：图上每行三列，教师门槛就从这三列倒推：

| 图上那一列 | 倒推出的教师要求 |
|---|---|
| 参加的赛事 | 这门课的赛，老师自己完整打过一轮——报名、提交、拿到结果 |
| 成果与认定 | 这门课要交的东西，老师自己做得出来，课堂上讲自己的成品 |
| 培养的能力 | 学生要会的，老师能当场做出、改得更好，说得清扣分点在哪 |

**分档（用户选定"按课程类型分两档"）**：六门课按学生真正在干的活，3 + 3 分开，正好对半。

| 档 | 场次 | 课程 | 三条门槛 |
|---|---|---|---|
| **作品课** | 第 1、4、5 场 | 信息可视化设计基础 / 信息分析与智能生成 / 智能工具应用基础 | 做得出 · 评得准 · 辨得真 |
| **材料课** | 第 2、3、6 场 | 作品迭代与答辩实务 / 创新项目策划与商业计划 / 成果转化与路演 | 写得成 · 讲得清 · 交得对 |

**两行"不要求"已按第四轮意见删除**：初稿两档各带一行反诉（"不要求会写代码、会训练模型""不要求获奖、创业经历或职称"），用户 2026-11-09 明确要求去掉。删掉后腾出的最右列改为**小标题"任课教师能力要求"横贯带顶**——原先两行档名孤悬在表格下方，读者看不出这一块是"对谁的要求"，这是用户原话"只有我知道这个能力要求是要求谁的"。

**标题做法**：不用额外的标题栏占高度，而是把 `.team` 的顶线去掉，改由表头行 `任课教师能力要求`（11.5px / 字距 .18em / 灰色）带 1px ink 下边线，与主体导图的列头（场次｜参加的赛事｜……）同构——读者一眼认出这是"另一个表的表头"。

**第 2 场为什么归材料课**：它不教怎么做作品，教的是已有作品怎么改、怎么交、怎么讲——三项能力（依评审意见迭代 / 规范提交 / 现场陈述）全是呈现动作。这是最容易被追问的一处。

**"完整参与过一轮"不单立**：用户明确选了把它写进两档各自的第一条（"本人完整提交过这类作品""本人完整写过或整理过一份参赛材料"），不另立一条共同前提，也不给"跟课一轮视同满足"的台阶。

**文案两处返工**：

- "写得成"初稿写"本人写过完整的项目计划书"——只覆盖第 3 场。第 2 场是改稿、第 6 场是编流程说明，都对不上。改成"写过或整理过一份**参赛材料**"才覆盖三场。
- 档名从"基础课型 / 项目课型"改为"**作品课 / 材料课**"。原名不准：第 1 场名字里就带"基础"，却要独立做出一件作品；第 6 场叫"项目"，其实只是材料包装。

**版式为什么从两栏改两行横带**：两栏各 891px，而每条门槛只有二三十字，横向留白过半；更要命的是"清楚"被断行拆成"清|楚"。改两行横带——150px 档名 + 三列等宽 + 172px 不要求列——横向填满，十格同高 35px，`footBottom` 与改前一样是 1056，**高度零增长**。

## 5 实测（2026-11-09）

- 1920×1080：`stageScrollH = stageClientH = 1080`、页脚底边 1056、`overX = 0`
- **七行**行高 94/94/94/94/94/94/93，能力列与赛事列 `scrollHeight === clientHeight`，**无裁切**
- **师资带**标题行 + 两行共八格全部 35px、`clip = 0`、`teamH = 113`；加标题后整体高度被 flex 从行高里吸收（96 → 94），页脚位置未动
- **课程副标**六张全部 17px 单行——加"（4 次课）"后仍不换行
- 场次序列逐行核对：03—04 → 04—08 → 08—11 → 09—11 → 10—12 → 次年 02—04 → 毕业学年，单调递增
- 左列七个日期全部单行（`dateW 84 / cellW 104`）
- 旧口径残留检查：`课程负责人 / 校内专任教师 / 学生助教 / 第一级 / 第二级 / 第三级 / 梯队 / 跟课一轮 / 评分偏差` 全部零命中
- 第四轮残留检查：`汇报版` 全文零命中；`.no` 元素 0 个
- 学分残留检查：全文只命中页脚一句"学分认定由学校确定，本页不列"
- 等比缩放：1366×768 → scale 0.711、1280×720 → scale 0.667，stage 撑满视口、`overflowX/Y` 均为 0
- PNG：1920×1080、542897 字节
