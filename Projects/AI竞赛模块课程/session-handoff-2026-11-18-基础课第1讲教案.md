## 2. 现行骨架（90′，八段）

| 时间 | 环节 | 台上发生什么 | 出口 |
|---|---|---|---|
| 00–03 | 开场交流 3′ | 问两句：用了哪些 AI／拿它干什么。点两三个人说，工具名写黑板**一列**。不写字、不发纸 | 黑板上有一列工具名 |
| 03–09 | 现场 6′ | 同一句话演两次：普通对话网页要你上传 → Workbuddy 自己找到、改好、存回 | 每人一句"它多做了哪几件事" |
| 09–15 | 演进线 6′ | 把黑板上那列名字摊成五步：会接话 → 会先想 → 会查 → 会动手 → 连起来做完 | 说得出"Agent 不是新一代模型" |
| 15–29 | 认零件 14′ | 六个零件各一句话＋当场显形（讲 7′、学生自己点 7′） | 圈出"我最没听懂的那个" |
| 29–49 | 演示 20′ | 一句话造俄罗斯方块，看它写→跑→报错→改→交东西；中途插"它说已完成，其实没做完" | 看见它自己撞墙自己修好 |
| 49–71 | 实操 22′ | 跟做 8′ 造猜数字；自主 14′ 换自己的（游戏或专业小工具） | 《Agent 运行记录单》五行 |
| 71–79 | 讲评 8′ | 抽两份记录单对照：记过程 vs 只记结果 | 补一行"我漏看了哪一步" |
| 79–90 | 收口＋缓冲 11′ | 回到开场那句；三个词；一句判断标准；下讲前置。末尾 5′ 不排内容 | 《运行记录单》收走 |

## 3. 现场那三拍（最容易讲歪的一段，逐字定死）

那句话（课前定死，一个字不改）：

> 把桌面上那个「报名表.xlsx」里重复的报名删掉，存成一个新文件。

| 时间 | 讲师做什么 | 屏幕上看什么 |
|---|---|---|
| 0–1′ | 说这句话，问一句"它能办吗" | 学生举手 |
| 1–3′ | 把这句话**原样**打进一个普通对话网页（豆包／文心／DeepSeek 挑一个） | 它回"请把表格内容粘贴或上传给我"——够不着电脑上的文件 |
| 3–5′ | 打开 Workbuddy，**一个字不改**，同一句打进去 | 它自己找到表、删掉 4 条重复、存出一个新文件 |
| 5–6′ | 收口两句 | — |

收口原话：

> 同一句话，同一个模型。差别只有一个：这一次，允许它碰我的文件。
> 会不会自己动手去拿，就是聊天机器人和 Agent 的分界线。

**这一段的意义只有一句话**：一个只能回你字，一个能自己去把事办了。学生看两件事就够了——它干不了，和它干成了。

## 4. 用户否过的写法（别再犯，按被否的顺序）

| 提过什么 | 为什么被否 | 现在的做法 |
|---|---|---|
| "每人纸上写三行 + 黑板分两列 + 第三行留到收口" | 3 分钟的环节不该有纸笔产出。用户："这个是比较重的" | 只问、只点人，3′ |
| "关手／开手" | 自造词。用户："我不知道你要表示的是什么，我一点都不理解" | 改写成事实句"一个只能回你字，一个能自己去把事办了"，文档里这个词已删净 |
| 两版并排截图讲 chat→Agent | 回不到过去，演不出来 | 同一句话现场演两次 |
| 问卷汇总／查资料／整理文档当演示题 | 都是"整理"，没有"啊"的瞬间 | 从零造东西：俄罗斯方块 |
| "接着写／只看这一屏／先写想"三条机制当课眼 | 讲师读不懂；整课讲成"它会怎么出错"，与第 ④ 讲撞车 | 课眼改「Agent 不是第五代模型，是几样东西叠起来的跑法」 |

**通用教训**（写在这里，免得第 2–6 讲再犯）：**环节的轻重要跟时长匹配**。5 分钟以内只做"问 + 点人说"；纸笔产出、两轮互动这类设计，至少要有 8–10 分钟才装得下。

## 6. 三个必须原话说的句子（讲师口播）

1. **Agent 不是第五代模型，是这四样叠起来的跑法**（在演进线末尾，否则后面认零件全白认）
2. **同一句话，同一个模型。差别只有一个：这一次，允许它碰我的文件。**（现场收口）
3. **它说的不算，它做的才算**／**你不需要会写。你需要会提要求，会验收。**（演示收口）

## 7. 四个待定（开课前必须销掉）

| 项 | 为什么卡住 |
|---|---|
| Workbuddy 是终端还是浏览器 | 决定演示时"它能直接动你电脑上的文件"这句怎么讲；纯网页版就改成"自己动手做、自己看结果" |
| Workbuddy 能不能读讲师机桌面文件 | 现场第 3 拍靠它。要授权提前授好；读不到就把表挪进共享目录，台词改成"共享目录里那张表" |
| 积分额度 | 每人够跑几个任务，决定自主段能不能连做两版 |
| 机房浏览器能否双击打开本地 HTML | 决定学生怎么验收自己造出来的东西 |

## 8. 课前物料（= 开课前 48h 打钩清单）

- **报名表.xlsx**：30–50 行，埋 3–4 处重复（同一学号两次）、2 处手机号少一位；放讲师机桌面；课前实测普通对话网页拿不到它。**这张表是后面几讲的"脏表"原型，做一份能用一学期**
- **对话网页**：豆包／文心／DeepSeek 任选一个，课前登好（第一拍用）
- **演示题**：俄罗斯方块那句话跑 2–3 遍，挑一个"必然要改一两轮"的版本；备一条"加动画音效"的加急要求；整段录屏一份（断网可播）
- **跟做题**：猜数字那句话自己先跑通，确认 8 分钟能出页面
- **记录单**：A4 一页五栏，双面印（第几步／它做了什么／成了没有／它自己怎么说的／我事后核对的结果）
