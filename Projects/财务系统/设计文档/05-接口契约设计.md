## 二、接口详细定义

### 2.1 上传6张Excel

```
POST /api/v1/analysis/upload
Content-Type: multipart/form-data
角色：仅 preschool_budget_admin

period: "2026-04"           (必填)
files: [6个Excel文件]        (必填)
```

**Response (201)**:
```json
{
  "code": 0,
  "data": { "uploadId": 1, "status": "uploading" }
}
```

### 2.2 上传批次列表

```
GET /api/v1/analysis/uploads?period=2026-04&page=1&size=10
角色：仅 preschool_budget_admin
```

### 2.3 批次状态/进度（前端轮询用）

```
GET /api/v1/analysis/uploads/1
角色：仅 preschool_budget_admin
```

> 前端每3秒轮询一次，直到 status 变为 `completed` 或 `failed`。

### 2.4 园所列表（默认仅 active）

```
GET /api/v1/analysis/gardens?uploadId=1&status=active&keyword=育树&page=1&size=20
角色：preschool_budget_admin, boss, operation_director, region_finance(过滤区域)
```

**region_finance 数据过滤**：后端按 `current_user.region` 自动过滤。

### 2.5 单园看板

```
GET /api/v1/analysis/garden/1001?uploadId=1
角色：preschool_budget_admin, boss, operation_director, region_finance(过滤区域), principal(过滤本园)
```

### 2.6 下载园所Excel

```
GET /api/v1/analysis/garden/1001/excel?uploadId=1
角色：同单园看板
```

关园园所返回 404。

### 2.7 学前经营看板

```
GET /api/v1/analysis/preschool-dashboard?uploadId=1
角色：preschool_budget_admin, boss, operation_director
```

> ⚠️ v3：region_finance / principal / group_admin 无权限访问此端点

### 2.8 下载学前经营Excel

```
GET /api/v1/analysis/preschool-dashboard/excel?uploadId=1
角色：同上
```

5 Sheet 结构：园所总览对比 / 区域汇总 / 建园类型汇总 / EBITDA率TOP15 / EBITDA率BOTTOM15

### 2.9 学前预算分析表

```
GET /api/v1/analysis/budget-analysis?uploadId=1&scope=group
角色：preschool_budget_admin, boss, operation_director(全集团), region_finance(过滤区域), principal(过滤本园)
```

### 2.10 科目字典（前端启动时拉取，缓存使用）

```
GET /api/v1/analysis/subject-dict
角色：全部（除 group_admin）
```

### 2.11-2.13 园长映射

```
GET    /api/v1/analysis/principal-mappings              → preschool_budget_admin
GET    /api/v1/analysis/principal-mappings/:principalId  → preschool_budget_admin
PUT    /api/v1/analysis/principal-mappings/:principalId  → preschool_budget_admin
    Body: { "companyIds": [1, 3, 5] }
```

## 三、错误码定义

| code | 说明 |
|---|---|
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token过期 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

| message | 场景 |
|---|---|
| "请上传恰好6个文件" | 上传文件数量不对 |
| "文件类型仅支持 .xlsx" | 上传了非Excel文件 |
| "文件大小超过限制(10MB)" | 单个文件过大 |
| "园所编码 XXX 在系统中不存在" | 上传的表中有未知园所 |
| "该账期没有数据" | 查询了不存在的账期 |
| "请先上传数据" | 没有上传批次时查询看板 |
| "只能查看自己负责的园所" | 园长越权查看 |
| "只能查看本区域数据" | 区域财务主管跨区域访问 |
| "关园不生成单体看板" | 请求关园园所的当期看板（园长除外） |
