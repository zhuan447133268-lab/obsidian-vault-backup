## ⚠️ 三层防御体系（2026-06-18 闭环）

### 第一道：解析层 — 每表独立 headerMap

每种表（YTD实际/单月实际/预算）的 `headerMap` 独立构建，按字段名映射到列索引。**不使用同一套列号索引**。

### 第二道：取值层 — 字段名匹配

所有指标计算用 `headerMap["字段名"]` 取值，**禁止 `row[67]` 式的列索引硬编码**。

### 第三道 ⭐：SubjectCode 归一化层 — 跨表合并安全线

跨表对比时（如实际 vs 预算），先统一归一化到 subject code，再合并：

```go
// 解析后，所有原始数据归一化到编码
func normalizeToSubjectCode(rawData map[string]string, dict map[string]string) map[string]float64 {
    result := make(map[string]float64)
    for excelName, value := range rawData {
        code, ok := dict[excelName]
        if !ok { continue } // 未在字典表中的列自动忽略
        result[code] = parseFloat(value)
    }
    return result
}

// 跨表对比：按 code 对齐，不按列号
// 实际表：{REV_001: 982.91, REV_002: 258.57, ...}
// 预算表：{REV_001: 950.00, REV_002: 260.00, ...}
// 合并后：直接按 code 做减法，不必担心列偏移

func computeBudgetDiff(actual, budget map[string]float64) map[string]float64 {
    diff := make(map[string]float64)
    for code, actualVal := range actual {
        if budgetVal, ok := budget[code]; ok {
            diff[code] = actualVal - budgetVal
        }
    }
    return diff
}
```

**三道防御的协作关系**：

```
Excel行数据
    │
    ▼
[第一道] headerMap → 字段名→列索引（消除列号依赖）
    │
    ▼
[第二道] headerMap["收入合计"] → 取值（消除 `row[67]` 依赖）
    │
    ▼
[第三道] normalizeToSubjectCode → code→值（消除表头文字变化的影响）
    │
    ▼
    subject code 级别的 key-value 合并（消除跨表列偏移的影响）
```

> 💡 第三道防御的价值：即使某个月的表头被加了空格/微调（如"学费收入" → "学费收入(2026)"），只要字典表里 `excel_name` → `code` 映射正确，计算结果不受影响。

```go
// 第一道 + 第二道：按字段名独立建 headerMap
func (p *ExcelParser) parseOneSheet(data []byte, tableType string) ([]RawDataRow, error) {
    f, _ := excelize.OpenReader(bytes.NewReader(data))
    rows, _ := f.GetRows(f.GetSheetName(0))
    headers := rows[3]

    // 对每种表独立建 headerMap
    headerMap := make(map[string]int)
    for i, h := range headers {
        headerMap[strings.TrimSpace(h)] = i
    }

    // 取值用字段名，不用列索引
    nameCol := headerMap["公司名称"]  // 预算表自动定位 B列，实际表定位 C列

    var result []RawDataRow
    for i := 4; i < len(rows); i++ {
        row := rows[i]
        gardenName := strings.TrimSpace(row[nameCol])
        if gardenName == "" { continue }
        if isAggregateRow(gardenName) { continue } // 内容匹配

        // 所有列都按 headerMap 取值
        rowMap := make(map[string]string)
        for fieldName, idx := range headerMap {
            if idx < len(row) {
                rowMap[fieldName] = strings.TrimSpace(row[idx])
            }
        }

        result = append(result, RawDataRow{
            GardenName: gardenName,
            GardenCode: extractGardenCode(gardenName),
            GardenStatus: detectGardenStatus(gardenName),
            RawData: rowMap,
        })
    }
    return result, nil
}

// 第三道：SubjectCode 归一化（跨表合并前的安全线）
func (s *AnalysisComputeService) normalizeData(
    rawRows []RawDataRow, dict map[string]string,
) map[string]map[string]float64 {
    // 返回：garden_code → subject_code → value
    result := make(map[string]map[string]float64)
    for _, row := range rawRows {
        if _, ok := result[row.GardenCode]; !ok {
            result[row.GardenCode] = make(map[string]float64)
        }
        for excelName, strVal := range row.RawData {
            code, ok := dict[excelName]
            if !ok { continue }
            result[row.GardenCode][code] = parseFloat(strVal)
        }
    }
    return result
}

// 跨表预算对比：按 SubjectCode 对齐，完全不依赖列号
func (s *AnalysisComputeService) computeBudgetComparison(
    actual, budget map[string]float64, subjectDict []SubjectDictItem,
) []BudgetComparisonItem {
    var items []BudgetComparisonItem
    for _, item := range subjectDict {
        if !item.IsAggregated { continue }
        items = append(items, BudgetComparisonItem{
            Code:    item.Code,
            Name:    item.DisplayName,
            Actual:  actual[item.Code],
            Budget:  budget[item.Code],
            Diff:    actual[item.Code] - budget[item.Code],
        })
    }
    return items
}
```

## 四、并发控制 + 关园过滤

```go
const MaxWorkers = 8

func (s *AnalysisComputeService) ComputeAllGardens(uploadID uint, rawData []AnalysisRawData) error {
    activeData := filterActive(rawData) // 仅处理 garden_status=active
    gardenGroups := groupByGardenCode(activeData)

    gardenChan := make(chan GardenGroup, len(gardenGroups))
    errChan := make(chan error, len(gardenGroups))
    var wg sync.WaitGroup

    for i := 0; i < MaxWorkers; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for g := range gardenChan {
                if err := s.computeOneGarden(uploadID, g); err != nil {
                    errChan <- err
                }
            }
        }()
    }

    for _, g := range gardenGroups { gardenChan <- g }
    close(gardenChan)
    wg.Wait()
    close(errChan)

    var errors []string
    for err := range errChan {
        errors = append(errors, err.Error())
    }
    return nil
}
```

## 五、安全约束总结

### 取值约束（三条红线）

```
1. 禁止硬编码列号        → 用 headerMap["字段名"]
2. 禁止绑定行号          → 用内容匹配（如"板块"字样）
3. 禁止跨表直接按列合并  → 先归一化到 SubjectCode，再 code 级别合并
```

### 文件上传安全

- 限制 `.xlsx` 类型 / 单文件 10MB / 每次 6 个文件
- 表头校验：6张表的表头行（第4行）与字典表预期的科目列表交叉比对

### 数据质量校验（内置 warning 日志）

导入时自动检查利润表内在等式（收入=各收入项之和、EBITDA=收入-成本+投资收益等）。不阻断流程，不成立的园记录到 warning 日志，提示人工核对。
