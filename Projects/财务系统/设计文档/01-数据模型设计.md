# 经营分析看板 — 文档1：数据模型设计

> 日期：2026-06-17（2026-06-18 更新：决策3 闭环 → 科目编码采用自定义编码 B-3）
> 状态：设计稿

---

## 一、新增表概览（共 6 张，物理隔离）

| # | 表名 | 用途 |
|---|---|---|
| 1 | `analysis_uploads` | 上传批次记录 |
| 2 | `analysis_raw_data` | 原始行数据（EAV 键值对，含关园） |
| 3 | `analysis_garden_data` | 园所汇总指标（**宽表，字段名用自定义编码**） |
| 4 | `analysis_dashboard_cache` | 看板缓存（JSON） |
| 5 | `principal_company_mapping` | 园长-园所映射（**只增不删**） |
| 6 | `analysis_subject_dict` ⭐ | 科目编码字典（约80行） |

---

## 二、表详细设计

### 2.1 analysis_uploads — 上传批次

```sql
CREATE TABLE `analysis_uploads` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `period` VARCHAR(16) NOT NULL COMMENT '数据期间，如 2026-04',
  `uploaded_by` BIGINT UNSIGNED NOT NULL,
  `status` VARCHAR(20) NOT NULL DEFAULT 'uploading',
  `total_gardens` INT DEFAULT 0,
  `active_gardens` INT DEFAULT 0,
  `closed_gardens` INT DEFAULT 0,
  `success_gardens` INT DEFAULT 0,
  `fail_gardens` INT DEFAULT 0,
  `error_detail` TEXT DEFAULT NULL,
  `file_names` TEXT DEFAULT NULL,
  `started_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `finished_at` DATETIME DEFAULT NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  KEY `idx_period` (`period`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.2 analysis_raw_data — 原始数据（EAV，含关园）

```sql
CREATE TABLE `analysis_raw_data` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `upload_id` BIGINT UNSIGNED NOT NULL,
  `data_type` VARCHAR(20) NOT NULL COMMENT 'ytd_actual|month_actual|year_budget|...',
  `garden_code` VARCHAR(32) NOT NULL,
  `garden_name` VARCHAR(128) DEFAULT '',
  `garden_status` VARCHAR(16) DEFAULT 'active' COMMENT 'active|closed',
  `period` VARCHAR(16) NOT NULL,
  `subject_code` VARCHAR(8) NOT NULL COMMENT '关联 analysis_subject_dict.code',
  `subject_value` DECIMAL(18,2) DEFAULT 0,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  KEY `idx_upload_garden` (`upload_id`, `garden_code`),
  KEY `idx_subject_code` (`subject_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> raw_data 用 EAV 便于追溯审计；garden_data 用宽表便于快速查询。

### 2.3 analysis_garden_data — 园所汇总指标（宽表）

```sql
-- ⚠️ 字段名采用自定义编码 B-3（分类前缀+数字编号）
-- 前缀规范：s_rev_（收入）| s_cost_（成本）| s_mgmt_（管理费）| s_prof_（利润）| s_kpi_（人数）| s_rate_（比率）
CREATE TABLE `analysis_garden_data` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `upload_id` BIGINT UNSIGNED NOT NULL,
  `garden_code` VARCHAR(32) NOT NULL,
  `garden_name` VARCHAR(128) DEFAULT '',
  `region` VARCHAR(64) DEFAULT '',
  `garden_type` VARCHAR(32) DEFAULT '',
  `garden_years` DECIMAL(4,1) DEFAULT 0,
  `period` VARCHAR(16) NOT NULL,

  -- 收入类
  `s_rev_001` DECIMAL(18,2) DEFAULT 0 COMMENT '学费收入',
  `s_rev_002` DECIMAL(18,2) DEFAULT 0 COMMENT '餐费收入',
  `s_rev_003` DECIMAL(18,2) DEFAULT 0 COMMENT '政府补助收入',
  `s_rev_011` DECIMAL(18,2) DEFAULT 0 COMMENT '延时服务',
  -- ... 其余收入科目
  `s_rev_total` DECIMAL(18,2) DEFAULT 0 COMMENT '收入合计',

  -- 成本类
  `s_cost_001` DECIMAL(18,2) DEFAULT 0 COMMENT '人工成本',
  `s_cost_002` DECIMAL(18,2) DEFAULT 0 COMMENT '食堂成本',

  -- 管理费类
  `s_mgmt_001` DECIMAL(18,2) DEFAULT 0 COMMENT '行政费用',
  `s_mgmt_002` DECIMAL(18,2) DEFAULT 0 COMMENT '日常费用',
  -- ...

  -- 利润类
  `s_prof_001` DECIMAL(18,2) DEFAULT 0 COMMENT '成本费用合计',
  `s_prof_005` DECIMAL(18,2) DEFAULT 0 COMMENT 'EBITDA',
  `s_prof_009` DECIMAL(18,2) DEFAULT 0 COMMENT '税后利润',

  -- 比率类
  `s_rate_001` DECIMAL(8,4) DEFAULT 0 COMMENT 'EBITDA率',

  -- 人数类
  `s_kpi_001` INT DEFAULT 0 COMMENT '在册学生数',
  `s_kpi_003` INT DEFAULT 0 COMMENT '员工人数',

  -- 同比/预算
  `s_rev_total_ly` DECIMAL(18,2) DEFAULT 0 COMMENT '去年收入合计',
  `s_prof_005_ly` DECIMAL(18,2) DEFAULT 0 COMMENT '去年EBITDA',
  `s_rev_total_budget` DECIMAL(18,2) DEFAULT 0 COMMENT '全年预算收入',
  `s_prof_005_budget` DECIMAL(18,2) DEFAULT 0 COMMENT '全年预算EBITDA',

  `status` VARCHAR(20) NOT NULL DEFAULT 'completed',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY `uk_upload_garden` (`upload_id`, `garden_code`),
  KEY `idx_garden_code` (`garden_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.4 analysis_dashboard_cache — 看板缓存

```sql
CREATE TABLE `analysis_dashboard_cache` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `upload_id` BIGINT UNSIGNED NOT NULL,
  `garden_code` VARCHAR(32) NOT NULL COMMENT '"group"表示集团整体',
  `dashboard_data` JSON NOT NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY `uk_upload_garden` (`upload_id`, `garden_code`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.5 principal_company_mapping — 园长映射（只增不删）

```sql
CREATE TABLE `principal_company_mapping` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `principal_id` BIGINT UNSIGNED NOT NULL,
  `company_id` BIGINT UNSIGNED NOT NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY `idx_principal_company` (`principal_id`, `company_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

> ⚠️ 运维约束：**只增不删**。园长调岗时加新映射，不删旧映射，确保历史看板可读。企微停用自然失效，无需系统主动清理。

### 2.6 analysis_subject_dict — 科目字典 ⭐

约 80 行，1 次配置永久使用。编码采用 **B-3 自定义编码**（阳阳确认 NC 科目与报表项目非 1:1）。

```sql
CREATE TABLE `analysis_subject_dict` (
  `code` VARCHAR(8) PRIMARY KEY COMMENT '科目编码（如 REV_001）',
  `excel_name` VARCHAR(128) NOT NULL COMMENT 'Excel原表头（导入匹配）',
  `display_name` VARCHAR(128) NOT NULL COMMENT '前端展示名',
  `category` VARCHAR(16) NOT NULL COMMENT 'REV/COST/MGMT/PROF/KPI/RATE',
  `db_field` VARCHAR(32) NOT NULL COMMENT '宽表字段名（如 s_rev_001）',
  `display_order` INT DEFAULT 0 COMMENT '展示顺序',
  `unit` VARCHAR(8) DEFAULT '万元' COMMENT '万元/%/人',
  `is_aggregated` TINYINT DEFAULT 0 COMMENT '是否聚合科目',
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  KEY `idx_category` (`category`),
  KEY `idx_excel_name` (`excel_name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 三、关园数据处理规则

| 环节 | 处理 |
|---|---|
| 解析 | 正常解析，`garden_status='closed'` |
| `analysis_raw_data` | ✅ 保留 |
| `analysis_garden_data` | ❌ 关园不进入 |
| `analysis_dashboard_cache` | ❌ 关园不生成 |
| 园所列表 API | ❌ 关园不展示 |
| 集团看板 | "在营98 + 关园44" |
