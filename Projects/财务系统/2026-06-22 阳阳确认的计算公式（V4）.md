## 一、收入相关

### 1.1 其他业务收入（8 个子项求和）

```
其他业务收入 = SUM(
    其他业务收入-延时服务,
    其他业务收入-教材,
    其他业务收入-园服/校服,
    其他业务收入-被褥/书包,
    其他业务收入-通勤费,
    其他业务收入-学习/生活用品耗材,
    其他业务收入-学生其他收入,
    其他业务收入-其他收入
)
```

Excel 原始公式：`=SUM(B13:B20)`

### 1.2 收入合计（4 个一级科目求和）

```
收入合计 = 学费收入 + 餐费收入 + 政府补助收入 + 其他业务收入
```

Excel 原始公式：`=SUM(B9:B12)`

## 二、成本费用相关

### 2.1 其他业务成本（8 个子项求和）

```
其他业务成本 = SUM(
    其他业务成本-延时服务,
    其他业务成本-教材,
    其他业务成本-园服/校服,
    其他业务成本-被褥/书包,
    其他业务成本-通勤成本,
    其他业务成本-学习/生活用品耗材,
    其他业务成本-外部服务费,
    其他业务成本-其他
)
```

Excel 原始公式：`=SUM(B25:B32)`

### 2.2 管理费用-行政费用（包含房租及托管子求和）

```
管理费用-行政费用 = 房租及托管费 + 物业费 + 水费 + 电费 + 取暖费 + 保安保洁费 + 网络通讯费 + 维修费 + 办公费用
```

Excel 原始公式：`=SUM(B38:B45, B34)`

#### 2.2.1 房租及托管费（3 个子项）

```
管理费用-行政费用-房租及托管费 = 房租 + 员工房租 + 托管费
```

Excel 原始公式：`=SUM(B35:B37)`

### 2.3 管理费用-日常费用（12 个子项求和）

```
管理费用-日常费用 = SUM(
    市内交通费, 会议费, 差旅费, 业务招待费, 招聘费, 审计咨询费,
    工会经费, 残保金, 开票税金, 保险费, 税金, 其他
)
```

Excel 原始公式：`=SUM(B47:B58)`

### 2.4 管理费用-市场费用（2 个子项求和）

```
管理费用-市场费用 = 环创费用 + 推广费用
```

Excel 原始公式：`=SUM(B60:B61)`

### 2.5 成本费用合计

```
成本费用合计 = 人工成本 + 食堂成本 + 其他业务成本
            + 管理费用-行政费用 + 管理费用-日常费用 + 管理费用-市场费用
            + 管理费用-外部服务费
```

Excel 原始公式：`=B59+B46+B33+B62+B22+B23+B24`

> **注意**：成本费用合计 = 7 项加总（包含 3 块管理费用 + 3 项直接成本 + 1 项外部服务费）

## 三、利润链（重要修正）

### 3.1 息税摊销前利润（EBITDA）

```
EBITDA = 收入合计 + 成本费用合计 + 加：营业外收入 + 减：营业外支出
```

Excel 原始公式：`=SUM(B21, B63:B65)`

> ⚠️ **关键修正**：之前理解错了
> - **错误理解**：EBITDA = 收入 − 成本
> - **正确逻辑**：EBITDA = 收入 + 成本（成本在Excel里是负数）+ 营业外收入（正数）+ 营业外支出（负数）
> - 营业外收支在 EBITDA 这一步就计入了

### 3.2 税后利润

```
税后利润 = 息税摊销前利润 + 减：折旧摊销 + 利息及手续费 + 所得税费用 + 调整项
```

Excel 原始公式：`=SUM(B66:B70)`

> ⚠️ **关键修正**：之前漏了"调整项"
> - 利润链：EBITDA → 折旧摊销 → 利息 → 所得税 → **调整项** → 税后利润
> - 调整项是独立科目，不能合并到其他扣减项里

### 3.3 最终利润

```
最终利润 = 税后利润 + 加：以前年度损益调整
```

Excel 原始公式：`=SUM(B71:B72)`

> ✅ 确认：税后利润 → 最终利润 只加了一项「以前年度损益调整」，不涉及营业外收支或投资收益（这些已在 EBITDA 阶段计入）

## 四、利润完整链路总图

```
学费收入 + 餐费收入 + 政府补助收入 + 其他业务收入
       ↓
   收入合计
       ↓
   (减) 成本费用合计 = 人工成本 + 食堂成本 + 其他业务成本 + 行政费用 + 日常费用 + 市场费用 + 外部服务费
       ↓
   (加) 营业外收入
   (减) 营业外支出
       ↓
   息税摊销前利润 (EBITDA)
       ↓
   (减) 折旧摊销
   (减) 利息及手续费
   (减) 所得税费用
   (减) 调整项
       ↓
   税后利润
       ↓
   (加) 以前年度损益调整
       ↓
   最终利润
```

## 六、与之前文档的差异修正

### 差异 1：EBITDA 公式

| 项目 | 之前理解 | 阳阳确认 |
|---|---|---|
| EBITDA | 收入 − 成本 | 收入 − 成本 + 营业外收入 − 营业外支出 |
| 营业外收支 | 在 EBITDA 之后扣减 | **在 EBITDA 之前计入** |

### 差异 2：税后利润扣减项

| 项目 | 之前理解 | 阳阳确认 |
|---|---|---|
| 扣减项 | 折旧 + 利息 + 所得税（3 项） | 折旧 + 利息 + 所得税 + **调整项**（4 项） |

### 差异 3：达成率口径

| 项目 | 之前理解 | 阳阳确认 |
|---|---|---|
| 看板 | 用全年预算 | 用期间预算 |
| 明细表 | 用期间预算 | 用期间预算 |
| 全年预算用途 | 看板分母 | 仅参考展示 |

### 差异 4：管理费用结构

| 项目 | 之前理解 | 阳阳确认 |
|---|---|---|
| 行政费用 | 单独科目 | **包含子项「房租及托管费」**，房租及托管费=房租+员工房租+托管费 |
