# 经营分析看板模块 — 业务需求梳理

> 来源：2026-06-17 与阳阳（出纳）的沟通录音 + 阳阳提供的资料文件夹
> 资料位置：`D:\财务系统\阳阳给的出纳表\`

---

## 一、数据来源

出纳管理员每月 **10~15号左右** 从报表系统导出 **6张原始表**，上传到系统：

| #   | 文件名                     | 内容              | 维度                |
| --- | ----------------------- | --------------- | ----------------- |
| 1   | `2026年1-4月实际报表.xlsx`    | 当年YTD累计实际       | ~150行×80列，每行=一个园所 |
| 2   | `2025年1-4月实际报表.xlsx`    | 去年YTD累计实际（用于同比） | 同上                |
| 3   | `2026年4月实际报表.xlsx`      | 当年当月实际          | 同上                |
| 4   | `2025年4月实际报表.xlsx`      | 去年同月实际          | 同上                |
| 5   | `01.学前教育-全年预算[财年].xlsx` | 全年预算            | ~147行×79列         |
| 6   | `02.学前教育-期间预算[期间].xlsx` | 期间预算            | ~147行×79列         |

6张表的关系：**4张实际表 + 2张预算表**，涵盖了：
- 累计实际（YTD）
- 当月实际（Mxx）
- 去年同期累计
- 去年同期当月
- 全年预算
- 期间预算

原始表结构说明：
- 每行 = 一个园所
- 列 = 各种收入/成本/费用科目（约80列）
- Row 1-3: 空行/标题行
- Row 4: 表头（科目名称）
- Row 5+: 数据行

## 三、单个园所看板包含的内容（参考阳阳给的HTML）

基于 `output/single_html/1001北京市昌平区育树家幼儿园_报告.html`，每个园所看板需要展示：

### 3.1 头部信息
- 园所编码+名称
- 区域
- 建园类型（自建/加盟等）
- 建园年限
- 报告生成时间

### 3.2 KPI指标卡片（5个）
- 收入合计
- EBITDA
- 税后利润
- 在册学生数
- 员工人数

### 3.3 收入结构饼图
科目：学费收入、餐费收入、政府补助收入、延时服务、通勤费、教材、园服/校服、被褥/书包、学习/生活用品、其他收入

### 3.4 成本费用结构饼图
科目：人工成本、食堂成本、其他业务成本、行政费用、日常费用、市场费用、内部费用、研发支出、外部服务费

### 3.5 利润瀑布图
收入合计 → 成本费用 → EBITDA → 折旧摊销 → 利息 → 所得税 → 税后利润

### 3.6 预算 vs 实际对比柱状图
全年预算 vs YTD实际（收入合计、人工成本、食堂成本、成本费用合计、息税摊销前利润、税后利润）

### 3.7 同比对比柱状图
2025年1-4月 vs 2026年1-4月（收入合计、人工成本、成本费用合计、息税摊销前利润、税后利润）

### 3.8 关键指标仪表盘（3个Gauge）
- EBITDA率(%)
- 税后利润率(%)
- 人工成本占比(%)

> ⚠️ 阳阳提到：税后利润率那个仪表盘可能要改成「预算达成率」，但先按现有参考做，后续微调。

## 六、角色权限设计

需要新增角色：

| 角色                | 角色值              | 能看什么             | 能做什么           |
| ----------------- | ---------------- | ---------------- | -------------- |
| **出纳管理员** (新)     | `cashier_admin`  | 全部看板+Excel       | 上传6张原始表、触发数据生成 |
| **集团管理员** (已有)    | `group_admin`    | 全部看板+Excel       | 全部管理功能         |
| **园长** (新)        | `principal`      | 仅自己园所的看板+Excel   | 只读             |
| **区域财务主管** (新/待定) | `region_finance` | 管辖区域内园所的看板+Excel | 只读             |
| **运营总监**（张汝成）     | 待定               | 全部单个看板+整体看板      | 只读             |
| **其他总监**（康总/王明总）  | 待定               | 仅整体看板（大盘）        | 只读             |
| **老板/董事长/高总**     | 待定               | 全部看板             | 只读             |

权限粒度说明：
- 角色可以叠加（现有系统已支持逗号分隔多角色），如某用户可同时是「园长」+「区域财务主管」
- 不需要看板穿透/下钻功能 — 想看明细就下载Excel

## 七、不需要做的

- ❌ **不需要看板穿透/下钻**：想看明细就下载Excel
- ❌ **不需要一键同步**：由出纳管理员手动上传6张表（因为BI那边目前无法自动对接）
- ❌ **不需要修改已有功能**：只在现有系统上新增模块
- ❌ **不需要环比**：阳阳确认只需要同比（今年vs去年），不需要环比（本月vs上月）

## 八、数据每月更新流程

```
每月10-15号
  → 出纳管理员从报表系统导出6张表
  → 登录系统，上传6张表
  → 系统解析6张表，按园所编码拆分数据
  → 生成 ~90+ 个园所看板 + ~90+ 个园所Excel报告 + 1个集团看板 + 1个集团Excel报告
  → 各角色按权限查看
  → 本月数据不变（结账后固定，不会回改）
```
