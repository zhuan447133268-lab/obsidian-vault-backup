## 四、上传方式

由于中文文件名在multipart中不稳定，上传使用英文别名：
- 复制6张表到 `tmp_upload/` 目录
- 文件名：ytd_actual.xlsx / month_actual.xlsx / ytd_actual_ly.xlsx / month_actual_ly.xlsx / year_budget.xlsx / period_budget.xlsx
- `IdentifyFileType` 已支持英文别名
- 或者用原始中文名（无 `[]` 括号版本）

上传命令示例：
```bash
TMP="D:/财务系统/doc/阳阳给的出纳表0617/tmp_upload"
TOKEN=$(curl -s -X POST localhost:8094/api/v1/auth/dev-login -H "Content-Type: application/json" -d '{"employeeNo":"BUDGET01"}' | python -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")
curl -s -X POST localhost:8094/api/v1/analysis/upload \
  -H "Authorization: Bearer $TOKEN" -F "period=2026-04" \
  -F "files=@$TMP/ytd_actual.xlsx" -F "files=@$TMP/month_actual.xlsx" \
  -F "files=@$TMP/ytd_actual_ly.xlsx" -F "files=@$TMP/month_actual_ly.xlsx" \
  -F "files=@$TMP/year_budget.xlsx" -F "files=@$TMP/period_budget.xlsx"
```
