### 1. 利润完整链路（V4 公式）

```
收入合计 = 学费 + 餐费 + 政府补助 + 其他业务收入
       ↓
   (减) 成本费用合计 = 人工 + 食堂 + 其他业务成本 + 行政 + 日常 + 市场 + 外部服务费
   (加) 营业外收入
   (减) 营业外支出
       ↓
   息税摊销前利润 (EBITDA)
       ↓
   (减) 折旧摊销
   (减) 利息及手续费
   (减) 所得税费用
   (减) 调整项
       ↓
   税后利润
       ↓
   (加) 以前年度损益调整
       ↓
   最终利润
```

## 开发避坑规则（必读）

来源：知识管理平台 25 个 bug 教训，详见 memory: `reference_knowledge_platform_bugs_lessons`

### 核心 6 条

1. **SQL 字段先 `DESC table` 验证**，不靠记忆
2. **Excel 列号用 openpyxl `cell.coordinate`**，不手拼 chr()
3. **逗号分隔字段不能直接 GROUP BY**，先拆分排序
4. **fetch 必须有 .catch() + 超时**
5. **"也可以" ≠ "就这么定"**，条件性确认记录为分支
6. **密码/特殊字符不走命令行**

### 开发前检查清单

- [ ] 所有 SQL 字段经过 `DESC table` 验证
- [ ] 所有路径是相对/可配置的
- [ ] 所有 fetch 有 `.catch()` 和超时
- [ ] Excel 列号用 openpyxl 原生 API
- [ ] 配置文件缺失时有明确报错
- [ ] 聚合/计算后加了验证步骤
- [ ] 条件性确认记录为分支结构
