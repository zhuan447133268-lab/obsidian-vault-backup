## 一、本次修了4个bug

### Bug 1：图表全部空白
- **症状**：学前看板7个板块所有ECharts图表不显示
- **根因**：`PreschoolDashboard.vue` 的 `loadData()` 中 `loading.value = false` 放在 `finally` 块，`initCharts()` 运行时模板还是隐藏状态（`v-else-if="!loading"`），所有 chart ref 为 null
- **修复**：`loading.value = false` 移到 `await nextTick()` 之前

### Bug 2：KPI 同比数据缺失
- **症状**：7个KPI卡片只有EBITDA有同比箭头，总收入/成本费用的 yoyPct=0
- **根因1**：`computeOneGarden` 对 LY 数据用 `val(ytdActualLY, "REV_TOTAL")` 查一个不存在的聚合码（数据库里 REV_TOTAL 0条记录）
- **根因2**：`costYoY` 变量声明后从未实际计算，`totalCostLY` 变量缺失
- **修复**：
  - `computeOneGarden`: REV_TOTAL → `REV_001+REV_002+REV_003+REV_004`（与当前年一致）
  - 模型加 `SProf002Ly` 字段，`computeOneGarden` 加计算，`buildGroupDashboard` 加 `totalCostLY` 累计和 `costYoY` 计算
  - 预算的 `REV_TOTAL` 同样改成 REV_001~004 求和

### Bug 3：缓存不更新
- **症状**：Go代码算出正确的 yoyPct 值，但数据库缓存 JSON 不变
- **根因**：`UpsertDashboardCache` 用 GORM `FirstOrCreate`+`Assign`，记录已存在时 `Assign` 不真正更新数据
- **修复**：改成 `First` 查记录 + `Save` 更新
- **附加**：handler `GetPreschoolDashboard` 加了 `?refresh=1` 参数，可强制从 raw_data 重建缓存（加了 `RebuildGroupCache` 方法）

### Bug 4：切Tab后图表消失
- **症状**：看板视图 → 切换到数据明细 → 切回看板视图，图表全空
- **根因**：`v-if` 销毁DOM后切回来，`initCharts()` 只在 `onMounted` 跑一次
- **修复**：加 `watch(view, ...)` 切回 dashboard 时自动 `nextTick()` + `initCharts()`
