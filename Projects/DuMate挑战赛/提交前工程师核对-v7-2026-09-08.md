## 3. 关键设计决策（工程师需要知道的"为什么"）

| 决策 | 原因 |
|------|------|
| 离线轮子 `resources/wheels/` + **脚本内依赖自举 `_ensure_deps()`** | 评测沙箱无 pptx/docx/reportlab；官方确认 Python 3.10 → cp310 命中；自举 = 导入失败自动 `pip install --no-index --find-links wheels`（不依赖 Agent 读文档）；SKILL.md 口径为离线 1 次 ≤60 秒，代码硬上限 `timeout=90`（正常 15–30 秒；异常时宁可早失败走 minimal 兜底，也不占掉 5 分钟预算的 40%） |
| `minimal_pptx/minimal_docx/minimal_pdf.py` | 主链路全挂时用纯标准库/预装库出简化文件——0 产物 = 0 分，兜底保产出 |
| `_recalc_with_soffice` timeout=40 | LibreOffice 重算公式缓存值（防读取端读到空），超时保护防烧穿预算（按 5 分钟口径收紧） |
| `plot.series` 用 `list(...)[:3]` | python-pptx SeriesCollection 切片返回裸 XML 元组，直接切片会抛异常（v7 修复的真 bug） |
| Excel 顶层 params 下发 + summary 三写法兼容 | SKILL.md 文档与实现曾不一致：Agent 照文档把 params 放顶层会全失效、summary 写 `cells` 会丢公式（v7 修复的真 bug） |
| 瑞士风视觉（纸灰底/面板蓝 #536A7A/发丝线/直角/常规字重大标题） | 评分细则原文是"排版整洁、字体字号配色统一、图表表格规范"——按阅卷标准设计而非审美设计 |
