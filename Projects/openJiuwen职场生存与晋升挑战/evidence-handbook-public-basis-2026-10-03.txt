- quickstart.html 快速上手：交付件目录逐字
    solution/
      manifest.json
      README.md
      design/skills_design.md
      design/decision_report.md
      skills/<名称>/SKILL.md
  manifest 字段 {team, name, mode, instruction}；mode: agent（单 Agent，支持通用工具/技能/MCP 调用，记忆被动）/ team（多智能体协作）。
  五个常用 MCP 能力：new_game / observe(session_id) / take_action(session_id, choice, notes) /
  show_employee_handbook() / check_latest_logs(session_id)。命令：make sync → cp .env.example .env →
  MODEL_NAME="deepseek-v4.1-flash" → make setup → make start-jiuwen（前端默认端口 6173）；stdio 入口 career-emulator-mcp。
- handbook.html 公开手册：公开信息＝职级结构与晋升窗口 / 可见状态 / 季度行动框架 / 48 个月时间结构 / 月薪与绩效等级 / 风险与失败方向提示；
  隐藏信息＝晋升分数、绩效计算指数、潜在隐患细节、随机事件触发概率。职级 L1–L10，每 6 个月开放晋升窗口。
- rules.html 规则说明：七种体力行动（高强度工作 2 / 技能学习 2 / 人脉维护 1 / 处理历史埋雷 2 / 心理修复 1 / 健康恢复 1 / 准备汇报材料 1）；
  八种主行动（申请关键项目 / 向领导汇报成果 / 主动争取资源 / 申请岗位轮岗 / 主动曝光成果 / 建立导师关系 / 修复关键关系 / 低调避险）；
  月薪 L1 0.3 → L10 9.1；绩效 S/A/B/C/D；每 6 个月晋升窗口，阈值不公开。
- failure-and-ending.html 失败与结局：失败方向七条；结局评分六维度（职级成就「较多」/累计财富「偏多」/身心健康「适中」/专业能力「适中」/
  风险控制「有一定占比」/同事关系「有一定占比」）；并明确「内部计数、阈值、连续触发条件和具体惩罚细节不会在官网中展开」。
- jiuwenswarm-mcp.html 配置：make setup 创建 career_emu 实例、写入 career-emulator-mcp、同步 .env；五个工具签名（同上）。
