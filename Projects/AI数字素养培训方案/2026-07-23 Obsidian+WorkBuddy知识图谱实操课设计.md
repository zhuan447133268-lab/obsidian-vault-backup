## 二、教学目标

1. 理解双链笔记与知识图谱的概念——为什么比"文件夹套文件夹"好用
2. 会用 WorkBuddy 把课程资料批量转成带 `[[双链]]` 的结构化笔记
3. 会用 Obsidian 图谱视图查看、调整、输出自己的课程知识图谱
4. 当堂产出可提交的作业成果（图谱截图 + vault 压缩包）

## 三、技术链路（2026-07-23 实跑验证结论）

### 链路 A：文件夹直连（主推，课堂用这个）

```
WorkBuddy 授权工作目录 = Obsidian vault 文件夹
        ↓ 一句话指令
AI 批量生成带 [[双链]] 的 .md 笔记
        ↓ Obsidian 自动识别
图谱视图即刻成图（零配置、零插件）
```

**为什么主推它**：Obsidian vault 本质就是一个普通文件夹，`[[双链]]` 是纯文本语法，WorkBuddy 只要会读写文件就能干活。机房 40 台机器零额外配置，翻车率最低。

### 链路 B：MCP 协议直连（课尾拓展演示，3 分钟）

```
Obsidian 装 Local REST API 插件（暴露 https://127.0.0.1:27124/mcp/）
        ↓
WorkBuddy mcp.json 配该地址 + API Key
        ↓
WorkBuddy 不授权文件夹也能读写知识库（还能跨应用联动）
```

课上只演示不实操，作为"回家自己折腾"的钩子。

## 五、讲师示范脚本（环节 3，7 分钟）

### 示范话术流
1. "我刚才把《人工智能导论》的大纲和几篇文献扔进了这个文件夹。现在我不动手，让 WorkBuddy 替我整理。"
2. 粘贴提示词（下附）→ 发送 → 学员盯着看它一个个建文件（约 1-2 分钟）
3. "切到 Obsidian，左边这个小蜘蛛网图标——图谱视图。"
4. 点开，图成形，放大拖动节点："8 个知识点、十几条关联，AI 帮我把一门课的知识结构画出来了。这就是你们 30 分钟后要交的作业的样子。"

### 示范提示词（投屏+发群，学员实操时照抄改学科）

```
你是高校教师的课程知识整理助手。请阅读当前文件夹中的课程资料，完成：

1. 提炼 8 个核心知识主题，每个主题创建一篇 Markdown 笔记，
   文件名 = 主题名.md，放进「知识图谱」子文件夹
2. 每篇笔记结构：
   # 主题名
   ## 核心概念（3-5 句话）
   ## 关联主题（用 [[主题名]] 双链格式，至少链接 2 个其他主题）
3. 再创建一篇《课程知识地图.md》作为总索引，用 [[]] 链接到全部 8 篇
4. 每篇笔记开头加 frontmatter：
   ---
   tags: [课程知识图谱, 你的学科名]
   ---
```

## 六、实操任务卡

### 任务 1（10'）环境就绪
- [ ] 打开 Obsidian →「打开其他库」→ 选择桌面「课程素材包」文件夹（或新建库）
- [ ] 启动 WorkBuddy → 点底部文件夹图标 → 授权同一个文件夹
- [ ] 发送测试指令：`列出当前文件夹里的所有文件`
- ✅ 通过标准：WorkBuddy 返回正确的文件清单

### 任务 2（30'）AI 生成学科双链笔记
- **基础版**：把自己的课程大纲/教案 PDF 拖进文件夹（或用备用素材包），粘贴示范提示词（改学科名），生成 ≥8 篇笔记
- **进阶版**（做得快的）：追加指令`再提炼 3 个跨章节的应用场景主题，比如"XX 在教学中的应用"`，并让它们与已有笔记互链
- ✅ 通过标准：Obsidian 图谱 ≥8 节点，且存在互链（非全是孤立点）

### 任务 3（18'）人工加链 + 图谱调优
- [ ] 通读 2 篇笔记，手动补 2 条 `[[双链]]`（理念：AI 生成骨架，人脑补灵魂关联）
- [ ] 图谱面板 → 筛选 `tag:#课程知识图谱` → 分组设置按 tags 着色
- [ ] 找到没有连线的孤儿节点，要么补链要么删除
- ✅ 通过标准：截图中节点 ≥2 种颜色，无孤儿节点

### 任务 4（8'）作业打包提交
- [ ] 图谱截图（快捷键截图，PNG）
- [ ] 整个素材文件夹右键 → 压缩为 zip
- [ ] 命名：`工号_学科_知识图谱.zip`（如 `20230145_大学英语_知识图谱.zip`）
- [ ] 上传到学分系统本课作业入口

## 九、风险预案

| 风险 | 概率 | 预案 |
|---|---|---|
| WorkBuddy 登录/网络故障 | 中 | 备用方案：改用网页版大模型（元宝/DeepSeek）对话生成笔记文本，学员手动存为 .md——图谱成图环节不受影响；另备 2 台教师机 |
| AI 生成质量差/双链格式错 | 中 | 任务卡给出标准提示词+补一句兜底指令：`检查所有笔记，把提到其他主题名的地方都改成 [[主题名]] 格式` |
| 学员进度两极分化 | 高 | 任务 2 设基础/进阶两档；助教巡场盯慢学员；快学员加做"消灭孤儿节点"挑战 |
| 机房机器数量不够/故障 | 低 | 允许两人一组，一人操作一人看，中途交换 |
