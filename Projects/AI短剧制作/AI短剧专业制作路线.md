# AI 短剧专业制作路线

> 这份文档回答两件事：**我要做短剧** + **怎么用专业路线做出来**。
> 给谁看：给新 session 的 agent，也给我自己。新 session 第一步见文末「接手指南」。

---

## 0. 路线选择：为什么是 AI 生成，不是程序化引擎

本次会话已经用实证排除了另一条路，别再走回头路：

| 路线 | 结论 | 原因 |
|---|---|---|
| 程序化 three.js 自研引擎（球形校园等） | **否决** | 代码画几何 → 画面糊、小人是方块、运镜线性插值晃动、配乐是 stdlib 合成音诡异。用户明确"效果差就算了别强行生产" |
| factory / machine 类仿真引擎 | **否决**（做故事场景） | 只能出微缩厂房和机器，故事场景做不到 |
| **AI 生成（ImageGen 关键帧 + VideoGen/LibTV 视频）** | **采用，已验证成功** | 5 秒试水片 `Cinematic_slow_forward_push_in_2026-11-18T02-44-42.mp4` 画质写实、运镜平滑单向、首尾严格贴合关键帧，用户认可 |

**一句话**：写实故事场景是 AI 生成模型的活，不是代码画几何的活。美术资产由模型提供，人负责分镜、提示词、一致性、剪辑。

## 1. 三大质量铁律（用户硬要求，缺一不可）

短剧和"好看的单镜头"的分水岭，就在下面三条。**每条都给可执行做法，不是口号。**

### 铁律一：人物一致性 —— 同一个角色，跨镜头必须是同一个人

这是 AI 短剧最大的生死线，也是培训时最该讲透的一课。

**核心机制：角色圣经（Character Bible）+ 参考图强绑定。只写文字描述"同一个男人"必崩，必须传参考图。**

每个角色开一张卡，包含四样：

1. **定妆照**：一张正面、中性表情、干净背景的标准照。用 ImageGen 生成，选定后全片不再重生成。
2. **外貌锚点**：3–5 个不可变特征，写成固定词块。例：`齐耳黑发、右眉一道浅疤、深棕色瞳、圆框眼镜、下颌线清晰`。
3. **服装锁定**：按场景分，每个场景一套，颜色写死（`米色风衣+深灰西裤`），不写"得体着装"。
4. **禁止项**：明确列出会漂移的东西 —— `禁止换发型/换发色/摘眼镜/服装变色/年龄感变化/正脸切大侧脸`。

**出图时的强绑定操作**（每次生成该角色的镜头都要做）：

- ImageGen：`image1 = 该角色定妆照`，`input_fidelity = high`，把外貌锚点+服装锁定词原样贴进 prompt。
- LibTV：用 `generate_character_style` / `save_character` 把角色存成 character，之后每镜用 `referenceImageNodes` 挂定妆照节点；prompt 里用 `{{Node <nodeId>}}` 引用。
- **铁律**：同一个角色的锚点词块和服装词块，每次**原样复制粘贴**，绝不凭记忆重写。重写 = 漂移。

**验收（一致性清单）**：把该角色在全片出现的所有镜头截图，排成一排，问自己"这是同一个人吗"。有一个不像就重做那镜，不放行。

### 铁律二：环境逻辑性 —— 镜头之间空间、时间、光线要自洽

AI 视频每个镜头是独立生成的，默认彼此不知道对方存在。逻辑性靠人 setups。

1. **场景主图**：每个场景先出一张 establishing shot（全景主图），后续同场景的镜头都把这张主图作为背景参考图传入。这样桌椅位置、色调、建筑风格才会延续。
2. **光线锁**：每场戏写死一段光线描述并全片复用 —— `清晨侧逆光、暖黄 3200K、窗外薄雾`。绝不同一场戏里一会儿正午一会儿黄昏。
3. **空间连续（首尾帧衔接）**：下一镜的**首帧 = 上一镜尾帧的机位延续**。用同一张图或图生图衔接，观众才不会觉得跳。这也是本路线用"首尾帧插值"而非纯文生视频的根本原因。
4. **轴线（180° 规则）**：对话镜头固定摄影机在轴线一侧，正反打不要越轴，否则观众会迷失方向感。
5. **道具连续**：角色手里拿的东西、身上的伤、端着的杯子，场次内要接得上；断了就在下一镜里显式交代。

**验收（故事板检查）**：把所有镜头按时间线排成故事板，从头看一遍，检查"人从哪来、到哪去、天黑了没、东西还在不在"。

### 铁律三：画面精致性 —— 关键帧质量决定成片上限

**成片质量的天花板 = 关键帧质量。视频模型只是把关键帧动起来，不会凭空变精致。**

1. **关键帧出图**：ImageGen，`quality = high`，尺寸用 `1536x1024`（横）或 `1024x1536`（竖，短剧常用）。
2. **风格锚定词**：写一段固定的风格描述，全片每一张图原样贴上。例：`photorealistic, cinematic lighting, tilt-shift miniature, warm golden hour, shallow depth of field, ultra detailed, 8k`。风格词不统一 = 全片像拼凑。
3. **运镜靠首尾帧插值控制**，不靠纯文生视频（后者运镜不可控、会晃）。给稳定的首帧+尾帧，让模型只补中间运动。
4. **运镜法则**（借自花叔 huashu-art-motion 的镜头表方法论）：
   - 一镜一动，单向缓推 / 拉远 / 横移；镜头要"稳、有动机"。
   - 快推、砸入只给重音和反转，一支片里数得过来。
   - 观众在读字 / 画面本身在动时，镜头停住，不要画蛇添足推。
   - 有来有回：推进去之后要拉出来，不连着三镜往里推。
5. **分辨率**：正式片用 **2K**；768P 只用于试水看效果。
6. **水印**：ImageGen 生成的图右下角有平台水印，**喂给视频前必须裁掉**（见第 4 节）。生成平台自带的视频左上角小水印，正式片也要后期裁/遮。

## 3. 标准工作流 SOP（照着做，别跳步）

```
① 定故事线（用户出，1-3 分钟短剧，先定梗概和主角）
② 写分镜表（huashu-art-motion 镜头表；每镜 2-6 秒；开头 3 秒是具体小场景，不是标题）
③ 建角色圣经 + 场景主图（定妆照、锚点词、服装锁；每场景一张 establishing shot）
④ 逐镜出关键帧（ImageGen，传定妆照/场景主图参考，风格锚定词原样贴，裁水印）
⑤ 逐镜生成视频（首尾帧插值，运镜 prompt；先关键帧给用户确认，再烧视频积分）
⑥ 配音 + 字幕（TTS 有 key 就用，没有就静音+硬字幕）
⑦ 剪辑成片（ffmpeg concat / LibTV export；镜头间用首尾帧衔接）
⑧ 质量验收（三张清单逐条过，见第 5 节）
```

**节奏原则**：逐镜确认，先出关键帧给用户看 → 点头 → 再生成视频。绝不一口气烧完整片再给用户看（这是上次失败被否的教训）。

## 4. 实测踩坑（省得新 session 重踩）

1. **ImageGen 水印**：右下角有 `AI生成 / WORKBUDDY` 水印。裁法：PIL `crop((0, 0, w, h-70))`，1536×1024 → 1536×954。裁完再做视频。
2. **VideoGen 分辨率**：填 `1080p` 会报错，只支持 `768P` 和 `2K`。正式片填 2K。
3. **复杂动作可控性有限**：踢球、打斗、多人互动这类，AI 视频容易糊掉或变形。做法：动作镜头单独生成、多试几次挑最好的；或者用动作关键帧（起势→击球→收势）拆成短镜剪接，别指望一镜到底。
4. **口型对不上**：AI 视频无法让嘴型精确对上中文台词。用 TTS 配音 + 硬字幕，观众能接受（抖音短剧大量是配音）。别追求口型同步，那是当前工具的死穴。
5. **成本会翻倍**：分镜/表演要反复调，实际消耗通常是理论值的 2–3 倍。先算成本账再开工。
6. **题材难度分级**：古风仙侠 / 水墨动画风 / 竖屏情绪片 → 容易成功；现代都市正脸对白戏 / 打斗 / 一镜到底 → 别碰。

## 5. 三张验收清单（放行标准）

**人物一致性清单**
- [ ] 同一角色的所有镜头并排，像同一个人
- [ ] 发型/发色/服装/标志物跨镜无漂移
- [ ] 没有出现"正脸切大侧脸"导致的脸崩

**环境逻辑性清单**
- [ ] 故事板按时间线排开，空间自洽（人从哪来、到哪去清楚）
- [ ] 同一场戏光线/色调一致，不跳时间
- [ ] 对话镜头没有越轴
- [ ] 道具/伤痕/衣着接得上

**画面精致性清单**
- [ ] 关键帧 high quality，无水印
- [ ] 全片风格锚定词统一，没有某一镜像从别的片子里来的
- [ ] 运镜单向平稳，没有晃动和乱推
- [ ] 正式片 2K 输出

## 7. 新 session 接手指南

**第一站**：读 `Projects/AI短剧制作/CURRENT.md`（现行状态），再读本文档。

**唯一未定的输入 = 故事线**。用户说要"做自己想做的故事线"，但还没给具体内容。

**接手第一句话就问用户**：

> "你的短剧故事线是什么？给我：①主角是谁（一句话人设）②讲一件什么事（梗概 2-3 句）③想要什么风格（古风/现代/动画风/情绪片）。定了我先出分镜表+角色定妆照给你看。"

**拿到故事线后的动作顺序**：
1. 用 huashu-art-motion 镜头表模板写分镜表 → 给用户确认
2. ImageGen 出角色定妆照 + 场景主图 → 给用户确认（人物一致性从这里开始锁）
3. 逐镜出关键帧 → 用户点头 → 再生成视频
4. 剪辑 + 验收清单 → 成片
5. 全程把踩坑和成本记回 `CURRENT.md`
