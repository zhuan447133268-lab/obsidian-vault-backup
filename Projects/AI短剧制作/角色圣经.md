# 角色圣经 · 跨集一致性

> 这是全系列共用的**冻结资产**，不是某一集的素材。
> 两条铁律：**定妆照选定即冻结、全系列不再重生成**；**锚点词块原样复制粘贴、禁止凭记忆重写**。
> 任何"顺手重生成一张"或"凭印象重描述一遍"= 跨集换人，前面白做。

## 冻结顺序（开工前一次性做完）

1. 全角色名单列全 —— **含后续集才出场的角色**，边拍边加必崩。
2. 每个角色生成定妆照（正面／中性表情／干净背景），存 3 个角度：正面 · 3/4 侧 · 侧面。
3. 定稿后写死下面四件套，然后冻结。
4. 场景主图 + 光线锁 + 风格锚定词同样冻结。

## 角色卡模板

复制下面这块，每个角色一张。字段留"待填"的先空着，别编。

```
### 角色名（主角／配角／仅背影）
- 定妆照：路径 ______ ｜ 选定日期 ______ ｜ 角度：正面□ 3/4侧□ 侧面□
- 外貌锚点（3–5 个不可变词块，原样复制用）：
  例：齐耳黑发 / 右眉浅疤 / 深棕瞳 / 圆框眼镜 / 下颌线清晰
- 服装锁（按场景分，颜色写死，不写"得体着装"）：
  - 场景A：______
  - 场景B：______
- 标志物（跨集靠它认人，比脸可靠）：______
- 禁止项：换发型 / 换发色 / 摘眼镜 / 服装变色 / 年龄感变化 / 正脸切大侧脸 / 标志物消失
```
