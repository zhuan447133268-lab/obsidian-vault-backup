## 2. 技术方案（已定，勿轻易推翻）

**一句话**：4090 机器（租极智算）跑腾讯开源 Hunyuan3D-2 批量生成 → 拿回笔记本做 FDM 后处理 + 四视图渲染 + 官方格式打包。

- **生成端** `cloud/generate_hy3d.py`：hy3dgen 管线 = 中文文生图(HunyuanDiT) → 形状(默认 tencent/Hunyuan3D-2mini，4090 可换完整版 2) → 纹理(可选，失败不阻塞几何落盘)。参数默认 steps=30/octree=320/guidance=5.5，seed=42+i。输出 `models_raw/<pid>/raw.glb + gen_meta.json`。**未实测，上机先 `--limit 2` 校准接口**
- **后处理** `pipeline/postprocess.py`：去浮渣(体积<1%主体) → merge_vertices/去退化面 → fill_holes×3 → 仍不水密则 pymeshfix 重建 → fix_normals → 底面贴地 z=0 → 尺寸策略 → 减面≤12万 → GLB
- **尺寸解析** `parse_size_constraints`（build_submission.py 内）：子句级解析中文 prompt；高度/限高→z 轴、厚度→min(x,y,z)、宽度/直径→max(x,y)、整体/长度→最长边；"建议约X毫米"→目标尺寸(取多条建议最大值)；上限词表=不超过/不得超过/不大于/不高于/以内/≤/限高/限宽/限长；毫米/mm/厘米/cm 换算；有效域 5~500mm
- **渲染** `pipeline/render_views.py`：matplotlib 纯 CPU，front(azim -90)/side(0)/top(elev 90)/perspective(-55,25)，1024px，纹理 UV 质心采样着色，无 OpenGL 依赖
- **打包/校验** `pipeline/build_submission.py`：build（逐题后处理+渲染+metadata+process.md+manifest+zip）/ validate（≥90% 门槛、必需文件、模型可加载）
- 尺寸兜底：默认目标 80mm，全局上限 --max-mm 150（prompt 解析出的更严限制优先生效）
