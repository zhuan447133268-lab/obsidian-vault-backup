## 二、平台前提复核（引证，非推测）

| Claude Code 方案的假设 | 复核结果 | 依据 |
|---|---|---|
| 「租实例 → 装 Docker → 按 Dockerfile 重建镜像」 | ❌ 极智算便宜档（**4090 ¥1.57/h = 容器实例**）**跑不了 docker**（嵌套容器）。产品线只有：容器实例 / 裸金属整机（8×4090，按天 ¥264 起）/ 模型 API —— **没有"能装 Docker 的单卡 GPU 云主机"** | 极智算官网产品线；**包内我们自己早记过**：`cloud/租机执行清单.md:175`「官方评测同构的容器级断网（`--network none`）❌ 实例上做不到（需要能跑 docker 且有 GPU 直通）」 |
| 「按交付 Dockerfile 重建 = 复现交付镜像」 | ⚠️ **不等价**。交付镜像是**两段式**造的：`base_prep.sh` 预热 → `docker exec` 装依赖 → `docker commit … hy3d-base:py310` → 再 `--build-arg BASE_IMAGE=hy3d-base:py310` 跑 Dockerfile 尾段。纯净机器用默认 `BASE_IMAGE` 重跑会走**从未端到端验证过**的 miniconda 分支，且本机实测 legacy builder 24 步需 **60+ 分钟**；重建镜像的层摘要 ≠ 交付 tar | `reproduction/Dockerfile:28-31,84-99`；`提交说明.md:46-59`（两段式命令原文）；`reproduction/README-复现说明.md:132`（60 分钟实测） |

→ 若一定要跑"镜像本体 + 容器级 `--network none`"：最小代价是**上传交付 tar（23.8 GB）+ `docker load`**，
宿主机仍必须能跑 docker（即必须换平台或租裸金属）。本机已用同一 tar 做过 `load` + `--network none` 单题阶段2 实测
（`实测记录/12`），**缺的只有 GPU**。

## 五、照着做（3 步）

```bash
scp -P <端口> gpu_verify.sh gv_stats.py prompts40.jsonl \
    baseline_chusai_stats.json baseline_chusai_model_stats.json root@<IP>:/root/gpu_verify/
scp -P <端口> -r pkg root@<IP>:/root/gpu_verify/

scp -P <端口> root@<IP>:/root/gpu_verify/gv_small.tgz .
```

**成功判据**：①冒烟两题的 `t2i.png` 是干净概念图（人眼）+ 4 视图齐全 + 完成率 1.0；②40 题完成率 ≥0.9、单题阶段1 中位 ≤1.5 分钟；
③对拍面数一致、尺寸差 ≤3 mm、种子一致；raw md5 全同 ⇒ **逐字节复现**，md5 异但几何同 ⇒ **功能等价复现**（官方不要求逐字节）。
