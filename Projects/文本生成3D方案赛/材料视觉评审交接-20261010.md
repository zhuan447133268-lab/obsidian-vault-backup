  **判据不是字符串检索，而是字符级坐标**：Word 用**定位偏移**而不是空格字形来表达这类空格，所以抽取器看不到字符、但页面上确有空隙。三处实测字间隙 = **2.28 ~ 2.76 pt**，与同页**本来就带空格**的对照位置（`生成可 FDM` 2.16 pt、`送入 FDM` 2.28 pt）同量级；而**修正前**同一位置的间隙只有 **1.20 pt**（那只是 Word 的中西文自动间距 `autoSpaceDE/DN`，没有真实空格）。对照位置在两版 PDF 中数值**完全未变**（2.16 / 2.28 pt），证明改动是**局部**的。
  → 一句话：**这两个空格确实已生效**（`docx` 里直接读得到、PDF 里量得出间隙变大），不要因为复制出来的文字粘连就再改一遍。

## 九、如果评审后要改材料：怎么重新生成页图

```bash
# 1) 改内容 → 重跑构建脚本（纯 python-pptx / python-docx）
python "D:\文本生成3D方案赛\决赛答辩准备\ppt源_bdci_text2_3d_final.py"     # 重建 pptx

# 2) PPTX → 12 张 PNG（PowerPoint COM，1920×1080）
powershell -File "%TEMP%\render_ppt\topng.ps1" "<pptx>" "<outdir>"
#    核心：$pres = $app.Presentations.Open($pptx,$true,$false,$false); $pres.Export($out,'PNG',1920,1080)

# 3) DOCX → PDF + 页数（Word COM）
powershell -File "%TEMP%\doc_pdf\topdf.ps1" "<docx>" "<pdf>"
#    $doc.ComputeStatistics(2) 取页数；$doc.ExportAsFixedFormat($pdf,17,...)

# 4) PDF → PNG（PyMuPDF）
python -c "import fitz; d=fitz.open(pdf); [p.get_pixmap(dpi=170).save(f'p{n:02d}.png') for n,p in enumerate(d,1)]"
```
