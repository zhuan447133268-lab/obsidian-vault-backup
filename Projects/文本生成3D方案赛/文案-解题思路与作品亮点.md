## 一、解题思路（完整版 · 不限字数）

### 1. 问题定义：把赛题还原为「双约束」问题

赛题要求从中文描述生成可直接 FDM 打印的 `model.glb`。官方评分由三部分组成：**FDM 物理合规**、**多视图语义与视觉**（MLLM 比对渲染图与 prompt）、**人工抽查复核**；并设三条反作弊红线（极简几何骗物理分、渲染图与模型不符、严重偏离语义）。

我们的判断是：**这不是单纯的文生 3D 题，而是「语义正确 × 物理可打印」的双约束问题**——为打印合规做补洞、水密与减面，很容易把语义结构磨掉；为保住语义细节保留高面数，又会撞上体积与打印限制。整套方案围绕这一对矛盾的取舍展开，并对红线逐条自证：渲染图由提交的 `model.glb` 经**同一条管线**真实渲染，不做美化、不做外部生成。

### 2. 总体链路：GPU 生成一次，CPU 侧完全可复现

- **阶段 1（GPU）**：HunyuanDiT 文生图（中文友好，直出概念图）→ rembg/u2net 去背景得白底主体图 → **Hunyuan3D-2 mini** 图生形状（显式用 `hunyuan3d-vae-v2-mini` 覆盖 VAE，规避拆包权重零占位导致的输出全零坑）→ 高面数 `raw.glb`。
- **阶段 2（CPU，全可复现）**：去浮渣 → 合并顶点/去退化面 → 补洞 ×3 → 不水密则 pymeshfix 重建 → 修法线 → 底面贴地 → 尺寸策略归一（mm）→ 减面 ≤12 万面（内部上限）→ **减面后尺寸兜底复核** → 四视图渲染（front/side/top/perspective）→ 打包 + 官方格式自检。

官方入口一条命令贯通：`bash run_infer.sh /input/prompts.jsonl /output`；另支持 `INFER_PROC_ONLY=1` 只跑阶段 2（便于评委在无 GPU 环境下验证后处理链路）。

### 3. 四个关键设计决策（每个都可核验）

1. **选 mini 版而非完整版**：评分看几何与渲染图，**纹理不参与评分**；mini 在 4090 上单题数十秒级，40 题全量 2~3 小时，性价比最优。纹理链未端到端验证，因此**不交付、不宣称**，`process.md` 中如实写明产物为纯几何。
2. **尺寸语义逐题解析，而不是全局固定缩放**：写了中文子句级解析器——「高度/限高」映射 Z 轴、「厚度」映射 min(x,y,z)、「外径/宽度」映射 max(x,y)、「整体/长度」映射最长边；**硬性上限**（越过即违规）与「建议约 X 毫米」（作为目标值）分开处理；词表覆盖 不超过/不得超过/不大于/以内/≤ 等，单位兼容毫米/厘米，有效域 5~500 mm。测试集 40 题的尺寸约束形态各异，逐题解析避免了一刀切缩放的越界风险。
3. **减面之后必须再复核尺寸**（本轮踩到的真坑）：二次误差边折叠**会移动顶点**——一个已归一到 50.0 mm 的网格，减面后被抬到 **50.1 mm**，肉眼不可见，但按题面「50 毫米以内」就是违规。修复：所有改形工序结束后加 `enforce_caps()`，按题面各轴上限**只缩不放**地兜底复核，系数写入 `build_report.json`（实跑 0.99899 → 最终恰好 50.0×50.0×50.0 mm）。
4. **渲染弃 OpenGL 改走 matplotlib**：无头容器 + 无 GPU 的复现环境里，OpenGL 渲染链路极易失败。改用 mplot3d 软件渲染（纹理 UV 质心采样着色），**零 OpenGL 依赖**。代价是 CPU 上每题数十秒——这个代价我们接受，换来的是「在评委机器上一定能跑出图」。

### 5. 工程化与可复现性（本轮工作重点）

- **断网实测**：交付镜像内 `--network none` 跑官方入口，**rc=0**；单题 CPU 耗时 **194.5 / 242.0 / 222.4 秒**（合计 658.9 s）。
- **镜像自足性实测**：先 `docker rmi` 把本机镜像连同中间层删干净，再由交付 tar 单独 `docker load`，还原出**同 ID（`56b164216646`）/ 同 CONTENT SIZE / 同层数（19）**的镜像并跑通单题，产物 md5 与三题实测**逐字节相同**——归档不是「结构看着对」。
- **「复现＝初赛提交」对拍（最强门禁）**：以初赛提交包内 40 题成品几何为阶段 2 输入，在交付镜像内断网重跑——**渲染图 160/160 张与提交包逐字节一致**、`metadata.json` 逐字段一致、面数/顶点/单体/水密 **40/40 相同**、包围盒 **39/40 ≤0.01 mm（中位 0.0006 mm）**；唯一离群题（26.69 mm）已用三条旁证归因为**提交版自身缺陷被复现修正**（提交版外廓 43.3 mm 且整体悬空 6.64 mm → 复现 70.0 mm 贴地）。
- **权重与依赖门禁**：23 个权重文件（18.92 GB）逐文件精确字节数 + safetensors **零张量扫描**（占位权重即判构建失败，堵住「构建成功但权重是空壳」）+ u2net md5 校验；依赖锁 **130 包**，断网零索引下 **130/130 可解析**。
- **构建期功能自检**：把「依赖缺失 → 静默降级」这类最隐蔽的坑挡在镜像构建阶段。

### 6. 局限与如实声明

只验证了 RTX 4090 24G，未做 12~16 GB 显存边界测试；产物为**纯几何、不含贴图纹理**；本机断网实测走阶段 2，语义质量结论来自初赛 4090 全链路实测；CPU 单题约 3 分钟（官方无硬性时限，已给出实测数字）；极端细长/多层悬空结构减面后可能残留 <1 mm 薄壁，属 FDM 工艺本身的边界。

## 二、作品亮点（完整版 · 不限字数）

### 亮点 1｜「复现＝初赛提交」不是声明，是逐字节实测（对应：工程落地与系统效率）

以初赛提交包内 40 题成品几何为阶段 2 输入，在交付镜像内 `--network none` 重跑：渲染图 **160/160 张与提交包逐字节一致**（40 题 × 4 视图），`metadata.json` **逐字段一致**，面数/顶点/单体/水密 **40/40 题相同**，包围盒 **39/40 ≤0.01 mm（中位 0.0006 mm）**，复现后贴地 40/40 归零。唯一离群题（26.69 mm）经三条旁证归因为**提交版自身缺陷被复现修正**。证据：`实测记录/14_初赛提交版几何离线对拍.txt` + `样例渲染图/初赛提交版几何/` 9 张对照图。

### 亮点 2｜交付归档经「删库重建」检验（对应：工程落地与系统效率）

先 `docker rmi` 把本机镜像连同全部中间层删净，再由交付 tar 单独 `docker load`，还原出**同 ID / 同 CONTENT SIZE / 同层数**镜像并跑通单题，产物 md5 与三题实测逐字节相同。即：**评委拿到的归档，删掉原镜像也能重建同一环境、跑出同一结果**。证据：`实测记录/12`。

### 亮点 3｜把「语义正确 × 物理可打印」的双约束做成全链取舍（对应：算法创新与管线设计）

识别出两个目标互相拉扯的本质（补洞/水密/减面会磨掉语义，保语义又撞打印与体积限制），并把「生成」与「后处理/渲染」按算力特性拆成两阶段：GPU 只做一次生成，CPU 侧承担全部可复现工序。评委在无 GPU 机器上也能验证阶段 2 全链（`INFER_PROC_ONLY=1`）。

### 亮点 4｜尺寸语义逐题解析，而不是全局缩放（对应：算法创新与管线设计）

中文子句级解析器：「高度/限高」→ Z 轴、「厚度」→ min(x,y,z)、「外径/宽度」→ max(x,y)、「整体/长度」→最长边；**硬上限（越过即违规）与建议值（目标）分开处理**；单位兼容毫米/厘米，有效域 5~500 mm。测试集 40 题的尺寸表述形态各异，逐题解析避免了一刀切缩放的系统性越界。

### 亮点 5｜减面后兜底复核尺寸——一个肉眼不可见的越界（对应：算法创新与管线设计）

二次误差边折叠会移动顶点：已归一 50.0 mm 的网格减面后被抬到 **50.1 mm**，正好越过题面「50 毫米以内」。加 `enforce_caps()` **只缩不放**兜底复核（实跑系数 0.99899 → 最终恰好 50.0×50.0×50.0 mm），系数写进 `build_report.json` **可审计**。

### 亮点 6｜渲染零 OpenGL 依赖：保证在评委机器上一定出图（对应：工程落地与系统效率）

无头容器 + 无 GPU 环境下 OpenGL 链路极易失败；改用 matplotlib mplot3d 软件渲染（纹理 UV 质心采样着色），四视图纯 CPU 产出。代价是每题数十秒，换来确定性。

### 亮点 7｜断网隔离环境的硬证据（对应：官方硬性要求）

交付镜像内 `--network none` 跑官方入口 `bash run_infer.sh /input/prompts.jsonl /output`：**rc=0、completion_ratio=1.0、meets_90pct=true、problems=[]、quality_warnings=[]**；单题 CPU 耗时 194.5 / 242.0 / 222.4 秒。权重内置（23 文件 / 18.92 GB）、依赖内置（锁 130 包、断网零索引 130/130 可解析）、**去背景模型内置**（rembg 默认要联网下载 `u2net.onnx`，断网必失败）。

### 亮点 8｜构建期门禁把「静默降级」挡在门外（对应：工程落地与系统效率 · 三处真问题均有实证）

### 亮点 9｜合规与红线自证（对应：人工抽查复核）

渲染图与提交模型**同源**（同一 GLB、同一渲染脚本，可复跑比对）；生成链路**全部开源权重**（Hunyuan3D-2 mini / HunyuanDiT / u2net），**零第三方商业 2D/3D API、零 LLM 介入生成、零密钥内置**；`metadata.json` 的 `commercial_api_used` 申报与《复现说明文档》一致。

### 亮点 10｜敢写边界：可核验的自我限定（对应：人工抽查复核 · 可信度）
