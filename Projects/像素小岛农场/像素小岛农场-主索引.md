## 一句话定位

用 **Phaser 3 + TypeScript + Vite** 复刻公众号系列《从零搓一座 AI 能玩的 2D 像素小岛》里的那座岛，
并在复刻完的基础上把它做成一款**有经济闭环的农场经营游戏**：
**36×28 格的程序化小岛，16px 瓦片，全部美术在运行时用 Canvas 画出来，仓库里没有一张图片。**

目标不是"做个 demo"，而是**一个真能玩、能投屏、能离线带走的小游戏**：
买种子 → 种四样作物 → 收成 → 卖钱 → 再买种子/买鸡，还有四季、天气和天黑屋里亮灯。

> [!info] 现在到什么程度
> 文章 ①（搭世界）、②（autotile 土地、地图层、滤镜层、E 键挤牛奶）的内容都已复刻完；
> 在此之上自己补了五件文章里没有的事：**经营闭环（金币/商店/收购）**、**存档**、
> **离线单文件**、**镜头缩放**、**大屏分辨率重构**。

## 怎么跑

```bash
npm install
npm run dev            # 开发：http://localhost:5173
npm run build          # 类型检查 + 生产构建
npm run preview        # 预览生产包
npm run build:offline  # 构建并压成单文件（离线版 + 课堂模板）
npm run typecheck      # 只跑类型检查
```

- **离线版**：根目录 `像素小岛-离线版.html`（约 1.2 MB），拷到任何机器双击用 Chrome/Edge 打开即可，不需要 `node_modules`、不需要联网。
- **课堂模板**：同一次构建还会出 `像素小岛-课堂模板.html`——同一份游戏，文件最前面多一段 `window.__FARM_CONFIG__`，
  改名字 / 金币 / 速度 / 一天长度 / 作物数值 / 两条规则开关，保存后双击就是「自己的版本」。教学用法见下方「培训材料」。
- 打包原理写在 [[技术实现与制作过程]] 的「离线打包」一节。
- 开发时常用调试键：`K` 循环切天气、`N`/`M` 跳 21:00 / 06:00、`X` 跳到 23:59 立刻过一天（连按换季）、`0` 清档重来。

## 玩法速查

| 操作 | 说明 |
| --- | --- |
| `WASD` / 方向键 | 四方向走路 |
| `E` | 统一交互：锄地 / 播种 / 浇水 / 收获 / 捡蛋 / 挤奶 / 开种子摊 / 卖货 / 看木牌 |
| 长按 `E` | 连续操作（320ms 一步），资源不足自动停 |
| `1`–`4` | 选要播的种子（种子摊开着时＝购买） |
| `5` | 买一只鸡（摊子开着时） |
| `Esc` / `E` | 关掉种子摊 |
| 滚轮 / `-` `=` | 镜头推拉（整数倍，像素不会一大一小） |
| `0` | 清档重来 |

**经济闭环**：24 金起家 → 种子摊买种子 → 一格格锄/种/浇 → 等 N 秒 → 收获进背包 → 围栏门口收购箱一次卖光 → 再买种子或买鸡。

| 作物 | 种子价 | 卖价 | 生长 | 可种季节 |
| --- | --- | --- | --- | --- |
| 草莓 | 4 | 9 | 7s | 春 · 夏 |
| 番茄 | 6 | 16 | 11s | 春 · 夏 |
| 玉米 | 10 | 28 | 15s | 夏 · 秋 |
| 南瓜 | 14 | 46 | 22s | 秋 |

下雨暴雨自动算浇水；冬天天冷一茬都种不了；蛋 8 金、奶 20 金。

**一天 4 分钟（一小时 10 秒），一季 3 天**，天气按季节权重随机。黄昏从 17 点渐暗到 22 点、约 50 秒走完。收成进右上角背包，进度自动存进浏览器（`0` 键可清）。

## 文件地图

```
src/
├── main.ts                  # 游戏配置 + 画布按「窗口 × 设备像素比」开
├── style.css                # 页面外壳，留白是海水色
└── game/
    ├── constants.ts         # 所有可调参数（瓦片/相机/HUD 基准/季节/天气权重/农田）
    ├── config.ts            # 课堂模板的配置层：读 __FARM_CONFIG__、逐项校验、配置指纹
    ├── types.ts             # Interactable / FarmContext / HudState / ShopState
    ├── economy.ts           # 经济数值：四种作物的价目与生长、蛋奶价、开局资金与种子
    ├── save.ts              # localStorage 存档（版本号 + 逐字段兜底）
    ├── art/
    │   ├── pixel.ts         # 调色板 + 像素绘制工具 + makeTexture
    │   ├── autotile.ts      # bitmask autotile：四邻是非题拼出 0-15 号边角砖
    │   ├── terrain.ts       # 高度场、色带、散点过渡、岛底座、岸线泡沫、小路
    │   └── sprites.ts       # 角色四向帧、树、房子、栅栏、作物三阶段、鸡牛、种子摊、收购箱、雨雪
    ├── entities/            # Player（移动+碰撞）、Animal（游荡 AI）
    ├── world/FarmPlot.ts    # 单格农田状态机 + 动态 autotile 号码 + 存档快照
    ├── systems/             # TimeSystem（时间/季节）、WeatherSystem（天气+天数光照）
    └── scenes/              # Boot（生成贴图）/ Island（主场景+经济）/ Hud（HUD、商店浮层、天空层）
```

## 关键数字（改之前先看这里）

| 项 | 值 | 位置 |
| --- | --- | --- |
| 瓦片 | 16 px | `constants.ts` `TILE` |
| 地图 | 36×28 格 = 576×448 世界像素 | `MAP_COLS` / `MAP_ROWS` |
| 视野基准 | 1 世界像素 = 3 CSS 像素（`WORLD_SCALE`），再乘 DPR | `WORLD_SCALE` / `MIN_ZOOM` |
| HUD 基准 | 高度 360（所有字号、边距乘 `画布高 / 360`） | `HUD_H` |
| 逻辑视口 | 480×270（只用来算初始相机位置） | `VIEW_W` / `VIEW_H` |
| 农田 | **6×4 = 24 格**，起点 (20,12) | `FARM_*` |
| 围栏 / 门 | 19–26 列 × 11–16 行，门在 21–22 列 | `IslandScene.FENCE` |
| 开局 | 24 金 + 草莓种×3 + 番茄种×2，鸡 3 只 | `economy.ts` |
| 作物成熟 | 草莓 7s / 番茄 11s / 玉米 15s / 南瓜 22s（浇水后计时） | `economy.CROPS` |
| 价格的锚 | 每格约 1.0–1.2 金/秒 | `economy.CROPS` |
| 买鸡 | 45 金（蛋卖 8、奶卖 20） | `economy.CHICKEN_COST` |
| 挤奶冷却 | 14 秒 | `IslandScene` |
| 长按 E 节奏 | 320 ms 一步 | `IslandScene.REPEAT_MS` |
| 一天 / 一季 | **240 秒（一小时 10 秒）/ 3 天** | `DAY_SECONDS` / `SEASON_DAYS` |
| 昼夜遮罩 | 白天 0.05 → 深夜 0.62，14 个关键帧线性插值 | `WeatherSystem.LIGHT_FRAMES` |
| 课堂模板可改项 | 名字 / 开局金币 / 速度 / 一天秒数 / 4 作物 ×（名字·种子价·卖价·生长秒数）/ 2 条规则 | 模板文件开头的 `window.__FARM_CONFIG__`，默认值在 `config.ts` |

## 培训材料（归档目录 `02-课堂材料/`）

**主推 · 90 分钟中小学「从零五阶段」**（2026-11-06 第 12 轮）

- `培训方案-90分钟-中小学-从零做像素农场.md` —— 0–90 分钟时间轴；五个阶段（世界 / 动作 / 循环 / 规则 / 手感），
  每段只让 AI 做一件能看见的事；阶段③拆 ③-A 闭环 + ③-B 种子经济；检查点 24′ / 38′ / 51′ / 59′ / 71′ / 79′
- `学员任务卡-A4-90分钟-从零版.md` —— 六张可直接复制的提示词卡（含 ③-B 买种）+ 四段式 + 三步协作法 + 验收三句 + 互测表 + 翻车三步
- 讲师保底版 `01-游戏成品/我的农场-保底版.html` —— 开场演示「90 分钟后你手上的东西」+ 救场，不提前发学员；
  开局 6 金币 / 2 颗种子、种子摊 3 金币 1 颗，22 条断言实测全过

**备用 · 2 小时改模板**（第 11 轮，大学场或时间宽松时用）

- `培训方案-2小时-用像素农场讲游戏制作.md` —— demo-first 的 120 分钟排期：每人当堂交付一个能双击运行的 HTML
- `学员任务卡-A4.md` —— 三档任务（小学改数值 / 初中加规则 / 大学重做平衡）+ 三句验收公式 + 互测表 + 常见问题

> 两套的区别：90 分钟版**从零建**，老师体验"游戏是怎么长起来的"，代价是规模压到 1/10；
> 2 小时版**发模板改**，27 分钟人人有 demo，但改的是别人做好的游戏。
