## 已兑现（2026-11-06 第 11 轮 · 课堂化）

需求原话："培训课相当于就是实操课，要求培训的学员，当堂课就要出一个游戏 demo，课后学员们再去丰富自己的游戏。"
→ 结论：**交付物必须是每人一个双击能跑的 HTML**，所以缺的不是课件，是「老师能改的那一层」。

| 想法 | 现在怎样了 |
| --- | --- |
| **老师改不动代码** | ✅ `像素小岛-课堂模板.html`：文件开头一段 `window.__FARM_CONFIG__`（名字 / 开局金币 / 速度 / 一天秒数 / 四作物三数值 / 两条规则），记事本改完保存即生效 |
| **改坏了就白屏** | ✅ 三层兜底：整段语法错 → 浏览器丢掉那块 `<script>`，一切走默认；单项写错类型/越界 → 只回退那一项 + 开场提示「配置有 N 处没看懂」；F12 里有逐条人话明细 |
| **"我改了怎么没反应"** | ✅ 存档带配置指纹（`CONFIG_FINGERPRINT`），配置一变老档自动作废，不会把钱读回 24 |
| **模板和成品分叉** | ✅ 同一个构建产物，只多一段配置；`isCustom` 为假时标题与文案一字不改，离线版回归测试全绿 |
| **课上讲什么、什么算完成** | ✅ `培训方案-2小时-用像素农场讲游戏制作.md` 重写成 demo-first 排期（讲解 ~33min / 动手 65min，四个检查点）+ `学员任务卡-A4.md`（三档任务 / 三句验收 / 互测表 / 7 条 FAQ） |

> [!warning] 这轮没做的
> 模板里**只能改数值和两条开关**，不能加新系统。想加"每日委托""季节价格波动"这类，仍要回到 `src/` 里改代码再重新 `npm run build:offline` —— 这是留给课后/进阶的方向，不是当堂要求。

## 更远 · 呼应原作标题

原作叫《从零搓一座 **AI 能玩** 的 2D 像素小岛》，目前这版还是人玩的。三个可选方向：

| 方向 | 做法 | 代价 |
| --- | --- | --- |
| AI 当玩家 | 暴露"读状态 / 发动作"接口，让模型自己种田 | 要联网调模型，和"离线"冲突 |
| AI 当 NPC | 村民每天说一句话、给一条委托 | 同上；可做"离线小语料库"降级版 |
| AI 当地图作者 | 让模型生成岛的地形参数，玩家点一下换一座岛 | 可纯本地跑（参数化即可） |

> [!note] 建议
> 真要往这条线走，先做**第三个**（本地参数化生成，不联网），把"AI 生成"的体验跑通再谈联网。
