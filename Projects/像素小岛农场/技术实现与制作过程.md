## 一、技术栈与硬约束

| 项 | 值 |
| --- | --- |
| 引擎 | Phaser **3.90.0** |
| 构建 | Vite **8.3.x**（`npm run build` = `tsc` + `vite build`） |
| 语言 | TypeScript **~7.0**，`tsconfig` 开了 `verbatimModuleSyntax` / `erasableSyntaxOnly` / `noUnusedLocals` |
| 资源 | **零图片、零字体文件**，全部贴图运行时用 CanvasTexture 画 |

> [!warning] 两个会让人卡住的编译约束
> - `verbatimModuleSyntax`：纯类型导入必须写 `import type { X }`，否则打包会留空导入。
> - `erasableSyntaxOnly`：**不能用构造函数参数属性**（`constructor(private scene)` 这种写法直接报错），字段要单独声明。
> - `noUnusedLocals`：删代码时要连常量一起删（曾因为留了个没用到的 `BAYER4` 编译失败）。

## 二、制作顺序（实际走的八步）

1. **项目骨架**：Vite + TS + Phaser 配置，`BootScene` 先生成贴图再切主场景。
2. **地形**：高度场 → 分层色带 → 两张贴图（水 / 陆）→ 细节（草簇、花、贝壳、浪花、石头）→ 石板路。
3. **角色**：48×48 四向 4 帧，逐轴碰撞（撞水只在那个轴上停，可以贴着海岸线滑行）。
4. **农田**：单格状态机（草地 → 翻土 → 播种 → 浇水 → 成熟 → 收获），统一 `E` 交互。
5. **动物**：定时换方向的游荡 AI，遇到不可走的地块掉头。
6. **天空层**：昼夜关键帧插值 + 天气粒子 + 闪电，全部挂在 HUD 场景。
7. **autotile 与地图精修**（文章 ② 的核心）：bitmask 边角砖、岛的底座、岸线泡沫、散点过渡。
8. **工程收尾**：大屏分辨率重构 → 离线单文件打包 → README / 本笔记。
9. **经营系统**（第 8 轮）：`economy.ts` 数值 → 农田扩到 6×4 → 种子摊与收购箱 → HUD 商店浮层 → `save.ts` 存档 → 长按 E。
10. **画面比例修正**（第 9 轮）：相机倍数改成固定 `WORLD_SCALE × DPR`，HUD 基准从 270 抬到 360，
    面板文字补 `setPadding` 并按 `text.height` 反算高度。
11. **配置层与课堂模板**（第 11 轮）：`config.ts` 读文件开头的 `window.__FARM_CONFIG__`，
    校验后喂给经济表 / 角色 / 时钟 / 农田规则；`build:offline` 一次出成品与模板两个单文件。

## 三、八个关键技术

### 1. 所有贴图运行时生成

- 用 `scene.textures.createCanvas(key, w, h)` 建画布，拿 2D context 逐像素画，最后 `refresh()`。
- **坑**：`pixelArt: true` 只影响"加载的图片"，管不到 `createCanvas` 生成的纹理 —— 必须手动 `setFilter(NEAREST)`，否则放大后一律是糊的。
- 好处：仓库零素材、配色改一个常量全岛跟着变、可以按号码批量生成（16 号边角砖 × 3 种土 = 48 张贴图）。

### 2. 地形：高度场 + 双贴图 + 厚度与浪沿

- `islandHeight(tx, ty)`：椭圆基础 − 距离 × 系数 + 两层 fbm 噪声扰动；`0.31` 以上是陆地。
- 一次采样得到像素级 `bands[]` 表，后面所有效果（填色、过渡、底座、浪沿）都读它，只算一遍。
- **填色按行合并同色连续段**再 `fillRect`，比逐像素快得多。
- **拆两张贴图**：`terrain-water`（水+沙）与 `terrain-land`（草+丘+路）。
  换季只给 land 上 `setTint`，水面和栅栏不会被染黄 —— "只有植被在变色"。
- **散点抖动**：草皮交界两侧互撒对方颜色，用逐像素 hash 决定撒不撒（阈值 0.45）。
- **岛的底座**：朝下的那圈沙滩，若往下 4px 内碰到水，就染成泥土色（距离 ≤1 用深色）——岛就有了断面。
- **岸线泡沫**：浅水里离陆地 3px 内的水像素压成泡沫色，海岸自己亮起来。

### 3. bitmask autotile（文章 ② 的核心）

- 四邻是非题：上 `1`、下 `2`、左 `4`、右 `8`，相加得 **0–15**，对应 16 张边角砖。
- 画法：先铺底色 → 内圈提亮一道 rim → 画细节（犁沟、草茬）→ 只给**外露的边**描线；外露的角切 3px 阶梯做圆角。
- 关键性质：号码只描述邻接关系，**形状多复杂都能自己接边**，不需要为每种形状单独出图。
- 农田的两种用法：
  - 没翻过的苗床：号码看"田的矩形范围"（固定的整块 6×4）；
  - 翻过的土：号码看"周围哪些格子也翻了土"，翻一块就变一次号；
  - 翻土时立刻 `refreshFarm()` 把周围一圈重算，交界处才不会留缝。

### 4. y-sort 与碰撞

- 所有立体物按"脚底 y"设 `setDepth(y)`；地面贴图固定在负深度（`-5` 起，苗床 / 土 / 作物各差 0.2），永远不会盖住站上去的脚。
- 树、房子、栅栏用 `add.zone()` + `physics.add.existing(zone, true)` 做成静态体，收集成数组后一次 `physics.add.collider(player, solids)`。
- **踩过的真 bug**：竖栅栏原来只挡下半截 6px，角色能从两根横栏中间钻出去。
  竖栏要按整根 16px 建碰撞体（横栏保持薄薄一条），改完从围栏外走会正确顶住。

### 5. 天气与昼夜

- **一个发射器复用**：雨、暴雨、雪共用同一个 `ParticleEmitter`，切天气时 `setConfig` 换一整套数字。
  - **坑**：Phaser 的 `setConfig` 是**合并**语义 —— 配置里没出现的 EmitterOp 会回到默认值。
    所以每次切天气都要给**完整配置**（贴图、速度、密度、朝向、emitting 全带上）。
- **闪电**：白屏 + 一条带分叉的折线电弧，120ms 后再白一次。
  - **坑 1**：`rectangle(x, y, w, h, color, 0)` 的 fillAlpha 是 0，`setAlpha()` 是**乘**上去的，永远 0 → 闪白永远不出现。填充色必须不透明，用对象 alpha 来控制。
  - **坑 2**：电弧 Graphics 的深度必须**高于**闪白，否则被整屏白光糊掉。
  - **坑 3**：白屏 + 白电弧分不清 → 电弧先铺一层冷蓝晕染（宽 3、alpha 0.45），再压白芯（宽 1）。
- **昼夜**：`LIGHT_FRAMES` 关键帧表（0 / 4 / 5.5 / 6 / 7 / 8 / 16 / 17 / 18 / 19 / 20 / 21 / 22 / 23 / 24 点），
  相邻帧之间按颜色与 alpha 插值。
  - **密度就是观感**：第 10 轮之前只有 10 档、一天 120 秒，黄昏 20 秒就从 0.05 压到 0.50，玩家感受是"突然变黑"。
    现在 14 档 + 一天 240 秒，相邻两档只差 0.06–0.09，黄昏铺满 50 秒。
  - **重设条件看透明度，不看小时**：原先是"小时差 > 0.03 才重设"，时钟一慢，同一个阈值等于一次跳一大格；
    改成"透明度差 > 0.002"。
  - **深夜封顶 0.62**（原 0.74）：夜里还得能看清田和栅栏。
- **天气色要淡进去**：天气在换天那一刻重掷，`setFillStyle` 是同步的 —— 直接写会让整屏"啪"地暗一下（0 → 0.24 只用 16ms）。
  现在颜色立刻换、`fillAlpha` 走 1.6 秒 `Sine.easeInOut` tween，并且**从当前值补间**（雨 → 暴雨是从 0.12 接着走，不会先掉回 0）。
- **必须在 HUD 场景**：世界相机 zoom > 1，如果粒子/遮罩放世界层，只会盖住一小块而且位置会偏。

### 6. 分辨率、缩放与清晰度（第 6 轮重构，第 9 轮修正）

**症状**：小窗口能看，大屏上字和角色糊成一团。

**根因**：画布固定 480×270，浏览器把整块画布拉伸到窗口大小。
1920 宽是放大 4 倍、2560 是 5.33 倍、4K 是 8 倍，而且是**非整数倍**双线性放大 ——
字是"先画成 10px，再拉成 53px"，像素块还会一大一小。

**第 6 轮的改法（三层一起动）**：

| 层 | 做法 |
| --- | --- |
| 画布 | `Scale.NONE` 自己接管：画布像素 = 窗口 CSS 尺寸 × 设备像素比（上限 2），CSS 尺寸 = 窗口尺寸 |
| HUD | 字号、边距、面板统一乘 `u = 画布高 / HUD_H`，**按画布真实像素渲染**，比例不变但不再放大 |
| 相机 | 倍数**取整**后 `setZoom` |

- 取整是必须的：世界像素被放大 5.37 倍时，有的占 5 个屏幕点、有的占 6 个，看着就脏。

**第 9 轮的修正 —— 相机倍数不该跟着画布宽算**：

第 6 轮用的是 `min(画布宽 / 240, 画布高 / 135) × 手动倍数`。这个公式在 1258×720 下给出 **5 倍**：
一个 16px 瓦片占 80 个屏幕点，草地上的草茬、花、碎石全被放大成色块 —— 用户说的"模糊 / 像素感太重"其实是**放大过头**。
像素画的清晰度靠"每个世界像素占整数个屏幕像素"，不靠继续加大画布。

所以倍数改成一条**与世界尺寸无关的固定基准**：

```ts
const fill = Math.ceil(cam.width / WORLD_W)      // 不露出岛外的下限
const base = Math.max(Math.round(WORLD_SCALE * dpr), fill)
cam.setZoom(Clamp(base + this.zoomStep, Math.max(MIN_ZOOM, fill), 32))
```

- `WORLD_SCALE = 3`：1 个世界像素固定占 3 个 CSS 像素 → 瓦片 48px、农夫 96px，细节看得清、像素味还在。
- 乘 `dpr` 是因为画布像素 = CSS 像素 × DPR：1080p 与 2 倍屏看起来一样大，不会在视网膜屏上"变小一半"。
- `fill` 是硬下限：窗口很窄时（比如 800px 宽）`ceil(800/3/576) = 1`，配合 `MIN_ZOOM = 2` 仍然够用；
  窗口极宽时 `fill` 会大于 3，宁可放大也不让镜头边露出岛外的海面。
- `zoomStep` 是**整数档位**（-2 … +6），滚轮加减一档，从根上避免了小数倍。
- `HUD_H` 同时从 270 调到 **360**：镜头拉远之后画面里的东西小了，面板也得小一档，否则面板比农田还大。

实测（1258×720、DPR 1）：倍数 5 → 3，世界视野 252×144 → 约 419×240；DPR 2 下倍数 6，CSS 相对大小与 DPR 1 一致。

**配套的排版问题 —— Phaser Text 是贴图，不是排版引擎**：

- Text 的纹理高度按行高**紧算**，中文（任何有上伸部的字形）的头顶会顶到纹理第 0 行，渲染时被切 1–2px。
  用户看到的"第一行显示不全"就是这个，跟面板边框"太近"只是巧合。
- 确认方法：把 `text.frame.source.image` 那张 canvas 抠出来，逐行扫 alpha 找墨迹首行。
  27px 字号修之前墨迹从第 **0** 行开始；加 `setPadding(0, 6)` 之后从第 4 行开始。
- 两条修法一起用：
  1. 所有面板文字 `setPadding(0, 4u)`，给纹理留头顶空间；
  2. 面板高度**不要写死**，用 `fitPanels()` 按 `text.height + 8u` 反算 —— 改了字号也不会回归。

### 7. 离线单文件打包（额外加的）

- `npm run build:offline` → `scripts/make-offline.mjs`：把 `dist/index.html` 里的 js / css / favicon 全部内联成一个 HTML。
- 为什么能双击打开：打包结果是**单个 chunk 且没有 import**，内联的 `type="module"` 脚本不发起任何外部请求，
  `file://` 下不会触发 CORS 拦截。
- 成品：`像素小岛-离线版.html`（约 1.19 MB），真实 Chrome 直接打开验证过。

### 8. 经济系统与存档（第 8 轮加的）

**数值全部外置**：`economy.ts` 只有数据和几个纯函数（`bagValue` / `bagSummary` / `produceName`），
`CROPS` 表里一行一个作物（价格 / 生长秒数 / 可种季节）。改平衡不动逻辑，`FarmPlot` 只读这张表。

- **状态机不碰钱**：`FarmPlot` 只负责土和苗的状态，收成通过 `ctx.addHarvest(kind)` 交给场景；
  金币与种子库存只有 `IslandScene` 一个地方改，避免"两块地同时收、金币算两次"这类问题。
- **`interact()` 返回布尔**：`false` = 这次没做成（没钱 / 错季 / 没种子 / 还没熟）。
  长按 E 的循环靠这个布尔决定要不要继续 —— `repeatOk = ok && target.repeatable`。
  没有这个信号，按住 E 会把种子点和金币点到负数。
- **商店面板布局**：`Phaser.GameObjects.Rectangle` 和 Text 的默认原点是中心，
  用左上角坐标摆必须 `setOrigin(0)`，否则面板会"以中心为锚"甩到屏幕外 —— 这是这轮最显眼的 bug。
  三列文字（名字 / 价格右对齐 / 备注）各用一个 Text 固定 x，中文宽度不齐也不会排成锯齿。
- **存档三原则**：
  1. 带版本号（`v: 1`），版本对不上就当没有存档；
  2. 读的时候逐字段兜底（`??` 默认值 + `crop in CROPS` 校验），坏数据不会让游戏崩；
  3. 整段 `try/catch` —— `file://` 或隐私模式下 `localStorage` 可能直接抛异常，禁了就当"没有存档"，游戏照常能玩。
- **什么时候存**：每 8 秒（`update` 里累加计时）+ 过一天 + 每次买卖/种植 + `pagehide`。
  存的是"状态"不是"过程"，所以刷新后田里的苗还长在原来的进度上。
- **存档入口**：`saveNow()` 一处组装 `SaveData`，`restoreSave()` 一处还原；
  田地要等贴图与 autotile 号码都建好之后再 `restore()`，否则会读到还没生成的纹理。

### 9. 配置层与课堂模板（第 11 轮加的）

目标只有一句话：**让别人能改，而且改不坏**。不是把代码整理漂亮，是把"改哪一行、改完怎么看、改坏了怎么办"三件事做完。

- **入口只有一个**：模板文件 `<head>` 里一段 `window.__FARM_CONFIG__`，排在打包脚本之前。
  `config.ts` 在模块初始化时读它，读不到就用默认值 —— 所以**成品与模板走的是同一条代码路径**，没有第二套分支。
- **语法错是天然的兜底**：配置块里少个逗号，浏览器把整段 `<script>` 丢掉，`__FARM_CONFIG__` 就是 `undefined`，
  游戏照默认值启动。这比自己写 try/catch 解析更稳（对象字面量比 JSON 宽容，还允许写注释）。
- **类型错要逐项兜底**：`readNumber / readText / readBool` 每项自己判断，坏的只回退那一项，
  并把原因翻成人话（"开局金币 startCoins 不是数字，按默认值 24 算"），控制台留明细、开场提示报总数。
- **范围也要管**：`daySeconds: 5` 不报错但会是灾难，所以统一夹到 60–1800 并提示"按 60 算"。
- **存档必须带配置指纹**：`CONFIG_FINGERPRINT` 是配置的 JSON 串，写进存档；读档时指纹对不上就 `clearSave()`。
  这一条是课堂上最值钱的一行 —— 没有它，"我改了开局金币怎么还是 24" 会把整节课拖进答疑。
- **规则开关是"半成品逻辑"**：`rainWaters` / `nightNoSow` 都只改一个判断的位置，
  不新增系统。学员拨一下开关就得到一条"能说清条件→结果"的规则，正好对上初中档的任务。
- **打包**：`make-offline.mjs` 先出成品，再把同一份 HTML 的 `<head>` 里插一段配置块 + 顶部一段中文说明，另存成课堂模板。
  两个文件都是 `file://` 直开，1.2 MB 左右。

## 四、踩坑清单（按坑的隐蔽程度排序）

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 闪电永远看不见 | `rectangle(..., 0)` 填充透明，`setAlpha` 是乘法 | 填充不透明，用对象 alpha |
| 电弧被白光吃掉 | Graphics 深度低于闪白 | 电弧深度放到闪白之上 |
| 切天气后参数错乱 | `setConfig` 只合并、缺项回默认 | 每次给完整配置 |
| 大屏字糊 / 角色糊 | 480×270 画布被非整数倍拉伸 | 画布跟窗口走 + HUD 原生字号 + 相机整数倍 |
| 画面"像素感太重、发糊" | 相机倍数跟着画布宽算，16px 瓦片被放大到 5 倍以上 | 固定 `WORLD_SCALE × DPR`，视野下限只用来防止露出岛外 |
| 面板第一行字缺一块 | Text 纹理按行高紧算，中文头顶顶在第 0 行被切 | 文字 `setPadding` + 面板高按 `text.height` 反算 |
| 玩着玩着画面"突然变暗" | 一天只 120 秒（一小时 5 秒），黄昏 20 秒压掉一半亮度 | 一天改 240 秒 + 关键帧加密到 14 档 |
| 换天时整屏"啪"地暗一下 | 天气遮罩用 `setFillStyle` 一帧换成暴雨色 | 不透明度走 1.6 秒 tween，从当前值补间 |
| 时钟变慢后夜色一格格跳 | 重设阈值按"小时差"，与透明度不成比例 | 改成按透明度差 0.002 判断 |
| 角色从竖栅栏钻出去 | 竖栏碰撞体只覆盖下半截 6px | 竖栏按整根 16px 建碰撞 |
| 草皮过渡像贴了张斜纹网 | 4×4 Bayer 矩阵 + 4px 步长 | 改成逐像素 hash 散点 |
| 水面跟着季节发黄 | 整张地形叠 tint | 拆成水 / 陆两张贴图，只染陆 |
| 翻土后交界留缝 | 只改了单格号码 | 翻土时重算周围一圈 |

## 五、怎么验证（这套方法比"看着还行"可靠）

1. **状态探针**：主场景挂在 `window.__island` 上，可以直接读
   `prompt` / `coins` / `seeds` / `bag` / `plots[].snapshot()` / `cameras.main.zoom` / `game.scale.width` 等，用来断言行为而不是猜。
2. **真实键盘事件**：向页面派发 `keydown` / `keyup`（带 `keyCode`），走的是引擎真正的输入路径，
   能验证"走位 → 交互 → 背包/金币变化"整条链。
3. **跑完整经济闭环**（第 8 轮的做法）：买种子（24→20）→ 长按 E 锄/种/浇 → 等成熟 → 收获进背包 →
   收购箱卖出（20→29）→ `Page.reload` 后核对金币、种子、田的状态 —— 只看截图是看不出存档坏没坏的。
4. **file:// 直开验证离线包**：用 Chrome headless 直接打开 `像素小岛-离线版.html` 截图，
   默认安全策略下能跑起来才算"真离线"；顺便断言 `localStorage` 可用（不可用也不能崩）。
5. **多分辨率截图**：1280×720 / 2560×1440 / `--force-device-scale-factor=2` 三档对比，专看文字与像素边缘。
6. **抓闪电帧**：闪电只有 300ms，用 `tweens.timeScale = 0` + `time.timeScale = 0` 把那一帧冻住再截图。
7. **看农田不看角色**：截图前 `cam.stopFollow()` + `centerOn(农田)`，并把角色挪开，免得挡住要检查的东西。
