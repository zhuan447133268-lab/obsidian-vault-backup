## 一、本节定位（一句话）

老师给一句话（学科 + 第几课），还他一节课。老师带走两样东西：
① 一个**按自己模板出教案的专属 Skill**（第1环节固化）
② 用「做课 Skill」现场备好的一节课（课件 + 教案 + 分层练习 + 交互演示 + 挑刺报告）

核心主张：**备课从「做」变成「改」**——模板固化后，后续只改不写。

## 二、培训沟通记录（需求迭代 / 决策点）

按时间线沉淀的关键决策，避免下次重踩：

### 1. 课前安装方式
- **结论**：老师只需在 WorkBuddy 里复制两句话（① 发仓库地址装 skill → ② 发一句话生成课），Python 与运行环境 **WorkBuddy 全自动装好**。
- **兜底**：保留了 Windows + macOS 双版本 Python 官方安装包 + 一键 bat（预装 python-pptx / python-docx / matplotlib + 清华镜像），但**默认不再要求老师手动装**。
- **实测依据**：新电脑装 skill 时环境全自举成功，推翻了「必须手动给安装包」的假设。

### 2. 水彩配图
- **结论**：skill 出课件配图走**内置 ImageGen**（无文字水彩图），**不需要老师另装 watercolor skill**。
- **稳定性提醒**：取决于老师各自账号的 ImageGen 额度，非 100% 可控。

### 3. 教案模板固化机制
- 第1环节老师做出教案模板 → 写入 `references/custom_template.md` 并标「已固化·默认」。
- 第2环节 `load_template()` 优先套用该模板，所以后续生成的课和老师的模板一致。
- 两张工作卡咬合：02_教案模板固化跟做卡（驱动固化）→ 03_备课指令卡（消费固化结果）。

### 4. 课件技术路线
- **保 PPT 路线**（python-pptx + python-docx + matplotlib），不用 HTML 路线——老师反馈「改 HTML 生成快但没 PPT 效果好」。
- 安装摩擦：把 `pip install` 从「生成时才装」前移到 bat **一次性预装三库 + 清华镜像**。
