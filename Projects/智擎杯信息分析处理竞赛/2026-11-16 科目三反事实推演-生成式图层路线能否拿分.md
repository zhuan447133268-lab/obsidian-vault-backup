# 科目三反事实推演 · 生成式图层路线能否拿分

> [!important] 一句话结论
> **不会。** 从 Day0 直接用生成式 RGBA 图层模型出图 → 分数大幅更低（81.39 → 20~40 量级，甚至 0）；
> 只借"图层原生"的架构思想、把图层放数据层 → 会高一点（推演 82~85），但补不上 5.31 分晋级缺口。
> **卡住这场比赛的从来不是图不够结构化，是 elm/obj/key 的文本抽取命中率。**

> [!warning] ⚠️ 2026-11-16 当日二次修正（**先看 §9 再看下文 §4：下文 §4.1 / §6 部分表述已作废**）
> 用户回看获奖作品后，回查规格书 §2.2「官方基准配图形态」，发现本笔记把**本地自评台的"全文覆盖率"误当成官方得分驱动**，并漏掉了版式的独立 **D 通道**（v8 实测 +4.30，本届最大单笔收益）。
> 修正后：**A 路线（生成式模型出图）仍必崩，结论不变**；**B 路线「只借架构思想」的收益被低估**，"只高一点、纯属少丢分"要改成"分区信息架构是承载层，间接放大抽取层收益，推演 83~86"。
> 更根本的一条：**差距不在美不美，在信息架构**——官方样本是 5~7 个语义槽位＋每槽配小图的情报简报，我方是 2 槽位的左右纯文字墙。已同步修订 [[参赛通用价值手册]] I1/I2、新增 I5。详见本笔记 **§9**。

> [!note] 本笔记的边界
> **可迁移条目已反哺至 [[参赛通用价值手册]] 新增 I 类（I1–I5）**，按手册 §9「唯一来源原则」，本笔记
> **不重复立条**，只保留：这次判断的案例细节、分数账、推演过程、课程迁移结论与证据路径。
> 关联：[[复盘-科目三全程-2026-10-29收官]] · [[科目三-分数复盘日志]] · [[AI竞赛模块课程-主索引]]。

## 0. 这份笔记解决什么

后续再做「机器读图打分 / 交图不交数据」这类比赛，或给大学生讲"如何打一场比赛"时，用得上三件事：

1. **看到一篇漂亮的新论文，怎么判断它能不能用**（三分法 + 三问）。
2. **"如果当初换条路线会不会更高"怎么算**，而不是凭感觉。
3. **一个现成的反直觉教学案例**：指标最亮的最新论文，在这场比赛里一分不值。

## 3. 反事实 A：从 Day0 真用生成式图层出图 → 大幅更低

四条硬证据：

1. **60 分靠逐字。** obj 15 + rel 20 + elm 10 + key 15 的判定全是"归一化后完全相同"/三元组三部分全同。生成模型写不准中文长句 → 五块同时塌。
2. **剩下 40 分靠文字面积，不靠好看。** vfy 拿到 **38.13/40**，靠 A 榜 50 篇全文覆盖率**均值 87.1%、中位 100%、36/50 完全上图**。图层化/视觉分层必然挤占文字面积。自证据：v8 把正文预算 1500→850 字，coverage 丢 47 条/11 事件，块和 **−0.40**（净分上涨来自 D 修复 +4.30，不是版面）。
3. **红线与封顶。** 不得加入无证据支持的关键视觉元素；「严重偏离事实或缺少关键视觉元素」≤25；不得生成可能被误认真实照片且无 AI 标识的图。
4. **工程契约装不下。** 论文 8/11 发、未给开源权重；A 榜备战 10/16→10/29 约 **7 天**；B 榜 `python main.py --input … --output …`、离线、鲲鹏 ARM、必须可复现。现有硬门禁「同一输入三次渲染 50/50 逐字节一致」会被采样随机性直接破掉，破不了复现即取消资格；跑不通 = 0 分。

**量级判断**：81 → **20~40**，封顶 25 是常见落点，装不上就是 0。不是"低一点"。

## 4. 反事实 B：只借架构思想 → 高一点，但过不了线

### 4.1 评分块剩余空间账（对照 #6 筹谋队，A 榜）

| 块 | 我方 | 相对差 | 由什么决定 | 图层化能否动 |
|---|---|---|---|---|
| obj 关键对象 | 7.94/15 | −2.03 | 抽取层实体召回、原词、名额排序 | 弱（只治名额可见性） |
| rel 主要关系 | 17.33/20 | −1.27 | 三元组逐字命中 | 不能 |
| elm 事件要素 | 5.74/10 | −1.50 | 时间/地点/主题/背景规则抽取 | 不能 |
| key 表达重点 | 12.25/15 | −1.88 | 长完整句上板 | 不能 |
| **vfy 配图核验** | **38.13/40** | **−0.22** | **图像问答（VQA）**：图上有没有能回答问题的证据锚点 | 能，但天花板只剩 0.22 |
| **D（公示分 − 五块和）** | **0（终榜）** | 早期曾 −4.90 | 版式/字号/密度，机制官方未公开 | **能，独立通道**（v8 实测 +4.30）|

⚠️ **口径不闭合**：块差合计 6.90 与总缺口 5.31 不一致（对手侧 D 扣分 / 取整口径差），**只看相对大小，不做加法**（呼应手册 A1）。

→ 图层化架构主要作用于版式可控与 vfy，而 vfy 已贴顶。~~**收益结构是"少丢分"，不是"多拿分"。**~~
> ⚠️ **§9 修正**：这句把"版式"整体判成不可测收益，漏了 **D 通道**——它是独立于五块和的第三条通道，且 v8 实测 +4.30 是本届最大单笔收益。正确说法：版式**不走内容门五块**（那里确实贴顶），但**走 D**；分区架构还间接放大抽取层命中（长句有独立槽位不被截断）。

### 4.2 根因账

| 收官五根因 | 图层化架构能否修 |
|---|---|
| #1 假设当确定性收益（−2.67） | 部分（slot 化让 A/B 变量可审计、门控自评台给分档判据） |
| #2 官方随机性发现太晚 | ❌ 不能（实验设计问题） |
| #3 最大分值块 vfy 投入最迟 | 部分（Day0 按权重倒排投入比），但 vfy 天花板只剩 0.22 |
| #4 elm/obj 最大杠杆测试排期排死 | ❌ 不能（排期与情报反制），**恰是最大缺口** |
| #5 渲染层信任未验证的浏览器行为 | ✅ 能（slot 化 + diff 只落手术声明区 + OCR 朝向抽检） |

**噪声门槛**：官方 ±1.5、同字节复投 80.8378→81.3898（+0.552）、D 随机 0~−1.4，判据 **>2σ**。
→ ~~版面更整齐这类收益在官方分上根本测不出来~~ **§9 修正**：版面作用于 **D 通道**、实测可测且量级最大（+4.30）；只是"整齐"不等于"分区槽位化"，前者是装饰，后者才同时服务 D 与长句承载。**图层化不落到抽取层与槽位设计，等于零内容门收益**。

→ B 的真实收益路径是**间接的**：省下 1~2 天自伤时间 → 投到 elm/obj/key 的抽取 A/B → 也许补上那 5.4 分。**但那分是抽取层挣的，不是图层挣的，别归错因果。**

## 5. Day0 最优解（下次同类赛直接照这个搭）

> **把图层放在数据层，别放在像素层。**

1. `facts.json` 做成五个带 slot ID 的语义图层，每个字段标注"服务官方哪一项判分"（论文「图层-指令绑定」+ 规格书 §7.1「排序即产出」）。
2. 像素层保持确定性 Pillow 渲染，**一个字都不交给生成模型**。
3. 自评台按论文的**奖励门控**建模：硬约束（可打开 / ≥1920×1080 / 必中串 / 缺图 / 同图 / 复现一致）外层 0/1 门，五块软分逐块对 truth schema 算命中；不对合成图打综合分。
4. Day1 下午先做同字节复投标定，拿到噪声带再开 A/B。
5. 每天额度按「已验证 / 假设 / 彩票 = 70/20/10」，假设弹提前一天出包留验证链。

**预期**：81.39 → 83~85。要过 86.699，仍得靠离线 LLM 抽长叙事三元组、补 elm/obj/key 命中，与 UniWorld-Design 无关。

## 6. 可直接引用的结论句

- 「技术路线相反、方法论值钱」是新技术迁移最常见的形态，别因为指标漂亮就整体换底座。
- 判断"如果当初走 X 会不会更高"，先算 X 能作用的那块还剩几分；天花板只有 0.22 的块，不值得最先投。
- 机器只读最终合成图，**图层本身不评分**。结构化的价值在管线可控与评测可信，不在交付形态。
- 官方噪声带 ±1.5，内容门里任何"更整齐"的改进都测不出来；只有结构性变化（elm 5.74→7.x）才过 2σ。**但 D 通道不在这条判据内**——版式从密排墙改到 22px/分区，D −4.90→−0.60 = +4.30，是本届唯一远超 2σ 的单笔收益（§9 修正）。

## 7. 课程迁移：4 课时给大学生，能借鉴，但别讲论文

> 关联 [[AI竞赛模块课程-主索引]] · [[2026-11-04 首期A形态课程设计-按讲师能力定稿]] §3
> 现有骨架：**4 次课 × 90 分钟 = 一件作品四次迭代**（1 拆题抽取 → 2 排版面 → 3 落图 → 4 自检提交），评分照搬科目三五块 + 四条封顶，L1 确定性自评 / L2 VLM 判官 / L3 官方校准锚。

### ✅ 值得进课（按性价比排序）

| 素材 | 放哪一课 | 学生能带走什么 |
|---|---|---|
| **本案例当反例研讨（15~20′）**：一篇 2026-08 最新论文、RGB L1 −37% / CLIP 全场最高，为什么在这场比赛里一分不值 | 第 1 课「拆赛题与抽取」 | **技术选型先过评分口径，不追新追炫**。反直觉 + 有真实分数账，比讲十条道理管用 |
| **三问决策卡**（作用于哪个评分块 / 该块还剩几分 / 工程契约装得下吗） | 第 1 课，做成一页卡片 | 通用能力，可迁到任何 AI 竞赛；对应手册 I1/I2 |
| **"给每个字段贴分数标签"**：facts 五槽位，每字段标注服务官方哪一项判分 | 第 3 课「从材料到信息脚本」 | 把论文的"图层-指令绑定"降维成学生版结构化，直接对应已有 L1 评分器与 §7.1「排序即产出」 |
| **硬约束门控 + 逐块软分** | 第 4 课，讲 L1 评分器怎么搭 | 为什么"好看"不能补偿"打不开/字数不够"；对应手册 I4 |
| **同字节复投 +0.552 / >2σ** | 第 4 课「像打榜一样交件」 | 科学思维训练：一次分数不能证明改进了。学生版只需一次课堂 A/B 演示 |
| 🆕 **双作品对照（2026-11-16 新增，性价比最高）**：81 分「左右两栏纯文字墙」vs 官方基准配图／头部队「分区简报＋小图＋精炼文字」 | 第 1 课，15~20′ 研讨 | 让学生自己拆出**三条得分通道**（内容门逐字命中 / D 版式门 / VQA 视觉锚点），得出"差距不在美，在槽位数与信息架构"。比论文反例更贴学生、更反直觉 |
| 🆕 **槽位化简报骨架**：5~7 槽，每槽标注服务哪一项判分，每槽配一个小图/图标/数字面板 + 一句精炼文字 | 第 2 课「排版面」、第 3 课「落图」 | 把"把文字搬上图"升级成"把文字装进能被机器和人同时读的结构"；直接对应手册 **I5** 与规格书 §7「分区问答友好」 |

> [!tip] 🆕 课程双目标（2026-11-16 用户原话触发）
> 用户回顾本届作品：「根本没有任何投产意义，感觉只是为了机器得分去的」。**课程不能只教过拟合机器分的做法**，否则学生 4 次课结束没有一件能给人看、能放作品集的东西。
> 建议立两条并行验收：① **机器分**（L1 评分器，五块逐块算命中）；② **人看的产品感**（这张图能不能当一页简报发给别人）。机器当第二读者，**人当第一读者**。注意官方专家评分原文「不以装饰效果作为主要依据」——"产品感"指分区与阅读顺序、文字可读性、信息完整，不是堆装饰。

### ❌ 不要进课

1. **别讲论文技术本体**（RGBA-VAE / LIB-MMDiT / DiffusionNFT / 渐进蒸馏）——通识选修、4 课时，讲这个跑题，且与拿分无关，最多一句带过"这是一篇生成式图层论文"。
2. **别把它当作品技术路线或课程主线**——课程已定 A 形态（锚视觉与信息设计类赛事、评分照搬科目三五块），换生成式路线会直接踩"机器读字"的题眼，学生交件必崩。
3. **别让学生读 arXiv 原文**——用一页中文摘要 + 一张分数账即可。

### 口径状态（2026-11-16 用户已确认两项）

- ✅ **「4 课时」= 4 次课 × 90 分钟 = 8 学时**（面授 8 + 课外实操 8 = 1 学分）。现有 §3 逐课设计、四件作品迭代全部装得下，**不重排**。主索引该待办已关。
- ✅ **原题授权风险解除**：课堂**不计划用原题**，是**把这场比赛当案例讲**（分数账、五根因、两次反事实、双作品形态对照）。可讲：公开口径与方法论、自制同构样例。**仍不外发**：赛题原件、50 篇 A 榜语料、官方 demo 基准配图（规格书 §2.3 标「只读、不进提交包、不外传」）；课堂展示用**照 §2.2 文字描述重绘的示意版**或本校公开素材自制样例。
- ⚠️ **阻塞件未做，且规格要改**：信息图模板应从「1920×1080 **四区**」升级为**多槽位情报简报骨架**（5~7 槽：标题+元数据 / 数字面板 / 主视觉小图+编号气泡 / 三文字区块 / 时间轴 / 结论框），每槽标注服务哪一项判分；L1 评分器（对 truth 算命中）仍缺。缺这两件课堂会退化成看老师演示。

## 9. 二次修正 · 官方基准配图形态 vs 我方纯文字墙（2026-11-16 当日）

> 触发：用户回看别的队伍/获奖作品后反馈——「都是那种简报，把赛事方给的信息精炼成一张很大的简报图，各要素再配小图，每张图配精炼文字，很精美。我提交的都是文字图，纯粹把文字放上去还放不全，都是左右结构，根本没有任何投产意义，感觉只是为了机器得分去的」。
> **结论先行：用户这个观察比本笔记 §4 的推演更接近真相。差距不在美不美，在信息架构；而线索一直写在规格书里。**

### 9.1 官方样本长什么样（规格书 §2.2 逐字）

深色军事/情报风横向信息图，1920×1080：

| 槽位 | 内容 |
|---|---|
| ① 页眉 | 大标题 + 一行元数据（执行方 · 时间 · 地点） |
| ② 左 | "演习要点"**数字面板**（5 天 / 第 5 次 / 8 个课目 / 2 艘） |
| ③ 中 | **舰船图像 + 地图**，3 个编号节点气泡（含日期与阶段说明） |
| ④ 右 | **三个文字区块**（港岸交流阶段 / 8 个海上课目 / 互派观察员） |
| ⑤ 底 | **四节点时间轴**（9月3日 → 9月8日 → 对海射击 → 9月9日） |
| ⑥ 右下 | "核心任务 / 结果"**结论框** |

规格书自己的判语（第 108 行）：**"图面文字量极大，几乎复述了文档全部要点。这不是装饰图，是一页纸情报简报。"**

⇒ **获奖/官方形态不是"文字少"，是"文字被装进 6 个语义槽位、每槽配小图/图标/数字面板"**。用户的左右两栏 = **2 个槽位**，"放不全"是架构容量问题，不是审美取舍。

### 9.2 三条得分通道（§4 原推演只算了第一条）

| 通道 | 谁在读 | 读什么 | 我方终态 | 版式/分区能否影响 |
|---|---|---|---|---|
| **① 内容门五块**（obj15+rel20+elm10+key15 = 60） | OCR 逐字 | 归一化后完全相同 / 三元组全同 / 成句 ≥80% 长度 | 43.26/60，缺 5.4 分 | **间接**：槽位化让长句/背景/时间地点有独立位置，不被截断、不被名额挤掉 |
| **② vfy 配图核验 40** | **VQA 图像问答** | 图上有没有能回答问题的证据锚点（数字、日期、节点、结论） | **38.13 贴顶** | 能，但只剩 0.22 空间 |
| **③ D = 公示分 − 五块和** | 平台（机制未公开） | 版式/字号/密度，复盘怀疑是"密排墙→视觉异常→补核" | 终榜已 **D=0** | ✅ **能，且量级最大**：v8 从 −4.90 → −0.60，**+4.30**，占那次 +3.90 净增益的 87% |

另：B 榜专家评分 **视觉表现 16 分**（文字可读性 / 分区与阅读顺序 / 画面完整性），官网原文「**不以装饰效果作为主要依据**」——奖励的是结构清晰，不是好看。A 榜不涉及。

### 9.3 实测证据：规格书 §7 那条战略被部分证伪

规格书 §7.1 铁律 2 写的是「召回优先，宁多勿漏……图面事实覆盖率**直接等于分数**，把文档事实尽量全搬上图」。**这是赛前假设，A 榜实测没有兑现**：

| 实验 | 结果 |
|---|---|
| 复盘 #19：覆盖 900 → **1500 字** | 与 v3 文字墙**净打平**（"双形态净打平第三次复现"）；结论写死「**停止堆密度**」 |
| v8：1500 → **850 字**（22px） | coverage 丢 **47 条 / 11 事件**，**块和只 −0.40**；但 D −4.90→−0.60 **+4.30**，净 +3.90 |
| 块稳定性 | 复盘原话「**要素块最稳，它靠时间/地点/背景面板，最少依赖全文流**」← 面板型槽位比全文流更稳 |

### 9.5 重构的因果链（下次同类赛照这个讲）

```
分区槽位化（6 槽，每槽标注服务哪一项判分）
 ├→ 长句/背景/时间地点各有独立位置，不截断、不挤名额 → elm/key 命中 ↑（内容门，真缺口）
 ├→ 字号/密度天然合理，不出现密排墙 → D 不触发（版式门，本届最大单笔）
 ├→ 数字面板/节点气泡/时间轴/结论框 → VQA 有答案锚点（问答门，已贴顶）
 └→ 顺带：专家视觉表现 16 分 + 成品能给人看（"投产意义"）
```

**Day0 就照 §2.2 官方样本形态做会不会更高？会，但原因不是"更好看"**：① D −4.90 那个坑根本不会出现，省下 v5a→v8 约 5 天排错；② 这 5 天全部可投到 elm/obj/key 抽取 A/B，而那才是 5.31 分缺口的所在。
⚠️ **不能把 +4.30 再加到 81.39 上**——终榜已经是 D=0，那笔收益早已兑现。净增量仍只能来自抽取层，量级 83~86，**推演、非实测**，且要过官方 ±1.5 噪声带 / >2σ 判据。

### 9.6 一句可带走的教训

> **把"把文字搬上图"当目标，就会做出只服务于代理指标的文字墙；把"让每个事实都有一个能被机器和人同时读到的位置"当目标，才会做出官方样本那种简报。**
> 这不是判断失误——是当时被「覆盖率」和「D」两个指标牵着走。可迁移规则见 [[参赛通用价值手册]] **I5**：Day0 先分账三条得分通道，逐字拆官方样本成品的槽位清单，本地指标一律标注"代理谁、验证过没有"。

### 10.2 关键区分：赛前预制 ≠ 运行时生成（本次最重要的一条）

| 对比项 | ✅ 预制静态素材 | ❌ 运行时生成整图 |
|---|---|---|
| 何时生成 | 备战期，人工逐张验收 | B 榜运行时现算 |
| 判分文字 | Pillow 确定性逐字写入 | 扩散模型写 → 错字漏字，五项同时掉分 |
| 复现门禁 | 两次 SHA256 一致（已实测） | 随机采样 → 破「可复现」 |
| 离线契约 | 不联网、不调模型 | 需模型／API，鲲鹏 ARM 装不下 → 0 分 |
| 无证据元素 | 只画文档确有的场景，可审 | 随机产出无依据元素 → 触红线 |

⚠️ **与 §3「A 路线必崩」不矛盾**：被否的是「让扩散模型在运行时生成整张图和文字」，**不是**「把生成图当静态背景素材」。两句话必须成对出现，否则下次备赛会误删整个配图层。可迁移条目见 [[参赛通用价值手册]] **I6**。

### 10.3 三类合规来源与红线

来源：① **主题场景图**（文档确有的场景，不虚构面孔／队徽／旗帜）；② **象征图**（抽象无品牌造型）；③ **算法绘制的数据图**（地图／路线／时间轴也算配图，官方 case-03 整幅就是地图）。
红线（规格书 §4.2／§6／§7.1）：不得加无证据关键元素；不得是可能被误认真实照片且无 AI 标识的图；不得未经允许使用外部数据（重大违规取消资格）；配图必须算法生成、不得手绘冒充；不同事件不得同图（判 0 分）；每个判分字仍由确定性渲染写入。专家「专业规范 7.5」含图标／图例／旗帜对应正确，不确定用中性图形。官网「不以装饰效果作为主要依据」——图服务分区与证据，不堆花边。§10 待确认项：加 AI 标识是否影响机器评分（图面多出文字）仍无官方答复。

**决策链断点**：`10-27「图化是靶心」→ 10-28「生图对 A 榜零贡献」→ 封存整批图`。中间少了 ① ② 两条的分账。
正确做法应是：**内容门不指望图，但版式门 / 封顶 / 专家 / 产品感仍要图**；把图当**静态素材**贴上去，文字照旧确定性渲染，两件事互不干扰——这正是 §10.2 的「预制 vs 运行时」区分，也是 `render_brief_v2.py` 在做的事。
⚠️ 归档里 `pipeline/assets/scenes/` 是**空目录**，那 50 张情景图没进归档 ⇒ 连"事后复用"都做不到了。**素材是资产，判死刑只判用法，不判文件。**

### 11.3 下次同类赛写进 Day0 checklist 的三条

1. **先分账再判死刑**：任何「某路线零贡献」的结论必须写明**对哪一条得分通道零贡献**，并逐条列出其余通道是否仍成立。禁止出现不带通道名的"判死刑"。
