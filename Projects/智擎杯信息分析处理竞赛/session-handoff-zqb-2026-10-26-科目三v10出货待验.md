## 1. 接手后修的两个 bug（对方未完成的部分）

### 1.1 崩溃级：字符类缺 `]`（对方编辑到一半被停的直接证据）
`extract.py` `_year_from_code` 里 `re.search(r"[舰船机型号艇弹", q)` **缺右括号**——
001/021/032/035 四篇只要引号串命中两位年份模式就抛 `PatternError: unterminated character

### 1.2 逻辑级：代号取年优先级过高、无窗口约束
- **038**：导语明写"2026年9月20日"，却被引号串"国防发展-2025"（展会名）抢成年份 2025；
- **035**：抗议事件（真值 2026-10-19，证据是"高市早苗于2025年10月21日就任…至10月21日执政满一年"）
  被背景语境里的演习代号"利剑27"错标成 2027。
- **修法**：① `_year_from_code` 只在**文首 120 字导语窗口**内找（代号是被报道事件自己的名字，
  必然随主日期出现在导语；035"利剑27"@340 字属背景）；② 判据重排为
  **算术自证 → 主日期近旁年份 → 导语代号 → 案例年 → 唯一年份 → 兜底**（原先代号排最前）。
- **验证**：001✓2026（代号）、016✓2026（生日算术）、038✓2026（导语日期）、045✓2026（周年）、
  012✓2026（兜底）。
- **残留 limitation**：035 仍判 2025（"执政满一年"不是"N周年"句式，现有算术规则不认；
  日期仍是 10月21日）——**与 v9 完全持平、无回归**，单篇影响 ≈0.06 分，按"不为单篇造规则"放过。

## 2. 本会话主改动：draw_elements 四槽位显式上板（render.py）

**动机**（调研结论 + 复盘 #9/#11 定案）：官方要素 10 分 = 主题2/时间3/地点2/背景3
（`eval/scorer.py ELEMENT_WEIGHTS_A`）；我方官方实测 5.38/10 只兑现 54%。v9 及以前

patch 交叉验证：判图侧 12~14px 是"这次读到下次读不到"的噪声源）。

**做法**：
- 四槽位全部"标签：值"结构；**主题/时间/地点值字号 22px，背景抬到 18px**（= 合并文本区下限）；
- **时间双形态**：变体串（年+最宽包络）之外，抽取原值不同再补一行（"归一化互相包含"级宽度，
  多形态不扣分）；
- **版面优先级**：主题 > 时间首形态 > 地点首形态 > 时间次形态 > 地点次形态，全部以
  `y_bg`（背景地板线）为上界。背景先锁 **2 行保底**——**地点两层级优先于背景第 3 行**
  （官方地点真值非"设施"即"行动"层级，少画一层=押错写法丢 2 分；背景真值最长 226 字本就不可能
  整段上图，判图按头部语义走，2 行与 3 行差别有限）；
- 016 目检通过：主题/时间/地点(双层级"·"续行)/背景四槽位清晰、字号达标、无越界。

- **并发会话改同一文件 = 交付级风险**：非 git 工作区里，"Edit 失败（file modified）"是救命信号
  而不是麻烦；发现即停、让用户拍板归属。→ **已写进《赛前核查协议》工具副作用表。**
- **"写到一半"的代码会同时有崩溃 bug 和逻辑 bug**：接手他人瞬态时，先跑全量门禁定基线，
  再逐 diff 审查，不要假设"看起来完整的函数"是对的。
- **要素面板教训（机器读图类赛题通用）**：字号 19px 在 1920 图上"人看着清楚"，但判图等效
  1365 宽后掉回 ~13.5px 临界区——"OCR 能读"≠"VLM 能读"，给 VLM 留的字号余量要比 OCR 大 30%+。
- **提交返回的 warning JSON 是新诊断通道**（10-26 晚发现）：每次提交必让用户全文保存；
  `failed_images` 名单 + 队均 D 值对账可验证"补核失败"假说。→ **已写进协议平台行为表。**
