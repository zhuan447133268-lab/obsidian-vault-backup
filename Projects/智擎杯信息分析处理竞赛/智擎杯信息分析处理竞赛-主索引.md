### 昇腾适配关键结论（详见技术备忘）
- **已纠偏**：网上"PyPI 无 aarch64 wheel、必须编译 torch_npu"的说法**已过时**——2026-10 实测 aarch64 wheel 齐全
- **推荐栈**：vLLM-Ascend v0.23.0.post1 + CANN 9.1.0 + torch 2.10.0 + torch_npu 2.10.0.post4 + Python 3.11/3.12
- **文生图（科目三）**：首选 `mindiesd`（PyPI 有 cp312 aarch64 wheel）；离线最稳是 vLLM-Omni + MindIE-SD 官方镜像
- **必须避坑**：`xformers` / `flash-attn` / `deepspeed` / `paddlepaddle` 在 aarch64 **无 wheel 或需编译**
- **最大风险**：现场无外网 + 只有 11-07 一天调试 → **必须提前打包**（镜像 tar + wheelhouse + 权重 + `run_infer.sh`）
- **两周适配路线**：见备忘第九章（10-15 锁版本 → 10-17 x86 跑通设备无关版 → 10-20 真机点亮 → 10-25 打包离线包 → 10-27 断网演练）
