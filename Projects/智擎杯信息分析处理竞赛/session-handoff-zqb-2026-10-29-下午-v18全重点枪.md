## 八、本轮新增避坑

33. **「块和天花板锁死」结论的盲区**：G-b3 证的是"装不下的新内容加不进去"，**没证"判分要求的旧内容装得下"**——余文略下面丢的 43 条重点就是反例。判死手术时要分清「加性」和「保底性」两种命题。
34. **判官 parse_readback 非贪婪正则 bug**：`\{.*?\}` 对嵌套 JSON 恒解析失败（parsed=0），但 raw 全文健康——本地 repair_rb.py 容错重解析绕过，别重跑判官。
35. **extract 被并行 session 改动**：所有"哪些事件截断/丢几条"的统计必须用**当前 extract 现算**，基于旧 build 或旧 extract 的清单会错（001 就是 stale build 假阳性 8 条丢失）。
36. **本地判官测不到核元/elm**：要素维度只有时间/地点/主题，elm 杠杆只能官方分回读验证，本地无 oracle 就别预烧枪。
37. **seq -w 1 50 在 Git Bash 补零到 2 位**（01..50），事件号是 3 位——批量构建要用 `seq -f "%03g"`，否则 50 个全静默失败。
38. **判官「重点」维度臂间噪声 ±0.5，不能当 0.01 级判据**：同一内容质量级别的两臂（v8臂 vs yaotu臂）逐事件可差 0.36→0.0（005）、0.625→0.5（046）。定判据时要看臂间复测方差，Δ<0.1 的差异全是噪声。判官能信的是「三键同向全升/全降」级别的信号（v18 对象/关系/核验齐升=内容可读性确实变多）。
