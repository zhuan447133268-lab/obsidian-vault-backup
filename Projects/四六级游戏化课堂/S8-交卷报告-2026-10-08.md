## 本轮踩坑与修正（自查出来并已修的缺陷）

1. **名单导入 500（真产品缺陷，已修 + 回归用例）**：教师端「初始密码留空 → 默认用学号」时，若学号短于 6 位，口令校验按**约定值**而不是**最终生效值**判定，导入直接 500。改为**按最终口令校验**、逐行给出原因，返回 `400 + CodeImportInvalid`（而不是 500）。提交 `e8d853f`，含回归用例。
2. **验收脚本自己的 SQL 口径错（假红一条）**：`98-baseline-after` 里"别人的单元/关/题数"期望 5/24/206、实际 9/24/206 —— 查出是脚本 `units` 分支写成 `FROM units c WHERE c.name NOT IN (班名)`（拿单元名去比班名，等于在数整库单元）。改为经 `classes` 回连过滤后，得 `17/128/4/24/206/845397835`，与跑前一致。**同时清掉排障遗留的两个临时班**（`S8排障班X` id 12、`S8排障班2` id 14 与其学生）——它们正是多出来的那 4 个单元的来源。
3. **拒绝回执被连接重置带走（真产品缺陷，已修 + 单测 + 链路双证据）**：学生越权调教师开关时，`step 07` 偶发 `ConnectionResetError [WinError 10054]`，导致后面"重新公开"那步没跑、连带 `step 08` 失败一条。复现是**30 发中 3 发**。根因：`middleware.RequireRole` 走 `response.Fail` 时**只写回执就 Abort、不读请求体**，Go http server 关闭连接时发 RST，把还没被客户端读走的回执一起带走 —— 回执"发了但没有保证送达"。修法：`response.Fail/FailWithData` 在写回执前 `drainBody`（`io.Copy(io.Discard, io.LimitReader(body, 1<<20))`，上限 1 MiB，防被超大 body 拖住）。修后**30 发 0 断连、30×403/40301**；链路探针（`07-hidden` 第 7 条）改为 **10 发断言 `{403:10, 40301:10, 断连:0}`**，并补了一条**确定性单测** `TestForbiddenReplyDrainsRequestBody`（断言拒绝后请求体确实被读到 EOF；**把修复回退掉这条必红**，打印"读了 0/28 字节"）。提交 `22f065d`。
4. **验收脚本的越权探针原先容不下断连**：修 3 之前，那一发断连会让 `api()` 直接抛异常、整步崩。已给 `api()` 加 `tolerate_reset` 分支（返回 `(0, 连接被重置…)` 并计入断言），**探针本身不再中断整链**。
5. **学生端"点了刷新按钮变成静默刷新"**：`@click="load"` 把 `MouseEvent` 当成 `silent=true`，于是手动点刷新不显示 loading、失败也不提示。改为 `@click="load()"`（提交见 `442efd5`）。
6. **浏览器取证的两次环境事实（非缺陷，但要记账）**：ZCode 内置浏览器在子代理里不可用（`Browser is not available in subagent`）→ 改用本机**真实 Chrome 390×844**；进地图时「🎯 选择备考目标」遮罩会挡住底栏 → 用真实 click 派发跳转；控制台只有 favicon 404×2。第 2 张（我的明细）因底栏 z-index 遮挡只能截到 `scrollTop=551`，"本周合计"行底部 3px 压在半透明导航下，**文字仍可读**（不修页面，只记账——这是原型也有的形态）。
7. **清点截图的老坑复发风险已提前堵住**：`step_09` 从"只要文件在"升级为 **7 条断言**（>20000 字节、PIL 390×844 ×4、MD5 两两不同、关闭态≠公开态帧）——S7 那次"清点脚本自己假绿"的教训没有在 S8 重演（本阶段首跑即全绿）。

- **D1 周榜实时算、结算只留痕**：`GET board` 每次实时算本周榜（保证学生刷新就看到最新分），周结算（周日 23:00）只做**归档与留痕**（`audit_log`）、不建赛季行、不改榜单数据。请评审确认"周结算 = 快照落痕、不冻结榜单"这个语义。
