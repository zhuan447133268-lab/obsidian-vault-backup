# 概念卡 · 课堂嵌入式游戏化设计

> 来源：四六级游戏化课堂项目（2026-09-17 苏格拉底式讨论沉淀）

## 一句话

把正课改造成游戏形式的闯关课堂，**不跟消费级学习 App 抢"学生自愿打开"**。

## 核心洞察

| 要素 | 课堂嵌入式方案的优势 |
|---|---|
| 流量 | 课表 = 强制流量，不需要获客 |
| 留存 | 教师监督 + 平时成绩 = 制度性留存，不需要上瘾机制 |
| 好玩门槛 | 只需超过"老师讲卷子"，不需要超过王者荣耀 |
| 场景 | 教室大屏 + 学生手机 H5，教师每节课收集闯关数据 |

反面教材：百词斩/多邻国模式的 C 端学习游戏是红海死路，别碰。

## 激励四件套（按优先级）

1. **计入平时成绩**（权重学校定）——制度抓手，最硬
2. **可开关的公开排行榜**——荣誉驱动；教师端可一键隐藏，防"差生公开处刑"；排名按努力值（XP）不按正确率
3. **关卡奖励**——解锁真题卷 / 小队宝箱
4. **福利商城**——XP 兑换**真实校园特权**（免早自习券/免早操券/双免卡/作业免检券）。核心逻辑：虚拟道具换不来忠诚，**制度内的小自由**才是大学生真正在意的硬通货。⚠️ 闭环前提：辅导员/教务认这个券

## 防弃坑设计

- 入学诊断 + 动态配关（不接受全国统一进度）
- 组队自愿，允许差生单人成队
- 每关 4~5 题 ≈ 5 分钟，靠"快赢"撑 45 分钟，不靠题海
- 每关之间给"闭幕仪式"（结算弹星+逐题总结），防答题疲劳
- 答错给安慰不给红字羞辱；错题自动收进复盘关变"回头收拾它"

## 复用场景

任何"高校课程游戏化"（思政课、计算机基础、考研公共课）都适用同一套骨架：诊断分层 → 微关卡 → 同辈组队互提醒 → 制度内福利兑换。
