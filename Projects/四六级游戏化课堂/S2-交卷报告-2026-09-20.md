## 新引入的决策 / 偏差（需评审确认）

1. **`enabled` 用 `*bool` 而非 `bool`**（`model.Question.Enabled`）。
   理由：GORM 建行会把「带 `default` 标签的零值字段」替换成默认值（`gorm/callbacks/create.go` 的 `isZero && DefaultValueInterface != nil` 分支），`Select(cols)` 也拦不住，`bool` 的 false 会被写成 true。指针的零值是 nil（交给数据库默认值），显式 false 原样落库。
   影响面：**只有列以外的 Go 类型**，MySQL 列定义与开发方案 §4 完全一致（03b 证据）；DTO 层对 nil 按已启用展示。
2. **题库导入的班级口径**：只往**已存在且属于该教师**的班级灌题，班级不存在 → 坏行报错（提示先去「学生名单」建班），不自动建班。理由：学生名单导入（S1）会建班，题库导入再建班会出现两个建班入口。（若要求题库导入也能建班，请拍板。）
3. **导入去重键**：同关卡下 `分套 + 题型 + 题干` 相同 → 跳过（幂等，可重复上传同一份表）。**不比答案**：答案改了重传不会更新已有题（要改题请用 PATCH 或删除重建）。此口径未写进任务书，请确认是否接受。
4. **关卡类型归一**：教师手填中文「词汇」与导入表里的「词汇」落同一个值 `vocab`；非法值 → `400`，空串按默认 `vocab`。理由：地图页按 type 分支渲染，混着中英文会出现一半命中、一半漏掉。
5. **建题未填 `difficulty` 按 1 存**（与表默认值、导入表留空一致），不再回 `400`。
6. **导入模板 18 列即契约**：`班级, 单元序号, 单元名称, 关卡序号, 关卡名称, 关卡类型, 限时(分钟), 是否Boss, 备考目标, 题型, 题干, 选项, 正确答案, 考点, 解析, 知识点, 难度, 启用`；限时表里是分钟（1~180），落库 `time_limit` 是秒；`answer_idx` 落 0 基下标序列（单选 `"0"`，多空 `"0,2,1"`）；选项用 `|` 分隔。
7. **原型转 xlsx 的三条转换决策**（转换脚本会打印，见 01 日志）：①复盘关的 10 道题原型只写「复盘」，按题干人工归到 vocab/grammar（规则表在 `internal/qbank/prototype.go`，缺规则会硬报错而不是猜）；②第 1/6 关关卡名两套不一致，**取四级版**（原型为准）；③原型无知识点数据 → `knowledge_tag` 全空。
8. **学生取题接口未做缓存/分页**：关卡内题量级个位数，按关卡一次取回；分页留到需要时再加（不属于本阶段验收）。
