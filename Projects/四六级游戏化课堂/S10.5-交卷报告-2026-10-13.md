### ② 到期 / 关闭：入口消失 + 40305（31 条，脚本 `section_lifecycle`）

### ③ 同卷发两个班：各打各的 + 班间 PK 判同卷（34 条，脚本 `section_cross_class`）

- 同一份卷发布到 **1 班 + 2 班** → 2 班拿到的是**副本**（独立单元行）；1 班先打，2 班进度不受影响（两边 `attempts` 各记各的）；卷名用第一份的（第二份发布不覆盖第一份的名字）。
- 2 班地图上是**两份卷共 4 个分关**（前一份整单元引用的 + 本次的），两关都能真打开答题。
- **PK 判同卷**：`pk/check` → `allowed=true, samePaper=true`（指纹逐位相同）；异卷对照组 → `samePaper=false` + `PK_PAPER_MISMATCH`；没有可对战套题 → `PK_NO_PAPER`；对手班没发布 → `PK_OPPONENT_NO_PAPER`。
- **互不见答案**：两个班取同一份卷，各自只拿到自己的题目与选项，**都不含答案/解析**。

### ④ 公共题库：权限边界 / 分享 / 引用（44 条，脚本 `section_bank_and_auth`）

- **分享前**：教师 B 的公共池 **0 道**；教师 A 的私有题在教师 B 的**私有池里不可见**（`source=mine` 只出自己的）。
- **分享后**：教师 B 的公共池里出现教师 A 的题，**每行带出题教师真名**（`ownerName=王一鸣`）与来源卷；教师 A 自己的题在私有池里也是真名但前端不重复署名（只在 `source=public` 时显示「出题：某某」）。
- **引用**：教师 B 从公共池引用「整单元」→ 组出一份**自己的**卷（教师 A 的卷与题一字未动，引用是复制）；引用出的卷可以正常发布、学生可打。
- **越权**：教师 B 关/删/改教师 A 的卷 → **404/40401**；教师 B 看不到教师 A 班的卷列表；**公共池里的题也不给出答案/解析**（分享的是题，不是答案）。
- **双栏角标**：站在任一 Tab，两栏角标都显示**另一栏真实条数**（实测「我的题库 26 / 教研室公共题库 11」两个方向都非 0）。
- **草稿编辑闭环**：勾 3 题 → 存草稿「编辑闭环用卷」→ 读回 **3 题（`source=mine` / `kind=paper` / `unitId` 正确）** → `rebuild` 200 仍是 3 题 / 草稿 → 删草稿 200（连单元行与分关一起带走）。
- **分享开关**：`share` 开/关两个方向都断言（开 → 他师可见；关 → 他师公共池里消失）；`GET /api/admin/papers?classId=` 的 `shared` 字段与开关一致。

### ⑤ 参数守卫 / 生命周期冲突 / 越权 / 保留带（56 条，脚本 `section_guards`）

- **缺 `classId`**：`POST /papers/:id/close`、`/reopen`、`DELETE /papers/:id`、`GET /admin/papers` 一律 **400**（写接口不替你猜班）。
- **已发布的卷不能重编题**（改了就不是同一份卷：PK 指纹会变）→ 409；**已发布的卷不能删**（学生作答要留档）→ 409；**草稿可以删**（回执 `deleted=true`，单元行与分关一并带走，不留孤儿）。
- **改卷名**：200 → 卷详情与学生端「本周练习」**立刻显示新名**（单元行本身也改名）；改成空名 → 400。
- **保留带**：教师用**内容维护口**（S2~S4 那套单元/关卡/题目接口）改卷单元 → **409**（文案指向组卷工作台）、删卷单元 → 409、改卷的分关 → 409、删卷里的题 → 409；用内容维护口把教学单元**建进保留带** → 400。
- **越权**：他师关我的卷 / 看我的卷 → 404；他师用我的 `unitId` 组卷 → 0 题（不给别人的题）。
- **分套约束**：一份卷不能混不同分套（四级/六级）的题 → 400「分套不匹配」。
- **上限**：题数 >100 → 400；卷名 >100 字 → 400；限时 >180 分钟 → 400。
- 守卫用例自建的临时草稿**用完即删**，不污染留库。
