教师 30 分钟上手 · 四六级游戏化课堂

一期试点版 · 2026-10-15 · 面向任课教师（看班级进度、组卷、课中大屏、核销、导出）

这套系统老师要干的事只有三件：看进度、发卷子、课上盯大屏。

其余（调关、核销、导出、排行开关）都是这三件事的补充动作，都在同一个顶栏里。30 分钟培训按「先跑通一遍，再回头讲细节」的顺序安排——老师在真机上亲手点一遍，比讲 30 分钟 PPT 有用。

教师端（本页入口在顶栏右） /t/ 看板 · 组卷 · 大屏 · 核销 · 校级 · 审计
学生端（手机，同 Wi‑Fi） /s/ 学生扫码/输网址打开，第一次登录要改密
本页永久地址 /teacher-training.html 可以打印，也能随时再看
30 分钟怎么用 登录与改密 九项功能 课前 5 分钟 课上应急 口径附录

一、30 分钟怎么用

讲师按这个节奏走；每段末尾都留了「让老师自己点一次」的时间，别替他点。

时间讲什么老师要亲手做的
0–3 分登录、首登改密用管理员发的初始密码登录 → 改密 → 用新密码再登一次
3–9 分班级看板：四张卡、趋势、错题知识点、学生明细切一次班、点开一名学生的「调关」看一眼（先别改）
9–14 分组卷工作台：选题池 → 组卷 → 发布组一份 5 题的小卷，发到自己的班（不设到期时间）
14–19 分课中大屏：口径、刷新间隔、全屏打开大屏 → 选刷新间隔「10 秒」→ 全屏一次 → 退出全屏
19–22 分兑换核销：检索 → 确认/驳回 → 留痕（有券就真核一张；没有就用学生端现场兑一张）
22–26 分校级汇总 + 审计日志 + 导出平时成绩表导出一次平时成绩表，在 Excel 里打开看列
26–30 分名单与口令：谁负责导入、口令忘了找谁；课前自检与应急把「课前 5 分钟自检」照着念一遍
培训当天用真账号真班级跑，别用演示数据。老师在真数据上看到的第一个数字，会成为他对这套系统的第一印象。

二、登录与改密（3 分钟，但必须讲清）

登录 /t/login

怎么点
浏览器打开教师端地址 → 填「账号（工号）」和「密码」→ 点「登 录」。
首登必做
第一次登录如果跳到「先改个只有你知道的密码」整页，说明你拿的是临时密码：填「当前密码」「新密码（至少 6 位）」「确认新密码」→ 点「修改密码」。
关键一步
改完密码后，系统会让你重新登录一次——这是设计如此（旧登录凭证在改密那一刻就作废了）。用新密码再登一次即可，不是出错。
口令规则：至少 6 位、两次要一致、不能和原密码相同。没有「必须字母+数字」这类复杂度要求——但请提醒老师别用学号。
教师端没有「忘记密码」按钮。忘了口令要走运维：由管理员在服务器上重置，重置后会生成一串临时密码（只在重置结果里显示一次），老师拿到后首登再改。所以：口令忘了找管理员，别自己试。

三、功能全览（九项，一项一张卡）

顶栏一共六个页面：班级看板 · 组卷工作台 · 课中大屏 · 兑换核销 · 校级汇总（仅校级账号可见）· 审计日志。九项功能里有三项（调关、排行开关、导出）就在看板页上，不单独占一个菜单。

功能 1看板 /t/

班级当前状态一屏看完：本周到课闯关率、人均通关数、班级平均 XP、预警学生，加一张近 8 周通关趋势、一张高频错题知识点、一张学生闯关明细表。

  1. 登录后默认落在看板，显示你名下第一个班。
  2. 点页面顶部的班级名切换班级（这里选的班，看板/组卷/大屏三页共用）。
  3. 看四张卡的数字 → 看趋势与错题知识点 → 在「学生闯关明细」里找需要关注的学生。
提示
明细表按本周 XP 排序，通关数是本周的、正确率是累计的（表头副文案写明了口径）。状态药丸「预警」＝连续 2 周闯关少于 1 关。
别踩
调关之后明细会刷新，但上方的数据卡和趋势不会跟着变——别以为没生效，切一下班或刷新页面即可。

功能 2校级汇总 /t/school

全校/全年级横向对比：班级数、学生总数、全年级人均通关、预警学生合计，加一张各班对比表（人数/到课率/人均通关/人均 XP/预警/排行榜状态）。

  1. 顶栏点「校级汇总」（只有校级账号能看到这个入口）。
  2. 点表头（人均通关 / 人均 XP / 到课率 / 预警）切换排序。
  3. 要最新数据点「刷新」——这页是打开时的快照，不会自动更新。
这页是只读：能看不能改。看到某个班「排行榜已隐藏」也改不了——排行榜开关只有该班任课教师本人能拨。

功能 3课中大屏 /t/live

课堂上投影用：① 参与率（已开始闯关 / 全班）② 进度分布（谁走到哪一关）③ 卡关热点 TOP3 ④ 实时易错题榜（答错即上榜）。

  1. 顶栏点「课中大屏」→ 点班级名切到本节课的班。
  2. 右上角选刷新间隔（「跟随服务端」「5 秒」「10 秒」「15 秒」「30 秒」「60 秒」），默认「跟随服务端」，一般是 10 秒。
  3. 点「⤢ 全屏」投影；课堂上想立刻看最新数据就点「⟳ 立即刷新」。
口径
所有数字都是今天 00:00 到现在；页面上永远不出现学生姓名（只有人数与题号），投影时不用担心点名。
别踩
刷新失败时页面不会黑屏，会保留上一帧并提示在重试——看见「仍在重试」别急着关页面。全屏被浏览器拦下时也不会打断，手动按 F11 即可。

功能 4组卷发布 /t/papers

三栏工作台：左边是你这个班已有的卷，中间是选题池（我的题库 / 教研室公共题库），右边是本次要组的卷。

  1. 顶栏点「组卷工作台」→ 选班级。
  2. 中间勾题（也可以点「整单元引用」一把把某个单元全选进来），题目会进右栏「这次的卷」。
  3. 右栏填「卷名」、选「发布形态」（课下练习 / 课内带打）、填「每关限时（分钟，0=不限）」，看一眼「自动分关预览」。
  4. 点「存草稿并发布」→ 在弹出的「发布到班级」里选目标班、到期时间（留空＝不设到期）→ 点「发布」。
提示
发布后学生端「本周练习」立刻出现入口；到期或关闭后入口消失，拿旧链接取卷也会被挡。想给自己留退路就先「存为草稿」，确认没问题再回左栏点「发布」。
别踩
① 一份卷最多 100 题；② 一份卷只能装一个分套（四级和六级的题不能混在一份卷里）；③ 分关是服务端按题型自动切的，老师不用排关；④ 已发布的卷不能再改题、也不能删——要改请新建一份（改了就不再是同一份卷，班间 PK 的「同卷」会对不上）。
跨班
一份卷发给多个班时，每个班各有一份同内容的副本，不是共用一份；要改得分别改。

功能 5核销 /t/redeem

学生把「福利券」页出示的券码给你，你在讲台前当场核销（或驳回）。每次动作都写操作留痕。

  1. 顶栏点「兑换核销」→ 输入框里敲券码（形如 C46-AB23CD45，大小写都可以）→ 回车或点「检索」。
  2. 核对结果卡：学生 / 班级 / 券种 / 兑换花费 / 学生当前余额 / 上次处理。
  3. 点「确认核销」→ 在确认框里再点一次「确认核销」。接着办下一个就点「清空，核销下一张」。
提示
券码字符集里没有 0 O 1 I L——看到这五个字符就是抄错了，让学生重新念一遍。
别踩
① 只看得到自己名下班级学生的券，别班的券查不到（页面会提示看不到学生名字就是不在你名下）；② 「确认核销」是终态，核销完不能改判驳回；③ 驳回只退券、不退积分；④ 被驳回的券，学生再拿出来给你时可以重新确认核销——这是正常的，不是重复操作报错；⑤ 页面下方「本次会话处理记录」只留最近几条且刷新就清，完整留痕在「审计日志」页。

功能 6调关（给学生放行/收回某一关）在看板页 /t/

学生卡在某一关打不动时，老师可以手动放行；学生刷得太快也可以收回。

  1. 看板 → 选班级 → 在「学生闯关明细」里找到那个学生 → 点该行的「调关」。
  2. 弹窗里按单元分组列出全部关卡，看清状态药丸（已通关 / 教师放行 / 教师收回 / 可玩 / 未解锁）。
  3. 点「放行」或「收回」。学生端刷新即可见。
调关只影响「能不能打这一关」，不改成绩与 XP；每次调关都会写审计日志。没题的关卡「放行」按钮是灰的（放行也拿不到卷）。

功能 7排行开关（公开排行榜）在看板页 /t/

控制本班学生能不能看到排行榜。差距拉得太大时关掉能保护后进学生，氛围恢复了再打开。

  1. 看板 → 先点班级名切到目标班 → 直接拨「公开排行榜」开关（立即生效，没有二次确认）。
开关作用于看板当前选中的那个班，切班后开关状态跟着目标班走。关闭后看板下方会提示「排行榜已对学生端隐藏（所有 XP 不可见）」。
必须是该班任课教师本人才能拨——校级账号在别的班上拨不动（这是权限设计，不是 bug）。

功能 8导出 看板页「📤 导出平时成绩表」· 审计页「导出 CSV」

平时成绩表（Excel）用于交教务；操作留痕（CSV）用于核销/调关的事后对账。

  1. 看板 → 选好班级 → 点「📤 导出平时成绩表」，浏览器直接下载。
  2. 审计日志页 → 选动作筛选 → 点「导出 CSV」。
平时成绩表
文件名形如「平时成绩_班级名_20261015.xlsx」，共 9 列：学号 / 姓名 / 班级 / 累计 XP / 本周 XP / 通关数 / 正确率 / 连续到课周数 / 预警标记。学号列是文本格式，Excel 打开不会变成科学计数法。
别踩
① 导出的是当前选中的那个班，没有「导出全部班」；② 列是固定的，不能自选；③ 审计页的 CSV 只导当前页（默认一页 20 条），要全量得逐页导。

功能 9名单导入 不在教师端 · 服务器侧操作

把班级学生名单（班级 / 学号 / 姓名）一次性灌进系统。这一步教师端没有界面，由运维/管理员在试点机上执行，教师只需负责核对结果。

  1. 老师提供名单 Excel（可照 data\班级学生导入模板.xlsx 填，或直接用教务导出的名单）。
  2. 运维在服务器上执行导入命令，指定这份名单属于哪位教师。
  3. 导入完成后，老师登录看板，确认班级人数与「学生闯关明细」名单一致。
口径
「初始密码」一列可以留空——留空时初始密码就是学号，学生首登必须改密。名单里没写过的班级会被自动创建并挂到这位教师名下。
别踩
① 学号是全库唯一的，名单里重复、或库里已存在都会按行报错；② 只要有坏行，整份名单都不会入库，改完重新导入即可（不是「导一半」）；③ 导入的学生第一次登录必须自己改密。

四、课前 5 分钟自检

上课前站在讲台上照着点一遍，1 分钟就能过完，能挡掉 90% 的课上意外。

  • 教室电脑能打开教师端，账号能登录（不用首登改密）。
  • 课中大屏能打开、班级选对、全屏成功（按 F11 也行）。
  • 本节课要发的卷已经在学生端「本周练习」里能看到（自己用学生账号看一眼最稳）。
  • 手机连着教室同一 Wi‑Fi、能打开学生端地址。
  • 知道今天要核销的券是哪种（手里有没有实物券/截图页）。
  • 投影电脑的浏览器缩放是 100%（大屏排版按 100% 设计）。

五、课上应急

现象先这么办
学生登录不了先确认是新学生还没改过初始密码（首登会强制改密）；再看账号是不是输错（初始密码可能等于学号）。仍不行→告诉运维重置口令。
学生看不到今天要发的卷检查卷的状态：是不是「草稿」（没发布）、是不是已到期/已关闭、是不是发给了别的班。
大屏数字不动看页面上的「更新于 … · n 秒后刷新」是否在倒数；点「⟳ 立即刷新」。口径是「今天」，昨晚的数据今天不会出现。
大屏刷新失败提示页面保留了上一帧，不用重开；等下一轮自动重试。连续失败再叫运维看服务是否活着。
券码查不到核对是否 C46- 开头、有没有 0 O 1 I L（不会有这五个字符）；确认该学生在你名下班级。
券码提示已被处理说明这张券已经核销或被驳回过——「已核销」不能改判；「已驳回」可以再确认一次。
某学生卡关打不动看板找到该学生 →「调关」→ 放行该关。放行只解锁，不改成绩。
班级成绩不方便公开看板拨「公开排行榜」开关关掉（对当前班立即生效，下次想公开再拨回来）。
全屏按钮没反应浏览器可能拦了全屏请求：直接按 F11（或投影软件自己的全屏）。不影响数据刷新。

六、附：老师常问的口径

词含义（老师视角）
XP闯关答题挣的经验值。看板上的「本周 XP」「累计 XP」都来自同一本流水账，两处不会对不上。
通关某一关的题目全部答完并通过。看板明细里的「通关」是本周的通关数。
到课闯关率本周有闯关记录的学生占全班的比例。
预警学生连续 2 周闯关少于 1 关的学生（看板明细里带「预警」药丸）。
卡关热点今天失败次数最多的关卡（爱心扣完判失败才会计入）。
易错题榜今天答错的人次最多的题目，答错即更新，只显示题号与人数。
积分 / 券积分是学生用在商城兑换的东西，券是兑换出来的凭证，需要老师核销才算数。核销与驳回都不退积分。
首刷第一次通过某一关（首刷给的分最多，之后复习性重打只给基础分）。
