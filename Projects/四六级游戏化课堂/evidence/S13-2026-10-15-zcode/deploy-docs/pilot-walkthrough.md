# 试点真机走查（S13 验收③：iOS + Android 各走完一关）

> 这份文档解决一件事：**让学生/老师的真手机把一关从头走到尾**，并留下可复查的截图。
> 验收要的是「真机」，所以跑在前面的准备（防火墙、地址、口令）必须一次做对，别到课堂上再折腾。

## 0. 走查前必须满足的三条（缺一条手机就打不开）

| # | 条件 | 怎么确认 |
|---|---|---|
| 1 | 试点栈在跑 | `Get-Process cet46-server,nginx` 两个都在；`curl http://127.0.0.1/api/health` 回 `"code":0` |
| 2 | 手机与试点机**同一局域网** | 手机连的是同一台 WiFi（试点机当前 `192.168.0.238`，WLAN） |
| 3 | **防火墙放行 80 端口**（管理员权限，做一次即可） | 手机能打开 `http://192.168.0.238/s/` 就说明放行了 |

第 3 条的命令（**必须以管理员身份**打开 PowerShell，普通权限会报「请求的操作需要提升」）：

```powershell
netsh advfirewall firewall add rule name="cet46-web" dir=in action=allow protocol=TCP localport=80
```

> 为什么单独拎出来：本机 WLAN 的网络配置文件是 **Public**，Windows 防火墙对 Public 的入站默认拦截，
> 而默认没有任何覆盖 80 端口的放行规则（已用 `Get-NetFirewallRule` 逐条核对过）。
> 也就是说：**不执行这条命令，手机的请求根本到不了 Nginx**——不是应用问题，是网络层就断了。

## 1. 地址

| 端 | 地址 | 谁用 |
|---|---|---|
| 学生端（手机） | `http://192.168.0.238/s/` | 学生手机浏览器 / 微信内置浏览器 |
| 教师端（老师电脑） | `http://192.168.0.238/t/` | 讲台电脑 |
| 教师培训页 | `http://192.168.0.238/teacher-training.html` | 培训时投屏 |

（`192.168.0.238` 是试点机当前的 WLAN 地址。换网/换机器会变，用 `ipconfig` 看当前 IPv4。）

## 2. 走查步骤（每台手机约 5 分钟）

### iOS（Safari + 微信各走一遍最稳）
1. 打开 `http://192.168.0.238/s/` → 用**学号**登录（初始密码可能等于学号）。
2. 首登会强制改密 → 改成自己记得住的（≥6 位）→ **改完要重新登录一次**（旧凭证失效是设计如此）。
3. 地图页：**上下滑动**看关卡列表是否跟手；点进第一关。
4. 答题页：**左右滑动/点击选项**（触摸手势重点看这个），做完全部题目 → 交卷。
5. 结算页：看分数/XP 是否正常弹出；确认按钮能点。
6. 截图 4 张：登录页 / 地图页 / 答题页（含选项选中态）/ 结算页。

### Android（Chrome + 微信）
同上 1~6。Android 额外确认：返回键行为正常（不要一按就退出登录）、键盘弹出时输入框不被遮住。

### 微信内置浏览器（两个平台都要试）
在微信里发给自己一个链接再点开，或直接用微信「扫一扫」扫网址二维码。重点：
1. 页面能开、不白屏；
2. 登录/答题/交卷全链路能走完（微信 WebView 的存储与跳转行为跟系统浏览器不同，这是最容易出问题的一环）；
3. 若显示异常，记录微信版本与机型 —— 这类问题要单独记，不要当成手机坏了。

## 3. 看什么（真机才能验的四件事）

| 项 | 合格表现 | 出问题长什么样 |
|---|---|---|
| 触摸拖拽/点选 | 点选项立即有选中态，不误触相邻项 | 需要点两次、选中态跳位 |
| 滚动性能 | 地图页/明细列表滑动跟手，不掉帧 | 滑动时白屏、卡顿明显 |
| 首屏与安全区 | 顶部标题不被刘海/状态栏遮；底部按钮不贴到手势条 | 内容被裁掉、按钮点不到 |
| 键盘弹出 | 输入框自动上移，可见 | 输入框被键盘盖住，看不到自己打的字 |

## 5. 打不开时按顺序排查

1. **手机能连 WiFi 但打不开页面** → 第 0 节的防火墙命令没执行（最常见）。
2. **本机能开、手机不能开** → 同上；再确认手机没连到访客网络（访客网通常隔离内网设备）。
3. **页面开了但登录报错** → 看 `logs\server.log` 有没有对应请求；没有请求说明卡在 Nginx（看 `nginx\logs\error.log`）。
4. **登录后立刻被踢回登录页** → 正常现象，见「走查步骤 2」（改密后旧凭证失效，用新密码重登）。
5. **学生看不到关卡** → 确认该生所在班级已导入单元/关卡（题库导入是否做完）。
