# 技巧卡 · edge-tts 双音色音频拼接

> 来源：四六级游戏化课堂听力题音频（2026-09-17 实测可行）

## 场景

网页 demo 需要"真人感"对话音频（男一句女一句），但不想引入音频文件依赖或付费 TTS。

## 做法

1. 本机 `pip install edge-tts`（微软神经语音，免费，英文音色质量高）
2. 对话按说话人拆句，男声行用 `en-US-GuyNeural`、女声行用 `en-US-AriaNeural` 分别合成单句 mp3
3. **按二进制顺序直接拼接** `f.write(part1); f.write(part2)`——MP3 帧自包含，浏览器解码器会自动重同步
4. 验证：`<audio>` duration ≈ 各句之和即成功（本例 10.8s / 7.4s 均正常解码播放）

## 注意

- 拼接处可能有轻微间隔感，demo 够用；正式产品要自录或买授权
- 跨网络合成时偶发单句失败，脚本里加容错重试
- 浏览器自动播放政策：`play()` 必须在用户手势里；自动化测试工具（JS click）没有用户激活会吃 `NotAllowedError`，要用 CDP 真实鼠标事件验证

## 前端配套状态机

播放条四态：`▶ 播放音频` → `⏸ 播放中，点我暂停` → `▶ 继续播放` → `🔁 重播`。
坑：`onpause` 会在 `onended` 之后触发，会覆盖"重播"按钮文案——`onpause` 里先 `if(ended) return`。
