## 怎么跑

```
cd "D:\03-个人文档\学习空间\lampwake"
python -m http.server 8000
```

浏览器开 `http://127.0.0.1:8000` → 点「开始下潜」。
也可以**直接双击 `index.html`**：全部是相对路径 + 普通 `<script>`，没有 `fetch`、没有 ES module，`file://` 下能跑（已实测）。

## 玩法

- **5 波**（`CFG.maxWave = 5`），每波鱼群散进礁盘，逐波变快
- **五种生物**：沙丁群（远看整齐、一受惊就炸群）、河豚（正面硬，鼓起来更难打）、海鳗（嗅到气味贴身突袭）、水母（随水漂，碰到会麻痹）、鲨鱼（绕圈后直线冲撞）
- **三把武器**：鱼叉枪 8/32（主武器）、气泡震弹 6/24（范围）、电击叉（无限、近距离）
- **两条命脉**：氧气与体力，任意一条见底就上不去了
- **操作**：WASD 游动 / 空格上浮 / Ctrl 下潜 / Shift 冲刺 / 左键攻击 / R 换弹 / Esc 暂停
- **界面**：左上 WAVE + SCORE，中上 DEPTH，右上鱼群剩余与计时

## 技术要点 / 踩过的坑

> [!warning] 复现这个世界，必须先固定随机数
> 珊瑚礁、礁石、海草的位置是**页面加载时**用 `Math.random()` 建出来的，早于任何运行时注入。想录出可复现的画面，必须在 `<head>` 里、在所有游戏脚本之前就把 `Math.random` 换成种子函数（录制时用 mulberry32，seed `20260826`）。否则每次刷新礁盘都不一样，"上一版构图"永远找不回来。

> [!warning] 视线俯仰同时是移动方向
> `updatePlayer` 里 `fwd = (-sin(yaw)cos(pitch), sin(pitch), -cos(yaw)cos(pitch))`——**低头瞄准就会往下沉**。脚本化镜头时不能只压 pitch，得把高度单独交给 `space`/`keyc` 控制（录制里用了 6.0–7.4 米的高度带 + 一个软地板护栏）。

- **没有触屏**：全库零 `touchstart`/`pointerdown`，手机打开只能看画面
- **单文件 135 KB**：所有逻辑在一个 IIFE 里，改玩法只能翻 `js/game.js`；好处是零构建、零依赖
- **可脚本化**：`window.__game` 暴露了 `player / camera / scene / enemies / state / cfg / start / spawn / fire / tp / look / cool / frame / render`，录制和验收都靠它

## 已知限制

- 手机不能玩（无触屏控制）
- 深水渔场只有 5 波，通关约 3–5 分钟；没有存档与关卡编辑
- 音频只是 WebAudio 程序音效，不是配乐；成片里的配乐是另外合成的（`music.py`，纯 stdlib）
