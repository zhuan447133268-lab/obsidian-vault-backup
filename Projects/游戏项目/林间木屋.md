## 玩法

- **五阶建造**（`STAGES`，造价见括号）：

  | 阶段 | 名称 | 消耗 |
  |---|---|---|
  | 01 | 支架与木台 | 木 8 · 石 3 |
  | 02 | 铺设地板 | 木 10 |
  | 03 | 立起木墙 | 木 12 · 石 4 |
  | 04 | 盖上屋顶（带冒烟的烟囱） | 木 10 · 石 3 · 藤 2 |
  | 05 | 灯与栏杆（含木梯） | 木 8 · 石 3 · 藤 6 |

- **操作**：WASD 走 / 鼠标看（指针锁定，也可拖动）/ E 采集与建造 / 触屏有摇杆
- **世界**：值噪声地形、实例化森林（树/草/蕨/石/花/蘑菇/芦苇）、池塘、飘落树叶、萤火虫、鸟、云、远山
- **昼夜**：一天 2000 秒（约 33 分钟）走完，慢慢逛刚好赶上一场日落
- **画质三档**：流畅 / 均衡 / 精致，另可单独调像素比、阴影、视距、植被密度、粒子、帧率上限、时间流速、灵敏度、音量——全部存进 `localStorage['forest-nook']`
- **完成演出**：第五阶搭完自动播放环绕镜头，最后把玩家放到阳台上（`state.complete` + `state.cinematic`）

## 技术要点 / 踩过的坑

> [!warning] 自定义天空必须自己补色彩管线
> 天空是自定义 `ShaderMaterial` 时，片元里必须带上 `#include <tonemapping_fragment>` 和 `#include <colorspace_fragment>`，否则天空会比同色号的物体暗一倍，远山和云看起来像贴在天上的贴纸。

> [!warning] 远山超出 fog 会被涂白
> 远山在 `fog.far` 之外，会被雾整片冲成白色。做法：材质 `fog: false`（但保留 tone mapping），并且每帧按天空调色板重新上色，才不会和天空脱节。

> [!warning] 夜间实例化植被会糊成黑块
> Lambert 材质在夜里接近全黑，实例化的草和树叶连成一片。给一点极小的 `emissive`（每通道 0.01–0.02，按夜晚程度缩放）就能保住轮廓。

> [!warning] 完成演出要按墙钟时间推进
> 环绕镜头如果用累加的 `dt`，标签页被节流或跑在无头环境里时，9.5 秒的演出会被无限拉长。用 `performance.now()` 判时间才稳。

- **近处落叶会变成大木板**：离相机 3 米内的树叶粒子会被放大成板子，得按距离把尺寸压到接近 0
- **可脚本化**：`window.__game` 有 `state / cfg / player / camera / scene / world / treehouse / start / teleport / look / give / gatherAll / build / interact / setTime / setQuality / progress / dbg / capture / fps`；`window.__errs` 收集运行时错误（本次实测 0 条）
- `__game.capture()` 会 `render()` 后返回 `toDataURL`，是导出干净画面（不含 HUD）最方便的路子

## 已知限制

- 完成之后没有"下一件事"：搭完树屋就结束了，没有第二栋、没有任务线
- 没有存档：只存设置项（`forest-nook`），建造进度不保存，刷新从零开始
- 植被密度与视距拉满时对集成显卡不友好，得靠「流畅」档
