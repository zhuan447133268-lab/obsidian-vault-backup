## 现在能玩什么（都是已实现、已实测的）

一条完整经营循环：

**客人从左边雪地里走过来 → 迎客 → 走到木门前（门等到人到了才开）→ 进屋落座 → 小二上茶 → 递菜单 → 客人点菜 → 进后厨 → 墙上点菜卡下锅 → 看着锅调两段火 → 出锅 → 端进屋里 → 收铜钱 → 送客**

- **四道菜**：桂花糖水蛋（小火→中火）、雪菜豆腐汤（中火→小火）、炭炙河鱼（大火→小火）、酥炸山蔬（大火→小火）
- **火候是活的**：下锅后按段判定——火对了金色熟度条往前走；火大了红色糊度条涨，涨满就糊锅、回炉重选、扣客人耐心；火小了熟度不动，牌子提示"锅还没热透"。火档随时可点，左右墙上的小火/中火/大火一直亮着当前档
- **客人有耐心**：等太久会走；结账按 `20 + 耐心/3` 给铜钱
- **店铺升级**：客房 +1 间（最多 4）／新锅灶／汤池，三样都能买，但 2026-11-27 时**房间里只有 2 个位置**（`S.rooms = Array(2)`）
- **头像系统**：6 套中式预设 + 面相/肤色/衣色/发式/须眉/随身自定义，昵称存 `localStorage['ryokan.me']`，坐进屋里的是自己这一身
- **三处场景**：店外全景（含汤池、两盏挑灯、雪与灯影）、客房、后厨

## 技术要点 / 踩过的坑

> [!warning] 走路不能用指数缓动
> 原来是 `x += dx * .02`——离目标越远越快、越近越慢，还跟帧率挂钩，看起来就是"贴图平移/飘"。现在改成定速行进（`WALK_SPD = 198`、`STEP_LEN = 84`），步相由**走过的距离**推出来，脚交替迈、袍摆提起、落脚扬雪；并且**门改成等人走到了才开**（原来人刚起步门就自己开，最假的就是这里）。

> [!warning] 火候原本是盲猜
> 改之前后厨墙上那四张菜卡不带任何火候信息，菜牌只在下单那一刻写过一次——所以"选小火/中火/大火"不是判断，是猜，猜错还要糊锅扣耐心。现在按用户选的"下锅后看着锅调火"重做：`RECIPES[x].plan` 是分段火候，下锅后逐段判定。

> [!warning] 底图改过一定要换缓存版本号
> `loadAssets` 里 `const V = '?v=…'` 是给 `bg.png` 用的。改了 `assets/bg.png` 却不换这个版本号，浏览器会拿旧图，现象是"代码明明改了，画面上还是旧东西"（做灯笼时第一遍就栽在这，截图上旧灯笼还亮着）。

- **改底图的记录**：2026-11-27 用 `cv2.inpaint(TELEA)` 把烘在 `bg.png` 里的两盏旧灯笼连同插杆抹掉了（掩膜＝灯体 `(r-b>25 & luma<178)` + 窄带杆子 `luma<118 & r>b`，膨胀 2 次）。原图备份在 `%TEMP%\ryo_bg_original.png`，要还原就从那拷回来
- **`render()` 只刷 HTML 操作栏/日志，不画 canvas**：验像素必须调 `__test.step(1, 16.7)`，否则会以为"改了颜色没生效"
- **canvas backing 尺寸 = 视口**：世界坐标 1920×1080，截图/取像素前都要乘 `k = canvas.width / 1920`
- **人物是两套画法**：`drawHead` 一套给头像/坐姿/站姿共用；头盖曲线控制点必须给到 `-1.40r`（给到 `-1.20r` 会让头顶露一圈皮肤，看着像剃度），发际线与眉线别顶在一起（会读成发箍）

## 怎么验证（新 session 照着抄）

页面挂了 `window.__test`，后台标签的 rAF 会被节流，所以都用虚拟时钟推帧：

```js
__test.start(); __test.seat();
__test.step(430, 16.7);          // 等人走到门口 + 开门 + 进屋
__test.tea(); __test.ask(); __test.menu(); __test.order();
__test.kitchen(); __test.step(90, 16.7);
__test.pick('炭炙河鱼'); __test.fire();
__test.heat('高'); __test.step(60, 16.7);     // 按段换火
__test.out(); __test.step(80, 16.7); __test.serve();
```

`__test.stats()` 看状态，`window.__errs` 看运行时错误（正常应为空数组）。
真相在 canvas 里：`tab.screenshot()` 会拿到过期的合成帧，要证据就用 `canvas.toDataURL()` 自己裁。
