## 3. 设计原则

1. **移动优先**：学生端主要在手机钉钉内置浏览器使用，所有页面先做移动端适配。
2. **角色首页分离**：不同角色登录后进入不同首页，互不干扰。
3. **路由权限显式化**：每个路由配置 `meta.roles`，路由守卫统一校验。
4. **Soft Clay 风格**：圆角卡片、柔和阴影、奶油色/莫兰迪配色、微交互反馈。
5. **本地账号登录优先**：第一阶段不使用钉钉 JSAPI，登录页为账号密码输入。

## 4. 布局结构

```
App
├── Layout
│   ├── MobileLayout（移动端底部 Tab）
│   │   ├── TabBar
│   │   └── RouterView
│   └── AdminLayout（管理端侧边栏 + 顶部栏）
│       ├── SideMenu
│       ├── TopBar
│       └── RouterView
├── BlankLayout（无导航：登录页、考试页、CAS 回调）
└── RouterView
```

### 4.1 MobileLayout

- 底部固定 TabBar，最多 5 个入口。
- 适用于学生、教师移动端操作。

### 4.2 AdminLayout

- 左侧折叠式侧边栏，顶部显示当前用户和面包屑。
- 适用于学校管理员、学院管理员、教师管理后台。

### 4.3 BlankLayout

- 无导航、无菜单，全屏页面。
- 用于登录、考试作答、CAS 回调、证书展示。

## 9. 路由守卫规则

### 9.1 全局前置守卫

```typescript
router.beforeEach(async (to, from, next) => {
  const authStore = useAuthStore();

  // 1. 未登录且访问非登录页 → 跳转登录
  if (!authStore.isLoggedIn && to.path !== '/login') {
    return next('/login');
  }

  // 2. 已登录且访问登录页 → 跳转角色首页
  if (authStore.isLoggedIn && to.path === '/login') {
    return next(authStore.homePath);
  }

  // 3. 角色权限校验
  if (to.meta.roles && !to.meta.roles.includes(authStore.role)) {
    return next('/403');
  }

  // 4. 加载用户信息和数据范围（如果尚未加载）
  if (authStore.isLoggedIn && !authStore.userLoaded) {
    await authStore.fetchMe();
  }

  next();
});
```

### 9.2 路由元信息

```typescript
interface RouteMeta {
  title: string;                // 页面标题
  layout?: 'mobile' | 'admin' | 'blank';
  roles?: UserRole[];           // 允许访问的角色
  requireAuth?: boolean;        // 是否需要登录
  keepAlive?: boolean;          // 是否缓存
}
```

### 9.3 角色可访问路由映射

| 角色 | 默认可访问前缀 |
|------|----------------|
| STUDENT | `/student`, `/profile` |
| TEACHER | `/teacher`, `/profile` |
| COLLEGE_ADMIN | `/college-admin`, `/teacher`, `/profile` |
| SCHOOL_ADMIN | `/school-admin`, `/college-admin`, `/teacher`, `/profile` |

> 一人多角色时，取最高权限角色决定首页和菜单。

## 12. Axios 封装

### 12.1 请求拦截器

- 自动携带 `X-CSRF-Token`（主方案）
- 自动携带 `Authorization: Bearer <token>`（备选方案）
- 统一添加 `Content-Type: application/json`

### 12.2 响应拦截器

- `code === 0`：正常返回 `response.data.data`
- `code === 1002`：触发 Token 刷新，挂起后续请求
- `code === 1001 / 1003 / 1004 / 1005 / 1006`：跳转登录页
- `code === 1100 / 1101`：跳转 403 页
- 其他错误：统一 Toast 提示

### 12.3 并发刷新保护

```typescript
let isRefreshing = false;
let refreshQueue: Array<(resolve: Function) => void> = [];
```

## 15. 已确认事项

### 确认内容（2026-07-08）

1. **管理端移动端适配**：第一阶段不做专门适配，管理端按 PC 浏览器设计，样式保持响应式即可。
2. **主题色**：使用 Soft Clay 默认配色（雾霾蓝 + 奶油色）做 demo，上线前如需贴合学校 VI 再通过 CSS 变量批量替换。
3. **左侧菜单状态**：默认展开，小屏幕自动折叠，记忆用户上次状态。
4. **表格组件**：管理端使用 Vant 的 List/Cell + 简单自定义表格，不引入 Element Plus / Ant Design Vue 等桌面端表格库。
5. **文件上传限制**：基础数据导入文件最大 10MB，仅支持 `.xlsx` 格式。
