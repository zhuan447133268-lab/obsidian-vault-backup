# 实验室准入考试系统 - 需求确认文档

> 状态：待业务方确认

## 1. 项目背景

| 项目   | 说明                           |
| ---- | ---------------------------- |
| 触发场景 | 哈尔滨剑桥学院 2026 年实验室安全准入考试      |
| 产品定位 | **通用在线考试平台**，不是一次性工具         |
| 核心目标 | 当前满足实验室准入考试需求，后续其他部门考试也能复用   |
| 题库来源 | 甲方/教务老师提供，已提供 9 个 Excel 题库文件 |

> 关键定性：强丹明确要做成平台化、可复用的考试系统。

---

## 2. 已确认需求

### 2.1 题库管理

- 支持创建**多个题库**，不同部门/学院对应不同题库。
- 支持通过 **Excel 模板导入**题库。
- 当前已提供 9 个题库文件，结构统一。

### 2.2 题库数据格式（已读取确认）

| 字段 | 说明 | 示例 |
|---|---|---|
| 题型 | 单选题 / 多选题 / 判断题 | 单选题 |
| 题干 | 题目内容 | 造成触电事故的直接因素是（ ） |
| 答案 | 正确答案 | 单选：A；多选：A\|B\|C |
| 标签 | 分类标签 | 通用实验室安全题目 |
| 分数 | 每题分值 | 2 |
| 选项 A-E | 候选答案 | 电流流过人体、电压高低…… |

**客观事实核对**：
- 9 个文件均只有客观题，**无简答题、无实操题**。
- 每个题库约 250 题：单选 100、判断 100、多选 50（通识教育学院多选 51）。
- 文件路径：`D:\2026准入题库\

### 2.3 考试与组卷

- 支持自定义：**题目数、总分、考试时长**。
- 考试时间到**自动交卷**。
- 答题过程**限制时间**，超时强制提交。
- 考试过程中**不允许切屏**（需前端检测 + 后端记录）。
- 考试次数由老师/管理员**自行配置**。

### 2.4 权限控制

- 支持设置**谁可以参加考试**。
- 具体粒度待确认（见第 3 节）。

### 2.5 部署与技术栈

| 项目 | 当前结论 |
|---|---|
| 部署环境 | 阿里云服务器 |
| 技术栈 | 无偏好，待技术方案确认 |

## 3. 待确认问题清单

以下问题需要业务方/强丹确认，**确认后才能进入开发**。

### 高优先级（影响核心功能设计）

1. **多选题判分规则**
   - [ ] 方案 A：必须全对才得分（推荐，准入考试常用）
   - [ ] 方案 B：少选按比例得分
   - [ ] 方案 C：少选得部分分，多选/错选不得分

2. **组卷规则**
   - [ ] 随机抽题组卷，还是固定试卷？
   - [ ] 如果随机，每个人试卷是否一样？
   - [ ] 是否按题型比例组卷？（例如：单选 50%、判断 30%、多选 20%）
   - [ ] 是否支持按标签/知识点抽题？

3. **及格线 / 通过标准**
   - [ ] 满分多少？（按当前每题 2 分，如果抽 50 题则满分 100）
   - [ ] 多少分算通过？（例如 60 分或 80 分）
   - [ ] 通过后是否颁发证书/准入资格？

4. **权限控制粒度**
   - [ ] 按部门/学院批量授权？
   - [ ] 按班级/课程授权？
   - [ ] 按具体人员名单授权？
   - [ ] 是否需要学生自己注册账号，还是由管理员导入名单？

5. **登录方式** ✅ 已确认
   - [x] **对接钉钉统一身份认证**（2026-06-29 确认）
   - [ ] 账号密码登录？
   - [ ] 通过学号/工号登录？

### 中优先级（影响产品体验）

6. **成绩展示**
   - [ ] 考完后立即显示分数？
   - [ ] 是否显示正确答案和解析？
   - [ ] 只显示通过/不通过，还是显示具体分数？

7. **考试界面**
   - [ ] 单题切换模式（一题一题做）？
   - [ ] 整卷展示模式（全部题目一起展示）？

8. **历史记录**
   - [ ] 是否保留每次考试的完整答题记录？
   - [ ] 老师是否可以查看学生的每次考试详情？

9. **切屏处理**
   - [ ] 切屏几次后强制交卷？（例如 3 次）
   - [ ] 切屏是否记录并提醒老师？

10. **考试次数配置**
    - [ ] 是"总共允许考 N 次"，还是"每天/每月允许考 N 次"？
    - [ ] 次数用尽后，是自动锁定还是管理员手动开通？
    - [ ] 不同考试是否可配置不同次数？

11. **题库更新**
    - [ ] 考试进行中能否修改题库？
    - [ ] 已生成的试卷是否受题库后续修改影响？

12. **多学院题库关系**
    - [ ] 通用安全题目是否所有学院都要考？
    - [ ] 学院专业题库是否只给对应学院学生考？
    - [ ] 是否支持"通用题 + 学院题"组合成一份试卷？

## 4. 建议技术方案（初步，待确认）

| 层级 | 推荐方案 |
|---|---|
| 前端 | Vue 3 + Element Plus 或 React + Ant Design |
| 后端 | Python + FastAPI 或 Node.js + NestJS |
| 数据库 | MySQL / PostgreSQL |
| 缓存/会话 | Redis |
| 部署 | Docker + 阿里云 ECS |
| 文件存储 | 阿里云 OSS 或本地存储 |

**选型理由**：
- 团队无技术栈偏好，优先选择开发效率高、生态成熟的方案。
- Python + FastAPI 适合快速开发、自动文档生成。
- Vue3 + Element Plus 适合后台管理系统。
