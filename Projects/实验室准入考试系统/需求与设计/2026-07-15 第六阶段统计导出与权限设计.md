# 第六阶段：统计导出与权限设计文档

## 1. 目标

实现三级角色（学校管理员 / 学院管理员 / 教师）查看权限范围内的考试统计数据，并支持 Excel 成绩导出。

## 2. 数据范围规则

基于现有 `DataScopeService` 的 `ALL / COLLEGE / CLASS / SELF` 四级范围：

| 角色 | 数据范围 | 可查看统计 |
|---|---|---|
| 学校管理员 | ALL | 全校 overview + 各学院 breakdown |
| 学院管理员 | COLLEGE | 本院 overview + 各专业/班级 breakdown |
| 教师 | CLASS | 本班学生考试状态列表 |
| 学生 | SELF | 只看自己（本次第六阶段不提供统计入口） |

### 3.4 Excel 导出

```
GET /statistics/export?examId=&collegeId=&classId=&startTime=&endTime=&scope=school|college|teacher
```

角色：按当前登录角色自动决定数据范围

返回：二进制 xlsx 文件

导出字段：
- 姓名
- 学号
- 学院
- 专业
- 班级
- 考试名称
- 试卷状态（未开始/进行中/已提交/超时/缺考）
- 考试次数
- 分数
- 是否通过
- 证书编号
- 发证日期

## 4. 前端页面

| 页面 | 路由 | 角色 | 主要展示 |
|---|---|---|---|
| 学校统计 | `/school-admin/statistics` | 学校管理员 | 全校 KPI 卡片 + 按学院表格 |
| 学院统计 | `/college-admin/statistics` | 学院管理员 | 本院 KPI 卡片 + 按班级/专业表格 |
| 班级统计 | `/teacher/statistics` | 教师 | 本班学生状态列表 + 搜索/分页 |

所有页面均提供「导出 Excel」按钮。

## 5. 数据口径

- **总人数**：当前数据范围内 `User` 表中学生总数（`userType = 2`）。
- **已参与**：`Paper.status IN (SUBMITTED, TIMEOUT, AUTO_SUBMITTED)` 的学生数，去重。
- **通过**：分数 >= 80 且 `Paper.status` 为终态。
- **缺考**：考试窗口已结束且 `Paper.status = DRAFT`，或由定时任务标记为 `ABSENT`。
- **考试次数**：`StudentAttempt.usedCount`。
- **证书编号**：通过且 `Certificate` 已生成时显示。

## 6. 权限与安全

- 每个统计接口必须调用 `DataScopeService` 限制查询范围。
- 学校管理员可以传 `collegeId` 筛选，但学院管理员传入非本学院 ID 时返回 403。
- 教师只能查看 `teacher_classes` 中分配的班级。
- Excel 导出走相同数据范围校验。
