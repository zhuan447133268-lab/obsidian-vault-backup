## 2. 设计依据与关键调整

### 2.1 设计依据

本文档基于以下已确认事实：

1. **技术方案 v1.3 第 6 章**：表结构、字段类型、关联关系。
2. **业务事实确认（2026-07-07）**：三场权限、组卷比例、考试次数、断网恢复、证书规则。
3. **实际导出的样例数据**：`D:\2026准入题库\student_sample.csv`、`D:\2026准入题库\organization_sample.csv`。

### 2.2 与技术方案相比的关键调整

| 调整项 | 技术方案 v1.3 | 本版本 | 原因 |
|--------|--------------|--------|------|
| 专业表 `majors` | 未单独设计 | 新增 | 样例数据包含 `major_code`、`major_name`；组卷规则中专业题需要按学院+专业绑定 |
| 班级表 `classes` | 仅 `id/college_id/name` | 增加 `code/major_id/grade` | 样例数据包含 `class_code`、`grade`；班级需关联专业 |
| 用户表 `users` | 无 `grade` | 增加 `grade` | 样例数据包含年级，教师选择学生时可按年级筛选 |
| 学院编码 | 用 `colleges.code` | 系统自动生成：学院名称拼音首字母，冲突时加序号；生成后不可手动修改 | 学校无法提供学院短编码；证书编号需要短代码 |
| 学生状态 | 未保留 | 导入时过滤，表中不保留 | 需求明确只让在读/正常学生参考，导入时即过滤掉其他状态 |

## 2.4 学院编码生成规则（已确认）

学校无法提供学院短编码，由系统在导入时按以下规则自动生成：

1. 取学院名称**前两个汉字**的拼音首字母；
2. 转大写，作为学院短编码；
3. 若编码冲突，在末尾自动加序号（如 `JY01`、`JY02`）；
4. 编码一旦生成，不允许手动修改；
5. 新学院导入时沿用同一规则。

**样例 6 个学院的生成编码：**

| 学院名称 | 生成编码 |
|----------|----------|
| 教育学院 | JY |
| 工商管理学院 | GS |
| 汽车与机电工程学院 | QC |
| 电气电子智能工程学院 | DQ |
| 智能科学与工程学院 | ZN |
| 艺术学院 | YS |

**实现位置**：`data-import.service.ts` 中的学院导入逻辑。

## 4. Prisma Schema

```prisma
// schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "mysql"
  url      = env("DATABASE_URL")

// ==================== 组织架构 ====================

model College {
  id         String   @id @default(uuid()) @db.VarChar(36)
  code       String   @unique @db.VarChar(32)   // 学院短编码，用于证书编号
  name       String   @db.VarChar(64)
  isSpecial  Boolean  @default(false) @map("is_special") // 汽车/电气/智科
  createdAt  DateTime @default(now()) @map("created_at")
  updatedAt  DateTime @updatedAt @map("updated_at")

  majors     Major[]
  classes    Class[]
  users      User[]
  exams      Exam[]
  questions  Question[]

  @@map("colleges")
}

model Major {
  id         String   @id @default(uuid()) @db.VarChar(36)
  code       String   @unique @db.VarChar(32)   // 专业编码，如 08060101
  name       String   @db.VarChar(64)
  collegeId  String   @map("college_id") @db.VarChar(36)
  createdAt  DateTime @default(now()) @map("created_at")
  updatedAt  DateTime @updatedAt @map("updated_at")

  college    College  @relation(fields: [collegeId], references: [id])
  classes    Class[]

  @@map("majors")
}

model Class {
  id         String   @id @default(uuid()) @db.VarChar(36)
  code       String   @unique @db.VarChar(32)   // 班级编码，如 202303
  name       String   @db.VarChar(64)
  grade      String   @db.VarChar(20)            // 年级，如 2023
  majorId    String   @map("major_id") @db.VarChar(36)
  collegeId  String   @map("college_id") @db.VarChar(36)
  createdAt  DateTime @default(now()) @map("created_at")
  updatedAt  DateTime @updatedAt @map("updated_at")

  major      Major    @relation(fields: [majorId], references: [id])
  college    College  @relation(fields: [collegeId], references: [id])
  users      User[]

  @@map("classes")
}

// ==================== 用户与权限 ====================

enum UserRole {
  STUDENT
  TEACHER
  COLLEGE_ADMIN
  SCHOOL_ADMIN
}

model User {
  id              String   @id @default(uuid()) @db.VarChar(36)
  dingtalkUserId  String?  @unique @map("dingtalk_user_id") @db.VarChar(64)
  casUserId       String?  @unique @map("cas_user_id") @db.VarChar(64)
  name            String   @db.VarChar(64)
  studentNo       String?  @unique @map("student_no") @db.VarChar(32)
  staffNo         String?  @unique @map("staff_no") @db.VarChar(32)
  userType        Int      @map("user_type") // 1=教职工, 2=学生
  collegeId       String?  @map("college_id") @db.VarChar(36)
  majorId         String?  @map("major_id") @db.VarChar(36)
  classId         String?  @map("class_id") @db.VarChar(36)
  grade           String?  @db.VarChar(20)   // 学生年级
  entryDate       DateTime? @map("entry_date") @db.Date
  status          Int      @default(1)        // 0=禁用, 1=正常
  createdAt       DateTime @default(now()) @map("created_at")
  updatedAt       DateTime @updatedAt @map("updated_at")

  college         College? @relation(fields: [collegeId], references: [id])
  major           Major?   @relation(fields: [majorId], references: [id])
  class           Class?   @relation(fields: [classId], references: [id])

  roles           UserRoleRel[]
  collegeAdmins   CollegeAdmin[]
  teacherClasses  TeacherClass[]
  publishedExams  Exam[]       @relation("ExamPublisher")
  papers          Paper[]
  certificates    Certificate[]
  examEvents      ExamEvent[]

  @@map("users")
}

model UserRoleRel {
  id      String   @id @default(uuid()) @db.VarChar(36)
  userId  String   @map("user_id") @db.VarChar(36)
  role    UserRole

  user    User     @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([userId, role])
  @@map("user_roles")
}

model CollegeAdmin {
  id        String  @id @default(uuid()) @db.VarChar(36)
  userId    String  @map("user_id") @db.VarChar(36)
  collegeId String  @map("college_id") @db.VarChar(36)

  user      User    @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([userId, collegeId])
  @@map("college_admins")
}

model TeacherClass {
  id             String  @id @default(uuid()) @db.VarChar(36)
  userId         String  @map("user_id") @db.VarChar(36)
  classId        String  @map("class_id") @db.VarChar(36)
  canCreateExam  Boolean @default(true) @map("can_create_exam")
  canProctor     Boolean @default(true) @map("can_proctor")

  user           User    @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@unique([userId, classId])
  @@map("teacher_classes")
}

// ==================== 题库 ====================

enum QuestionType {
  SINGLE
  MULTIPLE
  JUDGE
}

enum QuestionCategory {
  GENERAL_SAFETY   @map("GENERAL_SAFETY")
  PROFESSIONAL     @map("PROFESSIONAL")
  GENERAL_EDU      @map("GENERAL_EDU")
}

model Question {
  id          String            @id @default(uuid()) @db.VarChar(36)
  type        QuestionType
  category    QuestionCategory
  collegeId   String?           @map("college_id") @db.VarChar(36) // 专业题绑定学院
  content     String            @db.Text
  options     Json              // 选项：["A. xxx", "B. xxx", ...]
  answer      Json              // 答案：["A"] / ["A","C"] / ["TRUE"]
  score       Int               @default(4)
  enabled     Boolean           @default(true)
  createdAt   DateTime          @default(now()) @map("created_at")
  updatedAt   DateTime          @updatedAt @map("updated_at")

  college     College?          @relation(fields: [collegeId], references: [id])

  @@index([category, collegeId, enabled])
  @@map("questions")
}

// ==================== 考试与试卷 ====================

enum ExamStatus {
  DRAFT
  PUBLISHED
  CLOSED
}

model Exam {
  id                String     @id @default(uuid()) @db.VarChar(36)
  title             String     @db.VarChar(128)
  publisherId       String     @map("publisher_id") @db.VarChar(36)
  collegeId         String     @map("college_id") @db.VarChar(36)
  classId           String?    @map("class_id") @db.VarChar(36)
  startTime         DateTime   @map("start_time")
  endTime           DateTime   @map("end_time")          // start_time + 3 天
  durationMinutes   Int        @default(30) @map("duration_minutes")
  status            ExamStatus @default(DRAFT)
  paperConfig       Json       @map("paper_config")      // 组卷规则配置
  createdAt         DateTime   @default(now()) @map("created_at")
  updatedAt         DateTime   @updatedAt @map("updated_at")

  publisher         User       @relation("ExamPublisher", fields: [publisherId], references: [id])
  college           College    @relation(fields: [collegeId], references: [id])

  papers            Paper[]

  @@index([publisherId])
  @@index([collegeId])
  @@index([status, endTime])
  @@map("exams")
}

enum PaperStatus {
  DRAFT
  IN_PROGRESS
  SUBMITTED
  TIMEOUT
  AUTO_SUBMITTED
  ABSENT
}

model Paper {
  id              String      @id @default(uuid()) @db.VarChar(36)
  examId          String      @map("exam_id") @db.VarChar(36)
  studentId       String      @map("student_id") @db.VarChar(36)
  status          PaperStatus @default(DRAFT)
  answers         Json?       // { "1": ["A"], "2": ["A","C"], ... }
  score           Int?
  isMakeup        Boolean     @default(false) @map("is_makeup")
  startTime       DateTime?   @map("start_time")
  serverEndTime   DateTime?   @map("server_end_time")    // 服务端权威结束时间
  lastSyncTime    DateTime?   @map("last_sync_time")
  submitTime      DateTime?   @map("submit_time")
  createdAt       DateTime    @default(now()) @map("created_at")
  updatedAt       DateTime    @updatedAt @map("updated_at")

  exam            Exam        @relation(fields: [examId], references: [id], onDelete: Cascade)
  student         User        @relation(fields: [studentId], references: [id], onDelete: Cascade)

  paperQuestions  PaperQuestion[]
  certificate     Certificate?
  examEvents      ExamEvent[]

  @@index([examId, studentId])
  @@index([studentId, status])
  @@index([status, lastSyncTime])
  @@index([status, serverEndTime])
  @@map("papers")
}

model PaperQuestion {
  id                String  @id @default(uuid()) @db.VarChar(36)
  paperId           String  @map("paper_id") @db.VarChar(36)
  questionId        String  @map("question_id") @db.VarChar(36)
  seqNo             Int     @map("seq_no")
  contentSnapshot   String  @map("content_snapshot") @db.Text
  optionsSnapshot   Json    @map("options_snapshot")
  answerSnapshot    Json    @map("answer_snapshot")
  score             Int

  paper             Paper   @relation(fields: [paperId], references: [id], onDelete: Cascade)

  @@unique([paperId, seqNo])
  @@map("paper_questions")
}

model StudentAttempt {
  id         String  @id @default(uuid()) @db.VarChar(36)
  studentId  String  @map("student_id") @db.VarChar(36)
  examId     String  @map("exam_id") @db.VarChar(36)
  usedCount  Int     @default(0) @map("used_count")
  maxCount   Int     @default(10) @map("max_count")
  createdAt  DateTime @default(now()) @map("created_at")
  updatedAt  DateTime @updatedAt @map("updated_at")

  @@unique([studentId, examId])
  @@map("student_attempts")
}

// ==================== 证书 ====================

model Certificate {
  id          String    @id @default(uuid()) @db.VarChar(36)
  certificateNo String  @unique @map("certificate_no") @db.VarChar(64) // LAB-2026-CS-A3F9B2D1
  studentId   String    @map("student_id") @db.VarChar(36)
  examId      String    @map("exam_id") @db.VarChar(36)
  paperId     String    @unique @map("paper_id") @db.VarChar(36)
  issueDate   DateTime  @map("issue_date") @db.Date
  createdAt   DateTime  @default(now()) @map("created_at")

  student     User      @relation(fields: [studentId], references: [id], onDelete: Cascade)
  paper       Paper     @relation(fields: [paperId], references: [id], onDelete: Cascade)

  @@index([studentId])
  @@map("certificates")
}

// ==================== 审计 ====================

enum ExamEventType {
  PAGE_SHOW
  PAGE_HIDE
  ANSWER_SYNC
  SUBMIT
  TIMEOUT
  AUTO_SUBMIT
  RESUME

model ExamEvent {

  payload     Json?          // 可选扩展字段

  paper       Paper          @relation(fields: [paperId], references: [id], onDelete: Cascade)

  @@index([paperId, eventType])

  @@map("exam_events")
}
```

## 5. 表结构详细说明

### 5.1 学院表 `colleges`

| 字段 | 类型 | 说明 | 备注 |
|------|------|------|------|
| id | VARCHAR(36) PK | 学院 UUID | 系统内部使用 |
| code | VARCHAR(32) UK | 学院短编码 | 系统自动生成：取学院名称前两个汉字拼音首字母，冲突时加序号；生成后不可手动修改。样例 6 个学院编码：JY、GS、QC、DQ、ZN、YS |
| name | VARCHAR(64) | 学院名称 | 如"教育学院" |
| is_special | BOOLEAN | 是否特殊学院 | 汽车/电气/智科为 `true`，走特殊组卷规则 |
| created_at | DATETIME | 创建时间 | |
| updated_at | DATETIME | 更新时间 | |

**避坑点**：
- 样例数据中学院只有名称没有编码。如果学校不提供短编码，导入时需要根据名称生成，必须在导入前确认规则，避免证书编号不统一。
- `is_special` 需要在初始化学院数据时正确设置，否则组卷比例错误。

### 5.2 专业表 `majors`

| 字段 | 类型 | 说明 | 备注 |
|------|------|------|------|
| id | VARCHAR(36) PK | 专业 UUID | |
| code | VARCHAR(32) UK | 专业编码 | 如 `08060101`，来自教务系统 |
| name | VARCHAR(64) | 专业名称 | 如"电气工程及其自动化" |
| college_id | VARCHAR(36) FK | 所属学院 | |
| created_at | DATETIME | | |
| updated_at | DATETIME | | |

**避坑点**：
- 专业编码 `code` 来自教务系统，必须保持唯一，导入时重复要报错。
- 专业是组卷规则中"专业题"的绑定维度，不能省略。

### 5.3 班级表 `classes`

| 字段 | 类型 | 说明 | 备注 |
|------|------|------|------|
| id | VARCHAR(36) PK | 班级 UUID | |
| code | VARCHAR(32) UK | 班级编码 | 如 `202303`，来自教务系统 |
| name | VARCHAR(64) | 班级名称 | 如"23电气三班" |
| grade | VARCHAR(20) | 年级 | 如 `2023` |
| major_id | VARCHAR(36) FK | 所属专业 | |
| college_id | VARCHAR(36) FK | 所属学院 | 冗余字段，便于按学院查班级 |
| created_at | DATETIME | | |
| updated_at | DATETIME | | |

**避坑点**：
- `college_id` 是冗余字段，导入时需要与 `major.college_id` 一致，建议用触发器或事务保证。
- 班级编码 `code` 在样例中有长短两种格式（如 `202303` 和 `20250617086`），字段长度必须留够。

### 5.4 用户表 `users`

| 字段 | 类型 | 说明 | 备注 |
|------|------|------|------|
| id | VARCHAR(36) PK | 用户 UUID | |
| dingtalk_user_id | VARCHAR(64) UK nullable | 钉钉用户 ID | CAS/钉钉接入后回填 |
| cas_user_id | VARCHAR(64) UK nullable | CAS 用户 ID | 预留 |
| name | VARCHAR(64) | 姓名 | |
| student_no | VARCHAR(32) UK nullable | 学号 | 学生必填 |
| staff_no | VARCHAR(32) UK nullable | 工号 | 教师必填 |
| user_type | INT | 用户类型 | 1=教职工, 2=学生 |
| college_id | VARCHAR(36) FK nullable | 学院 | |
| major_id | VARCHAR(36) FK nullable | 专业 | 学生必填 |
| class_id | VARCHAR(36) FK nullable | 班级 | 学生必填 |
| grade | VARCHAR(20) nullable | 年级 | 学生必填 |
| entry_date | DATE nullable | 入学/入职日期 | 可选 |
| status | INT | 状态 | 0=禁用, 1=正常；导入时过滤非在读学生 |
| created_at | DATETIME | | |
| updated_at | DATETIME | | |

**避坑点**：
- 学生和教师共用一张表，通过 `user_type` + `student_no`/`staff_no` 区分。
- CAS 登录时按 `student_no`/`staff_no` 匹配本地账号，匹配不到禁止登录。
- 样例数据已脱敏，真实导入时姓名替换为真实姓名。

### 5.5 角色表 `user_roles`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(36) PK | |
| user_id | VARCHAR(36) FK | |
| role | ENUM | STUDENT / TEACHER / COLLEGE_ADMIN / SCHOOL_ADMIN |

**避坑点**：
- 一人多角色时，数据权限取并集。
- 学校管理员可同时是学院管理员或教师，查询时要避免数据范围冲突。

### 5.6 学院管理员表 `college_admins`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | VARCHAR(36) PK | |

## 7. 避坑清单

### 7.1 数据导入阶段

| 坑 | 避法 |
|----|------|
| 学院编码缺失 | 学院短编码由系统按规则自动生成，导入时无需学校提供；生成后不可修改，初始化前需确认规则 |
| 专业/班级编码重复 | 对 `majors.code` 和 `classes.code` 加唯一索引，导入时捕获冲突并返回明细 |
| 学生状态未过滤 | 导入时只保留 `在读` 和 `正常` 状态，其他状态直接跳过并记录 |
| 学院关系不一致 | `classes.college_id` 必须与 `majors.college_id` 一致，导入时用事务保证 |
| 重名学生 | 系统以学号为唯一标识，重名不是问题；展示时用"学号 + 姓名" |

### 7.2 组卷阶段

| 坑 | 避法 |
|----|------|
| 题库数量不足导致组卷失败 | 发布前校验每类题数量，不足时明确提示并禁止发布 |
| 专业题绑定错学院 | `questions.college_id` 必填且正确；组卷时按 `exam.college_id` 过滤 |
| 组卷不均匀 | 先查全部可用题 ID，Fisher-Yates 洗牌后取前 N 个 |
| 已发布考试受题库变更影响 | 发布时把题目快照写入 `paper_questions` |

### 7.3 考试阶段

| 坑 | 避法 |
|----|------|
| 客户端时间被篡改 | `server_end_time` 为唯一权威，客户端只做展示 |
| 断网恢复时间算错 | `lastActiveTime = max(start_time, last_sync_time)` |
| 多次交卷重复判分 | 用数据库状态机守卫，终态不可再次提交 |
| 考试次数并发超卖 | `student_attempts` 原子 UPDATE，`used_count < max_count` 时 +1 |
| 补考误消耗次数 | 补考 `is_makeup=true`，跳过 `student_attempts` |

### 7.4 证书阶段

| 坑 | 避法 |
|----|------|
| 证书编号重复 | 唯一索引 + 冲突重试 |
| 一个学生多次发证 | `certificates.paper_id` 唯一，且生成前检查该学生是否已有证书 |
| 证书图片与展示不一致 | 管理员导出用 Puppeteer/Canvas，学生端 DOM 展示用同一套 HTML 模板 |

### 7.5 权限阶段

| 坑 | 避法 |
|----|------|
| 教师看到其他班级数据 | 所有查询必须带 `teacher_classes` 过滤 |
| 学院管理员跨学院 | 所有查询必须带 `college_admins` 过滤 |
| 接口权限和数据权限混用 | 接口级用 `@Roles()`，数据级用 `DataScopeService` 双重校验 |
