## 2026-08-14：fixed 底部栏三等分布局翻车

**现象**

手机端考试页面底部按钮改为三等分后，三个按钮仍挤在小框里，文字竖排成三个字。

**根因**

删除组件内 `left: 0; right: 0` 后，没有给 `.bottom-actions` 明确宽度。fixed 元素宽度默认由内容决定，而 flex 容器没有明确宽度时，`flex: 1 1 0` 的子元素会被 shrink-to-fit 压到极小，导致按钮文字换行竖排。

**正确做法**

```css
.bottom-actions {
  position: fixed;
  bottom: 0;
  width: 100%;              /* 必须显式设置宽度 */
  display: grid;            /* grid 比 flex 三等分更稳定 */
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
  ...
}

.van-button {
  width: 100%;
  white-space: nowrap;      /* 防止文字换行竖排 */
}
```

**避坑规则**

1. fixed 定位的底部操作栏必须显式设置 `width: 100%`（或 `min-width` / `right: 0`），不能只依赖 flex 子元素撑开。
2. 需要稳定三等分/等分时，优先用 `display: grid; grid-template-columns: 1fr 1fr 1fr;` + 子元素 `width: 100%`，避免 flex shrink-to-fit 的不确定性。
3. 涉及 fixed / absolute 布局的样式改动，build 通过后必须做视觉自测（截图或真机），不能只看构建成功。
4. 多环境样式叠加时（如组件 scoped + global.less），要检查最终 computed 样式，确认没有冲突的 left/right/width 计算。
