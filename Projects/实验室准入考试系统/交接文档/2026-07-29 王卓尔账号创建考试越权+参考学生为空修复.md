# 2026-07-29 王卓尔账号创建考试越权 + 参考学生列表为空修复

**分支**：`feat/art-design-pro-migration`，commit `3da3697`

## 问题现象

王卓尔账号（TEACHER + COLLEGE_ADMIN 双角色）：
1. 创建考试时，弹窗提示「创建成功」的同时，也弹出「数据越权」
2. 考试详情页「选择参考学生」处，没有所在班级的学生名单

## 根因分析

### 角色与数据范围

王卓尔：
- `roles`: TEACHER + COLLEGE_ADMIN
- `collegeAdmins`: 教育学院
- `teacherClasses`: 23汉语一班、24学前六班、23小教五班（均为教育学院）
- `getDataScope()` 优先级：COLLEGE_ADMIN > TEACHER → 返回 `COLLEGE` scope，管理学院=[教育学院]

### 越权触发链

创建考试成功 → 前端跳转 `/teacher/exams/:id` → 详情页 `onMounted` 调用 `loadStudents`：

- 原代码用 `authStore.primaryRole !== 'TEACHER'` 判断是否传 `collegeId`
- 王卓尔 `primaryRole = COLLEGE_ADMIN`，所以同时传了 `collegeId=教育学院` + `classId=考试班级`
- 后端 `users.service.buildFilterWhere` 对 `classId` 的处理：
  ```typescript
  if (query.classId) {
    if (scope.type !== 'ALL' && scope.type !== 'CLASS') {
      throw new ForbiddenException({ code: 1101, message: '数据越权' });
    }
    ...
  }
  ```
- 王卓尔的 `scope.type === 'COLLEGE'`，命中 `!== 'ALL' && !== 'CLASS'` → **直接抛 1101「数据越权」**

请求失败后学生列表保持空，所以详情页「暂无学生」。

## 修复内容

### 后端 `server/src/modules/users/users.service.ts`

1. `buildFilterWhere` 改为 `async`，返回 `Promise<Prisma.UserWhereInput>`
2. `findAll` 中 `await this.buildFilterWhere(query, scope)`
3. `classId` 过滤分支重写：
   - `ALL` scope：直接放行
   - `CLASS` scope：校验班级在 `scope.classIds` 内
   - `COLLEGE` scope：**查 class 表校验该班级属于其管理学院**
   - `SELF` 或其他：越权

### 前端 `web/src/views/teacher/exam-detail.vue`

`loadStudents` 中判断改为：
```typescript
// 教师角色数据范围为班级，传 collegeId 会导致后端越权
// 多角色用户（如学院管理员兼教师）在教师端按班级视角查询
if (!authStore.hasRole('TEACHER')) {
  params.collegeId = exam.value.collegeId
}
```

只要有 TEACHER 角色，就不传 collegeId，避免与班级视角冲突。

### 发现并修复的构建错误

`web/src/views/teacher/statistics.vue` 中 `getMyClassList()` 直接返回 `MyClassListItem[]`，而 `listClasses()` 返回 `{ list: Class[] }`。原 7-28 代码统一写 `cRes.data.list` 导致 TypeScript 报错。

修复：
```typescript
interface ClassOption {
  id: string
  name: string
  grade: string
}
const classes = ref<ClassOption[]>([])

const loadOptions = async () => {
  if (authStore.hasRole('TEACHER')) {
    const cRes = await getMyClassList()
    classes.value = (cRes.data || []).map((c) => ({ id: c.id, name: c.name, grade: c.grade }))
  } else {
    const cRes = await listClasses()
    classes.value = cRes.data.list.map((c) => ({ id: c.id, name: c.name, grade: c.grade }))
  }
  const eRes = await listExams()
  exams.value = eRes.data.list
}
```
