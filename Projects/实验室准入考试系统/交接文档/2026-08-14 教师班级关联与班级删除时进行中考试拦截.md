# 2026-08-14 教师班级关联与班级删除时进行中考试拦截

> 对应 memory：[[lab-exam-teacher-class-remove-active-exam-block-2026-08-14]]

---

## 一、问题概述

**Bug 名称**：电脑管理端：教师端在考试时被移除班级没有阻止

**现象**：

- 管理端在「教师分班」里移除某教师的班级关联，或删除某班级时，没有检查该教师/班级下是否存在进行中的考试。
- 移除后，教师再去操作已发布的考试，教师端直接显示「越权」。

**期望**：

- 若目标教师在该班级下有进行中的考试，或目标班级本身有进行中的考试，应阻止移除/删除并给出明确提示。

---

## 二、修复文件

- `server/src/modules/users/users.service.ts`
- `server/src/modules/org/org.service.ts`

---

## 三、修复方案

### 3.1 `removeTeacherClass` — 移除教师班级关联前拦截

在删除 `teacher_classes` 记录前，检查该教师在该班级下是否存在满足以下条件的考试：

- `status = PUBLISHED`
- `startTime <= now <= endTime`

若存在，抛出错误：

```json
{
  "code": 1303,
  "message": "该教师当前有进行中的考试「{title}」，无法移除班级关联"
}
```

### 3.2 `removeClass` — 删除班级前拦截

在删除班级前，检查该班级是否存在满足上述条件的考试。

若存在，抛出错误：

```json
{
  "code": 1204,
  "message": "该班级当前有进行中的考试「{title}」，不可删除"
}
```
