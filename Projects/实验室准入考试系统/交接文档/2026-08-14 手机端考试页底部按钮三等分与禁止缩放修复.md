# 手机端考试页底部按钮三等分与禁止缩放修复

## 背景

测试反馈学生手机端考试页面存在两个问题：

1. 底部操作栏（上一题 / 题数 / 下一题）的三个按钮挤在正中央，形成一个“小框”，视觉上不好看，希望均匀铺满底部。
2. 手机端考试时页面容易“乱跑”：考生双指缩放或误触滑动后，页面偏移，需要手动拖回正中间。

## 问题分析

### 按钮布局

此前为修复“按钮不在正中央”，将 `.bottom-actions` 设为 `justify-content: center`，三个按钮按内容宽度居中排列，导致两侧留空过多。

### 页面跑位

- `index.html` 的 viewport 未设置 `user-scalable=no` 和 `maximum-scale/minimum-scale`，允许用户缩放。
- `.exam-paper-page` 未限制 `overflow-x` 和 `touch-action`，允许左右拖动。

## 修复方案

### 1. 底部按钮三等分铺满

文件：`web/src/views/student/exam-paper.vue`

最终采用的稳定方案（第三次迭代）：

```css
.bottom-actions {
  position: fixed;
  bottom: 0;
  width: 100%;
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 12px;
  padding: 12px 16px;
  padding-bottom: calc(12px + env(safe-area-inset-bottom));
  background: @bg-card;
  box-shadow: 0 -2px 12px rgba(0, 0, 0, 0.06);

  .van-button {
    width: 100%;
    white-space: nowrap;
  }
}
```

效果：上一题、题数、下一题/交卷三个按钮在底部栏中水平三等分排列，文字不会换行竖排。

> **迭代教训**：第二次迭代使用 `flex: 1 1 0` 失败，原因是 `.bottom-actions` 没有明确宽度，fixed 元素 shrink-to-fit 后 flex 子元素被压到极小，导致文字竖排。改为 `width: 100% + grid 三等分` 后稳定。

### 2. 禁止缩放与左右滑动

在 `exam-paper.vue` 中动态控制 viewport：

- 进入考试页时，将 viewport 设置为：
  ```
  width=device-width, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0, user-scalable=no, viewport-fit=cover
  ```
- 离开考试页时恢复原始 viewport，避免影响其他页面。

同时给 `.exam-paper-page` 添加：

```css
overflow-x: hidden;
touch-action: pan-y;
```

限制页面只能垂直滚动，不能左右滑动。

## 验证

- `npm run build`（web）通过
- 用 Playwright + iPhone SE 模拟器对相同样式做了截图自测，三个按钮水平等宽排列，文字未换行
- 已 push 到 `origin main`：`0ac4ccc`

## 影响范围

- 仅影响学生手机端考试作答页面。
- viewport 缩放限制只在考试页生命周期内生效，离开页面自动恢复。
- 未改动教师端、管理端、学生端其他页面。
- 未改动考试逻辑、倒计时、交卷、切屏检测、本地缓存、API 调用。

## 待确认

- 测试环境部署后，需在真实手机上验证：
  1. 底部三个按钮是否三等分铺满。
  2. 文字是否水平显示，没有竖排。
  3. 双指缩放是否失效（正常应无法缩放）。
  4. 左右拖动是否失效（正常只能上下滚动看题）。
  5. 交卷后跳转结果页时 viewport 是否正常恢复。
