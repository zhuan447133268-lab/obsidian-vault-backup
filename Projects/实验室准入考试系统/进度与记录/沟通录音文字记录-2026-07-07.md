## 关键事实摘要

| 主题 | 录音中的事实 |
|------|-------------|
| 考试对象 | 新入职教师必须考；上实验/实训课教师；所有学院学生 |
| 题目形式 | 25 道题，选择题 + 判断题，无主观题，及时出分 |
| 考试次数 | 未通过可考 10 次 |
| 考试安排 | 老师发布考试，学生在时间窗口内（约 3 天）自行完成，非统一安排具体时间 |
| 重考 | 第一次未通过可当场或窗口期内重新答题，直到通过 |
| 10 次未通过 | 需联系老师或管理员处理 |
| 权限结构 | 学校管理员 → 学院管理员 → 教师（监考/组卷） |
| 导出功能 | 教师导出本班名单；学院管理员导出本学院统计；学校管理员导出全校统计 |
| 证书 | 考后弹出电子证书；学生可长按/右键保存；**后台需要下载/导出功能** |
| 登录入口 | 钉钉工作台 |
| 考试有效期 | 一次通过后不需要重考；录音中提到"四年" |
| 特殊学院 | 部分学院需加通识教育学院题；录音中提到"物理"等三个学院 |
| 组卷 | 老师点击组卷，数据库随机按比例抽题，预览后发布 |
| 防作弊 | 不严格管控切屏，象征性考核 |
| 异常处理 | 中途退出/关闭网页需明确处理 |
| 钉钉小卡片 | 通过后发送小卡片提醒，对方表示"可以，没问题" |
| 重名处理 | 需要标注，以学号/工号区分 |
| 题库更新 | 会更新，但频率不高 |
| 未来扩展 | 可能做成通用考试平台，但目前只做实验室准入 |
