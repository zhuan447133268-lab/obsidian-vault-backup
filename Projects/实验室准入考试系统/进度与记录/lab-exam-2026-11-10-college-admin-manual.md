## 五、复现方式（生成器不入工作区）

工作目录：`C:\Users\dfjq\AppData\Local\Temp\labexam-doc-20261109\`

```
generate.js               # docx 9.15.3 生成器（封面/页眉页脚/分节/表格/图/FAQ/附录）
prep_images.py            # 截图裁切 + 显示尺寸（OVERRIDES 手工裁框）
postprocess.py            # 页脚 PAGE 域改 Roman/arabic、去掉 pgNumType
add_toc_placeholders.py   # 插 54 条目录占位（页码为估算值）
fix_toc.py                # TOC1/TOC2 行距锁 exact 348、删重复首条
build.sh                  # 串起上面全部 + 复制 render/manual.docx + 导出 PDF + 渲染 PNG
word2pdf.ps1              # Word COM：更新 TOC 域 + 页脚域 → 导出 PDF → 另存 render/manual-toc.docx
```

两个关键坑（下次改文档会再遇到）：

1. **目录页码不能靠估算**。占位脚本按 `1 + i // 8` 估页，实测差 5 页以上；必须在 `word2pdf.ps1` 里 `foreach ($toc in $doc.TablesOfContents) { $toc.Update() }` + 页脚 `Fields.Update()` 后再 `SaveAs2`，**交付件取 `manual-toc.docx`**（含真实页码），不是 `manual.docx`。
2. **封面出血白边**。封面节 `pgMar header/footer = 0` 仍会因继承来的空 `header1.xml` 段落留一条 19px 白带；解法是给封面节挂一个 1pt exact 的空 Header/Footer，navy 从 y=2 起满版。
