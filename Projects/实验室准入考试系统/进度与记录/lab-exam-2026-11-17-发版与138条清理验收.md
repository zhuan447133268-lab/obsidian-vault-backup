## 八、可复用手法

- **判「某前端改动上线没」**：入口 `index-*.js` hash 只反映入口自身 → 必须 `GET /` 取入口 → 抓 `xxx-[hash].js` 分片名 → 逐分片串行爬（最多 62 个）→ grep 中文/属性名标记串。**整批含 `web/src` 文件时入口 hash 必变，不能拿「入口没变」当整批没上**（`86db536..4f7e919` 就是这么判错的）。
- **正式环境免登录态截管理员页面**（本机 Playwright + Edge，全程只读）：
  1. Node `fetch` 打 `/api/auth/login`（`admin`/`oceg2026`）→ 取 `set-cookie` 与 `data.csrfToken`
  2. `context.addCookies` 注入 `access_token`/`refresh_token`（domain `lab-exam.oceghome.com`）
  3. `context.addInitScript` 往 **sessionStorage** 写 `csrf_token`（前端 `request.ts` 从 sessionStorage 取，`me` 接口不回传 token）
  4. 直接 `page.goto('/teacher')` 等 `.el-table`；翻页用 `page.evaluate(() => document.querySelector('.el-pagination .btn-next').click())`（DOM 级点击比 Playwright 元素点击稳）
  5. 列表关键词只匹配**考试标题**（`where.title contains`），按班级/状态过滤要翻页或走接口查页码
