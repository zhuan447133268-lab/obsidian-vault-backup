# 迭代 v0.3：统计与证书导出纳入教师数据（2026-09-17）

> 一句话：学院管理员能给教师发考试了，但统计/证书/导出这套纯学生时代写的代码「看不见」教师——教师行消失、教师试卷污染学生通过率，本次把教师作为**独立维度**接进统计与证书导出，并在同一天按业务方测试环境反馈补了导出内容选择（v0.3.1）与统计页排版修复（v0.3.2）。

## 一、触发与拍板

测试老师原话：现在学院管理员可以给教师分配考试了，那学校管理员和学院管理员的统计页面、全校统计、学院统计以及证书导出等相关页面，也应当增加教师的数据。

业务方拍板 4 条：

1. 教师**单独维度**，不与学生 KPI 合并；
2. 学院管理员页加「本院教师」一行，把本院教师考试情况统计出来；
3. 证书页把「考生类型」暴露成界面可选筛选；
4. 导出**取消 2000 条上限**，学校管理员要能导全部数据。

## 二、根因

教师考生（`users.user_type=1` + `exams.audience='TEACHER'`）是迭代 v0.2 才引入的新维度，而统计/证书/导出代码是纯学生时代写的——**分母按 `userType=2` 过滤、分子没有**。于是三种症状同时出现：

- 教师行整片消失（看不见）；
- 教师试卷混进学生分子，通过率可算到 >100%；
- 选教师考试时学生总数不收敛，通过率被稀释成 0.0%。

## 三、修复内容（v0.3：10 项关联漏洞）

| # | 改前行为 | 修复 |
|---|---|---|
| 1 | 学生参与率/通过率分子未按 userType 过滤，教师试卷混入 | 学生口径的试卷 where 统一加 `student.userType=2`（统计与导出同源） |
| 2 | 全校统计选考试后学生总数不收敛 | 选考试时学生/教师分别收敛到该考试实际已组卷考生（教师考试 → 学生口径为空） |
| 3 | 学院统计考试下拉过滤掉了教师考试 | 下拉恢复全量考试；教师维度按「本院教师」整体口径单独统计 + 提示文案 |
| 4 | 学院统计按班级/专业筛选时仍展示教师行 | 选专业/班级后隐藏「本院教师」行（教师无专业班级属性） |
| 5 | 成绩导出明细无考生类型列，教师行学号为 `-` | 加「考生类型」列；学号列回落工号（列名「学号/工号」）；导出支持 `audience` 筛选 |
| 6 | 按状态筛选导出时教师行整片消失（状态 id 只按学生口径算） | 状态筛选按考生类型各算一遍再合并 |
| 7 | 成绩导出 `keyword` 参数被静默丢弃（DTO 未接） | keyword 生效：姓名/学号/工号 |
| 8 | 证书列表/导出排序只有 `issueDate desc`，同日发证顺序不稳 | 补 `id asc` 次级键 |
| 9 | 证书详情学号字段教师为空 | `studentNo ?? staffNo` 回落 |
| 10 | 监考页按工号搜不到教师试卷 | 试卷关键字搜索补 `staffNo` |

新增能力：全校统计返回 `teacher` 汇总 + `byCollegeTeacher`；学院统计返回 `teacher`；证书列表/导出与成绩导出支持 `audience`；KPI 拆「学生 / 教师」两块（学生口径语义不变）。

## 四、v0.3.1：统计页「导出内容」选择（同日追加）

业务方追问「学校管理员是不是导不了教师考试情况、只有学院管理员能导」。核实结论：**两个角色早就能导教师行**（全校 `scope=school` 导出 201 行 = 学生 180 + 教师 21；学院 `scope=college` 68 行 = 学生 50 + 教师 18），前提不成立；真正缺的是「只导教师」的界面入口（接口 `audience` 早已支持，只差暴露）+「导出全部考生」这字样读不出含不含教师。

做法：全校/学院统计的导出按钮旁加「导出内容」下拉（导出全部考生 / 仅导出学生 / 仅导出教师），**只作用于导出、不改页面上方 KPI 口径**（切换不触发查询）；学院统计在「仅教师 + 带专业/班级筛选」时弹提示不导空表。**后端零改动**。

## 五、v0.3.2：统计页排版修复（业务方测试环境反馈）

反馈原话：全校统计页面中间学生和教师的 4 张卡片两边都紧贴着外面的边框，「学生」「教师」这两个字也紧贴边框，「全校统计」4 个字也紧贴最左侧边框；另外没看到只导出教师数据的选项。

三个结论（两个真问题 + 一个误判）：

1. **真问题·贴边**：v0.3 拆 KPI 时只加了 `<h3>` 和裸 `display:grid; repeat(4,1fr)`，**没给这块加容器卡片**。四格网格正好铺满内容区，左边缘与相邻卡片的**边框线**严格重合（实测 1440px 下 `h2`、`.kpi-section-title`、KPI 卡全在 x=285，而 `.filter-card` 边框也在 285、内容从 305 起）。改法=KPI 组包 `art-card`、`.page-header` 补 `padding: 0 20px`，统一到卡片内容左对齐。
2. **真问题·间距**：全校统计「各学院统计」与「各学院教师统计」两卡**贴死（间距 0）**——v0.3 新增第二张表时漏了 `margin-bottom`（学院统计页一直有）。补 20px。
3. **误判·导出内容**：下拉一直都在（v0.3.1 加的），但**无文字标签**、默认值「导出全部考生」像 placeholder，用户没认出来。补可见标签「导出内容」。同时明确回答：**导出默认含学生 + 教师全部考生，不需要手动筛选**；只要教师选「仅导出教师」；想只看某场教师考试用上方「考试」下拉。
4. 顺带：加标签后 390px 手机上标题被挤成两行 → `@media (max-width:768px)` 下 `.page-header` 改 `flex-direction: column`。

## 八、易踩的语义（勿随手改）

「通过 / 未通过」按**最新一张试卷**判定（与列表、学生口径一致）：重修/重考后再考一版未通过，即使早前已发证，统计仍显示未通过。前后端都不得改成"有证即通过"。
