# 手搓夸克 · 最小原型服务（已跑通）

> 把「搜索(PanSou) → 转存(Quark)」串成可跑的 HTTP 服务 + 极简前端。对应 [[手搓夸克 接口拆解]]。

## 落点
- 工程目录：`D:/培训temp/quark-research/prototype/`
- 依赖：FastAPI + uvicorn + requests（managed venv：`~/.workbuddy/binaries/python/envs/default`）

## 文件
| 文件 | 作用 |
|---|---|
| `quark_client.py` | 夸克转存客户端，照抄 quark-auto-save 的 `Quark` 类四步曲（stoken→detail→save→task），`base_url` 可注入便于测试 |
| `pansou_client.py` | PanSou 搜索客户端，只挑 `pan.quark.cn` 夸克链接，兼容 `merged_by_type` 与扁平 `list` |
| `app.py` | FastAPI 服务 + 内置演示 UI（搜索框→列表→逐条一键转存） |
| `mock_apis.py` | 本地 mock（模拟夸克+PanSou），不联网/不填真实 Cookie 也能跑通连线 |
| `test_wiring.py` | 连线测试：起 mock → 验搜索+转存，全绿才退出 0 |
| `README.md` | 启动/测试/真实使用要点 |

## 验证结果（2026-10-21 实测）
- `python test_wiring.py`：搜索只回 2 条夸克链接、转存四步曲请求/响应正确 ✅
- 起 app + mock，curl 全链路：`/health` ✅、`/api/search` 命中夸克链接 ✅、`/api/me` 验号 ✅、`/api/save` 经 HTTP 转存成功（saved_001/002）✅
- 真实模式（不传 QUARK_MOCK_BASE）`/api/save` 会打到真实 drive-pc.quark.cn，假 cookie 被拒→证明请求连线正确

## 接口
- `GET  /health`
- `GET  /api/search?kw=哪吒` → 调 PanSou，只回夸克链接
- `POST /api/save` → `{share_url, cookie, savepath?}`
- `GET  /api/me?cookie=xxx` → 验 Cookie 是否还活着

## 真实使用三件事
1. **Cookie**：浏览器登录 pan.quark.cn → F12 → Cookies → 复制整段（必须含 `__uid`）
2. **PanSou**：`docker run` 自托管后 `export PANSOU_BASE=...`，或 fork PanSeek 只留搜索 API
3. **合规**：仅限个人学习/管理自有内容；剑网2025 肃清下分享链接存活率降，`stoken` 步可过滤死链
