# Obsidian 知识星系 3D

> 把整个 Obsidian Vault 的双链关系渲染成可旋转的 3D 力导向星系。

## 文件说明

| 文件 | 作用 |
|---|---|
| `知识星系.html` | 最终交付物：单文件离线网页，内嵌 three.js r128 + 图数据，浏览器直接打开 |
| `knowledge_graph.json` | 解析产物：Vault 里的笔记、双链、分组、摘要 |
| `_build_kg_parser.py` | 解析器：扫描 Vault 所有 `.md`，抽取 `[[双链]]`、标签、摘要 |
| `_build_kg_html.py` | 生成器：把 JSON + 离线 three.min.js 内联成单文件 HTML |

## 当前数据快照

- 笔记 **275** 篇
- 连线 **735** 条（真实的 `[[双向链接]]`）
- 待写缺口 **108** 个（某篇笔记引用了，但对应目标尚未创建）
- 分组 **38** 类（按顶层文件夹，Projects 细分为二级子项目）
- 被链接最多的 hub：实验室准入考试系统部署检查清单（10 次被引）

## 怎么用

1. 双击打开 `知识星系.html`。
2. 操作：
   - 拖拽旋转
   - 滚轮缩放
   - 悬停看标题与分组
   - 点击左侧卡片显示摘要、标签、关联笔记
   - 右侧分组列表点击可「隔离」只看该分组
   - 右下角搜索框输入笔记名回车定位

## 如何重新生成

在 `D:/培训temp/` 目录下：

```bash
# 1. 解析 Vault，生成 JSON
python _build_kg_parser.py

# 2. 把 JSON + three.min.js 内联成 HTML（依赖 D:/培训temp/知识点演示培训包/three.min.js）
python _build_kg_html.py
```

重新生成后，新的 `知识星系.html` 会自动覆盖到 `Demo-知识图谱实操/知识星系.html`。
