# 游戏化课堂三件套设计法

> 适用场景：**0 基础学员 + AI 工具 + 90 分钟 + 必须人人带走产出物**的培训。不限于游戏——教案、PPT、海报、数据处理课都能套。

## 三件套结构

| 件 | 发给谁 | 作用 |
|---|---|---|
| **创意卡** | 学员，培训前 3 天 | 只收集"内容"（题目/素材/主题），不碰技术；填不出给兜底选项（科目+知识点，现场用急救包） |
| **跟做卡** | 学员，现场人手一份 | 统一样例跑通流程 → 换成自己的内容 → 验收清单打钩；每步写"**做对了的样子**"；⭐必做/▲选做分级 |
| **讲师手册** | 自留 | 分钟级总控表 + 风险预案 + 题库/素材急救包 + 进阶任务（水平混入时分层） |

## 五条设计铁律

1. **学员只出内容，机制/代码/美术全部预制**——收敛选项（如玩法三选一），不开放自由命题
2. **填空式提示词模板**：学员只改【】区，技术要求段锁死（单文件、零依赖、双击可开、答错不判死）
3. **让 AI 自己写操作说明**：提示词里要求生成后自报"怎么保存/怎么打开/改哪里"，0 基础学员不需要懂文件
4. **通关验收清单**：4~6 条可打钩的机器可验证标准（能打开/内容对/正向反馈/容错/完成态），互玩环节当评委卡
5. **现场熔断预案**：AI 服务/网络挂掉 → U 盘离线降级路线（不发新指令、改预制产物文字），流程不破

## 时间配方（90 分钟版）

演示 8'（建立信心）→ 统一样例跟做 27'（跑通流程）→ 换自己内容 30'（出成果）→ 互玩互修 15'（验收社会化）→ 展示 10'（收尾动机）。实操占比 ≥85%。
