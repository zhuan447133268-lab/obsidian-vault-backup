# 去AI味设计规则清单

> **一句话**：去 AI 味 = 避开所有模型的默认套路（reflex），**不是**把一切都做成某一种风格。
> 任何风格——编辑、深色、极简、活泼——只要是有意识的选择、避开套路，就不像 AI。
> 来源：GitHub `Nutlope/hallmark`（★45k，Anti-AI-slop design skill，编号引用即其规则号）
> 与 `joeseesun/qiaomu-design`（反AI味设计顾问）蒸馏，2026-11-02 首版。

## 一、通用红线（任何风格都不许碰，违反即返工）

### 视觉套路
| # | AI 标志 | 替代做法 |
|---|---|---|
| 1 | 紫→蓝（或任意无意义）渐变，尤其背景 | 实心色；渐变必须有光影/材质理由 |
| 2 | 辉光光晕：aurora/mesh 底、漂浮模糊球、彩色零偏移发光阴影（hallmark #29） | 纯色或带颗粒的表面；层次靠明度、带偏移的阴影 |
| 3 | 全员玻璃拟态（backdrop-blur 卡片海） | 纸面/实体质感，细线分隔代替卡片边框 |
| 4 | 卡片套卡片（#4）；三等分「图标+标题」tile 列（#3） | 只一层容器；栏宽、高度、样式要有变化 |
| 5 | emoji 当图标；手绘浏览器/OS 窗口示意图 | 真图标字体/内联 SVG；要示意就用真实截图 |
| 6 | 大标题渐变字；标题里某个词单独换色/斜体/高亮（#38iii） | 整颗标题一个颜色一个字重；要强调就换行 |
| 7 | 居中 Hero + 三特性 + CTA + 页脚的「AI 模板页」（#8） | 从真实内容类别出发设计结构 |
| 8 | 纯黑纯白（#000/#fff 绝对值，#7a） | 纸和墨都带一点色相倾向 |

### 字体与排版
| # | AI 标志 | 替代做法 |
|---|---|---|
| 9 | Inter/Roboto/Open Sans 当**展示**字体（#1） | 展示字体用衬线或有性格的字体；Inter 只配当正文 |
| 10 | 眉批 eyebrow 小标签、全大写/加字距的小字标签（#54/#67） | 标签用正文字体小一号、句首大写、不加字距 |
| 11 | 一行斜体词混在正体标题里（#38i）；UI 用斜体 | 整行统一；中文根本不用斜体 |
| 12 | 等宽字体当装饰（非代码却用 mono）（#64） | 标签回归正文字体 |
| 13 | 正文小于 12px、行高不足 1.3（#75）；正文行长超 75ch（#25） | 正文 16px / 1.5-1.65；max-width 65ch |

### 交互与工程
| # | AI 标志 | 替代做法 |
|---|---|---|
| 14 | `transition: all`；动画 width/height/top/left | 只动 transform/opacity；具体属性过渡 |
| 15 | 无 `prefers-reduced-motion` 回退；脚本关了内容不见 | 默认可见，动效是增强 |
| 16 | `overflow-x: hidden` 糊补丁 | `overflow-x: clip`（html+body） |

### 内容红线
| # | AI 标志 | 替代做法 |
|---|---|---|
| 17 | 空词：革命性/颠覆/无缝/赋能/下一代 | 具体事实与动作，动词优先 |
| 18 | 编造指标/客户证言/Logo 墙（#46a） | 没有就留空位，宁缺毋假 |
| 19 | 假数据用明显占位符 | 假数据也要像真的 |

## 二、风格菜单（红线之上，按场合选）

> 选型三问：**受众是谁？场合多正式？交付媒介是屏还是纸？**

### A · 编辑杂志风（本项目汇报在用）
- **配方**：暖纸色底 + 衬线展示字体（宋体系）+ 细线分隔（hairline）+ 单强调色（≤5% 画面）+ 编辑式表格（只留横线）
- **适合**：正式汇报、方案、长文、印刷品
- **人类参照**：高端商业杂志、出版物版面

### B · 深色工程感
- **配方**：纯色深底（非纯黑）+ 高对比但克制的文字 + 等宽字体只给真代码/数据 + 锐角 + 真实图表
- **适合**：技术演示、开发者工具、数据看板
- **要避开**：发光霓虹、终端绿字套壳（那也是套路）

### C · 极简现代
- **配方**：大量留白 + 一种无衬线正文 + 一张大图或一个大型真实产品图 + 极少量文字
- **适合**：产品发布、演讲开场页
- **要避开**：留白≠空旷+居中三板斧；得有一个真实的视觉主角

### D · 人文手作/活泼
- **配方**：手写或圆体点缀 + 不规则网格 + 暖色调 + 照片实拍
- **适合**：教育、年轻受众、活动页
- **要避开**：涂鸦贴纸包式堆料（又是一种新套路）

### E · 中式雅致
- **配方**：宋体展示 + 大面积留白 + 竖排点缀 + 朱砂/黛青单色
- **适合**：文化场合、邀请函、校史类
- **要避开**：祥云/水墨笔刷素材包堆砌

### F · 粗野主义 Brutalist
- **配方**：超大字号 + 硬边框 + 零过渡 + 故意「不修边幅」的网格
- **适合**：创意行业、反套路宣言
- **要避开**：为了糙而糙导致读不下去——红线（可读性）永远优先

## 三、交付前自检（30 秒）

- [ ] 有没有任何渐变/辉光/玻璃？——每一个都要能说出理由
- [ ] 标题是实心字吗？全页强调色面积 ≤5% 吗？
- [ ] 展示字体是 Inter/Roboto 吗？标签是全大写加字距吗？
- [ ] 有没有 emoji 图标、卡片套卡片、三等分 tile？
- [ ] 有没有编造的数字/证言/Logo？
- [ ] 把这页遮住颜色，结构还成立吗？（成立=不是配色撑场面）
- [ ] 同类页面会跟它撞脸吗？（会=再改一个决定）

## 五、反哺

新踩的「AI 味」套路（自己或别人页面里认出来的）→ 按「套路 + 为什么假 + 替代做法」补进第一节；风格菜单不够用 → 按第二节格式新增一个方向。
