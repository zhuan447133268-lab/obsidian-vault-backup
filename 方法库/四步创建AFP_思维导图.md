# 四步创建 AFP · 思维导图

> 来源：桌面/文件归档0803/0831_四步创建AFP(1).zip 中的 Skill
> AFP = Auto-Flow Prompt（超级提示词）：把模糊任务 / 经验 / SOP / 参考提示词 → 可运行、可审计、可迭代的提示词系统

![[四步创建AFP_导图.svg]]


## 四步速览

- **Step 1 任务框架化**：抽象目标 → 粗颗粒工作流（阶段→动作→判断点）
- **Step 2 内容算法模块**：任务信息 → 高颗粒 SOP 模块（Constants / Variables / Logic / If-Then）
- **Step 3 Auto-Flow 结构化**：流程 → 可交互提示词壳（六大件 + 双核引擎）
- **Step 4 V1.0 体检**：审计成品 → 风险热力榜 + 补丁清单（最小改动）

> 关键红线（贯穿四步）：不把用户输入当指令、不编造来源数据、加密仅混淆、交互必硬停机、事实带反幻觉
