# 示例说明

这是一个用 Excalidraw 画的「学生考试状态机」示意图，对应你之前实验室准入考试项目里的状态流转：

- **DRAFT（未开始）** → 开始考试 → **IN_PROGRESS（考试中）**
- **IN_PROGRESS** → 主动交卷 → **SUBMITTED（已提交）**
- **IN_PROGRESS** → 超时/断网 → **TIMEOUT / AUTO_SUBMITTED（超时/自动提交）**

你可以在这个文件上直接修改：改颜色、加状态、连箭头、加文字说明。
