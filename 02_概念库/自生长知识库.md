# 自生长知识库

## 一句话定义

知识库不是仓库，而是消化系统：吃进原料、消化成营养、长出肌肉、再把成果反哺回来。

## 存档库 vs 自生长库

| 存档库 | 自生长库 |
|---|---|
| 只保存信息 | 保存 + 消化 + 复用 + 进化 |
| 越用越乱 | 越用越懂你 |
| 每次从零开始 | 过去积累自动参与未来输出 |
| 收藏夹心态 | 工作系统心态 |

## 实现自生长需要 4 个动作

1. **消化**：把原料整理成结构化概念
2. **沉淀 Skill**：把重复方法写成可调用操作手册
3. **输出**：用概念和 Skill 生成结果
4. **回流**：把输出成果再拆回概念库或 Skill 库

## 关键原则

- 不要一开始就追求全自动。
- 结构先简单，四层足够。
- 一定要写规则说明（README），否则 AI 整理格式会漂。
- 重复出现三次以上的事，就应该考虑做成 Skill。
