# 情景化教学游戏 · 需求基线

> **本文档用途**：这是我（用户）给 AI 的"需求基线"。
> 任何时候我要求制作"情景化教学游戏 / 情景游戏"，请先读本文档，按其中定义、规范和差异执行。
> 本文档用于面向**小学教师**和**初中教师**的 AI 教学游戏培训课。

---

## 一、概念定义（给老师培训的口径）

- 这类游戏统称 **情境化教学游戏**（教育游戏 / 严肃游戏的一个分支）。
- 核心特征：**把知识点嵌入一个真实、有代入感的情境任务**，学生在情境中通过解决问题来学习知识。
- **情境是"知识发生的场景"，不是卡通包装**——这是培训中最关键的一句话。
- 培训时统一使用口径：**情景化教学游戏**（用户认可的叫法），可补充说明其学术对应词为"情境化学习 / 教育游戏"。

## 二、设计总原则（所有版本通用）

1. **知识匹配**：游戏内容必须与对应学段、对应学科的教材知识点真实挂钩（不是"看起来像"）。
2. **任务驱动**：玩家有一个明确情境任务（数动物、省钱路线、验证据……），知识是完成任务的手段。
3. **即时反馈**：答对/答错立刻有明确反馈（提示、修正、鼓励），引导而非挫败。
4. **演示友好**：面向教师培训，需在投影/大屏演示——全屏铺满、无黑边、操作区大、按钮醒目。
5. **可拆解**：游戏逻辑清晰，方便老师照着学（培训课教老师"做同款"）。

## 三、小学版设计规范

| 维度 | 规范 |
|---|---|
| 情境来源 | 生活化、童趣场景：农场、超市、动物园、游乐园 |
| 视觉风格 | 卡通插画背景、鲜艳配色、拟人化角色、大按钮 |
| 动画要求 | 像动画片一样生动，但**必须克制**（见下方"动画雷区"） |
| 任务复杂度 | 单知识点、单步/两步、即时反馈、可随机出题 |
| 语言 | 亲切、口语化，鼓励性提示 |
| 参考样例 | 鸡兔同笼·农场数学探究（已交付） |

### 小学版动画雷区（踩过的坑，务必避免）

- 整体平移+浮动：像"漂移/滑行"，不像走路
- 大步来回走+停顿：像"走两步退两步"
- 循环淡出消失、再淡入出现：像"鬼片"
- 水平翻转转身（scaleX 1 到 -1）：像"纸片突然转身"
- 头部统一后仰/多只动物同相位动作：像木偶，多只动物必须错开节奏
- 正确做法：**小幅踱步 + 部件动作**（腿交替迈步、身体起伏）；配角可静止只做局部动作（如兔子只动耳朵）；每只动物节奏错开

### 视觉硬性要求（小学版）

- 打开游戏**整个页面铺满屏幕**，任何屏幕比例四周都是背景景色，**不允许黑边**
- 背景用真实卡通插画（可 AI 生成），不是纯色
- 游戏操作区放**页面正中**，面积要大，背景与场景匹配（如农场版用木牌/台子风格）
- 大屏（投影/白板）下美观，符合小学孩子审美

## 四、初中版设计规范（与小学核心差异）

> 初中生不能接受卡通幼稚化。情景必须**匹配初中学生的理解水平、初中教科书的情景和知识点**。

| 维度 | 小学 | 初中 |
|---|---|---|
| 情境来源 | 生活化童趣场景 | **教科书真实情境**：课本例题场景、实验探究、真实社会/生活问题 |
| 视觉风格 | 卡通插画、鲜艳、拟人 | **写实/半写实、简约科学风、数据化界面**（仪表盘、数据表、实验台） |
| 任务复杂度 | 单步/两步、直接反馈 | 多步推理、条件分析、证据链、单元内综合 |
| 知识密度 | 单一知识点 | 单元知识、跨知识点综合 |
| 反馈语言 | 亲切鼓励 | 严谨、提示性（像老师批注） |

### 初中各学科情境示例（情境 = 知识发生的真实场景）

- **数学**：一次函数/方程 → 出租车里程计费、蓄水池进出水、商场折扣决策；几何 → 桥梁/建筑结构、城市地图坐标定位
- **物理**：杠杆 → 撬棍/天平平衡台；密度 → 轮船载货量；电路 → 家庭电路检修
- **化学**：化学方程式 → 实验室配比投料（烧杯、量筒、数据表）
- **历史**：史料实证 → 文物照片/文献考证排序，判断真伪
- **语文**：名著情节推进、非连续性文本阅读任务
- **英语**：真实情景对话任务（问路、点餐、就医），角色扮演式交互

### 初中版视觉硬性要求

- 界面用**写实/简约科学风**：任务面板、数据、真实照片或写实插画，杜绝幼稚化
- 情境元素来自教科书常见场景（实验室、地图、仪表、档案）
- 同样要求：全屏铺满无黑边、操作区居中够大、大屏演示美观

## 五、技术实现约定（给 AI 的执行要求）

1. **单文件 HTML**（内联 CSS/JS），本地可双击打开，依赖资源放同目录 `assets/`
2. 全屏背景：背景图铺满 body（cover），游戏画布固定比例居中缩放，**任何屏幕比例无黑边**
3. 动画只用轻量 CSS（GPU 加速的 transform/opacity），大屏流畅；**遵守"动画雷区"**
4. 随机出题、倒计时、核对反馈、结果页/过程页齐全（参考鸡兔同笼版结构）
5. 交付时附带：自检截图（桌面+移动）、无控制台报错
