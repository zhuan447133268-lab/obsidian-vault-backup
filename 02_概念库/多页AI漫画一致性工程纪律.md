# 多页 AI 漫画一致性工程纪律（AI 素养反面教材素材）

> 用于高校教师培训 / AI 素养课：把"AI 生图的工程纪律"本身当教学内容。
> 核心立场——**AI 生图好看，但一致性与可信度是"查出来的、分开做的、不许假装出来的"，不是提示词许出来的。**

## 一、给学生的三句话（AI 可信度认知底座）

1. **一致性是「查出来的」，不是「许出来的」**
   AI 生图提示词写得再满，跨页人物 / 道具 / 场景仍会漂。必须逐页看「真实生成的图」做 QA，不能只看提示词写没写要求。
2. **中文不能靠模型写 → 必须「图字分离」**
   画面阶段保持无字，中文旁白 / 对白后期叠加（PIL 叠字）。否则满屏错字、乱码、多字。
3. **没工具 / 没出图时，不许假装已经出图**
   状态要标 `blocked-no-image-tool`，这是 AI 工具的可信度底线，也是讲"AI 伦理 / 产品设计"的现成范例。

## 二、多页漫画工作流（reference-lock 路径）

- **先出「参考设定图」**锁视觉基因：人物（发型/眼镜/衣服/配色）、道具、场景、调性一次性定稿。
- **逐页把参考图作为 image1 传回**做 image-to-image（比纯文字锁一致性强很多）。
- **逐页 QA → 只返修失败页**（不重做全套）→ 连续两次失败必须换策略（如数量错误改单独画格、方位漂改图片编辑而非整页重生成）。

## 三、8 类漂移检查清单（逐页看真实图，不查提示词）

| 代码 | 含义 | 典型表现 |
|---|---|---|
| `identity_drift` | 人物身份漂 | 脸变了、气质变了 |
| `wardrobe_drift` | 服装漂 | 红雨衣变蓝、眼镜消失 |
| `prop_drift` | 道具形态漂 | 云朵面包漂成长条 |
| `scene_drift` | 场景漂 | 教室变室外 |
| `story_order_drift` | 故事顺序漂 | 转折落错页 |
| `orientation_drift` | 空间方向漂 | 木屋左页在左、右页在右 |
| `text_artifact` | 画内鬼字 | 图里冒出乱码 / 假汉字 |
| `extra_subject` | 多出来的人/物 | 凭空多一只猫 |

## 四、实测踩坑（已在 WorkBuddy 跑通验证）

- **并行生图会同秒撞名、互相覆盖** → 多页必须**串行**；分目录隔离救不了（工具不按各调用的 output_dir 落盘）。
- **裸叠字在「深浅分割背景」必翻车**（白墙/深屏交界、深色地板）→ 用**半透明字幕条**（白条 + 深蓝灰字），任何背景可读、风格统一。已沉淀为 `caption_bar.py` 复用工具。
- **AI 生图里的「图表 / 数字」是装饰性的**，不能当真实数据引用（如纪念册大屏上的柱状图）。

## 五、工具分工（关键，单独一个都是半成品）

| 技能 | 负责 |
|---|---|
| `hanxiaoyu-visual-story-comic` | 多页规划 + 跨页一致性 + 返修队列 |
| `linmumu` 绘本对 | 单页画质 + 中文叠字（`text_overlay.py` / `caption_bar.py`） |

→ 两者**串联**才出"可交付的漫画"。高校场景用例：校史/周年纪念册三格条漫、学科课件素材（算法/理论情境化）、AI 素养课反面教材。

## 六、教学用法（AI 素养课"反面教材"讲法）

- 把漂移结果（道具形态漂、方位漂）直接当"AI 局限"活教材，比讲理论有用十倍。
- 对比：图字分离**前**（满屏鬼字）vs **后**（干净叠字）→ 讲"为什么中文必须后期叠"。
- 把"不假装出图 / 标 blocked"作为 AI 产品设计的可信度范例。
- 把"撞名覆盖 / 装饰性图表"作为"AI 产出需人工核验"的实证。
