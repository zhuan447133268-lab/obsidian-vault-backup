# 四层闭环结构

自生长知识库的最小结构，不要一上来做复杂标签体系。

## 01_原料库

**定义**：只放未处理的信息。

**内容**：
- 网页文章、论文
- 截图、视频字幕
- 会议纪要
- 聊天记录
- 需求碎片

**原则**：
- 来源清楚
- 日期清楚
- 不要被格式绑架

## 02_概念库

**定义**：放 AI 整理后的结构化观点。

**内容**：
- 确认过的事实
- 核心观点
- 案例
- 数据
- 方法论
- 概念卡片

**原则**：
- 从原料中提炼
- 可被未来输出直接引用

## 03_Skill库

**定义**：放可复用的工作流。

**内容**：
- 选题判断
- 写作风格
- 周报模板
- 分析框架
- 检查清单
- Prompt 模板

**原则**：
- 重复出现三次以上
- 有明确触发条件
- 有固定步骤和输出格式

## 04_输出库

**定义**：放最终成果。

**内容**：
- 文章
- 报告
- 方案
- PPT
- 视频脚本

## 流转关系

```
01_原料库 → 02_概念库 → 03_Skill库 → 04_输出库
    ↑                                    ↓
    └──────────── 输出回流 ──────────────┘
```
