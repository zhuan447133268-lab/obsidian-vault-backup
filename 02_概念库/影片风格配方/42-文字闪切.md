# 42 · 文字闪切 / Text Flash Cuts

> 分类：平面排版
> 参考片：身后
> 原片一句话：一封信、一通电话、一面窗墙、十三级台阶：叫他别回头的她每一话都更近一步，直到她自己猛地回头。

## ⭐ 可直接复制的提示词

```text
用文字闪切风格：前卫TV动画文字帧派——满屏粗明朝体标题卡切入2–9帧、建筑简化为无纹理符号几何、人物只用黑剪影/平涂赛璐璐/满框碎片三态、招牌是越肩回头；人物由图像生成、其余代码绘硬边多边形。配色：红#d4162b、黑#0a0a0c、纸白#f2efe8，每说话人固定一色轨道；反色是红黑互换只作2–6帧冲击，绝不RGB反相。字体：Noto Serif SC 900巨字可出血、竖列对话、英文斜体约为中文四分之一、绝不居中，闪帧卡只重复已完整出现的词。运动：剪辑即动画、切锁拍、卡片砸入带逐帧整像素抖动、人物靠层与步进不补间。镜头：一点透视fast push、极端偏移、硬推网格单元、1:1插入镜、多格脸、分屏轨道；转场用红黑反色或红缝，绝不纯黑帧。声音：羽管键琴十六分、木鱼时钟、卡片撞击金属环、回头前最长静默。避免：歌词逐字动画、漫画话泡、血腥、幻灯片翻页、代码替身角色。
```

## 配方拆解

- **本质**：早期2000年代文字帧派的前卫电视动画式：满屏粗明朝体标题卡切入2–9帧，建筑简化为符号几何，红黑白配色，人物是剪影或极特写，招牌是越肩回头。人物由图像生成，其余（卡片、建筑、雨、剪辑、反色）由代码完成。
- **不是什么**：不是歌词视频（文字不与歌同步、绝不逐字动画），不是漫画分格片（无话泡、无网点），不是恐怖片（无血腥；恐惧来自剪辑、静默与静止），不是幻灯片（绝不纯卡片居中文字再翻页）。
- **配色**：红#d4162b（主角轨道、卡片底、光轨、主要道具、强调）、黑#0a0a0c（墙、剪影、第二人轨道、尾卡）、纸白#f2efe8（台阶、窗、卡片底、黑底上的字）、灰#8d8a84（仅英文行）。次级值只用于几何内部纵深：#d8d4cc、#26262a、#1b1b1f；皮肤与头发是生成图中的其他颜色。反色是红黑互换，绝不是RGB反相（会变青）：灰度→对比度(5)→反相→乘红，白变黑、黑变红；用作2–6帧冲击点缀而非整体风格。每个说话人固定一种场色，全片不变，让观众不用声音也知谁在说。
- **材质渲染**：角色：生成的赛璐璐画、干净细均匀黑线、完全平涂且只有一个硬阴影色、无渐变无纸纹；从绿幕key成RGBA，纯生成的红拉到片中红。所有代码绘制物是Canvas 2D硬边多边形；无模糊、无辉光、无颗粒（合成颗粒0）；唯一的拖影是回头残像（头部层三份28%副本）。剪影是同一画作用source-in填单色，故无需新图即可黑、白或红。
- **字体字幕**：卡片与标题：Noto Serif SC 900（重明朝感、OFL）；单字700–1100px，闪帧卡允许出血出框；对话竖列120–170px绝不出血。小竖注（集数、说话人标签、计数）：Noto Sans SC 900，40–64px。英文：一行Cormorant Garamond Italic 600，约为中文四分之一大、灰压黑或白、黑压红。竖排标点：。与，移到字格右上；？保持直立。绝不画面居中：字在角落、边缘轨道、物件上或出血。两类文字：闪帧卡（2–9帧，故意短于阅读时间，只重复或碎片化已完整出现过的词）与保持行（对话、信、尾卡），后者按完整阅读时间保持并用readcheck.mjs校验。
- **运动质量**：剪辑即动画：30fps闪帧卡2–9帧；建筑镜0.3–1.6s；静态不超一秒。切点锁拍（150BPM=12帧一拍在30fps很好用；八分=6帧、十六分=3帧）。卡片砸入：第0帧1.08×、第1帧1.02×、然后1.0；前两帧抖动10–14px、之后1–3px（整像素逐帧随机、无运动模糊）。轨道从画面边缘3帧砸入、完全入画才算在屏上。角色靠层与步进而非补间动作：头部层绕颈旋转、人物每拍跳近一次、剪影每步上下一次。靠缩短镜头加速（9→6→4→3帧），不是靠加快移动。
- **镜头语法**：完美对称fast push进一点透视走廊、楼梯或街道：必然性、被吸入——适合传唤、追逐、倒计时；极端偏移：主体在一边、半屏空：孤立、缺失——适合转身、等待、缺席；硬推网格中一个元素（柜、窗）：众多中的这一个——适合选择、线索、名单上的名字；沿正交墙横移：搜寻、消磨时间——适合走廊、立面、档案；锁拍步进推（镜头每拍跳一步）：努力、攀登——适合上行、层级、进展；从空间顶部人物下方的低角度：权力、路径尽头——适合对峙、目的地；1:1比例插入镜（眼、手、信）慢推下保持：亲密、威胁——适合揭示、触碰、讯息；一张脸多裁格：执念、监视——适合跟踪者、众多个自我、记忆；分屏：一边画面、一边说话人轨道：无唇对话——适合电话、审讯、告白。切在拍上。转场是切、1–6帧反色、一点透视隧道冲刺、黑上裂开红缝；绝不叠化、擦除或翻页，镜头间也绝不纯黑帧（用红缝）。
- **声音配乐**：乐器：羽管键琴十六分ostinato、低音提琴与大提琴拨弦、木鱼当时钟、钢片琴摇篮动机、耳语般小提琴颤音、弓颤音琴、定音鼓、大鼓、军鼓、低铜管（长号、大号、圆号）重击与♭9和弦、管钟、大锣；避开钢琴与铺天盖地弦pad。卡片撞击（合成）：高通噪声瞬态+1760/2637/4186Hz金属环+52Hz下坠；随张力逐卡升调。拟音：柜门哐当、纸、手机震动（155Hz门控方波）、渐强脚步、天气床、回头时的颈骨crack（低咔+咔哒+噪声瞬态）、心跳。静默即剪辑：至少两次硬静（只留一音、其余全关），最长的一次紧接回头之前。混音：时钟与撞击干而靠前、音乐在下；响度归一前先限瞬态（−14 LUFS、真峰值≤−1dBTP）。
- **招牌技法**：
  - 闪帧卡：纯场底+一巨字（可出血）+砸入抖动，2–9帧，与3–6帧画面切成字—画—字锯齿——适合倒计时、要求清单、打断的词
  - 说话人轨道：左或右边缘全高栏用说话人颜色、竖字+一行英文+一字说话人标签，旁边画面持续切——适合电话、告白、双人争执
  - 章节卡：一巨字+竖集数+英文行+色条切入，四种版式使章节不重样——适合系列预告、分章宣言、产品的四个承诺
  - 回头：角色画分层为头与身（头多边形+颈枢轴+遮缝黑领片），背转（头−35°）→60ms蓄力→120ms甩到+0.1rad过冲→0.1·e^(−9t)·cos(26t)安定；甩在全剪影中带三颗残头，安定帧硬切到彩色并2帧红黑反色——适合揭示、挑战、品牌吉祥物的回头
  - 符号建筑：几何楼梯（踏面按r^k缩放、红光爬立面）、窗隧道（嵌套矩形k=1/(z·0.32+0.08)）、按深度缩放路灯的一点透视街、柜墙、窗墙——适合学校、写字楼、夜城
  - 踏步逼近：人物每拍被重画得更大、绝不补间——适合截止日、对手、逼近的风暴
- **避坑**：
  - 必须有图像生成器：角色由用户提供的图像工具绘制（其Codex CLI经core/image/gen_image.py，先--check，或其他图像API/应用），二者皆无则此风格无法开工，需在brief说明；绝不用代码画替身角色。
  - 先问材料：生成前问用户有无自有角色设计、logo或产品图，用户给的优先；若无，生成前告知用户要几张、什么图（如两角色各一张model sheet，再六姿态三特写，共十一张）。
  - 管线：每角色一张model sheet（平绿幕#00FF00下半身定义姿态）；后续每张以该sheet作参考图（--ref）并在提示词说同一角色；新角色只以已有者作画风参考（不同人，参考仅画风）；特写（眼、嘴、手、信）单独生成，满框插入可纯背景，凡要合成的一律绿幕。
  - 任何图里不得有文字（no text, no letters, no logo, no watermark），所有字由代码排。
  - 提示词模板：现代前卫TV动画平涂赛璐璐风、严格匹配参考图画风：干净细均匀黑线、完全平涂只有一个硬阴影色、无渐变无绘纹无腮红排线；调色限漆黑、米白、淡肤、深红。[主体、姿态、构图、表情、服装]；背景纯均匀纯绿幕#00FF00、背景无影无地面。

**适用场景**：悬疑与剧情预告 / 片头字幕 / 宣言片
