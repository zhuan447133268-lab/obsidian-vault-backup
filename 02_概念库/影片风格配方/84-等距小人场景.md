# 84 · 等距小人场景 / Isometric People Scene

> 分类：立体微缩
> 参考片：七十二个座位
> 原片一句话：等距的登机口和机舱里，小人按顺序登机，讲清哪种叫法快将近一半。

## ⭐ 可直接复制的提示词

```text
用等距小人场景风格：画面是一处真等距（轴30°）、平涂纸色画满全幅的真实场所，无板边暗角；无脸小人从背后看按规则顺序做事，衬线关键词像画在地上逐字落下，遮住动作的屋顶切低或像纸盖翻开。配色：暖纸地面+深墨+专给规则的强调色+主题色+标记色，人穿四种低饱和上衣，阴影只往暖棕不往灰紫，强调色稀有只在规则处。字体：中文衬线与书本衬线数字，地面字大1.5m小0.8m沿右上轴每字约0.14s落下，字幕是下方浅色条中上英下。运动：30fps逐帧、人按顺序动走约1.5m/s、缓动不弹出、倒放配倒数。镜头：角度固定只有平移缩放，慢漂推、跟队首、开盖升全景、锁定框、尺度跳。声音：直立钢琴+颤音琴逐字、场所床跨切、旁白下闪避16dB。避免：浮板信息图、低模地形、卡通表情、人物飞驰、字被高物遮挡。
```

## 配方拆解

- **本质**：一个平静的日常规则解说，设定在一个用真等距、平涂色画出的真实场所：从背后看的无脸小人按顺序做事，衬线字像被画在地上一样逐字落下。遮住动作的屋顶或墙被切低或像纸翻盖掀起。动作的顺序就是解释。
- **不是什么**：不是等距信息图（那是在浮板上搭模型、用无衬线大头针与图标统计追踪流程；这里无板边、无大头针、无图标，场所是真实满幅的，标签是躺在地上的衬线词，解释靠小人遵守规则）。不是低多边形等距小岛（无光照、无分面地形、无阴影辉光；实体是三色平纸色、地面是印刷平面）。不是卡通（无表情无笑料），不是幻灯片（无页眉、居中标题、卡片）。
- **配色**：暖纸中性做一切地面（室外水泥略冷、室内地毯略暖）、一种深墨、一个专给规则的强调色（关键词、站这里轮廓、箭头、亮牌、中奖数字、重要的一段地面）、一种由场所自身承载的主题色（座椅、涂装带、椅子浅一档、牌边）、一种标记色（引导线、牵引车、行李拖车）。人穿四种低饱和上衣，满屋读成均匀的四色织纹。强调色绝不装饰，只在规则处出现且保持小（稀有才吸眼，许多帧完全没有）；强调色路径只标正在讲解的那段（在行者或车前方长出、身后淡去），不是全片留下的轨迹。主题色与标记色须与四上衣在色相和明度上都拉开。阴影只往暖棕与纸色走，绝不往灰或紫走：脏阴影最快毁掉此风格。示例：纸#F1E8D8、水泥#EAE2D3、地毯#F2E5CE、墨#2A2E29、强调柿#D0573A、主题绿#3D6B59/#A7C2B2、标记姜黄#E2AE3A；上衣赭、雾蓝、灰紫、燕麦。
- **材质渲染**：真等距（轴30°）、Canvas 2D、画家排序。每个实体与每个人都按地面footprint（地面层的x+y）排序，绝不按盒中心：按中心高度排的椅背会画到坐在它后面的人身上。实体每种颜色三档平涂：顶面提向暖纸、+y面是基色、+x面压向暖棕；曲面（机身、柱）分面并量化到同三档加一中间档，无渐变也读成圆。实体无描边、无阴影、无纹理、无高光点（圆树冠或球是平圆盘或同色分面实体，绝不是反光点）。新物件（车、机器、建筑、树）同模型：由盒、棱柱、分面实体按真实米尺寸搭成、三档来自kit的tri()、一眼可从剪影认出且比人简单；车从车身读（驾驶室、货箱、一条主题色带），轮小、低、多在车身下用一暗色，绝不是粗鼓或轮胎轮毂细节。地面只带功能标线（画好的车道、人字纹、引导线、停止条、座位方格）与淡砖或板缝网格。剖切是模型的一部分：近墙切低、远墙留窗；盖子是独立实体、纸色背面、在远边铰接故向远离镜头方向开；玻璃是淡色+细窗棂，凡挡在镜头与文字或人之间就切到女儿墙。人是锚在脚上的billboard、约1.6–1.8m高：圆发黑头+耳处一点肤、两档躯干、分开的裤腿、暗鞋、可选长发或裙、拉杆箱；坐着的人只在高靠背上方露肩与后脑。走路时腿沿屏幕剪动、手臂反向摆。身体遵守空间：人绝不穿过座椅、墙或彼此；队列脚间约0.75m；坐下的人先后退进排腿空间、侧走到座位再坐（绝不沉入或浮起）；提起的箱子要先上越过开着的箱口再放下，绝不穿墙或座椅。一切是时间的函数：排队人群载入时模拟一次（确定性）并用插值采样，故放慢重放仍每帧在动。
- **字体字幕**：中文衬线（Noto Serif SC，关键词700、虚词500）；拉丁与数字用书本衬线（Newsreader）。仅开放许可字体、按用字子集。地面字：大≈1.5m、小≈0.8m，沿右上轴阅读；每拍一个短语，画面紧时一行；每短语一个强调字或数字，绝不单个细笔画（『一』作强调会读成线）；字间距约0.14s落下：淡入并缩放1.22→1、淡幽灵→墨。绘制标题或一对数字可放大到×1.6。字落在干净地面上：其上无人站立、其前无凸起物，距每画边≥5%，避开字幕条。场中标识（门牌、组牌、屏幕）按等距角度朝房间镜头侧，绝不正对镜头的平卡。阅读时间：每段世界文字完整入画≥中文/4.5+拉丁/15+1.5s。旁白与字幕：讲述时旁白说出、画面同时展示：一动作或一镜一行、每行随其动作开始；冷静快速的朗读者；地面只承载该行关键词或数字，绝不整句。字幕：每条旁白一个提示、在下部安全区的浅色条上、中文行在上（约34px）、英文行在下（约25px、整句翻译）、硬切、绝不同屏两条。须记住的数字最多三个、每个都连同所比之物说出、屏上停≥2.5s。
- **运动质量**：30fps逐帧（渲染与mux.sh都传--fps 30）：人群与行走逐帧判定、检查也按此速率。人只在规则允许时按顺序动，顺序即重点；走约1.5m/s，屏上无人快于约3m/s即使延时：需压缩过程时表现为位置被填满（人坐进座位）而非人飞驰。一切都缓动、绝不弹出。一拍=一个地面短语+一个图示标记（描一条轮廓、在行者前长出箭头、光沿线跑）+一个动作。倒放把同一运动反向加速、配倒数。
- **镜头语法**：慢漂与推（约6–8%缩放）：对一条规则的平静注视——适合叫号、候诊室、读字停留；跟随队伍头部：事物的顺序——适合走廊、登机、列队；按主体速度沿地面行进：同一路上一个接一个——适合递送、游行路线、一排车间；盖子打开时升到全景：揭示整个空间——适合室内、容量、位置网格；锁定框：判断、阅读——适合判决、比较、最后一帧；退一步框住整个事件：一框看因果——适合一人阻挡、一门卡住；从外部向下tilt到人群：抵达、因→人——适合开场、换地点；尺度跳（房间→建筑→场地）：结果置于语境——适合判决、结尾。角度永不变（等距固定），镜头只有平移与缩放；每个运动都由动作驱动、字与主体在运动两端都留在框内。转场：连续运动、开盖、沿同路跑回、同角度拍上切；无翻页、擦除、黑或空帧；拉出须在半秒内显示下一主体（一个被画的标记）。盖子只在被看见时揭示：它在框内翻完、纸面朝上，然后向远离镜头方向滑走。
- **声音配乐**：柔和直立钢琴与颤音琴；每个落字一记颤音琴（关键词更响、强调字叠钢片琴）；人走时拨弦与沙锤。重复动作成节奏：卡住的队是碎拨弦刺，整齐的队每组一个和弦。安静的场所床（大厅空气、车厢空气、远引擎）与一记持续低弦根音跨过每次切、使换场不掉；场所的功能声（自制风铃、轮在地毯与金属上、箱盖、牵引车）。倒放把最后一秒音乐反向播放。有旁白时音乐在其下闪避约16dB并在行间抬起；混音约−16 LUFS（mux前）、真峰值低于−1.5dBFS。
- **招牌技法**：
  - 地面字：关键词落在动作旁的地上——适合医院分诊规则、投票站步骤、图书馆静音区
  - 多米诺起身：被叫的组坐在一起、从近端逐个起身进入画好的道——适合考场逐排离场、渡轮逐道放行、课堂演练
  - 揭盖：车顶沿远铰链翻开、纸面朝上并滑走、镜头升起看整个内部——适合车场里的公交、阶梯教室、装箱的集装箱
  - 顺序点亮：地点按将被使用的顺序依次亮起、在人动之前——适合座位分配、停车方案、按号排队接种
  - 顺序箭头：平强调箭头在行者前长出并在各自转弯处分支——适合扶梯车道、按类回收箱、单向博物馆路线
  - 织纹填充：地点按图案填入（隔一个、先窗）使房间成四色编织格——适合按区体育场、对号入座影院、按层停车场
- **避坑**：
  - 任何高出H米的物体会遮住其后方（朝+x的面遮−x方向、朝+y的面遮−y方向）：从长边向后H米内的地面被遮、站在那里的人低于边顶的部分消失、在H−1.7米内完全消失；低物件同理：0.8m的带或柜遮其后0.8m地面字、3.2m车厢侧遮其后3.2m内的人腿与1.5m内的整个人、玻璃墙或翼遮数米外的字。让字与重要的人在高物镜头侧，或把高物切低；逐帧检查有车经过的镜头。
  - 锯齿状路径（每个车或门都拐）读成噪音：路线沿世界轴走、少直角转弯、行者或车背向镜头。
  - 折成蛇形的队读成实心块、一条直线读成秩序；每人旁地面数字要留约1m间距。
  - 朝镜头走的人露出错误的背面视角：路线安排成向左上、右上或横向走。
  - 坐着的人消失在高靠背后：靠背低到肩可见。

**适用场景**：日常规则 / 排队 / 比较
