# 86 · 卫星简报 / Satellite Briefing

> 分类：仪器实证
> 参考片：地图上还写着海
> 原片一句话：卫星照着地图去找咸海，找到的是沙漠；只有筑了坝的那一块回来了。

```text
用卫星简报风格：真实卫星影像压成分析师冷灰，地面叠细白锁定框、轮廓、测距线与唯一读数；多层配准影像板羽化嵌套，一次对数缩放从轨道落地再返回，时间用扫描推进，转折处回真彩。配色：灰底、白专属测量，暖琥珀只给唯一读数，第二制图色只标旧地图。字体：细窄大读数、等宽仪器、引线标签，字幕为左下转录条。运动：镜头不停、停留缓行，标记靠生长落定，时间只扫描不叠化。镜头：斜视轨道开场、俯冲核验、锁定天底测量、沿线跟踪、爬回轨道。声音：FM ping、干哒、噪声扫描、定音鼓，人声高于音乐10dB。避免：图表、全息HUD、沙盘、幻灯片、生成图冒充证据。
```

## 配方拆解

- **本质**：以一个真实地点的真实卫星/航拍影像为底，压成分析师的灰色，再叠加极细的白色测量线：锁定框、轮廓、测距线、一个读数。一次由多层嵌套影像板构成的连续缩放把观众从轨道带到地面再带回，时间可以在同一个锁定画幅里推进。
- **不是什么**：不是数据故事图表、不是科幻全息HUD（无发光网格与虚构界面）、不是蓝图、不是等距信息图（要真实天底或斜视，不做沙盘），也不是发布会幻灯片（无翻页、页眉或章节号）。
- **配色**：中性灰地面（明度约3–65%），白色只属于测量标记；单一暖色（如琥珀）只给每屏唯一读数；可用第二种平面制图色标示被检验的主张图层（旧地图/规划），绝不用于测量。轨道与故事转折处才恢复真彩色，禁止伪彩渐变。示例：地面#070B0E→#A1A7A9，标记#F2F5F6，读数#FFBE55，地图蓝rgb(46,112,206)。
- **材质渲染**：地理配准栅格按分辨率嵌套（世界→区域→细节）羽化过渡，着色器中按相机射线落点采样。地球用射线-球求交、双精度计算|C|²−R²、仅轨道处加大气边缘与临边阴影。分析级调色：局部对比与清晰度、肩部保住盐雪云不过白、蓝黑→冷银至约65%灰、色度降至五分之一。标记是走同一世界→屏幕函数的2D叠层，1.2–2.6px带暗晕，虚线表历史与主张；主张图层是按旧轮廓距离场绘制的印刷地图（纸纹、网点、海岸线、经纬网）。后期轻颗粒+暗角，仅甩镜用方向模糊。
- **字体字幕**：读数用细窄无衬线（如Barlow Condensed，96–130px），仪器与日期用等宽（IBM Plex Mono，20–34px），标签用无衬线（24–42px），衬线只用于主张图层与标题；OFL自托管、CJK按用字子集化。标签用引线锚定地面，读数在右三分之一紧邻所测物、上标签下来源（如『Landsat，实测』）。字幕是左下角转录条：2px白线+向右淡出的暗板、左对齐、每行不换行。1080p下任何字≥20px；字幕停≥max(1.8s,语音+0.6s)，CJK标签≥字数÷4.5+1.5s。
- **运动质量**：镜头永不静止：距离按对数插值、分段缓动、停留保持2–5%缓行或慢转，冻结不超一秒。标记靠被制作出来呈现——线生长、轮廓在扫描后印制、计数器滚动落定带小弹、锁定框过冲。时间变化一律是扫描而非叠化，间距表速度，镜头随之加减速、末段刹车；地面及其标注、仪器位置绝不移动。
- **镜头语法**：斜视轨道（边缘入画）：开场、回归、标题卡；俯冲（对数缩放+转天底）：揭示、核验主张；锁定天底慢缓行：时间流逝与测量；推近某点：锁定一城一坝一田；沿线跟踪：测距、河流道路边界；带模糊甩镜：同高度换主体、反例；爬回轨道：结尾与总结。关键时刻主体占画高1/3，读数在右、字幕在左下、仪器在四角。转场用扫描替换、关地图层、穿越影像板、甩镜、锁定框展开成标题；不用交叉叠化、缩放中不硬切。
- **声音配乐**：遥测感：FM ping、栅格上的干哒声（分频加速）、噪声扫描（快进升、回倒降）、伺服啸叫、测距线棘轮声。重量：定音鼓、大鼓、大锣、弓镲，时间倒流用反锣，测量落点在音高打击上。合成：带2/3次谐波的脉冲低音、低通锯齿pad、俯冲riser。铺底：轨道嗡鸣、无线电嘶声、数据杂音，地点自身环境声（风、水、远角笛）克制使用并常做J/L切。全片保持干音色，只留一个湿音色（玻璃/水/弓金属）标记转折；寂静后第一声即转折；最重打击前0.2–0.45s吸声（音乐与音效降约25dB）。人声高于音乐约10dB，两三个设计打击最响，20–60Hz比全频低约15dB、冲击重量在60–120Hz，−14 LUFS、真峰值≤−1dBTP；旁白是冷静分析师、短陈述句。
- **招牌技法**：
  - 地图对照片：镜头落入主张的印刷地图，扫描条撕开露出真地面，名字比纸更长久——适合地图上仍在、实际已消失的湖，被清伐的林地，未建成的规划城
  - 锁定画幅时间环：带日期的影像板逐张扫入、各留轮廓，两环之间流失的带闪动——适合冰川退缩、城市蔓延、逐年火痕
  - 测距线：标终点、从A长出带刻度的线、追线头同时读数累加、落数后拉远看全程——适合岸线移动、村庄到水井、营地到边界
  - 俯冲与爬升：从轨道一次缩到地面或反向——适合定位任何目标、尺度揭示、把一个地点送回星球的结尾
  - 转折处恢复色彩：灰色中只有主体回真彩——适合灌溉田、回蓄的水库、复长的森林
  - 锁定框成画框：锁定括号展开框住标题卡或最后读数
- **避坑**：
  - 授权：Google Earth/Maps、Bing、Esri、Mapbox、Planet、Maxar、新闻图、AI生成图不可用；EOX Sentinel-2仅2016版为CC BY 4.0；原始Copernicus需注明『Contains modified Copernicus Sentinel data [year]』；USGS Landsat/NAIP、NASA Blue Marble/MODIS/VIIRS可署名用；把可读署名烧进画面并在CREDITS列全。
  - 影像缺口绝不能用生成图冒充证据；OSM(ODbL)、CC BY-SA及『no known restrictions』都不是CC0，先说明条款并问用户；地点属用户时索要其自有测绘或GIS图层。
  - 接缝：不同日期影像不一致——每条路径用同一天、在稳定地表做增益匹配、羽化重叠、只用同年补洞；老传感器Landsat MSS无蓝与短波红外且丢扫描行，需最近邻重采样、近零行作nodata由同年景补、条痕只在陆地清；羽状雾霾跨水成亮斜带时换同年另一景而非涂掉。
  - 边缘：对nodata重采样会让景边发暗（腐蚀掩膜），丢弃板边轮廓碎片；真实直边（堤、圩田）可能被误读为接缝，避开取景或加标注。
  - 近距灰糊：只在该高度提局部对比、量测走廊外压暗；水体用MNDWI且只取所测流域，云被读成灰地物故用旱季。

**适用场景**：气候 / 新闻解说 / 地理
