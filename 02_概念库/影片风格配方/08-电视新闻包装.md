# 08 · 电视新闻包装 / Broadcast News Package

> 分类：剪辑纪实
> 参考片：本周 AI 四件事
> 原片一句话：一周四条 AI 新闻，一整套电视台包装：串联单、标题条、翻牌价格表、规格卡。

## ⭐ 可直接复制的提示词

```text
用电视新闻包装风格：16:9干净画面、无烧录字幕无滚动条，全用代码扁平图形压墨底；统一组件（品牌板、签、标题条、墨卡、印章）＋永不退场的下三分之一标题条＋开合串联单；配色为墨#121417＋柠檬#F2CF1D＋金#D4B064＋纸#F4F1E8，强调上用墨字；中文Noto Sans SC、数字Barlow Condensed、标签中英各一行不换行；120BPM每剪辑擦除踩拍、镜内每0.5–1s翻牌计数盖章打勾；运镜为sting板砸入飞角变台标、串联单翻入打勾、折线破阈值、地图推摇、文件飞出城市；声音为冷静主播＋小调新闻主题＋签名击中＋拟音；避免社媒大字、仪表盘、keynote与虚拟演播室。
```

## 配方拆解

- **本质**：电视新闻演播室的整套屏幕包装，全用代码搭成：开场sting变成台标角、一条串联单贯穿开合、永不离开底部的下三分之一标题条，以及承载事实的全屏图形（翻牌价格板、破阈值折线、讲解地图、文件飞出城市、引语卡、带比例条的规格卡、印章）。风格＝包装系统＋剪辑规则，不是绘图风格。16:9干净画面：无烧录字幕、无滚动新闻条。
- **不是什么**：不是Caption News（那是字幕优先的社媒视频，巨大砸入字幕是主角、无串联单无标题条；这里字小而有序、图形主导），不是数据故事（每拍一图从不做仪表盘，图只是简报中的插页），不是主题演讲（无居中标题项目符号、无翻页），不是演播室节目（无虚拟场景、无主播、无穿越镜头）——是墨底上的扁平图形。
- **配色**：四角色＋一个预留报警色：ink#121417（底、板、标题条端块），ink2/ink3#1B1E23/#22262C（卡、地图落点），accent柠檬#F2CF1D（亮#F8DE4A、暗#D8B30C，用于板、签、擦带、条、印章、破线），gold#D4B064（阈值、日期、来源、浅鳍、徽章），paper#F4F1E8（标题条、文件、折线），breaking#FE6B3D只给BREAKING与LIVE（周综述没有故永不出现）。accent上用墨字；纸上英文副行用深橄榄#6E5A1E（gold太弱）。换品牌时保留「一强调＋一金色副色＋纸＋墨＋预留报警色」的结构。
- **材质渲染**：分区：内容x96–1824/y56–840（有标题条时y840下不放要紧物）；下三分之一签x96y856高48、条x96y904 1250×104＋120px墨端块；来源行右对齐x1836 y950/978、mono13px＋中文16px、75%不透明、英文≤36字符；台标右上角中心(1739,86)为sting板的0.327；角标左上x96y56 330×64，生成画面标ILLUSTRATION/示意·AI生成画面、示意图标SCHEMATIC/示意图，0.2s翻入翻出。内容层比带字幕版低60–110px，去掉字幕与滚动条后要重排版，不留死带。所有图版统一调色：灰度→自动黑白点（0.5/99.6百分位）→γ1.05→35%S曲线→黑8白232→双色#0E1013→#ECE7D8，加左侧压暗渐变供字、50–55%暗角、7%叠颗粒循环六块；图形与包装绝不加颗粒。无实拍时画面层是代码数据图＋至多几张插画版（各标ILLUSTRATION），只营造气氛绝不代替事件、地点、人物；有实拍走同一调色，现代片≤1.5×、档案≤2.5×且去块，裁掉台标。
- **字体字幕**：中文Noto Sans SC 900（标题、条）700（标签）；拉丁Barlow Condensed 800（数字、名字、板）600（副行、引语）600斜体（尾卡英文标题）；mono IBM Plex Mono 500写日期、来源、轴标，全大写字距1–4px；全部OFL自托管子集，无手写体。每个标签 bilingual 各一行、中文先英文小、绝不换行。
- **运动质量**：120BPM网格，第0拍在sting末（1.5s），每次剪辑与擦除踩拍或半拍。镜长：sting1.5s、串联单4–5s、故事镜3–7s、地图长镜6–12s作简报的呼吸、对比保持到每物完整在画≥2.5s。镜内每0.5–1s一个包装动作（翻、计数、盖章、打勾、换条、地图点亮、折线步进）；无帧平过1s、每次剪辑0.5s内有强动作。每个故事都标日期（在串联单行、眉线、读数或文件里）。故事内顺序：是什么（名字/数字）→多大（折线/条/价格板）→影响到谁或谁说的（条/文件/引语）→判语印章。
- **镜头语法**：镜内运动来自包装与图形动作：sting板砸入后飞到右上角变台标、串联单行按拍翻入结尾逐行打勾、标题条签换类别时闪白且文字上下翻、翻牌砖各格从旧值翻到新值、折线逐交易日推进后以强调色带抖动与环破阈值、地图长镜先推后摇让位、文件沿弧线飞出城市、规格卡括号把部分合到总量、印章落下、眉线计数。无交叉溶解、无滑页、无黑场切；转场靠sting带擦入第一镜。
- **声音配乐**：主播一人一图一句、切后0.1s起，HP90Hz、3:1压缩，默认Kokoro（或用户录音/自有TTS）；音乐低于人声≈−7dB且300Hz–5kHz在语音下削薄。新闻主题120BPM小调：跳弓提琴根-五-八度八分、拨弦贝斯、圆号铺、低通16分锯齿脉冲、底鼓1/3、军鼓2/4。分段情绪：市场＝提琴低八度＋颤音＋四踩底鼓（心跳），政策＝只拨弦与圆号。签名击中：sting全奏、串联单行落钟琴、硬切与换故事定音鼓、最大突破前静一拍再全片最重一击、判语章后持续低鸣、最后故事大调上扬、尾卡全奏。拟音：擦除呼啸、翻牌咔哒、盖章闷＋脆、市场图交易滴答、地图每国点亮咔哒、城市声呐ping、文件纸张与打字机、打勾咔哒＋钟琴。房间：科技版下服务器嗡、地图下轻空气。母带−14LUFS、真峰≤−1dBTP。
- **招牌技法**：
  - sting变台标：品牌板砸入后飞到角落留到全片末，开场与节目是同一物件
  - 标题条签＝类别：换故事时签变色并闪白，故事间不再插独立条目卡
  - 串联单先列后打勾：同一份清单开场与收尾，结尾每行打勾
  - 规格卡：一次发布缩成比例——整体与部分同一尺度，再接它靠什么运行，括号合到总量
  - 永不离开的标题条：一条标题组从第一条到回顾，只有字在翻、条本身不中途退场
  - 翻牌前后对比：新旧值同在一板，每格从旧翻到新
- **避坑**：
  - 包装遗留：标题条/来源/角标若画在一切之上，擦除会露出昨日标题而条迟0.3–0.5s跟上——每镜内画、在擦除clip内
  - 去掉字幕或滚动条不重排版会在条上方留死带；遮罩标题推进距离不够会提前露顶边——从遮罩下方完全起始、progress 0不画
  - 词强于来源：「征求意见」不等于「调查」或「处罚」，阈值须标明基准高点，机构自己页面可能与报道矛盾
  - 示意图冒充数据：滚动计数器闪烁不存在的数值→用遮罩推入定收盘；来源行右对齐≤36字符
  - 纸底金对比不足用墨或深橄榄；生成版裁掉角标；印章击中可能盖住人声，去铜味并低通其脆响

**适用场景**：新闻综述 / 简报 / 市场播报
