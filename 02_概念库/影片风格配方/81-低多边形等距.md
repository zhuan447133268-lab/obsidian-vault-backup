# 81 · 低多边形等距 / Low-poly Isometric Island

> 分类：立体微缩
> 参考片：长出来的岛
> 原片一句话：空海里一格格长出小岛和村庄，每放一块响一个音符，直到星空。

## ⭐ 可直接复制的提示词

```text
用低多边形等距风格：平面着色的几何块（六棱柱地形、棱柱屋顶的盒楼、锥形树）漂在刻面海面上，正交等距相机无透视无地平线、远处融进屏幕天空渐变；柔和不饱和色、时间靠光与色组关键帧变化、夜里暖发光块是唯一亮物、无描边无黑靠AO；正交转台、纯缩放、仰角变化、广角特写拍上交替、硬切或穿天变焦；每件升起/落下/弹出都带弹跳过冲与溅水并弹一个音，字幕圆润体旁配随时刻变色的瓦片图标；配马林巴卡林巴有音高打击与事件驱动旋律、无钢琴弦乐；避免体素方块、透视地平、光滑卡通与胶片颗粒。
```

## 配方拆解

- **本质**：一个由平面着色低多边形构成的迷你世界，用正交等距镜头观看：一切都是几何块，一切出现都带着弹跳与一个音符。
- **不是什么**：不是体素游戏（无方块叠方块、无像素纹理）、不是真实地点的移轴照片（无透视无照片细节）、也不是光滑着色3D卡通（无圆滑法线无次表面）。
- **配色**：柔和、低对比、少数几种色：一个地面族（沙/草/土或其等价）、一种中性岩石、一小套墙与屋顶色在全建筑重复。一天中的时间是可关键帧化的色组（天顶/地平/深/浅/日光色/强度/仰角/方位）并插值：白天通透偏冷、黄昏地平转暖、夜去饱和向蓝紫；夜里暖发光块是唯一亮物（窗/灯/光束）。关键镜头让太阳侧对相机（低太阳在目标背后会把刻面水变成眩光）、水面不受影；无描边无黑，影与AO是唯一的暗部。示例：沙与草配珊瑚屋顶在淡蓝白昼、雪瓦配松绿与红木屋在丁香天、赤陶台地配鼠尾草灌丛与绿松池在杏色黄昏。
- **材质渲染**：几何（世界单位＝六边形外接半径）：尖顶六棱柱（CylinderGeometry(r,r,h,6)），轴坐标转世界 x=√3(q+r/2)、z=1.5r；地形高度编码材质（沙低、草、丘、岩最高）；薄顶盖盖在较深的侧色上，侧柱的顶要下沉到盖之下否则z-fighting；瓦片间留小缝让AO画出接缝。道具是原语组合：盒、棱柱、低段圆柱与圆锥、detail 0的二十面体、收腰盒；发光件（窗/灯）每物独立材质以便单独点亮。材质为MeshStandardMaterial({flatShading:true,roughness≈.9})、无纹理，每块瓦的明度抖动几个百分点使地面不像表格。水（若有）：密集非索引平面在shader里叠加正弦位移、平面着色使每个三角独立闪动（粗糙度别太低否则刻面闪白），下方一张粗平面供拉远；每帧重绘一张浅滩图，在陆地存在处混深→浅色并带淡泡沫边，每块瓦的水线加一圈细透明环作浪花。无地平线的天空：后期把正交深度线性化并把远处像素混进竖直屏幕渐变，雾的起止按视锥高度×cot(仰角)设定，使地平带在任何缩放下都留在上三分之一；星只出现在雾厚处（哈希网格＋闪烁）。后期：MSAA＋深度→GTAO（必须，它画出瓦缝与屋下）→天空与雾合成→画幅边缘极轻的移轴→bloom（夜更强）→柔和调色→Neutral色调映射；2×超采样。光束（探照/投影/火把）是朝相机的高斯剖面带、根部亮随距离淡，外加更宽的淡晕副本，并在其下的表面用独立shader照亮。
- **字体字幕**：几何OFL无衬线：圆润体做字幕（Quicksand 600）、几何大写宽字距做标题（Josefin Sans）。字幕无框、暖白＋柔和深蓝投影、低置居中，旁边一个小平面着色瓦片图标、其顶色随时间变化；停留≥max(1.8s,语音+0.6s)，不与下一行或标题重叠。标题像瓦片：字母从水面下逐个升起、过冲后落定。覆盖世界的文字卡留一道空隙让世界保持可见。
- **运动质量**：逐帧24fps、平滑；魅力在"到来曲线"而非跳变。从下方升起：短三次ease向上＋阻尼正弦过冲，破水那一刻有涟漪与水花，事件时间取落定之时。落下堆叠（楼层/屋顶/环）：快速ease-in落下＋阻尼弹＋落地保体积的挤压拉伸。弹出（树/灯/细节）：scale=1−e^(−ks)·cos(ωs)，约25%过冲。生命：磨坊转、烟一股股、鸟盘旋、船按与水面相同的波函数起伏（在CPU上求值）。生长排在音乐网格上：最小格至多一件，使每个事件保有自己的音符；靠密度（二分→四分→八分）加速而非变速。永不移动的是投影（无透视、无fov变化）。
- **镜头语法**：THREE.OrthographicCamera，视锥高即缩放（特写几单位、整个世界十余、尺度揭示数百），相机距≥3×视锥高否则画面底部会露出海面之下。转台（方位扫，各面看一件）；纯正交缩放（无透视的尺度：背景中的细节/渺小/世界中的世界）；仰角变化（低≈20–25°展宽天空带、高≈50°读如地图）；锁定3/4广角（世界自活、灯亮/延时/等待）；一次到来的紧特写（弹跳与水花）；侧角跟拍移动物（横越画幅、绝不贴镜头）；沿一行瓦片横移（列表/序列）；相机不动的延时日光扫（光是时间机器）。广角与特写在拍上交替：广角显出形状增长、特写卖出弹跳；转场为拍上硬切、时间-of-day变化、穿天变焦；无叠化、无透视甩镜。
- **声音配乐**：音乐可事件驱动：生长事件带一个音、配乐在其确切时刻合成每个音，等于画面写曲；有音高的打击适合刻面（马林巴、卡林巴、木鱼、铃、颤音琴、钢片琴、钢鼓），其下是柔pad＋温和的ostinato＋轻沙锤或软底鼓；五声或调式材料使任意音序都协和；无钢琴、无弦乐。一个音可作母题（世界独有的铃/铃铛/号角，变化后再现）。拟音随材质且全可合成：升瓦＝气泡扫＋飞溅带水滴tick（越大越低）、楼层＝木敲＋轻一记回弹敲、屋顶＝陶瓷咔、空心木板敲、重石thunk、玻璃叮、通电＝低whump＋电流嗡。底床：低通棕噪的水带涌、鸟＝下滑的FM啁啾、吱木、夜里的蟋蟀或风。留白：降到低drone＋底床、大强拍前音乐总线数字归零、可把ostinato减到一声而非停、也可让世界自身的事件撑起一段节奏。旁白清晰温柔、少量短句，避开与主题撞词（烘焙片里"flour"听成"flower"）；混音：旁白压缩且远高于音乐、音乐在其下闪避、−14LUFS、颗粒0（平色遇颗粒会闪）。
- **招牌技法**：
  - 建造即作曲：每件落下的件都弹一个音，之后一次横扫按空间顺序把它们重放成完整旋律——适合楼层是音符的天际线/团队组装产品/花组成和弦的花园
  - 程序化生长：瓦片升起、楼层堆叠、树弹出——适合创业第一年/珊瑚礁恢复/街区规划
  - 纯缩放的尺度：一物填满画幅、然后世界变成一粒尘（或相反）——适合百万人中的一个用户/大陆上的一个村庄/网络中的一个数据中心
  - 转台：围绕被造之物连续旋转——适合机器组装/博物馆藏品/房屋翻新
  - 光作时钟：影子扫过、刻面重新着色——适合商店的一天/农场的一年/医院的一个班次
  - 暗中发光块：灯逐盏亮、光束像时针扫过——适合网络上线/小镇入夜/志愿者汇聚
- **避坑**：
  - 共享后期里的perspectiveDepthToViewZ对正交相机是错的→改用orthographicDepthToViewZ
  - GTAO把精灵与透明物渲成实心quad→AO pass时隐藏它们、零透明时设visible=false；侧柱与顶盖共面z-fighting→下沉侧柱
  - 双面加色圆锥读成两条白线→朝相机的高斯带＋光晕；相机距不足视锥高→画面底露出海面之下，距离≥3×视锥高
  - 两件落在同一格槽会搅乱旋律→每槽一件；half是GLSL保留字
  - 拉远穿过高物会出一帧丑画面→高物按缩放淡入；文字遇掠射不可读→俯视图印字；投影永不变（无透视无fov变化）；太阳关键镜头侧对相机、水面不受影

**适用场景**：游戏预告 / 世界构建 / 平静内容
