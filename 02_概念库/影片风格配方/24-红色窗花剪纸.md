# 24 · 红色窗花剪纸 / Red Paper-cut

> 分类：传统工艺
> 参考片：年兽进村
> 原片一句话：除夕年兽进村，小女孩剪出的大窗花照亮全村，把它吓跑。

## ⭐ 可直接复制的提示词

```text
用【红色窗花剪纸】风格：画面上一切都是剪刀剪开、平铺的窗花纸片，剪口即描绘、孔洞即透光，无描边无渐变，人物是铆钉连接的关节纸偶、可换脸片，纹样用锯齿月牙漩涡云与镜像团花；配色中国红为主角，深度靠相差一级的纸色而非明暗，底面与主角不同纸系，金箔仅后段一点缀；字体是画面里的红横批纸、米色字、锯齿燕尾约 44px；运动为人物 12fps 硬朗逐格、镜头光雨火 24fps，折剪展落重拍；镜头极近跟剪刀尖、平视锁定、横移视差、俯拍桌面、绕团花旋转，转场皆纸的动作；声音为琵琶筝二胡笛笙五声室内乐加剪纸拟音、温暖说书人；避免皮影背光、矢量描边、红压红糊团与悬空剪口。
```

## 配方拆解

- **本质**：把中国窗花剪纸唤醒：一切可见之物都是一张被剪刀剪开、平铺在另一张纸上的纸片，剪口本身就是描绘、孔洞就是透光处。红纸是主角，底面也是纸（日间浅纸、夜间深色染纸）；人物是铆钉连接的关节纸偶，以硬朗的 12fps 逐格表演。深度与角色靠纸色分级而非明暗。
- **不是什么**：不是皮影戏（无幕布背光、无半透明染色皮、无操纵杆）——这里纸是正面受光且不透明，背光是留给关键时刻的特殊事件；不是扁平矢量图（无描边、无渐变），也不是剪影片（每个形状内部都被剪空）。
- **配色**：中国红（约 #d2201f，范围 #c8102e–#d7261e）是主角材料；深度与角色靠相差一级的纸色而非明暗：近处亮一级、远处暗一级、反派或重物更深一级。底面与主角必须属不同纸系：夜间背景全为深色染纸、只有叙事关键纸片是红；日间为浅纸底配红与淡红层。金箔只作后段一次点缀（太阳、标题、铜钱），绝不做第二主色。底面纸系随题材选：靛蓝夜纸（远层偏亮蓝、近层更深）、暖宣纸白日配淡红远山、或非节庆题材的翡翠绿/黑纸。
- **材质渲染**：每个可见物都是被剪开平铺的纸片，细节、体积、表情只来自「剪掉了什么」：无绘画、无渐变阴影、无描边。纸纹为各纸片内中性灰纹理 soft-light 混合，再用 destination-in 恢复 alpha 保证孔仍是孔；剪边为带轻微低频抖动的手剪折线，左上 1px 亮边、右下暗边（切口面），建筑机器用直线段加抖动绝不平滑。纸片在下一层投紧贴柔影，叠折纸露 2–6 条偏移暗边。人物为红块+yin 线：每片有 inset contour（轮廓内几单位的细缝）形成经典双线并分隔红压红。民俗剪语：锯齿排（毛皮/草/瓦/流苏）、锯齿轮、月牙（鳞/绗缝）、漩涡（关节）、云、团花、梅花、铜钱、锥形缝。无悬空岛（闭环剪口会让中心掉落）；眼睛用上下月牙留桥加瞳孔孔。表情为可替换脸片（笑/惊/惧/定/睡）不渐变。团花以一个 45° 楔形镜像 8 次（D4），其他折法 2/4/6 次，阳刻与阴刻环交替，保留折痕。光照：日景用纸原色；夜景 frame×lightmap 加暖光池，背光纸片自发光（光×纸透光 multiply、孔全亮），两级泛光与可选光束，泛光保持中心纹样可读；投影图案为孔遮罩压到地面 lighter 叠加。
- **字体字幕**：字幕是世界里的一条纸：如比画面红色更深的红横批（保住米色字）、锯齿边、燕尾梢，结实 OFL 衬线（如 Fraunces SemiBold）约 44px、低位、带纸影；以两格 12fps 落纸像贴春联，停留≥max(1.8s,台词+0.7s)，绝不重叠。标题是镂空字（阳刻，字腔是真孔）逐字 12fps 弹出，配锯齿边条与代码生成的印章。小字幕后可印在纸上。
- **运动质量**：人物 12fps 逐格（姿态按 floor(t·12)/12 采样），镜头/光/天气/火焰/飞片 24fps 逐帧。骨架在铆钉处固定（颈、肩、肘、髋、膝、颌、尾），硬姿态、极小缓动、1 帧过冲（pop=1.15× 一格），重量来自尺寸与镜头抖动。侧面抬起近臂会挡脸：手保持在脸前或用道具遮挡。折叠：翻片拆约 16 条，每条按 cosθ 压扁并沿折线放大 1+0.28·height（假透视），立起时变暗、过 90° 露浅色背面、影渐长、之后留折痕，每折约半秒落在重拍。剪制：沿剪刀路径以圆遮罩逐步揭示纹样，剪过外缘后废料落下，刀刃开合按节拍细分，碎屑飘落。展开： successive unfolds 相隔零点几秒，每片 ease-out 从折到平（啪的 snap），再尺寸微弹与暖色闪光。
- **镜头语法**：词汇表非路线，开场结尾随题材。典型运镜：极近跟剪刀尖（制作/匠人专注，开场、精确动作、签名）；平视正面锁定（剪纸如徽章，标题、宣言、全家福）；横移掠过纸层带视差（铺开的世界，村庄、路线、时间线）；低机位广角看形状从底层立起（尺度、威胁，风暴、对手、截止日临近）；俯拍桌面（手艺即情节，折、剪、拼、分拣）；推向受光纸片再拉回众多（一个动作扩散，影响、网络点亮）；翻页/揭纸（时空变化，昼夜、前后、章节）；拉回房间里的物件（影片是某人做的东西，记忆、礼物、传统）；绕团花中心旋转（秩序、重复，循环、团队）。构图：纸层始终平行屏幕，深度只来自视差与纸色、绝不透视；转场皆为纸的动作（折、翻页、揭、飞纸、穿框一刀），无叠化。
- **声音配乐**：拟音随材料：剪刀=金属剪切扫频(2.5–9kHz)+短鸣+纤维断裂；折=嗖声+折痕轻敲；展开=清脆 snap；重步=纸板闷响而非肉声；揭纸、粘贴=掌心拍击；火柴、噗声；鞭炮=20–60ms 间隔密响配低沉轰鸣。乐器：明亮的中华室内乐而非钢琴弦乐或皮影戏锣鼓：琵琶（长音轮指）、筝（破和弦、刮奏、轮指）、二胡（滑音）、笛、笙或扬琴色彩、木鱼、大小锣、框鼓，五声音阶。选项：一剪=一拍细分；上行筝句每件出现一音；框鼓心跳增重量；一面大锣留一处重音；屏息全静。旁白温暖说书人少句，人声下音乐压约 9dB、拟音压约 3dB，冲击避开人声窗；民俗人名可能需在 lines.json 设 asr 别名。混音 −14 LUFS，无胶片颗粒（纸纤维即纹理）。
- **招牌技法**：
  - 折-剪-展：折 2/4/8 次，一刀变多刀，展开落在强拍——适合一位老师众多学生、一个设计量产、一粒种子变田野
  - 孔洞即光：背光镂空透出深红、每个孔发光、纹样投到世界——适合透过一个人的想法、灯塔、故事里夜晚的家窗
  - 对称复制：镜像纹样剥落并倍增（团花→窗花→烟花）——适合连锁品牌、细胞分裂、歌在人群中传开
  - 碎屑有来日：剪落碎片后来化作雪、彩纸、星星——适合回收、剩余的时间、累积的小失败
  - 万物同一张纸：共用剪口，山脊可立成生灵、波浪可变成路——适合风景变地图、工厂原来是一台机器、拉远到制成之物
  - 镜像成对：一张折纸剪出两个人物——适合双胞胎、搭档、同一个人的前后
- **避坑**：
  - 红压红糊成一团：换底面纸系、近远纸色分级、重叠处加内轮廓线
  - 用灯罩把某层压暗会连覆盖其上之物一起暗：直接给该层染色（multiply 后恢复 alpha）
  - 平面 cos 压扁的翻片像插卡而非折叠：用条带假透视、立起时变暗、露背面色
  - 剪口揭示时透过孔看到未剪叠层：只在未剪遮罩内保留叠厚，剪掉部分用自己的偏移副本
  - 剪刀朝后：刀轴顺着行进方向、铆钉略在剪点之后；镜头间空帧让出入纸动作相互重叠

**适用场景**：农历新年 / 节日祝福 / 民间故事
