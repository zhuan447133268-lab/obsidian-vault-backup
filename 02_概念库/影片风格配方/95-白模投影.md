# 95 · 白模投影 / Projection-Mapped Model

> 分类：数据地图
> 参考片：被炸平的城市怎样长回来
> 原片一句话：投影机把数据一层层刷上鹿特丹白模：从 1940 年的空洞到今天的塔楼。

## ⭐ 可直接复制的提示词

```text
用白模投影风格：真实地点的纯白体块模型立在暗室基座上，投影仪把数据当柔光一层层涂在朝向它的面上、稍溢出板边，模型永不变只变光、光落在实体上无线框；每层一色族（分类暖琥珀/连续顺序色带）、同色只在同义时回归、太阳暖色其影为深蓝；数字轻grotesk、标签无衬线、年份等宽，读数在左三分之一配来源与图例条，图钉细线引到暗板标签；光以洗、逐楼点亮、电平爬升到来、相机缓移随层变速；镜头屋顶微距滑、绕升、降低角、侧面跟、灯回时拉回；配投影风扇灯起辉与槌玻璃声、转折前投影灭留嗡；避免激光扫描线、全息线框、虚构地形、广角GTAO暗带与同屏多色板。
```

## 配方拆解

- **本质**：真实地点的纯白体块模型立在暗室基座上，投影仪把数据当光一层层涂上去——落在朝向它的面上、稍稍溢出板边。模型永不变，变的只有上面的光。
- **不是什么**：不是等距信息图（无立体小景或图标）、不是低多边形岛（无虚构地形）、不是科幻全息HUD（无线框、光落在实体上）、不是卫星简报（无影像）、也不是激光扫描或点云片（无扫描线、光是投射而非测量）。
- **配色**：中性底：白模、暗室（近黑）、暗基座，投影的黑位是板上冷近黑。每层一色族按数据选：一个分类强调色给"旧的/例外"（如暖琥珀），连续数据用顺序色带（时间蓝→青→白、高度紫→品红→桃）。一种颜色只在含义相同时回归（早先的"之前"色后来再标同一批楼）。太阳是暖色、其影是投射的深蓝，太阳来时收起数据色。居室的灯下绝不给模型上色、同屏最多两套层色板。
- **材质渲染**：模型是真实地点的真实几何：建筑轮廓与高度来自开放数据（如3DBAG荷兰CC BY 4.0、PLATEAU日本、城市开放数据门户），按声明比例（1:1000/1:2000）挤出，模型上没有任何虚构或"代表性"之物、绝不用生成图代替地点；哑光白约#F3F3F1、粗糙度约0.9、边缘利落，水体是底板里较深的缎面嵌件、桥是低白板、薄底板置于暗缎基座上。灯光模型：室内光＝一柔键＋中性棚环境＋近景AO；投影是在shader里加在受光面的一项 colour×(0.42+0.58·max(N·toProjector,0))×投射遮罩，按反照率缩放、在水面上减弱，绝不是网格上的贴图。数据即材质：每栋楼的属性（年份/高度/排名/标记）存在顶点数据里，shader逐帧决定投影给它的颜色。太阳是按地点纬度与真实日期时间的真实方向光＋shadow map（NOAA/Meeus太阳位置），投影仪可以描它的影并测量、绝不假造影子。后期：物理DOF（近景更强）、仅投影高光之上的bloom、暗角、ffmpeg轻颗粒；GTAO只用于近景（广角掠视会出带纹）。2D层（读数/图钉/测量线/字幕）走相机的世界→屏幕函数以钉在模型上。项目夹放FACTS.md（主张/来源URL/原文措辞或测量方法）随片交付，屏上每个数字由脚本从与模型相同的数据算出。
- **字体字幕**：数字用轻grotesk（Inter Tight 200，120–140px）、标签用影片语言无衬线（Noto Sans SC 300/500，20–36px）、仪器/年份/坐标用等宽（IBM Plex Mono 18–22px）；OFL自托管、CJK子集。读数在左三分之一、每层一个：索引＋层名、一个大数字、一个标签、一行来源、一条图例条。图钉是从屋顶或地面点引到暗板上标签的细线（标题26px＋副行20px）；身份标签安静置左上（地点/比例/数据源）。字幕底部中央软暗渐变、无框、用真字体量；若双语则影片语言在上、每种语言一行、会换行就拆成两条提示而非折行。1080p≥18px；字幕停留≥max(1.8s,语音+0.6s)，标签≥字数÷4.5+1.5s（中文）、字母÷15+1.5s（拉丁）。
- **运动质量**：相机连续缓慢移动、随层变速、绝不骤停。光是演员：每层以柔边的光势到来——从投射轴扩散的洗、楼宇逐个短闪点亮、一道电平同时爬上每面墙、太阳时钟走动；绝无硬线扫过桌面。室内灯快切（继电器0.25s）、慢回（1s），投影仪起辉带短闪。计数器随光滚动并在光落定时落定、测量线从A长到B带刻度。永不移动的是模型、基座与图钉在模型上的锚点。
- **镜头语法**：屋顶高度微距滑行＋浅焦（开场/重要细节）；升crane后拉（只有从上方才见整体，揭示空洞/聚集/边缘）；缓绕带升（城市整体、层累积，适合随时间增长/对比）；降到贴黑的低角（高度/天际线/单塔）；沿一条线侧跟（模型上的实测距离：影/走廊/路线/视线）；室内灯回起时拉回（数据停、物件留；结尾或话题间重置）。关键时刻主体占画高约三分之一、读数在左三分之一、字幕底中、图钉绝不压读数；转场是单镜内的光变（熄灯/一层替换另一层/投影灭），非切、淡或擦。
- **声音配乐**：房间：室声、投影风扇（嗡＋滤气，灯起辉时升高）、室内灯继电器、灯起辉（zap＋thump）、洗光的气声（滑动的带通噪声）。光即声：槌与玻璃配逐个点亮、弓颤音琴配持续的光、上行槌线＋气riser配爬升的电平、每栋高亮楼一记玻璃音。重量：定音鼓、大鼓、锣、低铜管配沉重事实，暖低铜管配转折；低音提琴与大提琴只作和声底、不用通用钢琴加弦乐的旋律。留白：转折前投影灭、只留细风扇嗡，之后第一声即转折；最重一击前短吸音。旁白高于音乐约10dB，两处设计出来的冲击是最响的时刻，−14LUFS、真峰≤−1dBTP；旁白平静、短陈述句、数字平实念出。
- **招牌技法**：
  - 熄灯、起辉：室内灯→继电器→暗→灯起辉→第一层到来——适合场地前后/规划前的街区/任何“再看近点”
  - 空洞：只点亮回答问题的那一组，让缺席描出形状——适合战损中心/无住房的泛滥平原/公司持地/保护区
  - 按时间分层：楼宇按建成年份逐个点亮、每层比上一层更快、年份计数器滚动——适合新城生长/校园分期规划/港口扩建/开发商逐年组合
  - 上涨的电平：一道柔光同时爬上每面墙、矮楼先完成最高楼最后、读数随之上升——适合楼高/海平面或洪深/层数/限高测试
  - 太阳时钟：真实日期的太阳扫过影子、投影再描一条影并测量——适合新塔对公园的影/庭院冬光/光伏最佳屋顶/街道日照
  - 挑出来：一栋或一组独亮、其余保持暗、配图钉——适合文保建筑/待售地块/疏散计划中的医院
- **避坑**：
  - 墙法线绕反露出内面（墙看着中空）→从环序推出外法线；共用墙z-fighting→低于矮邻的部分跳过
  - 暖HDRI把白模照成米黄→用中性棚环境；广角掠视的GTAO出楔形暗带→只留近景用
  - 低太阳只照墙不照顶→从受光侧或侧面拍；窄影淹没在众影中→描出并在要紧的那条加填充与边缘然后测量
  - 发丝般扫描线读成激光扫描→每道投影前沿给宽柔边或逐楼开关
  - 标签悬空→图钉锚在建筑最高处而非轮廓中心；混来源的数字（官方高度与实测屋顶）须在屏上标明（roof/measured）；模型与基座永不变、图钉锚点永不动；数据颜色绝不在室内灯下上色、同屏不超过两套层色板

**适用场景**：城市规划 / 展览 / 城市数据
