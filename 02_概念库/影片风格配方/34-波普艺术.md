# 34 · 波普艺术 / Pop Art

> 分类：印刷版画
> 参考片：同一根香蕉
> 原片一句话：超市里几乎每根香蕉都是同一株植物的复制：一面一模一样的版画墙，一根被网点吃黑的老香蕉，最后一波换色翻出上千种香蕉。

## ⭐ 可直接复制的提示词

```text
用【波普艺术】风格：画面上每帧是一整张印好的海报，四版（红黄蓝+黑 key）印在暖米白纸上，本戴网点固定在页面空间 45°、越近越大；配色三原色平涂且大，橙=黄+红点、绿=黄+蓝、暗=红蓝点淹没，黑只给 key 线与字轮廓，色版错位露白缝；字体为高瘦压缩 grotesque 100–260px 色填充黑描边加异版影；运动为印品盖章式或逐版式到场，镜头长缓、缩放取对数、副本加速、翻转是卡片转面，24fps；镜头从硬币大点拉到整张、从一张拉到一墙、穿字腔、沿长印横移，转场来自印品；声音为印刷厂拟音加颤音琴康加小号，旁白电台感；避免漫画分格、屏幕空间网点、摩尔纹与脏纸。
```

## 配方拆解

- **本质**：用 1960 年代丝网与波普海报语言来讲事：固定在纸上的本戴网点、粗黑 key 线、平涂红黄蓝、永远对不齐的印版。每帧是一整张印好的海报；镜头推入网点、拉回印品墙，并穿过印品自身的形状移动。重复即意义：同一印品一遍遍印、套准与墨色略有差异，表现批量生产与复制。
- **不是什么**：不是半调档案片（奶油档案纸、柔色、人物），不是孔版印刷（粉蓝黄大豆墨套印出新色），不是丝网旅行海报（平面分层色、无网点），不是瑞士动态图形（纯网格字无印品图像），也不是漫画（无分格、气泡、拟声词、表演角色）。
- **配色**：三原色加黑与纸，其余都是网点套印：橙=黄+红点、绿=黄+蓝、紫=红+蓝、暗=红蓝点长大淹没一切。原色平涂且大：每张海报一个底色、一个主体色、黑用于描绘、纸用于呼吸。绝不把颜色叠在自己身上（红字压红底、黄主体压黄底无 key 线或纸盘）。暗绝不是黑填充，而是红蓝点长大直到画面淹没；黑只留给 key（线、字轮廓）。示例：红 #E4232B、黄 #FFD21F、蓝 #1E62B0、key #141414、纸 #F8F2E2。
- **材质渲染**：三层一次印成：plates 画布 RGB 通道存红黄蓝版密度（1 实、0.05–0.95 点、0 纸），黑 key 画布用 alpha，spot 画布放罕见无网专色；WebGL2 着色器把密度变圆本戴点（≤50% 为点、以上为圆孔），油墨在纸上相乘、key 覆顶。不透明填充挖掉下层（版、key、spot），画家顺序成立；over 给已印之物加墨（红点压黄=橙阴影、红蓝点长大=印品变暗）。网点在页面空间，由相机逆变换从屏幕像素换算；每格屏幕低于约 2–4px 时淡为平调，宽镜绝不摩尔纹。错位：每色版相对 key 偏移几个页面单位（屏幕上钳到几像素），轮廓旁露白缝；每个副本相对其 key 线偏移不同的小量，重复印品绝不雷同。key 线为变宽缎带，背光侧更重、开放端收尖，线宽补偿局部缩放。纸为暖米白带淡纤维与墨不均，做旧与粗糙保持低（干净印品），仅为印品定年时提高。总线颗粒 1，无模糊。
- **字体字幕**：大标题用高瘦压缩 grotesque（如 Anton，OFL）100–260px，色填充、黑描边、另一版的偏移影；印刷式进场：色从偏移落位、key 啪地合上。标签为纸签配黑框、后面版色偏移块、倾斜±2°、固定在画角；标题行（压缩或重 grotesque 如 Archivo Black 90–130px）压一行中文（Noto Sans SC Black 子集 46–56px），拉丁中文混排用字体栈（拉丁在前）避免回退衬线。字幕为同样纸签在底部居中：中文 40px 压英文 28px，各一行不换行，停留≥max(1.8s,语音+0.6s)。标签以 0.5s 快印进场（纸与字同现）、滑出离场，无淡入淡出。页面空间的字（印在主体旁纸上）可被后续副本盖住或被镜头带走——这是媒介自己的退场。一次只有一个标题和一个标签；无页眉、居中字堆、项目符号。阅读时间每行≥字符÷15(拉丁)+字符÷4.5(中文)+1.5s。
- **运动质量**：印品两种到场：盖章式（短缩放 1.1→1，色版滑入套准，落拍）或逐版印（黄红蓝黑各带一声 thunk 落位）。镜头运动长、缓、常在缩放上取对数（从点到墙读成一个动作）。副本倍增时加速：盖章间隔缩短。翻转是卡片转面（scale X 过零），新印品从翻转中点显现。扩散之物（腐烂、颜色、信号）以锋面移动、后面带网点尺寸渐变。绝不移动：相对纸的网屏、纸本身。24fps。
- **镜头语法**：典型运镜：从硬币大网点拉到整张印品（这是印品、尺度、钩子）；从一张拉到一墙副本（雷同、数量、量产）；推入圆形匹配切到另一圆（一物是另一物的一部分）；穿过印刷字母或数字孔洞（进入另一时间或章节）；沿长印品横移（序列、增长、一列东西）；推到一格填满画再翻转（替换、转折）；缓慢推向墙同时锋面穿过（威胁、蔓延、必然）。构图：主体是整张印品或整墙，关键时刻一张印品至少占画高 1/3；标签左上、字幕底部居中，主体避开；转场来自印品（盖章、穿形、翻转、逐版印、滑动标签），无叠化、无淡黑、无翻页。
- **声音配乐**：印刷厂即拟音：刮板拖（带通噪声）、盖章（低闷+纸拍）、镜头运动纸呼、每次翻转卡片弹响、每版一声 thunk、扩散之物下低颗粒噼啪。1960 年代调性：颤音琴、马林巴、低音提琴或爵士贝斯、康加、沙锤、拍手、弱音短促小号；异国情调、休闲或冲浪色彩而非管弦铺底；暗段把律动剥到贝斯踏板与弓颤音琴。每次翻转或盖章一个音高沿音阶爬升。静默：转折前降到一记保持低音不足一秒，之后第一声是翻转或盖章。旁白温暖略电台感，压缩后 RMS 高于音乐约 10dB，音乐在 300Hz–4kHz 让路；−14 LUFS、真峰值≤−1dB（总线前限制盖章与拍手瞬态）。
- **招牌技法**：
  - 拉点：从某色阶网点内部（缩放×15–20、点大如硬币）对数拉回整张印品——适合名照的像素、肤色原来是张脸、人群原来是一个人
  - 盖章副本：一张印品一圈圈越印越快直到成墙——适合工厂产量、帖子病毒式复制、郊区一模一样的房子
  - 逐版印：藏起各版再逐一请回滑入套准——适合产品发布、新版本、由部件拼成的肖像
  - 点即数据：长大的点锋面穿过印品、点尺寸编码数量——适合旱情蔓延农田、购物清单上的通胀、谣言传遍城市
  - 颜色波：一格翻成新配色，随后一波翻遍整墙——适合多样性、团队、市场开放
  - 穿过字形：从 0/O/P 的字腔切出并推进下一张印——适合年份、比分、价格
- **避坑**：
  - 变成漫画：分格、气泡、拟声词；保持标签为纸签、故事交给旁白
  - 网点在屏幕空间：看起来像滤镜且随镜头游动——始终在页面空间算点
  - 宽镜摩尔纹：每格低于几像素时点淡为平调
  - 纸太脏：做旧、粗糙、斑墨过多像坏扫描；保持干净、做旧只用于定年
  - 同色相撞（红压红、黄压黄）：中间加 key 线或纸盘；空白印帧要从第一版已落开始、签的字与纸同印

**适用场景**：日常物件解说 / 品牌与产品海报 / 小型数据故事
