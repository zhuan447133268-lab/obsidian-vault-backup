# 69 · 科幻全息界面 / Sci-fi Hologram HUD

> 分类：屏幕界面
> 参考片：Volt 规格扫描
> 原片一句话：电助力车被扫描成全息线框，目标框依次锁定电池、电机、刹车。

## ⭐ 可直接复制的提示词

```text
用科幻全息界面风格：近黑舞台投影台上方是发光线框物体，扫描面生长模型，目标框锁定部件、沿轴爆炸、拉引线、数字从乱码滚成真值；线框近亮远暗加热边辉光，一冷一暖两色，暖色只给锁定数值，白是热度。文字有暗底板不压线框，字幕是带角括号和声纹条的 HUD。24fps 逐帧、锁定白闪 3 帧、数值右到左锁定、急甩跟框且只在甩动中加动态模糊；场景内不切镜不淡入，只用扫描面和放大镜。镜头用高 3/4 缓降环绕、俯视平面、平视锁定、急甩、绕轴环绕、转台。配乐踩拍、合成琶音与 drop，锁定音是闷响加咔嗒加蜂鸣，人声闪避音乐与拟音、−14 LUFS。避免暗色 keynote、蓝图、玻璃产品渲染与飞进文字的部件。
```

## 配方拆解

- **本质**：一个物体被扫描成发光线框，目标框依次锁定它的部件；每个部件沿装配轴做局部爆炸展开、拉出引线，数字从乱码滚动成真值。全片可以有一次、且仅一次点亮成实体全息。主体永远是近黑舞台上、圆形投影台之上的线框，不像渲染出的实物——一切读起来都是扫描出来的数据。
- **不是什么**：不是文字驱动的主题演讲（暗色 keynote）、不是制图蓝图、不是产品渲染（玻璃产品）。主体保持线框；可短暂获得半透明面，但线仍压在最上层。
- **配色**：一个冷色相加一个暖强调色，二者都是参数化可调的（如薄荷/橙、紫/青柠、冰蓝/红；从主体选色）。冷色承载线条、HUD 和填充；暖强调色只花在锁定的数值上：数字变成真值的那一帧转为强调色，别处绝不使用。白是热度——近白的边和单帧闪光标记当前活动的东西；静止的一切都待在冷色的不同透明度层级里。一个物体可保留自己的颜色（单色例外，用于品牌标志，绝不用于装饰）。
- **材质渲染**：舞台：被色相染色的近黑，主体后方径向提亮，渐隐的点阵网格，强暗角。投影台用真实透视：同心环（一实一虚）、刻度、微弱光线；缓慢旋转，转台动作时跟着转。线框：约 1.3 px 的加色描边，按深度雾设几档透明度（近处亮、远处约 25%），再加两道低分辨率辉光。热边（该色相的近白）只给当前重要的东西：扫描前沿、展开时标记 hot 的内部件、光波、被 ping 的部件。真实 CAD 拓扑：管子是环加纵线，每个部件都物理连接——悬空的零件最容易被看穿。实体全息：面用屏幕空间 Fresnel 乘滚动隔行扫描填充，点亮时线变粗、一道光波爬上模型；用一条路径（非零缠绕）加微弱光线和尘埃做光束。HUD 家具：角括号、视差标尺、左上角主体//模式、右上角实时状态行、底部遥测。文字绝不压在线框上：每个文字块都有自己的暗色底板（半透明近黑、1 px 边框、角刻度），摄影机仍要让主体避开文字。
- **字体字幕**：Rajdhani 全大写：Light 用于大数字与产品名（宽字距）、Medium/SemiBold 用于标签；Share Tech Mono 用于微小数据（坐标、计数、缩放）。数字用等宽字体，滚动才不抖；小数点画成小方块（发光的圆点会被看成逗号）。字幕是 HUD：带角括号的暗底板、「声纹」条随说话而动、近白 Rajdhani Medium、底部中央，比人声提前一点进入；停留 ≥ max(1.8 s, 语音＋0.6 s)。标题是场景的一部分（没有标题卡）：名字像数值一样滚入，接着是代码、类别和标语。
- **运动质量**：全部 24 fps 逐帧；只有字形乱码逐帧跳变。目标锁定：超大、旋转 45°、很淡，约 0.2 s 吸附贴合（三次 ease-out），强拍上白闪 3 帧。爆炸：每个部件沿自己的装配轴运动——外壳沿自身轴滑开、内部留在原位并发光；用一两拍打开、快速合上。引线：锚点环→斜线→水平到卡片，约 0.5 s。数值滚动：字符从右往左锁定，强拍上转为强调色并单帧闪光。芯片入轨：完成的值滑进侧边导轨并保持到结尾。摄影机跟随目标框：三次缓动、在下一个锁定之前就开始；真实动态模糊只出现在急甩内部（子帧、180° 快门），HUD 保持清晰。场景内不切镜也不淡入：只有扫描面（扫描进入或擦除）和放大镜光圈；最多一次、最多三帧的毛刺，用在最大的变化上。
- **镜头语法**：轨道摄影机（偏航、俯仰、距离、窄视角），目标带一个屏幕位置，好让主体挨着文字放；是一套词汇而非路线。高 3/4 缓慢下降环绕：审视、扫描面读成椭圆——扫描进入、普查；俯视平面图：布局、次序——零件清单、装配顺序；平视侧面锁定：使用中的样子——高度、前后对比；推进再漂移的 3/4：这个部件重要、内部朝镜头来——关键规格、瑕疵；急甩跟随目标框：注意力跳到下一部件——部件列表；绕部件自身轴环绕：轴向结构只有旋转才读得出——转子、叠层、铰链、镜头；沿长部件横向移动：长度、路径——梁、线缆走向；拉远加放大镜（画中画）：哪里（远景）与什么（放大）——小零件、传感器；升到平视或退回：状态改变、物体立起或落定——变形、尺度；转台 360°：每一面——整体、对称；近乎静止的慢移：有阅读时间又不是死帧——规格表、清单。关键时刻主体 ≥ 画面高度三分之一；卡片在一侧、芯片导轨在另一侧、字幕在下方中央、放大镜在它们上方，互不碰撞。宁可缩短爆炸矢量，也不让零件飞进文字。
- **声音配乐**：音乐先行，踩在网格上（一小节＝一个信息拍），锁定落在强拍并与配乐核对。合成音色：锯齿/方波琶音加乒乓延迟（为语音在 1–4 kHz 挖槽）、方波脉冲、八分贝斯、合成踩镲与拍手、失谐锯齿 pad。密度跟着信息走，任选两三种：半速留出阅读时间；一拍真正的数字静默（什么都没有，连 UI 提示音也无）；drop（808 式下滑加宽锯齿和弦）用于最大变化；每个部件加或减一层；用更长的音符减速；转调；长定格下一个持续音。拟音随材质：光＝调内的正弦与 FM 提示音；机器＝伺服滑音、气动喷气、液压嘶嘶、金属叮（J-cut）；锁定＝闷响＋咔嗒＋双音蜂鸣；滚动按帧率滴答。环境：投影仪嗡鸣（40/80/120 Hz）和房间声。人声：平静自信；用保持型包络同时闪避音乐与拟音（词间不泵动），锁定瞬态可以漏出；−14 LUFS。
- **招牌技法**：
  - 扫描生长＝「这是真实数据」——适合咖啡机、卫星、建筑模型
  - 目标锁定＝「现在看这里」，框就是摄影机——适合汽车的传感器、笔记本的接口、机械臂的关节
  - 局部爆炸＝「为什么这个数字是真的」——适合磨豆机的刀盘、跑鞋中底的分层、镜头里的镜片组
  - 滚动数字＝兑现的那一拍——适合冲泡温度、微米级公差、价格
  - 芯片累积＝阅读时间——适合必须全部读到的 3–5 条事实
  - 放大镜＝同时给出两种尺度——适合手表里的螺丝、板上的芯片、发动机里的气门
- **避坑**：
  - 目标框膨胀→用静止姿态、跳过 internal 零件、长挂件设 box:false
  - 长斜引线指错部件→圈在部件本体上并让部件闪光
  - 两个平行框一起移动读不出爆炸→外壳沿自身轴滑开、内部留在原位发光
  - 用通用方块拼出的部件不像那个部件→给每种部件标志性的轮廓
  - 人声被拟音而不是音乐盖住→拟音也要闪避，且闪避包络要保持到词的间隙之后

**适用场景**：规格讲解 / 发布视频 / 展会循环屏
