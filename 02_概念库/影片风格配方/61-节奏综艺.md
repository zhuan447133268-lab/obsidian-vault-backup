# 61 · 节奏综艺 / Rhythm Game Show

> 分类：电子游戏
> 参考片：AI 进化节拍
> 原片一句话：把 AI 发展史做成一局节奏游戏，模型踩着拍登场，最后发成绩单。

## ⭐ 可直接复制的提示词

```text
用【节奏综艺】风格：画面上玩具感吉祥物粗墨线站在糖果条纹与放射光芒上，平涂单一近黑描边、硬偏移影、无渐变纹理；配色每场次一个饱和色配同相浅色图案、相邻回合不同色，角色体色固定且不与背景同色；字体为重圆无衬线与黑重 CJK，字幕条白或黄字配墨描边、逐字弹出；运动为每拍弹跳、击打阻尼挤压、入场从天而降落拍、出现用回弹、小节线硬切加白闪，一切落速度网格；镜头正面镜框舞台，拍点冲、锁定全景、分屏对抗、竖滚升级、道具急推；声音为全合成大调流行乐每回合换风味、玩具感有音高拟音，配乐由画面时间线生成；避免微游戏狂欢、渐变慢揭示与真实产品标志。
```

## 配方拆解

- **本质**：扁平矢量里的节奏游戏综艺：玩具感吉祥物配粗墨线站在糖果条纹与放射光芒上，每次击打都落在固定速度网格上，有呼应与回合，回合获胜时出现判定词。长度随回合数而定，每回合=一张标题卡加若干小节游玩；旁白可选，短喊话与字幕条即可撑起全片。
- **不是什么**：不是微游戏狂欢（无 3 秒一动词的计时与指令、无每回合换画风），不是中世纪卡通（无纹理绘景、无角色表演），也不是主题演讲（无慢揭示、无渐变）。
- **配色**：墨+纸+糖果色：近黑墨、白、暖奶油用于卡与纸道具；约八种饱和糖果色（黄橙红粉绿青绿天蓝蓝）加两三个深色及更暗搭档用于夜场或终局。一场=一种色：背景、其图案与回合卡同色、卡随它引入的场次变色，相邻回合不同色。角色自有颜色：参赛者体色即身份且不变、与所站场次区分（角色绝不与背景同色）。大字为白或黄配粗墨描边、判定词可粉或黄。场次例：橘底 #FFB870 配 #FFA85A 条纹、青配薄荷点、海军蓝配金放射。
- **材质渲染**：纯矢量，SVG 或 canvas 路径 1920×1080：平涂、单一描边色（近黑）、角色道具 8px 描边、小件 5–7px、圆角圆头。无渐变、无模糊、无纹理、无软影；深度靠硬偏移影——同形以描边色偏移约 10px（贴纸、横幅）到约 14px（卡），上面盖彩色形。场次=一个饱和背景+同色相浅一档图案：斜条纹（常缓慢滚动）、偏移圆点（约 20% 白）、旋转放射；较深地面带加墨线 grounding 角色。角色：圆豆身、短粗臂配连指手、椭圆眼带高光、嘴可换成张开；人共用构造、旧机器或年代用更方轮廓区分。UI 套件：圆角卡、角贴横幅、判定词、爆发（星+环+速度线）、记分板。render(t) 是 t 的纯函数、每元素状态由 t 重算绝不继承上一帧。
- **字体字幕**：显示：重圆无衬线拉丁与数字（Fredoka 700）、CJK 黑重（Noto Sans SC 900）、手写体仅用于手写道具（ZCOOL KuaiLe）。字幕条文字：白或黄填充配约为字号 14% 的墨描边画在填色下面（paint-order: stroke）；标题逐字构建以便每字弹出。字幕条即字幕：回合卡、角横幅、标签、道具字、判定词承载意义，保持短（横幅行≤约 20 中文字、牌≤约 12、拉丁约宽 1.6×）；有旁白时字幕是底部同样描边字的字幕条牌，绝不是细通用字幕。每段文字保持≥max(1.8s,语音+0.6s)，判定词可更短（一眼读）。
- **运动质量**：待机=随拍弹跳：每拍一条抛物线（8–30px）、邻者反拍弹使人群起伏。击打=挤压：每次击打后阻尼摆动（约 30rad/s、约 0.35s）、每强拍小压。入场从天而降 ease-in 正好落在其拍、声音随之落地；人群每拍或半拍落一个。弹出用回弹 ease 给一切出现之物（卡、贴纸、章、字），离场 ease-in；绝不慢淡入，要么在要么弹。喊话姿势=举手+张嘴约半拍。打字机按拍的分数逐字、每几字一 click。场景切换是小节线上的硬切加极短白闪；淡出只留给最后（若有）。没有任何动作脱离网格：拍间事件落在细分上。
- **镜头语法**：舞台是正面镜框式对称、画框本身在动。词汇表非路线。典型运镜：拍点冲（中心缩放 0.8–5%、约 0.16s 衰减，重音、撞击、数拍）；一小节多次冲（画框随乐呼吸，副歌、升级图案）；锁定正面全景（整个舞台如游戏板，摆图案、人群、记分板）；小节线硬切+闪（新回合新场次）；分屏舞台（两半两场，对抗、人机、新旧）；缩成缩略图（完成的一段缩入槽位，回顾、然后这些都发生了）；场次竖滚（地面到天，升级规模、排行榜、物品塔）；对某道具急推（硬切到 2× 构图、下一小节切回，价格标签、数字、表情反应）。并发冲量总和<0.06 以免露出画框边；角色站地面带、横幅左上、判定词中上；只硬切无叠化。
- **声音配乐**：全部由画面事件合成：正弦底鼓带软饱和、带通噪声军鼓拍手、hats、slap bass、失谐锯齿铜管刺、带颤方波主奏、马林巴拨、八音盒铃、三角铁垫、方波琶音、牛铃。明亮大调流行和声短和弦循环、每小节一个和弦、每回合自有风味（放克、问答、电子、梦、重…）而非新歌。事件拟音玩具感且有音高：pop、噗通+boing 落地、盖章、打字机 click、蜂鸣、叮、伺服嗡、啪；人群落下时带音高 pip 可拼出旋律。喊话不是句子：一至三词的呼声（Hey!、数字、判定）放在拍前 20–30ms 让辅音落拍；人群喊=几个不同声音相隔几毫秒叠加并横跨声像。强度选项：每回合 jingle（镲+上行铜管+军鼓滚奏）、终局移调、大击前一节只留鼓、揭示用半速小节、一节静默被一声喊打破。混音：人声拟音独立总线、音乐从该包络闪避、软削而非硬限、−14 LUFS、真峰值≤−1dB。
- **招牌技法**：
  - 带卡的回合：一小节卡（回合号+名+如年份或步骤的标签）随 jingle 飞入然后游玩——适合菜谱步骤、创业阶段、博物馆参观章节
  - 成绩单：打字机式回顾加盖等级章——适合季度回顾、旅行总结、最终得分
  - 呼应：任何有来回合之事都成节奏型，加速型（四分→八分）就是情节——适合老师问学生答、顾客点单咖啡师回应、谈判乒乓
  - 下一关预告：某物孵化或解锁——适合下一版本、下一季、下一级
  - 判定词：回合最后一击时一个大描边词斜着弹出——适合物流已送达、许可已批准、训练个人最佳
  - 混音板：一场配一条时间带、每件中心几小节后缩入底槽、高潮所有槽一起弹——适合年度回顾、团队发布列表、音乐节阵容
- **避坑**：
  - 有状态更新破坏并行渲染：worker 冷启动显示初始态——每姿态从 t 重算、单张静帧与顺序渲染比对
  - 提示列表漂移（切闪、jingle、编配是分开的手工列表）：从一张表派生
  - 定长音频缓冲截断尾部：按持续时长定尺寸；字体加载前量文本溢出牌：先载字体再构建
  - TTS 误读喊话中的数字与符号：拼读出来
  - 真实产品当角色：标签上名字、原创吉祥物、无标志或 UI；真人只作通用替身

**适用场景**：科技时间线 / 年度回顾 / 综艺节目
