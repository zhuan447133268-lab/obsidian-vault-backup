# 98 · 立体地图解说 / 3D Map Explainer

> 分类：数据地图
> 参考片：霍尔木兹海峡
> 原片一句话：从地球一路落进这道海峡：世界约五分之一的石油挤过两条航道，剖开看水下有多深，再看绕行的管道只能分走多少。

## ⭐ 可直接复制的提示词

```text
用立体地图解说风格：真实高程与影像做成垂直夸张（×3注明）的三维地图，低暖阳+烘焙阴影让山从轨道立起，海按真实深度由浅青到深蓝；数据层发光流动、沿真实地理点亮（路线、航道、测量、数据柱），镜头从太空落入、飞越、切开露出45°剖面线的剖面、再爬回地球。配色：中性暖底，琥珀=数据、冷白=边界、暖白=移动与测量、青=对比量。字体：窄无衬线国名海名、大数字带来源，标签贴地随高度交接、测量先画后标、剖面像工程图、字幕是左下地图图例架。运动：对数插值镜头不停、线从源头生长、亮头沿真实路线跑、柱按拍长板。镜头：太空推入、俯冲拉平、锁定斜视、环绕降臂切开、侧视对比、拉回地球。声音：低拨弦脉冲、点亮时手铃、剖面下只余踏板。避免：正俯视灰卫星图、低模沙盘、全息HUD、编造地形边界。
```

## 配方拆解

- **本质**：把真实高程与真实影像做成垂直夸张的三维地图，由一轮低角度暖阳照明，海按真实水深着色；其上叠加会发光、流动、沿真实地理点亮的图层：路线、航道、测量、柱体。一台镜头从太空落入地点、飞越、切开、再爬出。
- **不是什么**：不是卫星简报（灰色分析影像、正俯视、发丝测量），不是交通图（抽象示意），不是等距信息图或低多边形小岛（无风格化沙盘），不是科幻全息HUD（无虚构界面、无线框地形），也不是地图上的幻灯片（无页眉、居中块或翻页）。
- **配色**：中性底：地点自身颜色并调暖，地形上不加色带。琥珀=数据（路线、航道、主量）；冷白=边界（航道边、界限）；暖白=移动与测量（交通、尺、被测线）；第二数据色（青）只在一个量与主量对比时出现，区间是同色浅一档。陆上字深棕墨、水上字淡海蓝、暗影山上字暖白；无描边无投影。海的深蓝与地球夜面是仅有的大暗区。示例：深海#0E2230、浅滩#1F5A5C、沙高光#E8D2A6、数据琥珀#FFA63D/核#FFC36B、边界#D9E6EE、交通#F4E6CF、尺与被测线#F6EEE0、陆墨#2B2119、海字#BCDBE6、对比青#2FA3B0/区间#8FD6DE。
- **材质渲染**：地形：每个细节级别一个网格（地点细网、区域粗网；粗网在细网下带小重叠并压低几十米使接缝不争）。影像作albedo、调暖略降饱和增对比；粗糙度图来自陆海掩膜，海有柔光泽、陆哑光。海：不用影像色，按真实深度着色——沿岸浅水保留些许影像纹理染青、深水转深蓝；沿岸距离以公里计故各级缩放着色一致。太阳与阴影：一轮约20°高的方向光+弱天地半球补光；阴影烘焙进纹理（沿高度网格向太阳方向行进、半影随离遮挡物距离变宽）并乘进直射光；大飞行中实时阴影图会闪。发光层：加色ribbons、不做tone-map故只有它们触发bloom；宽度=真实宽度与像素最小值（逐顶点按到镜头距离算）的较大者，轨道上路线保持2–3px、近处车道保真宽；一个着色器兼做draw-on揭示、亮头沿真实路线跑、流动脉冲、虚线边界、交通尾迹。陆上线（管道、边界）：发光线压在暗色casing上用正常混合，如海图印有套管线；亮沙漠上单辉光会冲淡。交通（船、火车、卡车、飞机）：平暖白字形+短淡化尾迹，缩放使任何高度屏上大小相近，在车道内稍偏以免压亮中心线。数据柱：叠板、一单位一板、每板亮边，在数量所属处一板板长出；对比并排在同尺度、在空地或水面上、正面看。剖面：沿有意义线（最窄处、边界、河）切开，镜头侧地形约一秒扫走、露出墙面剖面：水按真实深度×注明系数（×100–200）、亮表面线、每25m淡等高线、暖海底线、下方细纹岩石。地球：同影像上球（全球拼图+区域影像覆其区）、薄菲涅尔大气边、暗星场、夜面入影；叠化时地球镜头由地图镜头算出（纬经高、北朝上）使两者对齐。后期：物理景深焦点在主体、光圈随距离（下降时平滑加深）、发光层bloom、暖调+暗角、2×超采样。所有文字与测量在2D叠层，每帧经同一世界→屏幕函数定位。
- **字体字幕**：所有拉丁用窄无衬线（如Barlow Condensed，OFL）：国名600约30px宽字距（约0.3em），海名500约21px淡蓝，岛与港名15px，数据数字600 70–96px带小单位与更小来源行在旁或下；中文用CJK无衬线（Noto Sans SC，OFL，按用字子集）≥34px。标签贴在地图上实物所在处并随镜头高度交接：远景（国、海）交给近景（岛、港），将被画框切掉的标签淡出。测量先画后标：线从中点向两端长出、端点刻度吸附、标签才在线旁出现，绝不压在数据上。剖面像工程图标注：左上小说明+标题、其下夸张系数、侧面深度尺、从表面到海底带数值的虚线测深。标题：地点上一枚图钉+一圈脉冲+引线到空处（海或天）的标题，英文下配一行短中文。字幕（有人声时）：左下地图图例架、琥珀竖线、一行中文压一行英文、不换行、在柔暗渐变底上；地图标签避开该区。来源：整片一角一行小字（数据、影像授权、若用OSM则ODbL、路线示意、垂直夸张系数）。
- **运动质量**：镜头绝不死停：距离按对数插值、关键帧单调三次、停留保持慢漂。发光层靠被画出而到来：线从源头长出、车道由一亮点沿真实路线点燃、脉冲顺行进方向流、柱体按拍一板板长。景深、雾、bloom随高度连续变化，绝不跳变。交通以可读的延时速度移动（每片秒几公里），都在各自车道。24fps；合成颗粒1（轻胶片颗粒）。
- **镜头语法**：从太空推入：找到地点——适合开场；俯冲并拉平（对数距离、俯仰约80°→45°）：抵达——适合区域到关键点；近锁定斜视：读测量——适合宽度、名称、判决；环绕+降臂至切口：看表面之下——适合剖面；沿线低机位跟踪：走一遍——适合航道、河、路；绕数量升臂：重量、尺度——适合柱体生长；大拉远越全区：语境、替代方案——适合周边路线、其他地方；正面侧视：诚实对比——适合同尺度的量；拉回地球：后果——适合结尾。转场：穿大气叠化（地球↔地图、镜头匹配）、切开的地面、至多一次有节奏硬切、其余连续。关键处主体占画1/3；字幕左下；来源在一角。
- **声音配乐**：配器：低拨弦作脉冲、大提琴跳弓在运动时、弓颤音琴与竖琴给光与空气、每样点亮时手铃或钢片琴、强拍框鼓、数量下圆号渐强、带2/3次谐波的低正弦踏板；避开通用钢琴弦乐床。拟音：稀薄高空风随镜头下降变厚、每次俯冲whoosh、终端与尺的小数据哒声、车道点燃时sub闷击与电闪、切开的低撕裂扫、剖面内闷水下静、低机位下的海、每柱一板一记拨弦。静默：剖面下音乐稀至踏板、判决前半小节全无。混音：旁白压缩且高于音乐约10dB（RMS），音乐总线在300Hz–4kHz下陷并在每句下闪避，−14 LUFS、真峰值≤−1dB。
- **招牌技法**：
  - 从轨道俯冲：从地球一次推入地点、穿大气叠化使地球与地图共用一镜头——适合对世界重要的任何地点、国家中的城市、海洋中的礁
  - 流汇聚：点依次亮起、路线生长汇入一条线——适合通勤入城、支流入河、道路汇入山口
  - 线沿真实路线点燃：亮头沿真实几何跑、留下线、边界与交通——适合铁路线、边界、管道、迁徙路线
  - 切开地图：沿一线扫走一侧地形露出下方剖面——适合湖深、河谷、山下隧道、含水层
  - 飞越这条线：沿线低机位跟踪并横跨一把尺——适合桥跨度、运河、跑道、前线
  - 地面上的数量：柱在数量所属处长出、替代方案在同尺度旁长出——适合河流年径流、大坝发电量、分区收成
- **避坑**：
  - 授权：EOX Sentinel-2 cloudless仅2016版CC BY 4.0（后版CC BY-NC-SA）；AWS Terrain Tiles（SRTM、GMTED、ETOPO1、GEBCO）免费需署名；OSM数据ODbL（数据库需署名与相同方式共享）用前告知条款。不可用：Google Earth/Maps、Bing、Esri、Mapbox、Maxar、Planet、新闻图、AI生成图作地面。记录每次下载（URL、日期）并把署名行烧进画面。
  - 事实：屏上与旁白每个数字都要有具名来源与说明依据（谁的估算、哪年、算什么）；来源冲突就都展示并说明各自是谁的；存FACTS.md；示意物（路线、简化管道）在屏上标明示意。
  - 分辨率：z10地形约每格150m、近飞发软、小岛缺失（用点标出不要编造）；只为镜头真正接近的区域取更细数据。
  - 墨卡托与球：平地图是Web Mercator、地球是球；匹配叠化要转换镜头而非手摆，叠化要短（约0.8s）。
  - 闪烁：大飞行不用实时阴影图；线不细于约2px；轨道上虚线随距离淡出。

**适用场景**：新闻与地缘 / 能源、贸易与航运 / 河流、边界与地形
