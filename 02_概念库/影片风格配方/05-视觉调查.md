# 05 · 视觉调查 / Visual Investigation

> 分类：剪辑纪实
> 参考片：兴登堡号：四分钟与三十二秒
> 原片一句话：新闻片、照片、证词和调查报告排上同一条时间轴，五路来源指向一处。

## ⭐ 可直接复制的提示词

```text
用【视觉调查】风格：冷静调查桌上，同一事件的影像照片文件声音地图排在同一时钟上互校，时钟住在画面里（证据时间戳、图表播放头、关键秒秒表），定格圈出放大、引文在原页高亮、已知未知分列、结尾证据汇入一张地图；配色近黑底深灰面板，来源全灰度、唯一红#FF4A2E只用于圈与同步线；等宽时码、中文粗黑标题、字幕一行一语；30fps、元素切入带白闪如从证据柜抽出、只有画出来的才渐进、摄影机不动、硬切于0.5s网格；配乐低弦持续+钟摆滴答，原声带通逐词亮起、人声冷静、−14 LUFS；避免推断当事实、空占位框、慢镜灾难与居中翻页版面。
```

## 配方拆解

- **本质**：一张冷静的调查桌：来自同一真实事件的影像、照片、文件、声音与地图排在同一个时钟上彼此校验。时钟住在画面里——证据上的时间戳、图表上的播放头、关键秒数上的秒表；定格被圈出放大、引文在来源页上高亮、平面图显示机位与视线，已知与未知分列，结尾所有证据汇入一张地图。
- **不是什么**：不是卫星简报（无轨道影像/从太空推近），不是档案灯桌（无玻璃上铺纸、放大镜、手），不是半调卷宗（无印刷纹理/印章/拼贴），不是新闻包装（无台标/滚条/主播），也不是 keynote（无居中标题页/翻页）。
- **配色**：底#0B0C0E、面板#141619、细线#2E3238、文字#ECEAE4、次文字#8B9097、刻度/不确定#4A4F57，唯一强调色#FF4A2E（此处/此刻/匹配），纸卡#E4E0D4 配墨#1D1D1B；来源全为灰度，红色是唯一颜色且只用于「指」——圈、播放头、同步线、高亮、✓徽章、汇聚区、未解列、对错误说法的删除线。
- **材质渲染**：至少三类来源（活动影像、文件、照片），有则加声音、数据、地图；扫描文件以条/页呈现绝不重绘，只高亮决定性一行（红、multiply、α≈0.6、左至右擦除）；仅以转录存在的文本用代码重排并标明转录；档案影像管线（1950前）去隔行→裁边→去块→lanczos放大→轻锐化→灰度、统一颗粒，现代素材≤1.5×，绝不彩色化或「修复版」；统一调色（影像灰度对比1.22亮度0.94、纸灰度对比1.05亮度0.86、地图灰度反相亮度0.62成暗线图）；六块256²高斯噪声瓦片逐帧旋转 overlay，颗粒只在来源、字与线无颗粒；绘制证据为面板色上的细线、未实测标 schematic；去除台标水印与来源自带标题卡，绝不生成图代替历史图像。
- **字体字幕**：中文标题与结论 Noto Sans SC 700（30–124px），标签/时码/刻度 IBM Plex Mono，引文原文 Source Serif 4 斜体、译文 Noto Serif SC 500 用次色；每帧少字——主读数/标题 + 被引原文 + 每个证据一条短来源签，无眉标、无英文孪生、无档案号、无与字幕重复的话；来源签为6×12芯片+`类型·来源`等宽≤12字、贴在证据框上方；下三分之一为红条+地名+一行等宽；字幕双语一行一语、中文34px粗体压英文23px居中带10px黑影、按1500px测、长句拆两条，原声也配字幕并标【原声】；可读性 CJK÷4.5+其他÷15+1.5s，判定/对比帧停留≥2.5s。
- **运动质量**：30fps；元素切入（≤0.1s不透明度）带3–4帧白闪如从证据柜抽出，无飞行/弹跳/缩放弹出；只有「画」出来的才渐进——红圈0.5s顺时针（ease-out cubic）、指引线与链接0.4–0.8s、平面图逐笔、高亮擦除、电报打字机；帧内允许缓推（地图≤1.9×、照片≤1.06×）、「摄影机」本身不动、布局在切点变；事件时钟在关键帧间缓动、定时段内匀速（每刻度=1真实秒）；尺度变化发生在章节切点、靠读数变形承载而非缩放条；至少每秒有变化、停留只给判定。
- **镜头语法**：用布局而非运镜：地图→平面（左）配参考照与影像面板（右）；一个大陈述+一引文+一宽示意；五源板（上三证据、下声音与报告、右示意、红线汇聚）；三栏同步网格（报告/照片/视频同秒表下、各源开始时亮起）；文档条+两栏判定；主张卡+核查卡+点阵；证据地图（平面、断轴小时间线、示意、带链接缩略图）。1920×1080、60px边距、内容 y 60–900、字幕在其下；硬切于0.5s网格、白闪、倒带，禁叠化；禁居中布局/页眉/翻页。
- **声音配乐**：低D持续音（低音提琴与大提琴）与低于人声约30dB的滤波房间声；分钟级每0.5s钟摆滴答（等待分钟更响）、定时段每「事件秒」一响（每5重音）即可听秒表；慢段八分音拨弦 ostinato（Dm–B♭–Gm–A）、张力用小二度颤音簇、判定用慢持续和弦、证据地图用 D 小调 add9+颤音琴解决；foley 程序化——文件纸张、照片快门、电报摩斯滴与键击、电传喋喋、倒带扫频、平面铅笔沙沙、撞击一记深闷后近静；原声带通180Hz–5.5kHz带稀疏噼啪、以波形+红播放线+逐词亮起呈现、音乐在其下压12dB、与原声交替从不同时响；人声冷静平板、音乐下压9dB、−14 LUFS真峰≤−1dBTP。
- **招牌技法**：
  - 定格、圈出、放大：白闪定格、红圈顺时针、旁开×2放大镜（同源像素），适合监控车牌/焊缝裂纹
  - 硬同步点：选每个来源都能认出的瞬间对齐、晚开始的来源就晚出现，适合谁先开拍/发射相机何时丢失目标
  - 三栏同步网格：文件/照片/视频在同一秒表下按各自开始时切入、同步点红虚线贯穿，适合两台行车记录仪与警方日志
  - 证据→模型链接：每个圈向同一示意区发红虚线、✓徽章相隔0.12s落下并带小槌音，适合起火房间
  - 证据地图：平面+断轴小时间线+示意+所有来源缩略图链接汇聚，适合任何调查的结尾
- **避坑**：
  - 推断冒充事实→机位/照片时间/偏差须在画面与FACTS.md标≈/推断/未定位
  - 早期报道当事实→首夜备忘录与当年新闻片只作图像或被核查主张、不作数字来源
  - 伪造多机位→用同一可授权影片交叉核对影片+照片+文件+声音；「连续」镜头接缝→用官方时长并说明对齐误差
  - 一次太多/字太多→一版一结论、最多五源、字幕不逐字重复标题、只留本拍所需
  - 空占位框像渲染错误→换真实素材或让来源按时出现；底部预留长条会在无内容时留空带；灾难当奇观→无慢镜火焰撞击、无死亡音效

**适用场景**：事件重建 / 事实核查 / 事故报道
