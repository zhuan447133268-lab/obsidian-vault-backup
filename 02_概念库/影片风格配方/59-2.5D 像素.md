# 59 · 2.5D 像素 / 2.5D Pixel Art

> 分类：电子游戏
> 参考片：守灯人
> 原片一句话：灯塔熄灭，孙女提着最后一簇火穿过夜林、爬上风暴悬崖。

## ⭐ 可直接复制的提示词

```text
用2.5D像素风格：手工像素精灵像纸片立在带灯光雾气的真实3D立体模型里，高3/4视角经移轴镜头拍摄，精灵平面低清逐帧跳变而相机光粒子焦点每帧平滑；一盏冷或淡的大环境光对小的暖实用灯，灯投真实精灵影、火闪窗亮、重bloom与暗角，主角穿场景不用的饱和服色；章节卡与带打字光标的金属框对话框、斜体衬线字幕；永远俯视、慢推/横跟/俯冲/移焦；配室内奇幻乐与逐材质拟音、旁白缓慢低通；避免体素角色、眼平视角、纯2D像素RPG、真实微缩照片与胶片颗粒。
```

## 配方拆解

- **本质**：手工像素精灵像纸片一样立在被灯光与雾笼罩的完整3D立体模型里，用高三分之四视角经移轴镜头拍摄：一个每盏灯都投下真实影子的玩具世界。光是主角；精灵保持平面、低分辨率、逐帧跳变，而相机、光、粒子与焦点每帧平滑运动。
- **不是什么**：不是体素游戏（无立方体角色）、不是纯2D像素RPG（布景是真实3D带真实光）、也不是真实微缩模型的移轴照片（纹理是像素不是材质）。
- **配色**：两种温度：一个大环境主光（冷/淡/尘）对小而暖或饱和的实用灯；实用灯承载故事、环境承载情绪。最暗是暖墨而非纯黑、最亮是泛光的灯源本身。每个场景自带一种雾色与一盏主灯，切到新地方即刻可读；主角穿一套任何场景都不用的饱和服色，使小精灵在远景中也能被找到。UI为一种金属（金/银/铜）＋一种纸白，压在深半透明板上。示例：夜运河镇（蓝雾/琥珀窗）、黄昏秋市（紫天/粉纸灯）、正午雪矿（灰白日光/绿矿光）。
- **材质渲染**：恒定纹素密度：表面在小canvas上逐像素绘制、NearestFilter、世界空间UV以一个密度（如24px/m），精灵相近尺度（角色约30–60px高）。颜色来自3–6色ramp、经窄4×4 Bayer抖动按亮度选；精灵加1px的selout描边（邻色向墨压暗）。方盒与圆柱做建筑/地面/岩石、广告牌（实例化）做植被/远景道具/山脊；窗是发光像素格、火是约10fps跳变的像素图集、水是量化波纹＋朝相机光柱的shader。每场景灯组：一盏暗的投影主光＋半球补＋带影的实用点光（灯/火/窗/屏）＋主角前约2m的前补（被背光照的广告牌会全黑）；每个光源加一个加色glow sprite让bloom有抓手。后期链在渲染时：超采样渲染→物理DOF且移轴在同一有符号弥散圈内（带上方=远、带下方=近；远处绝不溢到清晰前景）→bloom→暗角/调色→filmic色调映射；无胶片颗粒。
- **字体字幕**：铭文大写衬线（Cinzel、宽字距）用于章节标签与标题；旧体衬线（Cormorant/Cormorant Garamond斜体）用于字幕、对白、tagline，皆OFL。旁白字幕：斜体衬线约46–54px、居中低置于柔暗渐变带、每个语音片段一行、提前约0.35s出现。屏上说话用对话框而非字幕：深色板＋细金属边＋角饰＋顶边名牌，文字在约90%语音时长内打出、带闪烁光标、进场轻铃。章节卡与标题卡属于该语法；停留≥max(1.8s,语音+0.6s)；从驱动叠层的数据导出.srt。
- **运动质量**：精灵逐帧跳变、其余一切滑行：走路循环4帧6–10fps、待机两帧交替约1–2Hz、几秒一眨、姿势切换是两张画之间的瞬切；相机/灯/粒子/光束/焦点每输出帧更新（60fps）。姿势即数据：每张画一个参数对象、新姿势即新表项。灯呼吸：每团火焰闪动（几个正弦叠加约±20%），灯值一个数值同时驱动精灵绘制、点光强（∝level^约1.3）、glow透明与缩放。天气程序化：斜向雨丝、闪电是脚本化的闪光曲线（击→落→再击→衰减）同时抬升天光、补光与曝光。世界除冲击外不抖、布景永不移动，只有相机与其中之物在动。
- **镜头语法**：一部词汇表而非路线，开合随题材而定。永远俯视这个世界（绝不眼平）、每条路径是几个键的单调样条无过冲、焦点每帧由相机到主体重算。极高极远的慢推、光带落在一个极小主体上（珍贵/把整个地方当地图）；中高3/4近静止漂（两人同台）；横跟、相机略前、前景虚掠（穿越世界的路径）；俯冲到低近处、当人物跪下或停下（玩具世界忽然私人）；升起拉回、焦点由人交给物（行动扩散/系统开启）；绕建筑或道具半圈（物件全貌）；正顶视、移轴成一条带（棋盘/计划/排队）；锁定帧在两深度间移焦（注意转移）；回到变过的旧构图（韵脚显出变化）。角色约占画高1/12–1/8、清晰带跟随主体的投影高度（钳制在屏高约0.2–0.8）；无角色时每镜用固定带高；转场是短暂淡黑或场景间硬切，无擦、无3D旋转。
- **声音配乐**：室内奇幻/电影色彩（竖琴、钢片琴、弦、圆号、低合唱、定音鼓）或小民乐（鲁特琴、竖笛、手鼓）：可一首其自身弧线与故事相符的曲子在强拍内剪接，或原创配乐；一个强拍可落在视觉事件的那一帧。留白作工具：硬停入混响尾、单独一块pad、光将熄时一记心跳、某事失败时不到1s的短 breath。拟音随立体模型的材质：各表面的脚步（木/土/石/雪）、火噼啪、布、对话框与菜单的UI铃、点亮时的小铃、每次闪后的雷、大点火时低沉轰鸣＋微光；每场景环境床交叉淡化。旁白是故事书口吻、缓慢（速度约0.82–0.90），屏上角色低通约7kHz使其"在世界里"、虚构名写进TTS的asr字段；台词压缩并RMS匹配、每行自动闪避约10dB（只降），−14LUFS、颗粒0。
- **招牌技法**：
  - 灯亮时影子跳：一盏实用灯在精灵旁点亮、它们的影子扫过地板——适合拂晓开店/服务器加电/老师开投影
  - 携带的光当量表：角色带着的一盏小灯既是主光又是仪表、亮度随所测之物起伏——适合长途中的手机电量/病人监护/烛光守夜
  - 移轴的珍贵感：超广角把清晰带落在一个极小主体上——适合城中一辆配送车/整院中新生儿的房间/夜市的一个摊
  - 灯逐盏亮：窗、灯或船以稳定的节奏点亮——适合用户加入网络/村庄通电/节庆开场
  - RPG语法：章节卡、带名字的对话框、群系、地标、标题卡——适合新员工入职/分时代的历史/分阶段的食谱
  - 天气掠过立体模型：雨、雪或雷按闪光曲线扫过桌面——适合市场崩盘/收成受威胁/艰难的一周
- **避坑**：
  - 满屏棋盘格→抖动带过宽（精灵约.22、纹理约.45）；灯烧坏持灯精灵→灯向相机移约0.45m并在shader里限制精灵受光
  - 广告牌背后的灯照不亮它（法线只朝前）→始终加前补；朝相机的圆柱光束出NaN被bloom放大成黑块→用朝相机、向镜头淡出的广告牌光束卡、由glow sprite接管
  - 暗场不可读→除必须暗下来的那一拍外把环境中调提约2–2.5倍；远处光被雾吞→depthTest=false、更高renderOrder
  - 移轴却没有角色可跟→每镜固定带高；把倾斜单独做成模糊pass会破坏遮挡→折进DOF的有符号CoC
  - 世界除冲击外不抖、布景不动；用“HD-2D”当片名或品牌要避免（该词为Square Enix的商标），本风格与之无关；节点渲染脚本打印done后可能不退出（服务器保活）→process.exit(0)，打印done即文件完整

**适用场景**：游戏预告 / 奇幻 / 故事片
