# 36 · 瑞士动态排版 / Swiss Motion Graphics

> 分类：平面排版
> 参考片：海报的五条规则
> 原片一句话：一张音乐会海报按瑞士设计的五条规则自己排版，第五条是只打破一条。

## ⭐ 可直接复制的提示词

```text
用瑞士动态排版风格：画面是纯2D网格设计——平纸、黑字条块、浅灰、一种信号色；12列齐左参差、极大尺度对比，每元素吸附网格落拍、不弹跳，唯一破格元素成为角色。配色：纸墨灰加唯一信号色（红/橙/群青/绿选一），只有它承载信号且唯一允许不精确。字体：全片一个OFL新怪诞字族，字幕是版面列起点的clip揭示而非底部条。运动：只有精确缓动cubic-bezier(.7,0,.2,1)与linear，入场用擦除不淡入，删除是刀切，例外linear不吸附。镜头：锁定跨页因果、硬摇一列、转90°停、拉远成果物墙、推进模块、切等格、垂直滚动；转场用擦除刀切。声音：motorik或极简techno脉冲、拟音干而近、强拍硬停、人声高于音乐6dB。避免：发布会渐变辉光、歌词飞字、数据图表、包豪斯拼贴、叠化。
```

## 配方拆解

- **本质**：国际主义排版风格动起来：模块网格、单一字体、一种信号色，运动像印刷机一样精确。全片遵守系统，于是唯一破坏系统的元素成了角色。
- **不是什么**：不是发布会风格（无渐变、无辉光、无设备渲染），不是歌词动态排版（文字不飞不转不弹），不是数据可视化（条块作为图形形式有质量，除非网格赋予其数量含义），不是包豪斯基本形拼贴。
- **配色**：纸、墨、灰、一种信号色。只有一样东西承载信号色，这使它成为主角，也是唯一允许不精确的东西；允许黑字压在信号色上叠印。信号色可红、橙、群青或绿，按题材选定后绝不加第二种。示例：#EAE9E5纸/#FFFFFF/#111111墨/信号#E30613；或#F2F0EA/#141414/信号#FF5A00；或#E9ECEF/#0B0B0B/信号#1F3FFF。
- **材质渲染**：画面网格：1920×1080、12列、约96px边距、24px间距、24px基线；画面可作跨页：左页（程序：数字、规则文本、注释）与右页（成果物）。成果物网格由内容推导（Gerstner）：列与行意味着什么是设计决定；选给元素以质量的模块尺寸，太细的列会让版面像图表。表面：页、纸、墨、信号色、两三档浅灰网格线（在页上、搭建中、纸上）；无渐变、无阴影、无粒子、无颗粒（合成颗粒0）。条块是平矩形；同单元连续格并成一条，接缝处多画1px（抗锯齿会露发丝，旋转或缩放时尤甚）。次级声音可以是黑元素下的浅灰元素：不引入第二色而有深度。所有运动用一个2D相机矩阵（中心、缩放、旋转）。
- **字体字幕**：全片一个字族，OFL新怪诞（Archivo、Inter、Schibsted Grotesk、Instrument Sans等）多种字重；≥90px字距约−2%；标题可小写；绘制前document.fonts.load每个字重。齐左、右侧参差；一切都落在网格线上，大片留白是版面的一部分；巨型数字视觉上齐左（减去字形左bearing）。字幕是版面的一部分而非底部条：每行落在当前构图的列起点（小灰引导+大粗陈述，或如博物馆标签的说明），每词按whisper时码clip揭示；停≥max(1.8s,语音+0.6s)并在代码中断言。说明行：约19px中等字重注释、上方1px线；角落的技术注释（模块尺寸、计数、条计数）。
- **运动质量**：只用两条曲线：精确缓动cubic-bezier(.7,0,.2,1)用于吸附，linear用于画线、播放头和那个例外；无过冲、无弹簧、无弹跳。时长是影片速度下的音符值；吸附提前一个音符值起并落在拍上。入场是擦除或clip揭示，绝不淡入：词从基线下方clip矩形升起、向上离场；线沿长度生长；纸以擦除出现；巨数按缓动阶梯爬升（一次一模块）。删除是刀切：细线掠过元素、元素塌向中线。涟漪按离因由的距离排序，每细分几个单元。例外运动不同：linear、不吸附、也许中途停顿；旁边的坐标读数可从on grid变off grid。平滑24fps、无跳帧：数字精度而非手工感。
- **镜头语法**：镜头只以精确缓动且只在拍上运动。词汇表非路线。锁定跨页：因（左）→果（右）——适合规则应用、前后对比、比较；硬摇一页或一列：系统中的下一步——适合序列、目录、时间线；转90°停住：同一事物换一种读法——适合海报当乐谱、图表当地图；拉远到成果物墙：一个程序多种输出——适合品牌系统、产品线、系列；推进一个模块：细节、系统的单元——适合像素、字母、单个数据点；网格越出页面：系统大于成果物——适合尺度、野心、突破约束；把画面切成等格：平行案例——适合选项、变体、团队成员；沿一列垂直滚动：阅读、列表——适合宣言、规格表、时刻表。构图：一切在网格上；信号元素只有在演例外时才可离格。转场是擦除、刀切、镜头运动与重排；绝不叠化。
- **声音配乐**：有自己的网格的音乐：稳定脉冲，其细分为吸附提供时长。可选：motorik/krautrock鼓与贝斯、极简techno、马林巴或颤音琴音型、机械钢琴ostinato、鼓机加钢片琴；每加一条新规则加一件乐器是清晰的建造。画面与音乐可共享一个数据文件（列→音高、行→起始），于是图形可字面成为乐谱。技法（可选）：例外那一刻撤掉鼓、揭示前一小节近静、揭示时削薄频段让每个音可闻。拟音跟随印刷材料、干而近、无混响：凸版咔嗒、制图笔tss、裁纸机咔嚓、纸拍与滑动、数字闷响、块吸附、落地的毛毡闷击、橡皮图章、打字机回车。例外可以是唯一会唱的元素（正弦滑音跟随其位置）。静默：强拍上一切硬停，下一次吸附读成事件。混音：人声压缩且高于音乐≥6dB、音乐在人声下闪避约10dB、−14 LUFS。人声冷静、清脆、规则式句子，优选亮辅音的嗓音。
- **招牌技法**：
  - 网格意味着什么：列与行变成数量（音符、小时、楼层、年）——适合一栋楼的楼层与房间、一周时间表、城市分区
  - 吸附=拍：每次到达都是一次打击乐——适合产品功能列表、食谱步骤、倒计时
  - 程序：规则逐条应用于一个成果物，然后同一程序生成许多——适合品牌识别、字族、一套邮票
  - 极端尺度对比：巨大元素作章节卡配小注释——适合破纪录统计、年份、价格
  - 例外：一个元素破格、linear不吸附——适合发明家、数据中离群点、叛逆员工
  - 刀切：元素被一条线删除——适合预算削减、编辑文本、移除功能
- **避坑**：
  - 细列太多像图表→更少更宽的模块。
  - 所谓更好的构图并不明显更好→一条强对角线配长短节奏、更大的信号元素、出血、字压色；只倾斜不够。
  - 同时旋转和标注读成噪音→先转、停住、再加标签。
  - 并合的条旋转后露缝→多画1px。
  - 共享相机矩阵的元素漏进别的镜头→只在屏上时才画。

**适用场景**：品牌识别 / 活动 / 设计教育
