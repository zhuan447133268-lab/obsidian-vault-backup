# 44 · 工程蓝图 / Blueprint

> 分类：线稿图解
> 参考片：专利申请中：接云机
> 原片一句话：发明家的蓝图自己画出一台接云机器，修订云线变成了真的雨云。

## ⭐ 可直接复制的提示词

```text
用工程蓝图风格：深色制图桌上一张蓝晒纸，普鲁士蓝上白色技术线按制图顺序画出——中心线、轮廓、排线、尺寸、带编号圆球的引线、标题栏，摄影机像读图的眼睛在纸上移动；线宽随缩放调整，阴影让抬起物体离开纸面。只有蓝与白，一种非蓝印章墨只用一次承载结论；被设计之物是主角，人只以执笔手影或签名出现。24fps 逐帧描线、段落间强拍硬切，机构像擒纵器踩拍迈步。镜头用整纸远景、中景绘图、沿力路跟踪、2 倍特写、锁定深思、斜向厚度展开、剖线扫过、图 1→图 2→图 3。配羽管键琴与巴松的对位机械乐，拟音随纸木铜水，人声下音乐压到 0.36 倍、−14 LUFS。避免全息线框、白板、铜版画排线与底部字幕。
```

## 配方拆解

- **本质**：工程图纸在深色制图桌上的一张蓝晒纸里活过来：普鲁士蓝上白色技术线条按制图顺序画出，标注会移动。摄影机像一只读图的眼睛在纸面上游走；被设计出来的东西就是主角，通过它的部件行动；人只以执笔的手影或签名出现。严谨的制图惯例承载冷峻的基调，而注释可以带机智、温度或分量。适合 30–60 秒的片子。
- **不是什么**：不是全息 HUD（没有发光线框、没有 3D 环绕）、不是白板（没有白底马克笔）、不是铜版画（没有以雕刀调子排线作为整体外观）。
- **配色**：只有蓝与白。蓝色在明度上变化（涂层、污渍、折痕），白色在粗细与柔和度上变化，绝不变色相。一种非蓝颜色只用一次：橡皮图章的印泥（经典是红色；绿色 APPROVED 或黑色 VOID 也行），它承载结论。高潮处那个「真实」的物体可以带光（白色辉光、柔和明度），但不是新色相。示例蓝：#18336B→#2A58A6，线条 #E7F0F9、桌面 #0D1116；日晒褪色的纸 #3A6DA8→#5B8CC4；深度曝光过度的纸 #0F2350→#1D3F80。
- **材质渲染**：纸：在着色器里按图纸坐标程序化生成蓝晒，任意缩放都清晰——两种普鲁士蓝之间的 fbm、涂布条纹、纤维、折痕（亮边、暗边、泛白）、漂白边缘、斑点；纸外是带投影的深色制图纸。线：淡蓝白、略软（mipmap 渗色）、受纸纹驱动的轻微墨色断裂；四种线宽（轮廓、细节、细线、发丝，如 3.2／2.0／1.25／0.9 图纸单位）。屏幕宽度＝图纸宽度×zoom^0.65，所以特写不会变成香肠、远景不会消失。虚线惯例：中心线（长—短）、隐藏线（短虚线）、假想线/剖切线（长—短—短），随缩放保持图案留在纸上。用画家顺序做遮挡：每个实体先填「纸色」再描轮廓；斜向挤出时在 N 个深度步以 2 倍线宽描轮廓、再用纸色填同样的步，留下干净剪影。缓冲区合成：ink（白＝曝光出的线）、fx（阴影、湿度、印章墨作通道）、字幕最后叠加；阴影也会让线变暗——这就是被抬起的物体证明自己已离开纸面的方式。排线调子用于剖面、土壤、配重，45°、间距 8–14 单位。蓝晒与水：水滴晕开成更深的蓝并带浅潮线，污渍内的白线变软，墨水签名洇开。那「一个真实的东西」（可选，最多一次）：一个绘图符号离开绘图语言，获得柔和体积、整体一个渐变、辉光，以及投在线条上的影子；它原处留下未曝光的浅印。
- **字体字幕**：手写字体做页眉、标签、注释与字幕（如 Architects Daughter）；技术无衬线做标题栏字段（如 B612）；脚本体只用于签名（如 Allura）；均为 OFL。文字像其他东西一样用发光笔尖从左到右写出。字幕是图纸注释：浅色半透明盒、双白线、一个「NOTE / n」格、文字约 0.35 s 写出、一枚小引线刻度；按镜头放在画面空处，绝不固定在底部（图纸底部是地平线、基座和标题栏）；约 880 px 处换行。停留 ≥ max(1.8 s, 语音＋0.6 s)。每条字幕同时写进图纸的 GENERAL NOTES 栏，于是最后的全景里能看到全部旁白变成了图纸注释。标题就是图纸页眉，标题栏放状态与结论字段。
- **运动质量**：摄影机与描线走逐帧 24 fps。段落内连续运动，段落间在强拍硬切；只在物理撞击（拍纸、盖章）时给极小的镜头抖动。描线：按弧长截断、笔尖发光，同层内错开开始，每层踩拍起笔。制图顺序：中心线→轮廓→细节→排线→尺寸→带编号圆球的引线→标签。爆炸图：部件按拍的细分依次离开、带缓动，再按拍组带咔哒声逐个归位。机构按网格迈步，像擒纵器：齿轮每个细分前进一齿、带短 ease-out，啮合相位算准让齿真正咬合，链条随链轮运动。机器表演：角度、下垂、体积和仪表指针就是它的表情；失败＝约 1.5 s 内变慢、下垂、发条走完；喜悦＝猛地立直、指针过冲（回弹缓动）。
- **镜头语法**：词汇表非路线，开头结尾由主题决定。整张纸在桌上：尺度、作为物件的文件——建立、结论、成组图纸；中景推到一个图形、主体约占高度 80%、一侧留天：设计被画出——制图、解释部件；沿力的路径（链、管、线、梁）跟踪：因果——工作原理、操作顺序；强拍上切进 2 倍特写：机构的心脏——齿轮啮合、阀门、关节；锁定一拍：深思——手在修改、一个决定；斜向深度系数由 0 到 0.5：平面图纸「转起来」有了厚度——从平面到实物、深度揭示；剖切线扫过：内与外——剖视图、隐藏结构；横移过图 1→图 2→图 3：版本、步骤、时间——修订、施工阶段；缓慢推近、无人声：惊奇——那一个真实的东西。叙事镜头要近，整纸远景罕见；主体离任何要框进来的纸边至少 960/zoom。转场用强拍切或在纸上改写图号，不用叠化。
- **声音配乐**：对位式机械音乐：羽管键琴、巴松、弦乐 spiccato、竖琴、钢片琴、音乐盒、古钢琴、小型管乐组；模仿式线条（发明曲、卡农、赋格段）像互相咬合的零件；短促重复的动机可以当「齿轮」。拟音随材质：纸——卷纸噼啪与拍击、丁字尺木滑、制图笔刮擦（2–6 kHz 颗粒，长度等于笔画长度）、写字爆发、圆规吱嘎、排线笔触、橡皮摩擦、描图纸沙沙；铜与木——零件咔哒（约 3–5 kHz 共振）、擒纵滴答、链条哗啦、弹簧 twang、发条走完时间隔按几何递减的滴答；水——每滴柔和的闷拍、轻雨床；橡皮章闷响、笔帽咔哒。弧线选项（任选）：乐器随写出的渐慢逐一退出、进入真静默；单独一个疑问乐句；魔法下方挂一个不解决的悬留和弦；盖章时给完整终止式；结尾把主题加长；每多一个机构就多加入一个声部。静默里可以只有纸声。人声：干、克制，念设计笔记、少量短句；最动人的时刻留白无人声。混音：人声下音乐压得很低（约 0.36 倍）、拟音减半、呼啸声做低通以免盖住辅音；−14 LUFS、少加颗粒（纸本身已有）。
- **招牌技法**：
  - 制图顺序：物体像工程师那样把自己画出来，一拍一层——适合桥、小提琴、厨房改造
  - 活的标注：尺寸量着运动的部件、数字随之变化；带编号圆球随零件飞、剖线揭示内部——适合心脏瓣膜、折叠自行车、火箭级间分离
  - 图号当转场：「FIG. 1」被划掉改写成「FIG. 2 · EXPLODED VIEW」——适合产品版本、施工阶段、食谱步骤
  - 投影当摄影机：斜向深度系数做动画、爆炸零件沿深度轴飞——适合平面图变建筑、电路板、平板家具
  - 符号成真（全片至多一次）：制图惯例离开绘图语言——尺寸箭头飞出、排线变雨、中心线变公路、焊接符号迸火花——适合发明终于运作、城市规划变成街道、梦想变成方案
  - 蓝晒与水：水滴晕开、线条变软——适合防洪设计、悲伤、海堤
- **避坑**：
  - 主体靠近纸边→远景要露出桌面，留边距或把纸放大
  - 向上爆炸撞到页眉→改为侧向爆炸，长件在爆炸时压平
  - 字幕放在 ink 缓冲上会跑出纸外、盖不住线→用单独的预乘 alpha 叠加层
  - 物体被自己的阴影压暗→只在它的区域把阴影通道清零
  - 团状形体逐瓣加明暗像葡萄→整个并集一个渐变；月牙用并集减去偏移遮罩；并集填成一条路径（nonzero），否则重叠填充会出气泡

**适用场景**：工程制造 / 硬件发布 / 科技讲解
