# 62 · CRT 字符终端 / CRT ASCII Terminal

> 分类：胶片录像
> 参考片：静海日志
> 原片一句话：月球基地的 AI 沉睡 40 年后被唤醒，用字符画出“家”来回复。

## ⭐ 可直接复制的提示词

```text
用CRT字符终端风格：单色磷光屏（琥珀P3或绿P1）弯边有扫描线，画面、标题、人脸与字幕全是等宽网格上的真字符按墨密度选字、靠留白成图，绝非图片加滤镜；一种磷光色包办一切、至多一种柔第二色在强拍出现一次，亮度靠暗/正常/粗与反显；字幕是底部LOG条随旁白逐词打出；唯一相机是字号——推入拉出、推进单字见内文、清屏滚动开关机转场；配模拟合成冷脉冲配乐、打字继电器与调制解调拟音、静音为主；避免绿雨黑客、像素精灵、科幻HUD线框、RGB栅格与图片滤镜。
```

## 配方拆解

- **本质**：屏上的一切都是等宽字符网格上的真字符，被老式单色CRT的磷光照亮。
- **不是什么**：绝不是图片加"ASCII滤镜"——字符必须作为字符画在网格上；不是黑客片的绿雨、不是像素游戏（无精灵无自由像素）、也不是科幻HUD（无线框无浮空面板）。
- **配色**：一种磷光承载一切：琥珀（P3）或绿（P1）或白，各有自身亮度梯度，无第二种装饰色。至多一种柔和第二色只用于一件事物（那个情感物件），在唯一时刻、在强拍上开启，绝不轻易收回；其余全片不出这一色。示例：琥珀屏配冰蓝白表远方之物、绿屏配暖粉表有生命之物、白P4屏配淡金表记忆。亮度是唯一其他工具：暗/正常/粗体与反显。
- **材质渲染**：字体：一种等宽点阵风字体（VT323, OFL），单元0.4em×0.8em（1:2）；大幅预渲染字形图集带一笔描边模拟电子束扩散，用drawImage缩放使变焦连续清晰。网格：每镜列数不同（标题约20、终端80、画面200+），推入可到一格内含自己的子网格。密度阶梯：每个字实测墨覆盖率×暗/正常/粗体约20级、去掉近似项、每格加小幅有序＋哈希抖动、低于阈值的格留空——留白是ASCII可读的关键。画面管线：把灰度画进与网格精确对齐的离屏"负片"（每格多次采样，通道为磷光/第二色/标志），逐格平均后选字；内部加局部对比(m+0.9·(m−mean))保住轮廓。可辨主体是剪影而非噪声（真实海岸多边形、几个平面构成的脸）：暗＝稀疏的暗字、亮＝密的粗字、阴影侧只有稀疏的`.`，选轮廓清晰的角度。网格上的深度：远＝更暗更疏、近＝更亮更密，一道细亮边分开前后平面。CRT后期（WebGL）：磷光色沿亮度梯度映射（深橙→琥珀→近白过曝，P3）；多级bloom＋淡晕；玻璃＝细扫描线（亮处更窄）、轻微桶形弯曲、圆角遮罩、暖近黑玻璃、淡反射、约1%闪烁、细噪——绝无RGB栅格，因单色管没有。余辉：消失的文字按τ≈0.1s解析衰减、使每帧确定；运动字留一道淡拖影。
- **字体字幕**：字幕是终端输出：底部保留一条LOG带——暗分隔线＋反显tag＋prompt＋大写行约45px，随旁白逐词打出（用耳语词时间戳）、停留≥max(1.8s,语音+0.6s)；它活在变焦的网格之外、像一条状态行，带着同样的扫描线与辉光；无人说话时显示系统状态（进度条/等待信息）。故事本身展示的屏上字是画面而非字幕，在.srt里记为[SCREEN]…；标题用键击声打出，可以是文件名、命令或页眉。
- **运动质量**：字符绝不离网格（除声明的变形时刻）：打字、滚动与计数逐格跳动；滚筒数字离散翻转、先快后慢。只有三样东西连续运动：网格尺度（相机）、CRT物理、变形中的粒子。打字速度即表演：机器输出匀而快（约10–40ms/字）、戏剧性的句子放慢到配乐的乐音值、人手打字则手 timed 不匀、有停顿与爆发。粒子从源字内部的随机点生成、由小淡入、缓动到目标格、落定短闪，绝不堆叠成亮条。推入一个字符：先停在整字可读处、再推到其中文字可读，内文全亮、外文字只有几个百分点亮度、邻字压暗，使形先于文被读到。
- **镜头语法**：唯一的相机是网格尺度，外加CRT的电源状态与一次可能的屏外镜头。静态80列终端（等待/程序/机器时间）；推入（格变大＝注意/亲密）；拉出（格变小＝背景/尺度）；推入单个字符（符号由什么构成＝隐藏深度）；滚动（缓冲区移动＝累积/时间流逝）；清屏／硬重绘（一次切／新状态：重启/新章/崩溃）；字变成图（格缩小、字落下＝话语成世界）；开机／关机／消磁（生/灭/睡/震）；从玻璃拉回到画出来的房间（屏是世界中的物件）。开合随题材而定；文字留在弯曲以内的安全区、LOG带保持清空；转场发生在屏上（清屏/重绘/滚动/电源），绝不两屏叠化。
- **声音配乐**：原创模拟合成配乐、代码渲染（numpy/numba）：PolyBLEP锯齿与方波振荡器、4极点梯形谐振滤波器带移动截止、滤波包络、方波音序器、慢磁带抖动（±几个音分）、pad长混响、击的门控混响；可选次低音drone、采样保持噪声、失谐齐奏主音。绝不chiptune。技法：成图时让一个琶音生长、唯一的大和弦只持一刻、震惊时连混响尾一起落到数字零、变色时打开一个和弦。静音是主乐器：打字与闪烁光标下只留室声、变形前一小段近静。拟音全合成：继电器咔与消磁嗡（电流嗡加谐波＋一记thump）、回弹弹簧键（塑料嗒＋弹簧ping＋键帽thock，空格更闷、回车更沉）、电传打字tick、调制解调器与电话线音（应答音/FSK/带限噪声）、方波错误哔与BEL、粒子用的高频小tick簇、可选点阵打印机或磁带机、室声（风扇低嗡与极轻的回扫啸）。旁白若由机器说则处理（轻环调/短梳状/电话带通/软饱和）并确认耳语仍可读、短句少言；音乐在旁白下闪避约−8dB、母带−14LUFS、mux无颗粒（噪声在画面里）。
- **招牌技法**：
  - 画面由字做成：一句话拆开、其字母按墨密度排序后变成只含这些字母的图像——适合宣言成人群/食谱成菜/诗成风景
  - 字号即相机：推到一个字充满屏幕、且它本身由更小的字构成——适合公司名由员工名构成/年份由头条构成/心形由消息构成
  - 打字节奏即剪辑节奏：机器匀打对人手不均打、闪烁的光标就是表演——适合求职申请/一封道歉/想起密码
  - CRT物理：开机点→线→框、关机收成一点、余辉、泛光、弯曲的玻璃——适合监护仪/夜班结束/旧档案重开
  - 一次变色：一种柔和第二色只出现一次——适合数据日志里第一片绿叶/天气报告里血橙落日/机房里孩子的一幅画
  - 日志文件：时间戳、错误码、进度条讲故事——适合产品上线日/一场救援/一次迁移
- **避坑**：
  - 反显：destination-out只改alpha而上传忽略→用不透明黑画布、以黑色图集刻出字；负片未与网格对齐会在数百列上漂移→按格宽/采样数精确映射
  - 格心算错：格高是2·cw、中心应是(j+.5)·2cw而非(j+1)·cw
  - 每个暗像素都变成字（出现-+-+的墙）→加阈值、gamma≈1.25、局部对比；噪声纹理主体读成斑块→用剪影、暗而稀的背景、阴影侧只留点
  - 粒子从字心生成叠成亮条→从字内随机点生成、小、淡入；描边字形图集会封死字腔（M/B）→采样细的纯填充位图作遮罩
  - 懒构建的数据到不了导出器→在导出window.EV前先构建粒子时间线及其声音事件；开机参数为0仍画中心点→开机前曝光设0、点项乘以曝光；绝不用图片加ASCII滤镜，字符必须画在网格上

**适用场景**：开发者工具 / 科幻 / 科技品牌
