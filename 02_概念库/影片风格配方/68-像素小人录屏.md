# 68 · 像素小人录屏 / Mascot Screencast

> 分类：屏幕界面
> 参考片：Clawd 搬进来了
> 原片一句话：像素小人 Clawd 搬进 Claude 应用，一镜到底演示 Plan 模式和自检。

## ⭐ 可直接复制的提示词

```text
用【像素小人录屏】风格：画面像真实产品录屏，但窗口菜单按钮都用2D重绘、镜头可去任何地方且文字缩放清晰，大方块像素小人住在高清界面替软件表演，光标是用户、小人是软件；配色跟随产品明暗主题、小人用UI未用的高饱和色、叠加磨砂玻璃；UI字体跟随产品、字幕底部磨砂药丸；30fps、小人按像素网格阶梯站立于实测DOM顶边、有预备挤压拉伸、眼睛表演、光标弹簧平滑、因果触发真实UI变化；镜头推近光标、窗格甩镜带模糊、移焦、拉远整窗、随小人跟拍；配乐hi-fi世界层+chiptune小人层、键盘foley、静默铺垫承诺、人声平静、−14 LUFS；避免虚构UI、截图、手出现与小人盖字。
```

## 配方拆解

- **本质**：一个看起来像真实录屏的产品演示，但窗口、菜单、diff行、按钮全用2D重绘，让镜头无所不能、文字任何缩放都清晰；一个大方块像素的小人住在高清界面里，替软件表演它正在做什么。光标是用户，小人是软件。
- **不是什么**：不是黑色舞台的科技 keynote（无虚构抽象UI、必须是真产品），不是像素游戏（世界是高清矢量UI、只有小人和道具是像素），不是真实截屏（没有一张是截图）。
- **配色**：产品自身界面配色为准、严格跟随其明暗主题；小人保留产品或品牌的吉祥物色、或一个UI未用的高饱和色，以便在任意画面都抓眼；叠加层（章节药丸、按键HUD、字幕）为中性磨砂玻璃、最多一个取自产品的强调色；主题切换可以成为故事事件、整片随之换状态。
- **材质渲染**：真UI重绘——每个标签/模式名/快捷键与真产品一致、无截图无lorem ipsum、演示内容（代码/数据/测试输出）自洽且被测应用真的改变；像素网格神圣——小人、道具（铅笔/!/闪光/心/尘）与拖尾共用同一方块像素网格、边缘脆、随镜头缩放、位置吸附半像素使运动带阶梯感；重力=UI顶边——小人只站在真实元素顶边（输入框/菜单/列表行/代码行/按钮/状态栏/标题字母），位置每帧测量实时DOM而非手摆；窗口浮在壁纸上带柔影、缩放不越出显示器；景深只服务注意力（移焦模糊不重要窗格、暗角聚光），绝不模糊要读的字；运动模糊只在甩镜时以各向异性施加于未变换的 wrapper、慢移保持清晰。
- **字体字幕**：UI字体跟随产品（或免费近似如Inter/JetBrains Mono/编辑衬线）；信息层仅——章节药丸(01–04)、KeyCastr式按键HUD、磨砂玻璃字幕药丸、可选「▶▶4×」延时签，无其他叠屏；字幕在底部药丸、绝不压被讨论元素也不在小人下方、停留≥max(1.8s,语音+0.6s)；标题若有是 diegetic（作为UI出现：空状态标题/窗口标题/通知）。
- **运动质量**：30fps、UI逐帧、小人位置按像素网格阶梯；小人表演——跳跃有预备蹲、起跳拉伸、收腿、落地挤压+阻尼弹+尘，待机随乐拍呼吸（微挤压）并不规则眨眼、交替腿走路并翻转精灵；眼睛承载表演（中性/左右上下/睁大/开心/闭/眨）看向要点、手臂下/上欢呼/挥；光标平滑弹簧路径、点击微推、绝不瞬移；因果——小人每个动作触发真实UI状态变化、用户每个动作是显示在HUD上的光标移动/点击/按键；UI按真产品方式动画、不发明它没有的花哨。
- **镜头语法**：录屏软件式镜头——屏幕内一镜到底、缩放≥1、仅章节切换时切；推近光标/插入符（「事情在此发生」）；静止缓漂（我们听着时app活着）；窗格间甩镜带模糊（此处因、彼处果）；推近+暗角定格（要记住的那个承诺）；窗格间移焦（注意力移动）；拉远到整窗（整体工作流）；随小人沿列表跟拍（软件逐项处理）；分窗重构（两件事同时）。讨论物与字幕不重叠、小人不盖要读的字；转场为章节药丸擦除、像素擦除、主题揭示圆，禁叠化或截图。
- **声音配乐**：两种分辨率的音乐：hi-fi层（钢琴/直立或电贝斯/刷镲或紧鼓/钢片琴/真采样）是世界，chiptune方波或脉冲声是小人，可交替、对唱或融合；暗色主题用低通「夜晚」版乐队、章节接缝加通鼓填充与镲、撤鼓制造张力、小人的音符落在它踩的词上、分屏做立体声分离、定格时一个持续pad；foley——键盘thock+click带人类抖动、触控板点击、窗格嗖、弹窗啵、通知铃、CI滴、截图快门、小人8-bit脚步跳落；静默在关键承诺前短降到房间声；人声平静、一句一功能、产品名用whisper核验、效果避开词首、音乐下压、−14 LUFS。
- **招牌技法**：
  - 匹配剪辑起源：小人从UI里已有的东西（logo块字/图标/加载圈）爬出并留轮廓，适合聊天气泡变向导/图标变助手
  - 移动地板：小人骑在光标、弹窗、发出的消息、进度条上，适合消息飞进会话/上传条/拖放
  - 聚光定格：推近并暗角那个承载承诺的徽章，适合「已保存」/「已加密」/「此前不收费」
  - 影片改变状态：开关的效果溢出预览接管整片、之后恢复，适合深色模式/语言切换/离线模式
  - 光标与小人当角色：光标抚摸、戳、拖小人，小人反应，适合批准建议/撤销/新手引导惊喜
- **避坑**：
  - 发明功能或改模式名→逐个对照产品文档、文档没有的就不出现
  - 小人漂浮或偏离元素→每帧测DOM、只站顶边；小人盖字或在字幕下→给它留无字通道
  - 对要读的字加模糊假景深、或缩出屏幕→只移焦不读的窗格、缩放≥1；画面出现手/臂/手指→光标才是用户
  - 运动模糊加在变换层会把像素精灵抹错→模糊未变换wrapper且只在甩镜；按键/弹窗落在产品词上遮住它→foley移开词首、终混用whisper复查
  - TTS读错产品名→换嗓音与拼写、用whisper核验

**适用场景**：产品教程 / 功能发布 / 新用户引导
