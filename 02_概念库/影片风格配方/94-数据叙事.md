# 94 · 数据叙事 / Data Storytelling

> 分类：数据地图
> 参考片：一百个夏天
> 原片一句话：一百年的夏季气温，图表本身就是故事。

## ⭐ 可直接复制的提示词

```text
用数据叙事风格：真实数据由红蓝铅笔在奶油纸上一笔一笔画成图表，手写便签钉在数字旁；图表就是摄影机、节奏与情节，每次运动都是图表操作，轴随故事生长、重缩放、编码变形，转场就是图表操作，不叠化。颜色只编码数值：发散数据用以均值为中心的对称色带、其余用连续色带，浅值保持浅、不夸大；蓝笔芯给记忆与便签、红笔芯给记录与警告。笔尖有抬起—落地—回弹、峰值发颤；镜头在一张纸上一镜到底，用标记特写、全景扎进、跟铅笔、轴生长时拉远、破框推近、锁定机位。声音化即配乐：音高＝值、节奏＝时间密度，关键处全层数字静默，音乐闪避 11dB、−14 LUFS、无颗粒。避免仪表盘、幻灯片、装饰与外推数据。
```

## 配方拆解

- **本质**：一张会讲故事的图表：真实数据，由一支红蓝铅笔在奶油色纸上一笔一笔画出，手写便签钉在数字旁。图表本身就是摄影机、节奏和情节——每个标记都是真实数字，每次运动都是有意义的图表操作（标记落定、轴生长、比例变换、序列变形、便签钉上）。数据必须真实、开放授权且可追溯；你改变的是取景，绝不是数字。
- **不是什么**：不是仪表盘（一次只讲一个想法）、不是带图表的主题演讲（没有幻灯片），也绝不做装饰。
- **配色**：颜色只编码一件事：数值。发散型数据用一条以有意义参考期均值为中心、对称跨度的色带（ColorBrewer RdBu 家族）；没有自然中心的数据用单条连续色带。其余一律是奶油纸上的墨。诚实胜过戏剧：浅值保持浅，绝不拉伸色带让变化显得更大。两支笔芯各有含义：蓝色给记忆和人的便签，红色给记录和警告；换笔芯标记转折。一个 accent 色可以绕过色带给非数据的标记（标志、高亮）。
- **材质渲染**：纸：暖奶油色、固定种子纤维噪声和淡淡的点阵网格，都在世界空间。墨：深暖墨用于轴与系列、淡暖灰用于网格和零线、IBM Plex Mono 做刻度。标记：数据点带一圈细墨环，浅值在奶油底上也看得见；标记落地时短促弹出带细涟漪，间隔小于约 0.1 s 时抑制涟漪。手写（Caveat）用铅笔画、逐字抖动、石墨颗粒，笔尖在 x 高度上跳舞时写出；引线是摇晃的曲线、末端在标记周围画一个不闭合的圈。红蓝铅笔：六角笔身、蓝半红半、削尖的木锥；只露出笔尖一端、从右下进入；影子随抬起飘得更远更软，笔尖尖锐、笔身柔和。版式：固定在世界空间的绘图框、给早期便签的记忆区、每个便签钉在数据空间（数值＋像素偏移）以便重缩放保持布局、底部字幕带。
- **字体字幕**：字幕就是图注：文本衬线体（Newsreader）、墨色、与图表左对齐、不超过 2 行，上方一条发丝线，外加一个小等宽 kicker 表示已画到的范围；文字按低语时间戳出现在纸色带上。停留 ≥ max(1.8 s, 语音＋0.6 s)。标题是图表自己的头条（Newsreader），设在绘图框上方的世界空间里；摄影机推近时淡出、回到全景时回来。在小节的图表操作或静默期间绝不上字幕。
- **运动质量**：数据的节奏就是影片的节奏：把标记映射到音乐网格；要加速时可以细分拍而不改速度。选一个最细分的拍落在整帧上的速度（24 fps 下一分钟 1440 帧，每分钟最细音符数必须整除它），画面与声音才不漂移。铅笔表演：每次落笔前先抬起、落地时影子与笔尖相遇、带轻微回弹；数据变密时加快、峰值时像地震仪针一样颤抖。它可以退缩（回弹并冻结）、犹豫（下笔前悬停）、退出（把故事交给观众）。重缩放读成棘轮咔哒（分级、每级带缓动），平静的重缩放则平滑。morph 是错开的扫掠、每个标记缓入新形；便签经过时淡出、回来时变成小标记。没有淡入空白或叠化：转场就是图表操作——轴生长、拉远、重缩放、morph、一个格子展宽成下一帧。
- **镜头语法**：一张纸上方的 2D 摄影机 {x, y, zoom, roll}；一部片子就是一镜到底，硬切稀有且有意义。一个标记的极特写并跟随其引线：一个事实、一个人——单个案例、具名的人物；先全景再扎进一个标记：先见模式后见案例——熟悉的趋势、待纠正的迷思；随标记长出坐标轴而拉远：单位出现时框架也来了——命名度量、扩大主张；跟拍铅笔、最新标记保持在画面宽度约 60% 处：进展——过去在后、未来在前——时间序列、比赛、队列；随数据上升而升降、让荷兰角悄悄潜入：升级与不安——失控增长、债务；两帧内快速推近、震动衰减、重缩放时抖动：惊讶、框架被打破——异常值、崩盘；快速拉远、滚转、持续小颤：一股 rush——暴涨、连锁、恐慌；锁定机位：变换本身就是运动——morph、慢读；停在一个标记再拉远：局部在整体之中——结论、语境；拉远并平移加入更多真实数据：尺度切换——更长的记录、名单的其余部分；在记忆区横移过便签：回忆——传记、事件时间线。关键时刻主体 ≥ 画面高度三分之一；真轴移出画面时把刻度标签钉在画框边缘的纸条上（冻结窗格）。
- **声音配乐**：环境声跟着便签唤起的地点走（J-cut 进、L-cut 出）。拟音是石墨、纸和木：笔尖滴答与纸张轻拍、手写刮擦、尺子嘶声做轴、破框时纸张刺破、铅笔翻转的木头咔哒、重缩放的棘轮齿、morph 的纸张扫过。声音化就是音乐：音高＝数值、节奏＝时间密度。低值吸附五声音阶、中值吸附半音、极端值不量化，偏离参考越远失谐越大。音色是低通门控的 plonk（正弦＋FM，FM 指数随值上升：木→金属）；密集段落音符更轻、衰减 ≤ 间隔的 1.5 倍。铺底：失谐锯齿 pad、软底鼓、噪声沙锤、低通踩镲、正弦低频、采样保持提示音、持续音；和声可随数据变暗或变亮。静默是工具：在关键标记、morph 或结论之前，让全层真正数字静默，好让数据自己被听见；之后的第一个声音最重要。混音：压缩而平静，中立旁白，音乐闪避约 −11 dB，拟音除关键轻拍外要轻；−14 LUFS、无颗粒。人声绝不盖过 rush、静默或 morph。
- **招牌技法**：
  - 一个标记＝一个事实——适合连锁店开出的第一家店、试验的第一位病人、发射的第一颗卫星
  - 轴随故事生长：旁白第一次说出单位时 y 轴才出现——适合营收、城市人口、接种率
  - 钉住的注释：内容与颜色承载叙事弧——适合运动员的一个赛季、一家人的迁徙、使用曲线上的各次发布
  - 打破画框：图表必须让出空间、撕边留作伤痕——适合病毒式暴涨、价格泡沫、破纪录的洪水
  - 编码变形：柱变华夫、地图变排名、折线变坡道，以揭示整体——适合把预算化成人数单位、把国家变成排名、把每日步数做成年度条带
  - 尺度切换：一个值→序列→更长的真实记录，绝不外推——适合一天的用电→一年、一个物种的计数→一个地区
- **避坑**：
  - 按表头名而不是索引选数据列，并把旁白声称的每个事实打印出来核对
  - 便签与后来的数据相撞→用数据空间定位、设记忆区
  - 破框重缩放太快看不见→把被刺穿的状态保持至少半拍
  - 右对齐的注释仍从左到右写→铅笔要跳到第一个字母处
  - 设置 globalAlpha 的辅助函数要乘上传入的 alpha，否则淡入会跳过它们

**适用场景**：数据新闻 / 报告 / 气候与科学
