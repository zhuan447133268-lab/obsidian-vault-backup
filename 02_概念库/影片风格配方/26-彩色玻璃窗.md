# 26 · 彩色玻璃窗 / Stained Glass

> 分类：传统工艺
> 参考片：东窗之龙
> 原片一句话：阳光从清晨移到黄昏，照到哪一格花窗，哪一格的故事就动起来。

## ⭐ 可直接复制的提示词

```text
用【彩色玻璃窗】风格：黑暗石厅内看中世纪彩玻璃窗，切块玻璃嵌深色铅条、脸褶用棕色grisaille，人物逐片僵硬地动，只有太阳照到那格才活并把彩光斑投到石地；配色两种主色相（深钴蓝底+ruby热色）加少量金绿，太阳色即时钟（蓝白黎明→金午后→深橙黄昏）；统一合成使玻璃石地同一光下，保色调映射使蓝仍宝石而太阳烧白，光斑模糊带光晕；字幕为底部羊皮纸卷轴、展开75%才出字；人物8fps、光与镜头24fps、破裂带白闪、靠被照亮而非淡入；运镜随光带横移、锁定单格、拉远整窗、沿光束到地面；配乐管风琴竖琴手钟、击玻璃非谐分音、人声温和、−14 LUFS；避免矢量黑描边、万花筒滤镜、马赛克与叠化。
```

## 配方拆解

- **本质**：从黑暗石厅内部看一扇中世纪彩色玻璃窗：只有当太阳照到时才活过来——光是时钟、是摄影机、也是故事。切开的彩色玻璃嵌在深色铅条中，脸与衣褶用棕色 grisaille 绘出，人物一片一片僵硬地动；玻璃透出的彩色光斑落在石地上。
- **不是什么**：不是黑色描边的矢量图，不是万花筒/Voronoi 滤镜，不是蒂凡尼新艺术，不是马赛克（马赛克反射、玻璃透射）；且必须世俗——无十字、圣徒、光环等宗教图像，借工艺不借题材。
- **配色**：两种色相撑起画面（一深一热），再三四色只作小点缀（如钴蓝底、ruby，金/绿/暗红点缀）；绿白玻璃慎用（脸、饰边、天空），肤色比想象更暗否则背光烧白；故事光源（烛/灯/屏）可用玻璃没有的颜色以显出是光源；太阳颜色即时钟——蓝白黎明、近白正午、金午后、深橙黄昏（提高强度而非加红）、弱蓝月光，光斑长度随太阳高度；石与铅只取溢光或投影的颜色。
- **材质渲染**：统一 WebGL 合成公式使一切处于同一光下：玻璃=tonemap(背光×透射率×玻璃纹理)+风化雾×室内光；保色调映射 1−exp(−x) 把钴蓝变柔和，仅最顶端按通道混合使太阳烧白而蓝仍宝石蓝；每片玻璃有纹理（每片角度的条纹、±10%色漂、靠铅的暗边、±9%厚度），着色器加种子气泡/划痕/厚度云，0.6倍缩放以下淡出小特征；铅条近黑、单一平面网络、小片更细、圆角接点、灰法兰与焊点、只在色与色相接处；grisaille 为锥形描线+哑光罩染+刮出高光（每褶旁一道本色细线）；脸为杏眼重上睑、表情靠换脸片绝不变形；背景为手切菱形格与 Pearl 饰边、白色卷草细边；地面光斑模糊、降饱和约20%、石纹调制、带光晕、镜像（窗顶投最远）；光束加性带尘、窗边近0、约40%处最强。
- **字体字幕**：字幕为底部羊皮纸卷轴 banderole（卷端、轻垂、细线），IM Fell English 深墨约44px，从中心展开、展开≥75%才淡入文字、pad 留足、停留≥max(1.8s,语音+0.6s)；标题为石上雕刻罗马大写（Cinzel 600），暗刻、亮下唇、镀金、由移动光带揭示，小行≥30px；玻璃内文字仅作白玻璃卷轴上的 grisaille。
- **运动质量**：人物 8fps 逐格、光/镜头/光束/尘 24fps 逐帧（阶梯光会像闪烁）；刚片用 2D FK、长身为分片脊柱链；冻结规则 min(t,t_lightLeft)、动作踩拍；破裂时锯齿线约¼秒从撞击点奔出、带光、白闪+2帧抖；重嵌铅时片组每拍沿铅向外轻 bump 滑动、以焊花收尾、裂纹化为修补铅条；玻璃绝不弯曲变形、出现靠被照亮而非淡入。
- **镜头语法**：随光带横移（时间流逝/章节推进）；锁定单格特写（此刻）；拉远到整窗（规则/总结/余波）；沿光束俯仰到地面再俯视（画离开玻璃变成光）；穿越破裂不切（事件即媒介破碎）；缓推向小光源（注意力收窄）；上摇到玫瑰窗/花格（有物在主宰）；两格间移焦（过去与现在并置）；沿窗洞低角度玻璃斜掠（建筑与尺度）；新光下回到旧构图（韵脚显示变化）。主体大、靠近中心、≥约1/8画宽并带辉光；转场靠移动的光、光束、破裂、黑暗，禁叠化/擦除/翻页。
- **声音配乐**：管风琴（踏瓣持续音、柔和音栓、全奏）、竖琴、手钟、管钟、竖笛或吟诵声、水杯音、定音鼓，另有手摇琴 drone、psaltery、便携风琴；不用通用钢琴弦乐；调式家族为教会调式、开放五度、平行奥尔加农；自由无拍吟诵用于黑暗、每格亮起一个「光」的音、踏瓣持续后切出、每片亮一级上行音阶；foley 材质优先且可合成（击玻璃非谐分音1:2.32:4.25:6.63:9.38、破裂、铅条粘滑吱嘎、玻璃滑进铅条、焊锡嘶滴、光移动时的气声、石厅环境、拱顶鸟、铁件冷却滴答）；静默是硬停含混响尾；音乐宏大混响、在人声下压约9dB、−14 LUFS；人声温和均匀的叙述者、几句短句。
- **招牌技法**：
  - 光即时与摄影机：只有被照亮的格才活、光离开人物冻结，适合食谱步骤/工厂班次/农场四季
  - 玻璃投到石上：关键场景在地面光斑上演、随日落拉长，适合被放大的记忆/用影子重演的球赛/由渐长光斑画出的趋势
  - 破裂与重嵌：碎片沿铅滑入新画面并留下疤，适合公司重塑/受伤与康复/老建筑修复
  - 窗自有光源：夜里一格从故事内部发光，适合守塔人/夜班护士/不眠的服务器
  - 窗作图解：尖拱为列、玫瑰为表盘、边框为时间线，适合产品阵容/循环的各部分/家谱
- **避坑**：
  - 隐藏铅条透出前片→每片描铅前先擦掉其下表面
  - 粉彩玻璃→保色调映射、肤色更暗；红黄昏×蓝玻璃=泥→保住蓝、提高强度而非加红
  - Voronoi 像滤镜、平涂像剪贴画→手切菱形、每片纹理、重 grisaille
  - 地面光斑锐利像贴纸→模糊、降饱和、石纹调制、光晕；光束在窗处满强会洗白玻璃
  - 俯视投影翻转→把墙放画面底部使人物直立；雕刻字在暗宽处不可读→推近并打光

**适用场景**：传说故事 / 文化遗产 / 节日故事
