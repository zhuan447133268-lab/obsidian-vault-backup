# 93 · 热成像 / Thermal Camera

> 分类：仪器实证
> 参考片：冬夜，一栋楼的体温
> 原片一句话：雪夜里，一台热像仪绕着一栋老居民楼转：漏风的窗、墙里的暖气管、睡在热车盖上的猫，还有一年后改造完的同一栋楼。

```text
用【热成像】风格：画面透过辐射热像仪，低分辨率带噪声iron伪彩（亮度即温度），屏幕自带色标点温区域框等温线热点跟踪与时间戳，读数皆从热像本身读出；配色一部片一套调色板、对比锁同标尺、等温线独占饱和绿只表超阈、可见光保持自然色；等宽体读数贴十字线、无衬线标签挂指引线、数字末位按刷新率跳动；30fps、传感器噪声逐帧全新、仪表约6Hz刷新、扫描线1–3秒恒速横过；运镜为扫描线掠过、固定分屏横移、推近读数、同标尺双画框判断；声音为风扇嗡、扫描电嗡、锁定哔与等温线双音报警，配乐稀疏冰冷、结论一个暖和弦；避免透过玻璃显室内、反射误读、过度干净的渐变、不同标尺对比与跟踪器抖动。
```

## 配方拆解

- **本质**：通过辐射热像仪看世界：低分辨率、略带噪声的 iron 伪彩画面，亮度即温度，屏幕自带相机仪表（色标、点温、区域框、等温线、热点跟踪、时间戳）。扫描线或分屏把普通夜景变成热度，每一个数字都从热像本身读出，可见光是基线、热像是揭示。
- **不是什么**：不是科幻HUD（无发光线框、无虚构铬边），不是数据叙事（无纸上图表），不是霓虹调色（无色标就不许假彩），不是显微镜式的实验室光学。
- **配色**：每部片只用一套调色板（iron：黑→靛→紫→洋红→橙→黄→白）；level与span是叙事的一部分（宽看全局、窄显微结构、对比时同标尺），越界值截断到两端；等温线独占饱和绿、只表示「超过阈值」；叠加图形为白字暗描边、淡绿只留给判定；可见光画面保持自然色、绝不染色去匹配热度。
- **材质渲染**：两遍合成一遍相机：图像遍（PBR真实光）与热遍（每种材质写入°C到浮点目标）逐像素选择图像/热/分屏；表面温度模型（稳态墙 T_out+ΔT·U·R_se、热桥成带、局部源高斯、羽流动画噪声），表观温度=ε(θ)·T+(1−ε(θ))·T_reflected，掠射角发射率下降、反射温度取镜像方向（上冷云天、下雪或地面）；玻璃ε≈0.84、漆/砖/皮肤0.9–0.98、裸金属0.1–0.3；传感器仿真在屏幕空间——以约3倍感测网格渲染→光学模糊积分到传感器分辨率→加时域噪声(≈0.1°C)、固定行列纹、角阴影→读回传感器做所有测量→双三次上采样+轻细节增强；透明热气（尾气/呼吸/蒸汽）在温度空间alpha合成；图像遍必须自身成立。
- **字体字幕**：等宽体用于读数、色标端、时间戳与测量名（22–40px），无衬线用于标签（中文24–40px、英文20–32px），OFL自托管CJK子集；标签属于相机或世界——点温值贴十字线、标签挂指引线、色标与时间戳在边框，无标题栏无居中字幕；双语两行一语一色，数字保留一位小数且末位按仪表刷新率跳动、登记读数取测量中位数；1080p下无小于20px元素，每个标签停留≥max(1.5s, 字符÷阅读速度+1.5s)。
- **运动质量**：30fps；传感器噪声每帧全新、仪表读数约6Hz刷新、叠加以短缓动吸附（十字线收拢到点、数字从环境温度滚上落定）；热按热的方式动——羽流升腾摇曳、呼吸与湍流闪烁、冷却缓慢、生物体呼吸；扫描线以恒定机械速度横过画面（1–3s）带细白边与热侧暖辉；色标与时间戳位置、锁定对比框绝不移动；轻胶片颗粒（mux grain 1）。
- **镜头语法**：扫描线掠过锁定或缓推画面（不可见变可见）；固定分屏+相机横移（眼见vs机见并置）；推近单一读数（检视/怀疑）；吊臂或俯仰越过边缘（巡览范围）；低推靠近活物（温暖/生命）；锁定同标尺双画框（前后/好坏判断）。承载读数的主体避开右侧色标与左下时间戳、读数绝不盖住所测热点；转场用扫描线、分屏、level/span变化、探测器快门冻结、踩拍硬切，禁可见与热之间的交叉叠化、非传感器动作的擦除。
- **声音配乐**：仪器声：相机开机微弱风扇嗡、扫描电嗡+滤波噪声扫频、锁定哔声+急促滴答、等温线双音报警、探测器NUC快门轻机械咔哒、level/span切换咔哒；世界的热化声：风与冷空气、管道流水、引擎冷却滴答、主体贴近干爽的声音；音乐稀疏冰冷（弓颤音琴、玻璃、竖琴、钢片琴、低弦），血液循环题材可变心跳，结论一个暖和弦；tones与foley压过音乐、音乐在读数和活物声下让路、低端受控（高通≈40Hz）、约−16 LUFS母带前、真峰≤−3dBTP。
- **招牌技法**：
  - 扫描线：一线横过画面使背后万物变热（或变回），适合夜间机房/开餐前厨房/黄昏林缘
  - 行进分屏：固定竖分屏而相机移动、世界从热滑回常态，适合地板下水管/面板后线路/运动后皮下血流
  - 等温线报警：超阈值的一切变单一颜色，适合过热断路器/群体测温/冷库门漏封
  - 热点跟踪跳：最高点标记跳向新热源、间隙钉在物体上不动，适合桌面充电器/睁开的眼/将失效的轴承
  - 同标尺两时刻：前后并排锁定同标尺读取判断，适合修好的屋顶/退烧/保养后的机器
  - 残影：某物离开后留下的热痕，适合无犯罪之谜/谁坐过哪里/多久以前
- **避坑**：
  - 玻璃不透明——红外看不透窗、亮室不更暖，热遍绝不透过玻璃显室内
  - 反射会说谎——光亮的金属与玻璃映天空冷或灯的热，要在哑光高发射率面测或说明反射的是什么
  - 太干净读成CG——必须仿真传感器（噪声、光学模糊、粗网格）再上采样；细几何摩尔纹→超采样模糊后再抽取到传感网格
  - 数字必须与颜色同源——所有值从着色的温度缓冲读、登记测量中位数、显示读数时保持色标可见
  - 不同标尺的对比无意义——判断前锁定level与span；跟踪器不得逐帧抖——从缓冲找一次热点钉在物体坐标随相机走、只刷新读数；远处细热特征消失→靠近取景或用框最大值

**适用场景**：建筑与能源巡检 / 夜间野生动物 / 机械与电气检测
