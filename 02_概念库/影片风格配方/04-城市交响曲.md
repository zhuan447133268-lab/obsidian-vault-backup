# 04 · 城市交响曲 / City Symphony

> 分类：剪辑纪实
> 参考片：纽约的一天
> 原片一句话：纽约的一天：延时光河、踩着十六分音符的网格，1899 年和今天并排。

## ⭐ 可直接复制的提示词

```text
用城市交响曲风格：真实素材剪成极简音乐——延时把车流人群云变成光河，切点落拍且越来越密，一物刹到静止，强拍硬切黑；无旁白，音乐即剧本。35mm发行拷贝质感：1.85:1遮幅、暖高光抬黑、中调颗粒、柔暗角。配色：暖白字、灰线，钠橙唯一强调（数字下划线、人群轨迹、日环）。字体：全大写与中文无衬线左对齐不加框，数字卡逐位锁定。运动：0.3×–75×，>1×帧混合使车灯成线人群成雾，速度坡必有所指。镜头：同机位长延时当时钟、形状匹配剪辑、1×2到4×4网格、档案今日对位、日夜闪烁。声音：纯配乐加性叠加，琶音骤停于长和弦、硬停15ms干切只留混响。避免：旁白、无人机炫技、下三分之一条、翻页、生成图、灰平衡洗白夜景。
```

## 配方拆解

- **本质**：一部像极简音乐一样剪辑的城市片：延时把车流、人群与云变成光河，剪辑随配乐细分越来越密，一件事被慢到几乎静止，最后在一个强拍硬切到黑。没有旁白，音乐承载全片。
- **不是什么**：不是旅行宣传片（无流行乐无人机炫技蒙太奇）、不是vlog、不是新闻包装、不是带旁白的解说片，也不是明信片幻灯片；无姓名下三分之一条、无页眉、无居中标题卡翻页、无logo动画。
- **配色**：暖白字#EDE8DF、次级线#B0AAA0、钠橙#D9772F是唯一强调（数字下划线、来源线、人群轨迹、日环指针）、遮幅与黑#000000。调色：先逐镜局部灰世界白平衡（只作用于亮度0.12–0.88像素，强度0–0.6；夜镜为0以保钠灯与蓝），再统一LUT：S曲线（sigmoid斜率6.2、枢0.47、与线性55/45混合）→黑7/255白250/255→R×1.025、B×0.965（暖高光、暗部微冷）→饱和度0.86；bloom阈值170/255、⅛尺寸6px模糊、白天0.09夜0.15–0.2；半分辨率高斯噪声按0.35+1.3L(1−L)加权、强度9/255。档案片保持黑白走同一LUT。统一为35mm发行拷贝质感：1.85:1遮幅、暖高光、抬黑、高光溢出、中调结块颗粒、±0.5px片门抖动、柔暗角。
- **材质渲染**：只用真实素材（2D）：三脚架延时、单机≥12h长延时（同框日出日落）、移动延时、无人机航拍（顶拍为佳）、高帧率慢镜、1931年前档案片、照片（同机位一对为佳）、历史文本扫描页。禁生成图；禁修复、上色或变速过的档案复制品；禁YouTube翻录。放大上限：档案≤2.5×（降噪→lanczos→轻锐→颗粒），现代≤1.5×。
- **字体字幕**：拉丁Michroma（OFL）全大写、字距0.06–0.32em；中文Noto Sans SC可变字重300–350、字距0.08–0.14em；片尾字幕17px。左对齐、左边距168–196px、绝不居中或加框，靠文字块后极柔椭圆压暗（α≤0.6）保证可读。数字卡：Michroma 84px（三数叠排44px），下方长出2px钠橙线，一行中文（28px）+一行英文（14–16px）说明计数内容与来源年份；人口类数字按十六分音符逐位锁定（每位一记钢片琴），流量类0.6s ease-out从0累加，约数带≈与『约』。档案日期只标年份Michroma 22px置档案画面左下。结尾引文：书页镜头整句照亮，卡片则在最后运动镜头上放短句——中文60px、英文原文大写20px、来源行14px钠橙，0.25s内淡入并保持略超阅读时间。每种语言一行不换行；文本块完整停留≥中文÷4.5+其他÷15+1.5s。无旁白，.srt承载画面文字供静音/无障碍播放。
- **运动质量**：速度是主乐器：镜头速度0.3×–75×，凡>1×用帧混合（360°快门）平均所覆盖源帧并设上限——车灯成连续线、人群成雾、云成水。速度坡平滑（关键速度间smoothstep）且必有含义：走廊1×→6×脱离实时、延时1×→7×入狂热、快镜在音乐停的小节2.2×→0.3×刹入慢镜。后期克制添加镜头运动：全镜慢推1.00→1.05–1.10，开场静帧坠落式推近1.0→1.3（0.35s ease-out，随后加速至×2到切点）；无抖动、无甩镜、无超限数字变焦。
- **镜头语法**：剪辑点表由配乐决定（120BPM/30fps：1拍=15帧、三连音=5、十六分=3.75）；所有切点出自同一函数bar(n,beat)，镜头时长从不以秒键入，音乐由同一文件渲染。切点落在拍上；一条长单机延时当时钟，三、四次同机位回归（夜→晨、正午云、一秒入夜、昼夜闪烁）让观众无需字幕知时。密度随配乐：不快于当前细分，最慢画面放在琶音停止处。形状匹配剪辑：钟→钟、拱→拱、街道格→单元格，允许同形状由小到大punch-in。网格是本风格分屏：1×2→2×2→3×3→4×4，每半小节或一格一阶段，新格0.3s内散序点亮（绝不回黑），格间距6px黑，最后一拍每十六分重切。对位分屏：左档案右今日同类地点或形状，6px间距8帧从中心长出。日夜闪烁：同机位正午帧与夜帧每2帧交替；同机位照片对每2帧交替。倒放闪回：硬停前一小节早镜头按倒序回归，先每镜4帧再2帧。转场只有硬切和切黑；除书页与片尾卡从黑淡入外无叠化。
- **声音配乐**：纯音乐：无旁白、无现场声（素材原声是他人音乐）、无音效；旁白会把看变成听并与配乐争结构。若必需，仅在极开头或结尾一句短词，绝不压在剪辑上。配器（采样、CC0）：管风琴（全奏与弱音栓、踏板）、木管断奏（长笛、单簧管）、弦乐（跳弓大/小提琴、持续大/小提琴、低音提琴）、最后两小节加圆号对、大段落强拍管钟鼓、吊镲渐强进入重击、钢片琴只用于数字锁定。写法：一小节一和弦上的琶音、加性叠加（八分→三连覆八分→十六分）、break是所有琶音骤停于一个长和弦（maj7或9）、回归是管风琴全奏一击、硬停是15ms内干切所有乐器只留混响尾、coda是不解决的柔和弦并让开场音型以四分音符在片尾卡下回归。混响主体size .7/mix .28、coda .78/.36；总−14 LUFS、真峰值≤−1dBTP，颗粒0（已在画面）。
- **招牌技法**：
  - 光河：积分速度曲线到源时间、每输出帧平均窗口内源帧（设blend上限）——夜景40×/blend30、云37.5×/24、一秒入夜75×/30
  - 速度坡：speed关键帧间smoothstep共用积分器
  - 刹入慢镜：2.2×→0.3×，柔体用运动补偿插帧、细线（电缆、轨道、文字）用交叉淡化以免撕裂
  - 人群→轨迹：固定机位逐像素中值背景，差值>22/255的块（面积8–900px半分辨率）当作人，质心连前帧最近点成2px线、每帧×0.9淡出，轨迹出现时画面压暗去饱和0.15→0.55s
  - 网格：内存中池化30帧片段960×540，阶段由GRID_STAGES定、点亮散序、末拍每十六分重切
  - 对位分屏：档案4:3中960px｜今日中960px，6px间距从中心长出
- **避坑**：
  - CC素材里藏水印与场记板：角落logo从中心放大到出画（1.5×内）、片头鸣谢卡、片尾音乐署名、首几镜上的标题字；选入点前查每源1秒contact sheet。
  - 源内藏切：移动延时含2–3帧跳切与甩镜，跨切帧混合会出鬼影；用scene>0.25扫描并把每个片段窗口限制在单一镜头内。
  - 混合过多正午云成灰糊：约40%快门（60帧取24）优于100%。
  - 灰世界平衡毁夜：钠灯被洗白，夜镜强度设0。
  - 轨迹需固定机位：漂移无人机会把每栋楼判为运动；中值背景只用于三脚架镜，移动航拍改用混合。

**适用场景**：城市影像 / 音乐蒙太奇 / 开场片头
