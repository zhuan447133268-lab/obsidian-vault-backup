# 50 · 笔式绘图仪 / Pen Plotter

> 分类：线稿图解
> 参考片：8848.86
> 原片一句话：深夜台灯下，一台笔式绘图仪用四支笔按真实高程画出珠穆朗玛峰，最后一笔写下它的高度。

## ⭐ 可直接复制的提示词

```text
用笔式绘图仪风格：台灯下，龙门绘图仪在奶油纸上一笔一笔画出地图与文字，抬笔走空、落笔留墨、在笔架换笔，摄影机和机器待在桌上；每个记号都是笔画，调子靠排线、粗细靠回描，没有填色渐变和字体排版。几支墨各司其职，强调色只留给发现且很晚才出现，笔杆带自己墨的颜色。30fps 不抽帧、笔缓入缓出、滑块不瞬移；段内真实速度、段间踩拍跳时而摄影机连续运动。镜头用笔尖微距、跳切俯视拉远、贴纸低角度、长焦跟笔、面板锁定、笔架插入、拉远到房间。机器声音就是节奏：步进啸叫随笔速变、刮擦滴答、抓手咔哒、拖链哗啦；一支笔一件乐器，结论前真静默、约 −16 LUFS。避免蓝图、屏幕空间生长图表、飞笔加速与编造数据。
```

## 配方拆解

- **本质**：桌上的一台笔式绘图仪一笔一笔地画出主体：真的笔、纸上的真墨、真实的机器运动。地图、图表和文字以龙门架放下的折线出现，笔在笔架上换笔、抬笔走空、落笔留墨；摄影机就待在桌上，和机器生活在一起。作图的顺序就是论证的顺序。
- **不是什么**：不是蓝图（没有蓝底白线与 CAD 装饰）、不是数据叙事（没有屏幕空间里补间生长的图表）、不是白板讲解或一笔画（没有手、没有马克笔；线是机械的，不是手势的）、不是工程简报板（纸正在被制作，而不是被展示）。
- **配色**：中性底：暖灯下的奶油纸（约 #F1ECDF）；房间沉入近黑，加一道冷色的反光灯（窗）。一种墨一个工作，最多三到四支：深色墨画边框与文字、地形或数据墨、浅色墨画调子与网格，再加一个强调色只留给「发现」（路径、答案、圈住结果的那圈）。强调色很晚才出现且有意为之，除排线外绝不铺满一个区域。笔杆带着自己墨的颜色，所以换笔一眼可读。示例：黑 #16161C、棕黑 #763C1A、灰 #686662（70%）、红 #CC221A。
- **材质渲染**：笔画就是数据：每一笔都是纸面毫米为单位的折线，按绘制顺序、带笔号标记；程序把列表变成机器时间——抬笔走空、落笔、上墨、抬笔、换笔；一个函数给出任意机器时刻笔的位置与落墨量。运动学：每段用梯形速度曲线，参考值：落笔约 60–125 mm/s、抬笔约 200–300 mm/s、加速度约 1000–2500 mm/s²、落抬约 0.07–0.1 s、换笔约 2–4 s（走到笔架、下降、松开、移一格、下降、抓握、抬起）。纸：整张纸的画布纹理（约 10 px/mm）加只在摄影机靠近处的局部高分辨率补丁（20–40 px/mm）；墨用正片叠底、圆头；落笔处有一个略湿的点；纸纹与少量纤维做凹凸贴图。时间倒退时从头重画、前进时增量绘制、笔下的那一笔只画一部分。墨：半透明、绝不纯黑；浅墨（灰）0.6–0.75 不透明度；描两遍的笔画更暗，和真纸上一样。机器：导轨、移动横梁、滑块、带抓手的 Z 轴笔夹、拖链、一排带帽笔位；金属粗糙度 0.15–0.35、哑光塑料、清漆笔杆按墨色配色；一盏灯投下的影子是外观的一部分。字：拉丁与数字用单线字体（每条子路径一笔）；中文用发丝级字重字体的轮廓，以比笔画更粗的笔画出，使它读起来像单线；展示标题用细排线填充的轮廓。屏幕空间只留给尾卡，其余都在纸上或房间里。后期（参考）：超采样、物理光圈景深、轻环境遮蔽、暖暗角、金属上少量辉光。
- **字体字幕**：数字与拉丁标签用单线无衬线（纸上 2.5–10 mm；主角数字 40–50 mm）；中文标签用发丝级 3–5 mm；图纸标题用排线衬线体。均为 OFL、只子集用到的字；字母烘焙进笔画数据，页面不加载字体。标签活在纸上：紧挨被命名的东西，一行一种语言（中文行、英文行，然后是数值），绝不在屏幕空间。粗细靠回描：标题与关键值用 0.2–0.3 mm 的偏移画两三遍。可读性：要读的东西在摄影机停住时须达 1080p 上 ≥30 px 字高；小图例文字可以保持读不清。可读文字停留 ≥ CJK 字数÷4.5＋其他字数÷15＋1.5 s，从其最后一笔写完起算。
- **运动质量**：30 fps，不抽帧；笔在每一次移动中缓入缓出；一个镜头内滑块绝不瞬移。跳切延时：一段之内笔以真实速度运动；段与段之间机器时间踩拍往前跳。跳变时摄影机持续移动，只有机器跳；作品越丰满，跳变间隔越密。线只在笔尖下出现；标签逐笔出现；没有任何淡入。绝不移动：被贴住的纸、笔架、房间。
- **镜头语法**：笔尖微距、纸纤维对焦：画的动作、精准——第一笔、最后一笔、数值被写下；跳切延时中俯视拉远：整体从笔画中浮现——地图被填满、图表建立、图案扩散；贴着纸的低角度：纸作为风景——起伏、深度、尺度揭示；长焦跟笔：行进、路径、顺序——路线、时间线、一步步的过程；锁定面板的 3/4 视角、轻微蠕动：阅读、判断——对比、结论、图例；切进笔架：主题或声音的变化——新图层、新数据系列、答案的颜色；从纸拉远到书桌与房间：语境、完成的作品——结尾、整份文件的揭示。别让滑块挡住要读的内容：从横梁不在的那一侧取景，或等笔离开。切在拍上或落笔瞬间；没有交叉淡化、没有翻页、没有屏幕空间标题。
- **声音配乐**：机器就是节奏：步进电机的啸叫音高随笔速变化、落笔时笔在纸上的刮擦、落笔的滴答、抬笔时的伺服嗡鸣、笔架处抓手的电磁咔哒、拖链的哗啦。一支笔一件乐器（值得保留的做法）：第一支墨用定音打击乐（马林巴），调子用弓击金属（颤音琴、弦乐），强调用钟与竖琴（钢片琴），文字笔用拨弦。跳变可以在拍上带一记柔和的木鱼。房间：电源嗡鸣、窗外的夜、几乎没有别的声音。结论前的静默：音乐退出，留下房间和画外的换笔声。混音：音乐在机器之下（机器才是主体）；参考约 −16 LUFS 母带前、真峰值 ≤ −3 dBFS、60 Hz 以下很少。
- **招牌技法**：
  - 等高线向外生长：从顶向下按最近邻顺序绘制地形层、每拍跳一次，形体从中心长大——适合城市的年轮、从源头扩散的热图、人口密度曲面
  - 纸站起来：低角度下把画好的线抬到它真实的值（高度、时间、数量）再落回纸面，墨仍留在纸上——适合降雨曲面图、声音频谱图、股价地貌
  - 排线当调子：浅色笔只在数值越过阈值（阴影、风险、损失）的地方排线，更深处用两个角度——适合洪水风险区、火灾失地、任何地形的背光面
  - 强调色的路径：长焦跟随一条线穿过安静的底图、每个停靠点留一个记号——适合迁徙路线、送货路线、河流走向
  - 放大的刻度：从图上一点引出到放大的坐标轴，让相差 0.1% 的值可分辨——适合常数的连续测量、一分钱内的三个报价、纪录时间
  - 换笔当标点：去笔架一趟（画内或画外）后，答案以新颜色到来——适合证据后的裁决、旧数字之后的更正、历史之后的今日数值
- **避坑**：
  - 笔飞着画：为赶片长加速绘图会读成动画→保持真实速度，在段落之间跳，整张纸可能需要一小时机器时间
  - 滑块挡住作品：它悬在正画的线上方→从开阔一侧取景、等它离开，或用另一个镜头展示结果
  - 横梁阴影：一盏灯把横梁投成一道硬杠→阅读用的镜头把灯放在摄影机这一侧的横梁前方
  - 细线在远景消失（mipmapping）→用更深的墨、关键线回描，远景只留形状、近景留给文字
  - 抬起的线在 3D 里变粗→抬起的笔画改用屏幕空间线宽；填充式字体画成轮廓像镂空模板→用单线字体或比笔还细的发丝字重

**适用场景**：地图与地形 / 测量与记录 / 生成式与数据绘图
