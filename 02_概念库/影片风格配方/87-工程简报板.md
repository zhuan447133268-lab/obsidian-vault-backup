# 87 · 工程简报板 / Engineering Briefing Board

> 分类：仪器实证
> 参考片：船说了算
> 原片一句话：一条河要架桥，四种桥型在一面简报墙上逐个受检，拍板的是桥下要过的船。

## ⭐ 可直接复制的提示词

```text
用【工程简报板】风格：画面是被拍摄的真实搪瓷白板墙，窗光斜落、留擦除残影，真实物体全分辨率剪报带窗光投影视差落下，标签磁铁钢尺印章钉其上，石墨/蓝/红三色笔自画测量线与结论；配色中性暖灰，石墨记名称规则、蓝记水与测量、红只标极少决断，全彩只属照片；单一字重马克笔体，字幕为底部中央磨砂亚克力条配蓝刻度、每语言一行；24fps逐帧、镜头重叠缓动、剪报落下弹跳、磁铁咔哒、墨按手速画出；运镜沿尺寸线滑行、沿投影线倾斜、阶梯对比、判定框停留2.5秒、结尾长拉远亮整墙；声音为房间底噪、毡尖吱响、磁铁咔哒与小合奏，人声冷静；避免叠化、文字缩放弹出、弹性缓动与照片风格混杂。
```

## 配方拆解

- **本质**：一面被拍摄的真实白板墙：窗光打在搪瓷面上、留着擦除后的残影，真实物体的剪报带着重量落上去，标签、磁铁、钢尺与印章钉在上面，三种颜色的记号笔画出各自固定的含义。镜头沿着线、投影线与指引线在事实之间游走，只有结尾才拉远亮出整面简报墙。
- **不是什么**：不是「白板讲解」（手在平面上画线条）——这里白板是被拍摄的实物、主体是剪报照片；也不是 PPT keynote：无标题栏、居中项目符号与翻页。
- **配色**：中性暖灰墙面与搪瓷为底；石墨=名称/规则/事实，蓝色=水与测量（尺寸、投影线、数字），红色=决断（每帧最多两三处、绝不落在红色物体上），灰色仅用于制图；全彩只属于剪报照片，道具保持中性，一枚红磁铁即一个判定。
- **材质渲染**：搪瓷为程序化材质，带擦拭残影、污渍、窗光衰减与滑动斜向反光、框影；剪报是全分辨率抠图（抠像模型或手绘多边形），离板几毫米、单一窗光投影视差，细结构（线缆/桅杆/栏杆）按实测重绘为单色干净线，绝不上采样（最大处≥1源像素/屏像素）；记号笔约90%平色、浅芯、圆头、绘制中湿尖反光，擦除留约7%残影；磁铁、钢尺、印刷卡、印章等道具近镜、托盘最靠镜头；视差按高度、180°快门亚帧模糊、轻颗粒，仅字幕在屏幕空间。
- **字体字幕**：单一字重马克笔字体（LXGW Marker Gothic，OFL 子集、改字重跑）覆盖全部文字，正文100–160板px、判定词230–400；印刷标签用粗无衬线、署名等宽；字幕为底部中央磨砂亚克力条配蓝色记号刻度，每语言一行、nowrap按1500px安全宽测、关键内容留在条上方（底部15%以上）；字幕≥max(1.8s,语音+0.6s)，板面文字自出现起停留 CJK÷4.5 + 其他÷15 + 1.5s，终墙可读字≥20px。
- **运动质量**：24fps逐帧、无阶梯；镜头为重叠缓动，速度∝u^a(1−u)^b（a,b≈1.5–4），叠加≤3px手持呼吸、只在撞击时抖；剪报从镜头侧降下、落定、弹跳、阴影收紧，磁铁咔哒吸附、标签摆动、移除的磁铁朝镜头弹出、被敲之物震动回弹；墨按手速画出、尺寸线以箭头轻点落定；运动处模糊、读字处清晰；每1–2拍有东西落下/画出/摆动，静默与判定保持才静止；禁叠化、文字缩放弹出、弹性UI缓动、文字自行淡入。
- **镜头语法**：沿标记线或尺寸线滑行（测距/路线/时间线）；沿投影线倾斜（平面→立面、整体→部分）；缓推+轻微荷兰角（逼近的问题）；后拉加侧移（陈述规则/论点转折）；甩线过冲再落定（超出预期/异常值）；沿指引线升起（从证据到结论）；阶梯式框取（每个新项带上一个结果，逐个对比）；判定框（整体+限值+结论，停留≥2.5s）；长拉远到整墙（总结/全局）。构图偏心、裁切、近景，首个强动作在0.5s内。
- **声音配乐**：房间空调底噪与窗外车流约低于人声20dB（可闻非嘶声，静默只留此）；foley：毡尖吱响按笔长变、笔尖轻点、磁铁咔哒（一排各不同音高）、吸盘啵、剪报落板、钢尺嗡鸣、橡皮擦、印章闷响；主体声以J-cut先入、静默后第一声是撞击或主体声；音乐为小节奏合奏（贝斯+轻鼓+木打击+低铜管判定音或槌），落点踩拍；人声冷静自信约高于音乐8–10dB，−14 LUFS。
- **招牌技法**：
  - 整墙揭示：先按海报设计墙面再让每个镜头都是它的裁切、留一区专供结尾，适合产品路线图/家庭预算
  - 骑尺寸线：把数量按同一比例画成真实长度、镜头骑着箭头走，适合四款车续航对比
  - 投影线：虚线把边缘从一视图带到另一视图共享比例，适合轨迹图配海拔剖面
  - 磁铁可数：单位随节奏咔哒吸附、被规则移除时弹开，适合投票席位
  - 印章判定：结论伴随闷响与震动落下，适合通过/未通过测试
  - 擦除成残影：被否方案擦掉但仍隐约可见，适合去年计划压在今年之下
- **避坑**：
  - 文字一闪而过读不完→把字放在镜头停留处、每个新项带上一个结果入画
  - 只有特写看不到整体与限值→细节→判定框→停留→判定→推进
  - 照片风格不统一→统一调色、单一光向、同一视角族
  - 细部被抠图丢失或阶梯→按干净背景抠键、在实测位置重绘线条；上采样照片特写发虚→全分辨率裁切、大源图、逐帧检查
  - 墙被看见太早耗尽结尾、或终墙稀疏→测量每帧可见比例、按海报定层级、留安静次级层不留空档

**适用场景**：工程方案 / 方案对比 / 简报汇报
