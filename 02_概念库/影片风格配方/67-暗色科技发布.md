# 67 · 暗色科技发布 / Dark Tech Keynote

> 分类：屏幕界面
> 参考片：思考的空间
> 原片一句话：虚构 app Tidy 的发布片：被埋掉的光标一键把几百个窗口归位。

## ⭐ 可直接复制的提示词

```text
用暗色科技发布风格：画面是近黑渐变舞台+发丝网格+柔光，主角是原创代码UI（圆角窗、通知卡、磁贴、光标），吸附网格落拍；光扫过只有被照像素点亮，巨大数字独占一屏且不加字幕。配色：冷中性微蓝不暖棕，一个饱和发光强调色只给产品主角与关键数字，问题红只在问题存在时。字体：Inter与等宽标签，字幕是底部居中深色胶囊toast带小圆点，画内打出的字只进.srt。运动：24fps逐帧、fast-out一次小过冲、生成动作0.2–0.3s、飞行沿曲线过冲、消失也被设计。镜头：锁定极特写、按小节对数拉远、穿冻结帧推入、一拍甩拉、UI展开/收起做转场。声音：马林巴/颤音琴/合成pad、失序声散开对产品同一声音家族、静默后第一声最重要。避免：玻璃渲染、录屏、扫描线、图表、淡入空帧。
```

## 配方拆解

- **本质**：一部软件发布片，界面本身就是主角：近黑渐变、发丝网格、柔光、一个品牌强调色，UI以吸附网格的精度运动。光负责揭示，一个巨大的数字，声音设计像像素一样有序。
- **不是什么**：不是玻璃产品渲染（无实物）、不是录屏（无真实OS或应用）、不是全息HUD（无扫描线）、不是图表片（一个数字，不是图表）。
- **配色**：只用冷中性阶梯：近黑舞台、三级抬升表面、三级灰文字（主/次/标签），中性微蓝绝不暖棕。一个强调色饱和发光、自带辉光，只留给产品是什么或做什么（主角元素、行动号召、确认、关键数字）；两个东西同时强调则一个是错的。问题色（通常红色给徽章与警告）只在问题存在时出现，转折后不再回来——问题色是噪音，强调色是产品。副色只作运动中的类别码（每类数据一条轨迹）、去饱和且不上静态UI。示例强调每片选一：青柠#B7F34A、电紫#8B7CFF、信号橙#FF7A1A。
- **材质渲染**：舞台：近黑底+上中径向提亮、一个个位数不透明度的偏位冷光大辉光、50–55%角暗；48px模块的发丝网格（白约3%、每第四条约6%）；无颗粒。UI套件全原创代码绘制：圆角窗（标题栏只有一个小字形与标题，绝不红黄绿按钮、菜单栏或Dock）、通知卡、文件图标配等宽文件名、程序化缩略图、列表行、标签、徽章、进度条、统一磁贴。表面：三级深色台面、1px边框（白约8%）、1px内顶高光、柔阴影。景深：2.5D镜头s=1/(1/zoom−z)，近镜卡片随放大虚化；旋转用条带渲染透视（rotY≤约24°）。光是揭示工具：只有被光扫过的像素点亮，未照处停在几个百分点。
- **字体字幕**：OFL字面：Inter（UI、字幕、标题；可变字重）、Inter Tight 600用于巨数（字距约−4.5%）、JetBrains Mono用于标签/文件名/状态（小caps标签宽字距）。标题每屏一行。巨数独占一屏且其上绝不加字幕——数字即信息。字幕是UI组件：底部居中的toast（深色半透明胶囊、1px亮边、柔阴影、Inter 500约40px、一个小的强调『正在说』圆点），以小上升+淡入约0.16s进入，复杂画面可提高不透明度；停≥max(1.8s,语音+0.6s)。画内光标打出的字是它自己的字幕：不烧录两遍（只进.srt）。字幕出现时抬升产品内容使toast不遮挡。
- **运动质量**：24fps逐帧、无跳帧、无沸腾：这是精度不是工艺。一切落在网格与拍上，运动提前一拍起、落在拍上；缓动是fast-out带一次小过冲（back，s≈1.3）并立即安定，无飘浮正弦漂移。生成动作短促且分型（掉落+弹、甩入、滑入、弹出；0.2–0.3s），一种元素型一种运动。张力可以是几px颤抖。飞行沿曲线路径且沿末切线过冲，同类元素同向弯折且绝不交叉。活元素可表演：挤压、拉伸、预备（≥8帧蓄力）、2帧接触、弹簧跟随；光标眨动是天然节拍器。消失也被设计（每拍收掉一部分、CRT关断压成一点），没有只是淡出的。舞台与网格绝不自行移动，只有镜头移动它们。
- **镜头语法**：锁定极特写对准微小UI元素：亲密、屏幕上某物活着——适合单一动作、念头成形、安静状态；连续拉远按小节在对数空间key：积累、从一个点长出尺度——适合负载扩散、网络生长、团队加入；穿冻结帧推入：时间停止、焦点收窄——适合决定、提交前一瞬、发现bug；一拍甩拉：因果同框——适合同步完成、部署落地；俯冲进小UI元素（对数缩放）+匹配剪辑：进入细节——适合重要计数器、日志行、设置；半秒插入镜从源扩张：过载、读不过来——适合通知风暴、报错、选择过载；近锁定帧中物体旋转、光扫过：展示、产品为主角——适合揭示、新版本、功能名；沿UI平面慢横移：眼睛读出秩序——适合时间线、流水线；网格俯视plan：系统视角、结构——适合架构、权限、工作流图；回到早前取景：押韵、什么变了——适合前后对比、闭环、回声。构图：大量留白、一个焦点、强调色在焦点；荷兰角与晃动只用于表现失序。转场=UI展开/收起：每次换镜都是界面元素展开入画或画面收进一个元素；无淡入、无空帧；拍上展开提前一帧起使拍帧已约80%打开。
- **声音配乐**：调打击与pad：马林巴、颤音琴（槌击或弓拉）、钢片琴、钢片琴、合成pad或drone、低正弦脉冲、沙锤、拨弦合成、毛毡钢琴；干净、干、极简。音乐作为可见过程：可选相位（两声部同型一漂移）、加性搭建（每小节一音）、减性过程（移除音符直到剩一个）、细分拍加速而非变速、所有落点归于一个和弦；画面事件可由共享音符表从配乐音符生成。两个声音族=故事：失序声散开（失谐几十音分、随机声像、每源不同音色），产品的声音是一个家族（毛毡哒、玻璃敲，同一模式居中），于是许多落点汇成一句同调闪光。拟音材料：光标哒、低键程键盘、通知玻璃、文件plop、窗口whoosh、glitch点缀、堆叠闷响、毛毡槌+正弦下坠用于按下、扫光辉光、数字颗粒、CRT关断。环境：安静房间、电脑风扇、可随压力增长的高频线圈啸叫；风扇与啸叫在人声带，台词结束前压低。静默是工具：画面暂停时各轨数字零、喘息时−60dB房间近静；静默后第一声最重要。J/L切让声穿过UI转场。混音：音乐在语音下闪避约8dB、拟音约4dB，−14 LUFS，无颗粒。人声自信克制、短陈述句。
- **招牌技法**：
  - 生成式堆积：按规则生成UI越来越快、数百项；你不是画混乱而是生成它——适合未读工单堆积、云成本爬升、依赖树爆炸
  - 吸附网格：一个动作承载整个承诺——一切在一拍内飞入网格，网格此前不可见——适合CMS发布到全渠道、排程填满一周、审计转绿
  - 活元素：光标或产品最小的活体元素是主角也是品牌标记——适合日益野心勃勃的搜索框、不肯完成的进度环、状态点
  - 冻结：一切半空停住、声音掉到数字零，只有屏幕能这样停时间——适合抓到安全入侵、失败部署、发送前一秒
  - 光揭示：柔带扫过只有被照像素点亮（柔前沿、闪光≤20%、≤约1.3s免得留黑）——适合重新设计、新定价页、API控制台
  - 数字从字形噪音中锁定：数字乱序、每十六分锁一位带小弹——适合延迟降低、用户数、价格
- **避坑**：
  - 半透明画布做条带透视会露竖缝（重叠切片alpha叠加）→先投影不透明表面再在屏幕空间打光。
  - 硬白闪光像贴纸反光→柔前沿、闪光≤20%。
  - 吸附到最近槽像闪烁而非归位→分型落点、曲线路径、拖尾。
  - 元素太少让网格留洞像出错→按规则生成再裁或补到每组恰好的槽数。
  - 平涂色块当关闭像占位符→把真实表面压扁。

**适用场景**：产品发布 / SaaS / 主题演讲
