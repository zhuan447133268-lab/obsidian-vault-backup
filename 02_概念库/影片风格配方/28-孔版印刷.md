# 28 · 孔版印刷 / Risograph Print

> 分类：印刷版画
> 参考片：周日骑行
> 原片一句话：周日早晨骑车穿过城市：面包店、公园、河边，每到一处加一版油墨，最后三版套印。

## ⭐ 可直接复制的提示词

```text
用【孔版印刷】风格：画面上像逐格孔版印出，2–3 种半透明专色套印在暖米白纸上，网点 6–8px、油墨有针孔走纸条纹；配色小调色板、平涂无描边、每处最多两版且最多一版淡调，满套印留最关键一刻，纸白也是颜色；字体是被印上去的，标题重 grotesque、字幕几何无衬线约 40–46px 在纸白镂空条上；运动为人物 12fps、镜头 24fps，每镜固定套准偏移、重音 kick；镜头宽幅横移、静态宽幅、锁定构图、推入半调直到点成形、拉回露出纸，转场用套印生长与滚筒扫掠；声音温暖干爽 lo-fi，每多一版多一件乐器，机器走纸拟音；避免矢量加噪、CMYK 四色与 RISO 品牌。
```

## 配方拆解

- **本质**：看起来像逐格用孔版印刷机印出来的动画：两三种半透明专色套印在暖纸上、加网线、油墨颗粒，且各版永远对不齐。孔版一次只印一色这一事实造就整体外观：小调色板、套印混色、错位、网点、不完美油墨、平涂无描边。
- **不是什么**：不是叠了噪点的扁平矢量图（每色都来自印版），不是 CMYK 波普网点（无 process 四色、无 keyline），不是丝网海报（riso 油墨半透明且带颗粒、非不透明）。绝不出现 RISO 品牌、标志或机器外观，油墨名只作色彩参考。
- **配色**：2–3 种专色加纸，绝不多；其余颜色都是套印或淡调，无渐变除阶梯网点。纸为暖米白约 #F4EEE2、绝不纯白；纸白也是一种颜色（镂空、高光、字幕）。浅中性表面（皮肤）用最浅油墨的淡调，饱和油墨点在皮肤上像皮疹。挑选两两能混出有用颜色的油墨，至少一种能单独承载剪影。满套印（各版最密混色）留给最值得的一刻。示例油墨组：蓝 #0078BF+黄 #FFE800+荧光粉 #FF48B0；青 #00838A+荧光橙 #FF7477；联邦蓝 #3D5588+红 #FF665E+向日葵黄 #FFB511。
- **材质渲染**：管线：每帧画进一张 RGB 画布，每通道是一种版的密度（R=墨1、G=墨2、B=墨3；0 无、1 实），source-over 得真正镂空，globalCompositeOperation='lighter' 只给设定通道加墨=真正套印；WebGL2 着色器印刷：每版按 px 偏移+微旋转制造错位；半调为旋转网格上的余弦点函数、1080p 周期约 6–8px、抗锯齿阈值、密度≥约0.9 印实、网角相隔≥15°；点阈值加颗粒、实地里针孔、密度随走纸方向条纹与缓慢斑驳噪声；合成 paper×Π mix(1, ink_i, coverage_i) 加淡纸纤维；网点锚定在纸（屏幕）而非物体，横移时图像在固定网下滑动像每帧重印；每版有闸门与滚筒扫掠（移动边、略重墨带）可让某版在镜头中途到达。构图：每处最多两版、最多一版作淡调；大平形、大量实纸与实墨，半调只用于少数阶梯带（20/40/60/100%）做天空阴影距离；人物有 4–5px 纸白镂空白晕：先把其层盖成 ring filter:brightness(0)（零墨=纸）再画人物，版在其周围错位形成真套准色边；一条地平线、一个大平场或圆盘、一个小人；为单版版本设计（每主色含第一版成分），刻意例外留白直到其版到达（揭示）。
- **字体字幕**：字是被印上去的：标题与字幕活在同一版上，随版错位与颗粒；标题可印在两版上形成可见偏移（riso 双击）。字体（OFL）：标题重 grotesque（Bricolage Grotesque 800）、说明几何无衬线（Jost 500–700），READY 前预载所有字重。字幕为纸白镂空条（零墨、小圆角）配单版文字约 40–46px，边缘带错位色边；停留≥max(1.8s,语音+0.6s)。印刷品不淡出：标题随滚筒擦入或落拍、切点离开。
- **运动质量**：人物逐格 12fps，镜头逐帧 24fps（阶梯镜头=卡顿）。套准不是每帧抖：每镜一组固定偏移（±1–3px）；重音处一次 kick（约 8–14px、约 0.25s 衰减带轻振铃），保持时刻 drift 至多约 25px 并在强拍弹回。颗粒部分沸腾（每次印约 1/3 重掷）；走纸条纹与斑块只在剪辑时变。简单循环少张数；次要运动（围巾、旗、尾）用行进正弦波。
- **镜头语法**：词汇表非路线。典型运镜：宽幅横移、小人空天（旅行、日常、余地）；静态宽幅主体穿画（尺度喜剧）；锁定构图地平线+圆盘+人（静、敬畏、全片一次停顿）；贴地低角大前景形（能量、丰盛）；双人中景保持对视（反应）；正俯拍长影（图案、地图）；推入半调场直到点成形（进入印品）；拉回露出纸（原来是一张）；平形匹配剪辑（形式连贯）。构图：大量纸与实墨，文字在空天或镂空条；转场：套印生长、滚筒扫掠、形匹配、拍上硬切；绝不叠化与柔性数字擦除。
- **声音配乐**：乐器选项：温暖、干、手工、略 lo-fi：低音提琴或电贝斯、颤音琴或马林巴、尼龙吉他、口哨或哼唱旋律、Rhodes、玩具钢琴、刷鼓、沙锤与边击、小鼓机过磁带饱和。像印版一样分层（选项）：每多一版带来一件乐器，也可逐一离开。机器即标志拟音：走纸 shhk、印版到达时鼓 ka-chunk、电机嗡、纸张落堆、裁切刀。其余拟音干、近、纸感，随故事材料。静默：保持一小节、切掉混响尾、至多环境或一个远声；与套准漂移配对，弹回时一切恢复。混音：干而近，人声下音乐闪避约 8dB，−14 LUFS；旁白放松会话式短句、whisper 验证；总线不加颗粒（颗粒在印品里）。
- **招牌技法**：
  - 印版即叙事：每个转折点世界多一版——适合产品作为一种新墨到来、城市史每个时代一色、康复中颜色回归
  - 两色交汇生第三色——适合合并、二重唱、两组数据的交集即发现
  - 套印转场：一色形状长满画面把下面变成混色，再缩成下一场关键形——适合药片溶解、聚光变月亮、印章变地图钉
  - 套准即节奏与情绪：重音 kick、保持时 drift、强拍弹回——适合演讲前紧张、眩晕、记忆逐渐清晰
  - 倒影作分版：每版按各自相位晃动——适合橱窗、路面热气、咖啡表面
  - 镂空揭示：一个只由缺墨构成的形状，其版稍后才到——适合缺失的一块、秘密、藏在眼皮下的标志
- **避坑**：
  - 三张半调叠一处=糊：两版一淡调
  - fract(p*vec2(233.34,851.73)) 在 1080p 实地上画竖条：改用混合良好的 hash（fract(vec3(p.xyx)*.1031) 族）
  - 逐帧套准抖与走纸条纹闪烁且撑大文件：每镜固定偏移、重音 kick、剪辑处纸噪声、部分沸腾
  - JPEG 截图(4:2:0)抹糊饱和点：PNG 帧进无损 yuv444 中间体、-tune grain 编一次、100% 与 50% 查摩尔纹
  - 光晕层未复制画布变换致缩放镜头比例错；透明层内加法 over() 失去意义要在版画布上套印；无第一版成分的主色在单墨帧漂离须从单墨剪影反推配色；拱形 evenodd 填实要反向描内边

**适用场景**：独立品牌 / 同人志与小杂志 / 生活方式
