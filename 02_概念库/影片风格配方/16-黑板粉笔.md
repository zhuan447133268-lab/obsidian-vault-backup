# 16 · 黑板粉笔 / Chalkboard

> 分类：速写板书
> 参考片：汉字的故事
> 原片一句话：粉笔写下网上的说法，再一擦，把「射」写回三千年前。

## ⭐ 可直接复制的提示词

```text
用黑板粉笔风格：真教室深墨绿石板上粉笔自己按真笔顺写出、不见手粉笔板擦，一板一问——写出人们以为的、一擦、原处写出真实的；画面干净无旧痕浮尘、相机始终正对板；笔画按弧长揭示、板齿决定吃粉；最多三支粉笔（白结构、橙只追踪一个部件、浅粉标他人），画的格暗细、无渐变辉光；中文是手写笔画数据非字体、字幕是底部素楷体软暗板随语音来去；30fps、大字每笔约0.1s、相机三次缓入缓出、物只靠写擦滑panel变干出现绝不淡入；运镜为近写、沿行慢横摇、拉回中景、锁定框滑panel、整墙广；声音为语音最响＋粉笔颗粒拟音＋毡擦＋稀疏拨弦，读问判定时静；避免亮白板彩笔、悬浮磁铁、旧课残影与幻灯片淡入。
```

## 配方拆解

- **本质**：真教室黑板上粉笔自己一笔一画按真笔顺写出，不见手、不见粉笔、不见板擦。一个概念像老师那样教：写出人们以为的、一擦、在原处写出真实的。
- **不是什么**：不是白板讲解（那是亮光板、彩笔、悬浮笔道具与磁铁、旧课残影、相机穿知识地图多区解释原理）；黑板是暗哑石板、前面无悬浮物、保持干净、一板一问、相机正对；靠写主张→擦→原地重写推进，且活在教室（板可滑、格是画的、粉笔槽、墙）。也不是幻灯片：无排版、无淡入。
- **配色**：底＝深墨绿石板、木框、暖白墙、若见房间加彩色墙裙。白粉笔扛全部结构：字、线、标签、箭头。强调粉笔（如橙）只给课程追踪的那一个部件，绝不装饰、绝不画非该部件的箭头下划线。第二支浅粉（如黄）标另一个人的字。无彩虹、粉笔无渐变无辉光；画的格暗而细让粉笔永远赢。
- **材质渲染**：Canvas 2D画一切可见；WebGL2只做post（相机运动模糊、轻暗角、调色、抖动）。每笔一次烘成板空间coverage sprite（coverage、弧长、横向位置）；部分笔画按当前弧长揭示像素、圆形前缘、板齿决定哪些颗粒吃粉（2×超采样沉积＋淡粉晕）。粉笔边扎实、松粉只在收笔处（2–5粒）；绝不撒糖。写字笔画按笔型带宽度profile（起顿、转角顿、撇提收尖、捺脚、钩快挑）与压力profile（两端重中轻）；直笔略弓、横右仰2–3°、横竖折从左上短顿入。板、滑panel、框、槽、钟、墙按世界单位烘一次、石板齿是周期tile在世界空间画（柔光）仅相机近时。擦＝沿一条光滑path的模糊destination-out带、只在承擦笔画的层、留极薄均匀雾；每片一次擦足够。湿痕（刚用湿布擦过的板）＝软mask、干燥缘宽blur、上下淡、略压暗石板；绝不硬边。光＝离窗渐暗的柔乘、至多一淡暖窗斑；近镜光绝不跨字画形。
- **字体字幕**：中文是手写笔画数据（中心线＋每笔笔型）由粉笔引擎画，绝非字体轮廓；主题需要的每个字加入数据并在拍摄前对照OFL楷体检查。板上英文＝单行OFL手写体（EMS族）同引擎画；字体缺的符号（箭头、加号）画成笔画。板上：只关键词、一行中文、下一行英文略小。1080p尺寸：大字300–450px、标签≥55px中文与≥30px拉丁cap高、小字加重粉笔使无笔细于3px。阅读：每块完整在画≥CJK÷4.5＋其他÷15＋1.5s、从完全可见那帧算；一块先写完才读。旁白片：一位冷静老师短句、粉笔出现时说、语音名的正被写或示；字幕板在底部安全区上方、中文句＋自由英译各一行、素楷体于软暗板、随语音来去、长句在句末切多cue；板上须读之物不在板后；语音间停0.25–0.4s、判定留约1.5s长停；板动作（滑panel、擦）在语音下进行不等它。
- **运动质量**：30fps连续。粉笔速度：大字每笔约0.1s含笔间空中（十笔字约1s）、标签每笔约0.04s；写快于等语音但大字快过约0.07s/笔就不像手。短片里阅读与粉笔速度冲突时改词不改手（少而短块、只追踪物用大字其余标签尺寸、语音未完就起写使其被点时已完成、上一块还在读同帧写下块、停帧不前进、加长片）。相机三次缓入缓出、除甩落不弹；物只靠写、擦、滑panel揭示、变干出现；绝不淡入。
- **镜头语法**：相机始终正对板（无透视倾斜）。近写＝注意字或线如何构；沿一行慢横摇＝时间顺序；拉回固定中景＝全问同时；同框稍后＝判断；锁定框而panel滑＝房间自己的翻页；带运动模糊甩（≤0.5s）＝跳到墙另一处；线穿缝切＝连接；整墙广＝所学地图。房间是风格一部分：至少一次广到读成教室（板、框、槽、墙）。构图：近景主体不小于画1/3、读时文字块不被框切、空板不超半秒；转场＝硬切、滑panel、线穿缝；无溶解翻页。
- **声音配乐**：语音第一最响；音乐低于15–18dB只在停时上来。拟音：真粉笔录音切成颗粒、每笔一颗粒链、电平随笔长；落笔轻叩；强调粉略软闷；擦＝毡pass、滑panel低滚止于停、极低房间声、学校声（远钟）仅标点。音乐：稀疏拨弦（古琴模型或尼龙吉他）＋马林巴＋拨贝斯；拨音可从所画之物「生出」；读问或判定时静。混音：总约−16LUFS母带前、真峰≤−1.5dBFS。
- **招牌技法**：
  - 写擦原地重写：错读写在物下、一擦、正解同处同机位写——适合常见物理谬误、记错日期、人人算错的题
  - 强调粉追踪部件：一部件跨数字保持色与高度——适合词族中的词根、方程变形中的变量、世代中的基因
  - 滑panel揭示：前板滑开露干净背板、可滑回关闭课程——适合「但在此之前」、藏起的证明、留后的答案
  - 一线缝两板：一强调线跨缝连两地——适合两公式中同一常数、引文与出处、因果
  - 湿痕干：刚擦板干回露出未擦之物——适合昨天的问题、学生留的条、角落提醒
  - 第二只手：另一儿童色与手同板——适合学生提问、访客评语、错误尝试
- **避坑**：
  - 脏板（旧旋、残影、浮尘）读成乱非真→保净让颗粒扛真实；等宽折线像绘图仪且字误读→用笔型宽度与压力profile
  - 结构错字被母语者一眼看穿→拍前逐字对reference；1080p小字同宽消失→小字加厚粉笔
  - 相机移开时写字失阅读时间→停帧或保块在画；强调色蔓延到箭头装饰失去意义
  - 笔前软晕像辉光→去径向渐变只留颗粒；湿痕硬边像贴纸；旁白板话部件首次出现连意义一起说

**适用场景**：字词来源 / 破除谬误 / 课程
