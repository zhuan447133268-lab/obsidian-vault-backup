# 60 · 微游戏快闪 / Microgame Frenzy

> 分类：电子游戏
> 参考片：五秒宇航员
> 原片一句话：见习宇航员闯五秒训练营，越来越快，Boss 关亲手降落回地球。

## ⭐ 可直接复制的提示词

```text
用微游戏快闪风格：一个口令词＋2.5–4秒＋一个动作＋一个结果，每个微游戏用完全不同的媒介画（蜡笔、水墨、终端、riso、像素、蓝图、瑞士字体、黏土、剪纸、木刻），切换的跳变既是笑点也是节拍；固定主场（画中画屏＋生命板＋关卡徽＋触发道具）串起全片，每几局速度时长停留帧率一起升级；主场饱和派对色粗描平涂一道硬影，各媒介用自己配色、一记强调色跨媒介跟随主角；口令词粗展示体砸入后缩成角签、游戏内字用该媒介字体；角色帧率成阶梯而相机转场计时逐帧、推入屏开场缩回屏回场带印章、失败即时回放；声音为恒定groove＋每媒介一音色＋拟音＋真静默；避免单一画风节奏秀、无输赢样片与白闪空帧。
```

## 配方拆解

- **本质**：快节奏派对游戏片：一个口令词、几秒、一个动作。每个微游戏用完全不同的美术风格画成，片子越来越快。
- **不是什么**：不是节奏游戏秀（单一画风、一轮轮小节、呼应式），不是风格样片集（每个游戏都有输赢、生命值把它们串起来），不是蒙太奇（每游戏规则一秒内可懂）。
- **配色**：主场拥有饱和派对色：深底上旋转日芒、两三响亮强调色，加固定的成功色与失败色（只给印章与生命板）。每种媒介自带传统配色（蜡笔色、一墨＋朱、琥珀荧光、三块riso、有限像素色、蓝底白字、黑白红）；绝不用主场色染媒介。一个强调色跨媒介跟随主角（水墨里一点朱、终端里反显字形、瑞士字体里信号红圈）：切换后眼睛据此找到主角。示例主场：紫#2a0f5c配洋红#ff2e88、金#ffc928、青#1fd1d1；或青绿底配珊瑚与柠檬；或黑台配热橙与电蓝。
- **材质渲染**：主场＝扁平卡通、近黑粗描≈7px、平涂、一道硬影（填影色、裁到形、左上偏移重填）；固定家具＝画中画屏（电视、街机柜、手机、窗）、生命板、关卡徽、触发道具（按钮、杆、铃）。每种媒介＝简化重画、100–200行代码，围绕一个一眼可读的通道技巧：绘画媒介把压力或湿度存在通道（蜡笔alpha＝压对纸齿、墨＝湿干两通道）；印刷媒介存版密度（riso每版一通道、加色叠印、网点、错位）；屏幕媒介是低分辨率缓冲放大（像素＝索引缓冲＋自动描边＋抖动、终端＝手写字形＋荧光shader）；技术媒介是线系统（蓝图＝线宽与标注、瑞士＝严网格一sans一信号色）。主角转译：每媒介从头重画但保留两三剪影标记（帽形、一色点、胸号）；动画前先做各媒介主角模型表。混合媒介帧：alpha覆盖媒介压底、纸媒介正片叠底、屏幕媒介平涂裁入面板；WebGL2材质shader把通道缓冲变成各观感。媒介举例：蜡笔、水墨、终端、riso、像素、蓝图、瑞士字体、黏土、剪纸、木刻。
- **字体字幕**：口令词即字幕：重展示体（如Titan One）白字粗墨描＋彩色投影＋背后放射、斜几度，约3帧砸入（过冲→落定）、停住，在首个动作前缩成角签（绝不遮结果）；一次性横幅飞出而非留签，故签不堆积。其他行＝主场色圆角卡配主场描边与硬影、友好圆体（Lilita One约50px）、小喇叭图标、置于游戏计时器上方；停留≥max(1.8s,语音+0.6s)，绝不压大横幅。游戏内任何字用该媒介自身字体。口令词只进.srt、绝不烧两遍。
- **运动质量**：帧率即阶梯：角色早期隔帧或8fps、后期更快、高潮逐帧；相机、转场、计时火花始终逐帧。加速时五件事一起升级：速度、游戏时长、停留、口令保持、角色帧率。计时器可见且踩拍（如保险丝每拍一结、火花正拍过结），回放时冻结。统一转场经画中画：推入屏开场约0.25s、游戏缩回屏约0.33s回场带✓或✗印章；无淡入无空帧。失败被表演：动作过冲、拍扁、撞头、滚走，由媒介自身物理造成笑点。需看懂的失败即时回放：冻结、半速、推入、宽银幕、媒介字体字幕。主场主持每拍一tick、骤停是最强情绪工具。
- **镜头语法**：开场就在游戏中口令正砸＝规则自解释；从游戏屏拉出＝尺度（这只是节目里一屏）；锁定正面主场框＝恒定物只记分板变；老虎机卷轴（场分裂成旧帧条每拍停一条）＝加速、总结；触发道具极特写＝开场重拍；灯光切到一顶光而框不变＝赌注、最后机会；瓷砖翻（过去游戏末帧翻成新帧块）＝Boss或终局、回顾；推入细节停住＝观众先于主角发现；一拍急回宽＝释放；分屏两媒介并列＝比较、对手。构图：游戏屏固定占画幅约40%宽；混合媒介帧保持一条焦点链（A引B引C）、信息板推角。
- **声音配乐**：音乐优先：先定速度网格与cue表再动画，每个画面击中落表上某cue。恒定groove＋每媒介一音色：groove（带ghost note鼓、slap或合成贝斯、铜管刺、键）贯穿；各媒介加音色（蜡笔玩具钢琴、水墨尺八或古琴、终端方波哔、印刷vibes、像素脉冲琶音、制图打字机、瑞士响木、黏土卡林巴、木刻古筝）。拟音随媒介：蜡吱、湿拍、电传继电器、纸脆、bit-crushed噪、棘轮印章、空哐。主场：弹簧触发咔、失命玻璃裂、翻牌、卷轴嗡、稀疏掌声。加速选项：每次加速上行铜管run、每轮调升一级、音符时值减半而非变速、最后一条命groove降成心跳。真静默：最大一击前至少一次（可留心跳或一音）；最响在最长静默之后。人声：主持每句口令在铜管刺后一发丝喊出以免被掩；主角极少词（反应最好）；音乐低于人声约11dB、拟音低约6dB；−14LUFS。
- **招牌技法**：
  - 每游戏换画风：每个任务用最适合的媒介画——适合烤面包步骤（面粉蜡笔、烤箱旋钮蓝图、脆皮木刻）、护士的一天、劫案角色
  - 口令词：一个动词即剧本字幕与重拍——适合结账SCAN、瑜伽BREATHE、签约SIGN
  - 生命当UI：计数带情绪无需旁白，3→2→1闪——适合手机电量、路考重试、答题机会
  - SPEED UP：一切同时升级——适合高峰、截止前一周、晚餐厨房
  - 失败成为解法：早先失败的材料在最终游戏成为答案——适合洒的咖啡后来染出获胜地图、bug成feature、错过的车带到正确会议
  - Boss混规则：终局由早先媒介碎片搭成——适合期末考、发布日、节庆闭幕夜
- **避坑**：
  - 亮度阶ASCII人像＝糊→手写结构字形、强调用反显字形；墨形若无设计剪影像烟→短圆墨块阶段后清晰带缝与亮边结构
  - 高速度下失败读不出→让动作过冲撞物或即时回放；alpha覆盖媒介缝隙透底→需实处铺满压力底
  - 全局context绘图助手在离屏缓冲画错画布→设并还原context；口令签堆积→次要的飞出
  - 100%白闪读成空帧→限约60%；TTS单词口令拖尾元音→生成两词短语按ASR时间戳在第一词后切、逐条验证

**适用场景**：游戏预告 / 新手引导 / 社媒短视频
