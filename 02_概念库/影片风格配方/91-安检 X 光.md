# 91 · 安检 X 光 / Security X-ray

> 分类：仪器实证
> 参考片：安检口的夜班
> 原片一句话：机场安检机屏幕上的一个夜班：一个充电宝、一瓶水，还有在 CT 里动了一下腿的六只活蟹。

## ⭐ 可直接复制的提示词

```text
用【安检 X 光】风格：画面上物体从不以实物出现，只有双能 X 光透视影像，按材料着色——有机橙、混合绿、金属蓝、不可穿透黑，轮廓来自厚度，操作者以拖框、放大、测量、过滤、盖章判定存在；配色近黑海军蓝底，材料色专用，琥珀=复核、红=拒绝、绿=放行、淡蓝=机器状态且每屏一色；字体为机器界面纯英文等宽大写，操作员标签中文黑体 34–44px 加粗配英文行；运动为传送带匀速带惯性停顿、CT 缓慢环绕，30fps；镜头隔间机位与屏内放大/CT 环绕，判定帧锁定、转场走扫描线；声音为朴素控制台音色、机器拟音与拨弦短弓弦配乐，判定时留嗡鸣；避免全息发光、爆炸拆解、文字压物体与编造品牌。
```

## 配方拆解

- **本质**：影片完全通过安检机的双能 X 光成像呈现：物体从不以实物出现，只有按材料着色的透视影像（有机物橙、混合绿、金属蓝、不可穿透黑），轮廓来自厚度而非描线。观众只看到屏幕上的操作动作——拖框、放大、测量、材料过滤、盖章判定；物体靠内部结构（吹风机线圈、吉他弦、书中脊）被理解。本质是「机器屏幕上的实证判读」，屏上引用的规则是真实有来源的规定。
- **不是什么**：不是科幻全息 HUD（界面朴素、功能化、暗色，不凭空发光），不是爆炸拆解图（物体永不被拆开或当作实体打光），也不是显微镜片、医学扫描片或主题演讲幻灯片（无幻灯片、无居中标题页）。
- **配色**：四种材料色为 X 光专用：有机橙、混合绿、金属蓝、不可穿透黑；UI 与标注不得用纯有机橙或金属蓝做装饰。中性底为近黑海军蓝（机身）与略浅海军蓝（空传送带）。操作员色各司其职：琥珀=标记/复核、红=拒绝、绿=放行、淡蓝=机器状态，每屏只出现一种判定色。文字近白配暗底板、次要机器字暗蓝灰；时段信息留在屏幕外（夜海军蓝→黎明琥珀），屏幕整夜保持原色。示例：传送带 #080F1A，有机 rgb(255,133,26)，混合 rgb(115,235,51)，金属 rgb(46,122,255)，琥珀 rgb(255,178,58)，拒绝 rgb(255,74,64)，放行 rgb(96,232,140)。
- **材质渲染**：核心是「透射而非渲染」：每个像素是 X 射线穿过物质的路径长度按材料分类的结果，重叠变色（线缆压在衣物上变绿）、壁的边缘发亮、实心金属发暗。three.js 实现：每个网格双面、关深度测试、加法混合到浮点目标；片元写 ±距离×密度×材料类（正面负、背面正），使每像素保存有机(R)/无机(G)/金属(B)三类路径长度；空心物体用外实体加同形缩小负密度得到真实壁厚。固体必须闭合（管端封口、法线朝外、不用负缩放镜像，否则出斑点与负厚度）。双能着色器由高低能衰减之比决定色相（橙→绿→蓝）、总量决定亮度，亮度随厚度上升到峰值后向黑回落（厚钢暗蓝、实心块黑）。两种显示：筛视图不透明压在海军蓝传送带背景上（黑才能读作黑），CT 体在暗重建场上加法发光。扫描为固定帘线，已过列着色、未过列淡灰预览；材料过滤与重扫为同式擦除 wipe。纹理锚定在物体空间（织物经纬、食物块状、纸与泡沫），以毫米计保证放大不滑动。屏幕外一切（暗隔间、玻璃外夜间停机坪散景、机器隧道口与滚轮）为 2D、带视差且失焦。后期仅屏幕图像泛光、暗角、总线轻颗粒。30fps。
- **字体字幕**：两种字体声音绝不混用。机器声：等宽（如 IBM Plex Mono，OFL），界面 15–22px、时钟与计数器 56–64px、状态词约 32px；仅英文，状态与按键大写（ORGANIC/MIXED/METAL/OPAQUE，SCANNING/REVIEW/CLEAR 等），像真实控制台打印。操作员声（标签、规则、判定）：中文黑体（如 Noto Sans SC，OFL、子集化）34–44px 加粗，下配英文等宽 17–22px，每语言一行；放不下 34px 中文的标签改用机器声（纯英文）。标签用引线连到物体或置于旁侧面板；判定为落下的印章（勾/叉+词+英文行）。每张图带自己的印章（包号、时间）以在特写中保留时钟。1080p 下必读文字≥18px、图例与界面可到 15px；尺寸按屏幕计，外机位拉远时必读内容等推近再读或放大。有旁白时字幕为操作员日志：暗板固定在画面左下（不随机位移动）、左缘细白条、中文 36px 压英文 24px 等宽各一行；面板、判定章、被判物体避开该角（面板右上、CT 判定右下）；间隔小于约 0.6s 的提示共用同一底板避免闪烁。停留：判定帧展示物体+规则+数字后留 2.5s 再盖章，判定≥1.5s，标签≥字数÷4.5+1.5s。
- **运动质量**：传送带匀速运行并带短暂减速停机与轻微回弹（真实皮带惯性）。操作动作快而精准：拖框 0.25–0.3s 自一角拉开、缩放缓入缓出、测量线生长并跳动。计数器与时钟在剪辑点跳变以压缩小时，镜头内实时运行。材料过滤与重扫为擦除，CT 经短数字撕裂出现。CT 环绕缓慢连续、缓入缓出，在细节处推近并近乎停顿。永不移动：控制台界面、图例、取景框；判定帧锁定。30fps。
- **镜头语法**：两台机位：屏幕外（2D，隔间与显示器）与 X 光内部（图像缩放或 CT 环绕）。典型运镜短句：隔间全景配背后窗外（地点与时段，开场/时段变化/结尾）；从隔间推入屏幕（注意力收窄，下一件行李/接班）；控制台局部硬裁切（单物体单次读数，蒙太奇/计数器/时钟）；操作者在图像内放大（怀疑，被标记物）；带面板的锁定帧（判读：规则/测量/判定）；CT 环绕加推近（看见平面图像藏不住的三维，揭示隐藏机构或活物）；拉回窗外（后果、时间流逝、黎明/下班）。被判物体至少占画面三分之一，面板放在远离物体一侧，绝不用文字盖住物体。转场来自机器而非亮度硬跳：行李之间用扫描线沿传送带方向右到左扫掠（约 0.2s 卡点或 0.3–0.6s 新判定/时间跳跃），无叠化无白闪；进出 CT 用调暗的数字撕裂；隔间远近推拉为机位运动非剪辑。
- **声音配乐**：一类控制台音色（带少量二次谐波的正弦、柔和边缘）贯穿全片：扫描啁啾、双音报警、单音放行、低嗡拒绝、清单行上升提示音。机器拟音：皮带电机与滚轮、行李通过时的隧道嗡鸣（120Hz+滤波噪声）、缩放伺服啸叫、按键继电器咔哒、CT 机架呼呼、皮带停止闷响、掉电降调。配乐：拨弦与短弓弦（pizzicato、spiccato）推流动，悬置判定用颤弓弦与定音鼓，释放用竖琴与持续弦，小型喜剧或温情用定音打击（颤音琴、马林巴、钟琴、木琴）；用细分节拍推动而非改速度。判定时撤掉律动只留嗡鸣。混音：音调与拟音在音乐之上，报警/判定/清单提示音下音乐压 4–5dB，50Hz 以下少能量，−14 LUFS、真峰值≤−1dBTP。可选旁白为操作者近距干声、压缩，RMS 高于音乐约 10dB、高于音乐加机器床约 7dB，300Hz–4kHz 挖空音乐，避开报警与判定音；隐藏物揭示时留白不说话。
- **招牌技法**：
  - 扫描帘幕：行李越线，灰色预览逐列变彩——适合揭示任何密封物内部、产品发布时露出内构、分拣中心包裹
  - 拖框-放大-读数：拖框、图像放大、读数面板滑入、判定盖章——适合合规规则、产线缺陷发现、防伪查验
  - 对照规则测量：图上标尺给出尺寸，旁置同尺度限值轮廓——适合登机箱尺寸、零件公差、剂量或容量
  - 材料过滤：有机/金属过滤擦除一类只留其余——适合找玩具里的电池、墙内布线、鞋的金属骨架
  - 进入 CT：平面图像说不清，撕开看旋转三维甚至有东西在动——适合箱内活物、手表机构、手机元件堆叠
  - 一班岗：时钟、计数器与窗外天空在数秒内走过数小时，汇总表收尾——适合分拣中心一夜、全年货运、发射日
- **避坑**：
  - 材料配色错误：铝是绿蓝、钢是蓝、锂电是蓝绿、玻璃与骨是绿、水与食物是橙；每件道具核对类别，黑色区域必须是真正厚而致密之物
  - 画面杂乱：每件行李保持 4–8 个可辨物体，用图标化形状（键盘格、螺旋弹簧、J 形钩）并搭配不同类别
  - 细物消失（平看的带子、1mm 薄板）：提高密度或厚度直到在该镜头尺度可读；开放与镜像网格出斑点：管端封口、法线朝外、禁负缩放
  - 文字压图：面板放物体旁，把操作框外图像压暗而非盖住；低矮物侧视成一条，宜用于高或分层物
  - 规则与品牌：国内国际航线与航司规定不同，引用所展示航线确切规定并在 FACTS.md 留来源链接与原文；机身界面与标签不得出现厂家名称、标志或真实产品

**适用场景**：机场与海关安检 / 包裹与货物运输检查 / 产品内部结构
