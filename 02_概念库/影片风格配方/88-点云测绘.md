# 88 · 点云测绘 / LiDAR Survey

> 分类：仪器实证
> 参考片：林下的田
> 原片一句话：激光点云剥掉一片森林的树冠，露出当年农田的石墙：3.4 公里。

## ⭐ 可直接复制的提示词

```text
用点云测绘风格：真实地点的激光点云漂在近黑冷调中，扫描线或切面穿过后点凝聚成斜光扫亮的实体表面，再用发丝细仪器标注读数；点按高度走去饱和色带、强度调明度，前沿与接缝是冷白的光，表面暖中性，琥珀色只给读数与追踪特征。仪器固定一角、读数在右三分之一、字幕在左下条。24fps 逐帧、摄影机不停、前沿缓动、切面按节拍分级推进。镜头用贴近点云低斜视、缓环绕、上升拉远、推进剖面；转场只用前沿与切面。声音用 FM ping、细噼啪、噪声扫频与定音鼓，主揭示前近乎静默，人声高于音乐 10dB、−14 LUFS。避免全息 HUD、卫星俯拍、彩虹色带、点间抖动与云内交叉淡化；绝不虚构数据。
```

## 配方拆解

- **本质**：真实地点的机载激光点云漂浮在黑暗中，是一道被测量的云；扫描线或切面穿过点云，点在其后凝聚成实体、被低角度光扫亮，再用发丝级的仪器标注读数。整部片子由一个设计好的运镜承载：点云是要飞进去的空间，不是看着的一张图。
- **不是什么**：不是科幻全息 HUD（不虚构界面，点是真实且有测区才稀疏）、不是卫星俯瞰简报（不是俯拍照片而是可穿行的 3D 点云）；也不是蓝图、低多边形等距图或玻璃产品渲染。
- **配色**：背景近黑带冷调，绝非纯黑或渐变天空。点按高度或类别走一条去饱和色带（深青绿→浅，或灰→白），强度调明度不调色相，禁用彩虹高程色带。前沿与接缝是冷调近白——是光不是颜色。实体表面为受光的暖中性色（石、陶、灰泥），不抢强调色。唯一琥珀色留给被找到并测量的东西（追踪特征、读数、剖面线），更冷的第二个色只用于对比图表。示例：背景 #05080A、树冠 #1F3F35→#5C9A7A→#E2F3DC、地面回波 #C8B38C、表面 #BDB5A6、前沿 #D4FFF0、强调 #FFB347、图表绿 #83C495。
- **材质渲染**：点是 GL 点，按世界单位定尺寸（0.12–0.3 m）、下限一个输出像素、柔和圆盘、不透明且做深度测试（仅幽灵层用加色）；按高度或类别着色、强度调明度，带距离雾。浏览器端量化为 uint16 位置（2 cm/1 cm）外加每点一字节存离地高度、类别、强度、种子。每个回波算出离地高度（减去由 class-2 回波三角化的地面模型），用来驱动色带、切面和标尺。实体表面是 0.5–1 m 网格，平滑法线、烘焙短半径 AO、20–35° 低角度斜射阳光、淡等高线、山脊提亮；微地形夸张显示（×2–3）必须带屏上注释，测量用未变形数据。前沿是点与表面着色器共享的一个世界空间平面：其前的点变亮，其后一条细接缝发光，表面在几十米内填入。切面按离地高度：上方回波抬起淡出、与树相交处一圈光、画框边缘标尺跟随。表面标记（追踪特征、剖面线）是表面着色器里的距离场，用 fwidth 保持发丝细；读数、引线、图表是经同一 world→screen 函数的 2D 叠加。测区外点云保持暗点而非切黑。后期 2× 渲染、高阈值辉光（只作用于前沿与接缝）、暗角；无颗粒（点已是细节，用更高 CRF 编码）。
- **字体字幕**：读数用细窄体数字（110–130 px，如 Barlow Condensed 300）；仪器、坐标、计数、来源行用等宽字体（19–22 px，如 IBM Plex Mono）；片中标签用无衬线体（24–36 px，如 Noto Sans SC 500）。OFL 字体自托管，CJK 只子集化用到的字。仪器信息固定在一角：地点、坐标、面积、数据源、点数、任何夸张系数，只在媒介改变时才变。读数放在右侧三分之一、紧邻所测对象：标签、数字、来源或方法行，特征在画面内时加引线，滚动计数器报出落定值。字幕是左下角逐字稿条（2 px 细线、色板向右淡出），每种语言一行并按真实字体测量，宁可断行不要自动换行；双语时片子语言在上。1080p 下不小于 19 px。字幕停留 ≥ max(1.8 s, 语音+0.6 s)；标签 ≥ 字数÷4.5+1.5 s（中日韩）、字母数÷15+1.5 s（拉丁）。
- **运动质量**：24 fps 逐帧；摄影机永不停止；关键帧用 C1 样条控制目标/距离/朝向/俯仰（不用从正天顶 lookAt）。前沿按缓动移动、在主体处最慢；切面按节拍分级推进（缓动阶梯+短暂停）让层次可读。点只在前沿之后或按高度出现，绝不全画面随机淡入。读数以小弹跳落定；追踪特征沿长度依次点亮。绝不移动：点之间的相对位置（无抖动、无噪声位移）与仪器的位置。
- **镜头语法**：正锁天顶缓慢推进（照片显示了什么：待验证的说法、之前、回到地图的结尾）；降机加倾斜转到斜视（进入数据、地点有高度，从图片切到云）；贴近点云的低斜视（俯仰 10–20°、90–150 m，表现体积与立起来的东西，如树冠、建筑、立面、崖壁）；缓慢环绕（研究、切面在工作，用于剥离、扫描、读数定格）；上升拉远（揭示所发现之物的尺度：网络、场地平面、走廊）；横向跟拍（沿墙、路、管线、海岸行进）；推进到剖面（证明细节：横断面、净空、高度）。关键时刻主体 ≥ 画面高度三分之一；读数在右三分之一；仪器在一角；字幕条内不放东西。转场用前沿与平面，从不在云内交叉淡化或硬切。
- **声音配乐**：仪器音：FM ping、点到达的细噼啪、与前沿绑定的噪声扫频、不断细分的滴答（八分→十六→三十二）加速、每剥离一层一个下行音高 blip、计数器滚动时的棘轮声、读数落定时的 ping。重量与合成：定音鼓、大鼓、大锣用于凝聚与切分，主冲击前用反向渐强；低通失谐锯齿 pad；脉冲低音带可听的 2/3 次谐波。干与湿：主体还是点时可用电子乐，实体表面出现后给发现的特征加一种有机木质或弓弦音色（马林巴、弓形颤音琴）。环境床：开头结尾用地点自身的环境声（风中树叶、水、车流）做 J/L 切，中间用一层薄空气床。静默：主揭示前近乎静默（只有空气），之后第一个声音是冲击。混音：人声高于音乐约 10 dB 并让音乐闪避；冲击不进总线压缩器；−14 LUFS，真峰值 ≤ −1 dBTP。人声：平静朴素的叙述者，短陈述句。
- **招牌技法**：
  - 照片转点云：扫描线掠过航拍照片，其后地点变成点——适合设计前的场地踏勘、卫星漏掉的东西、采石场的真实体积
  - 树冠剥离：切面按离地高度下降，上方回波层层抬起淡出、标尺跟随——适合森林下的考古、隐藏小径、泄洪道、滑坡痕
  - 点凝聚成面：前沿把剩余点变成实体表面，发现的特征依次点亮——适合建筑扫描转 BIM 外壳、崖壁转灾害模型、街道转车辆净空模型
  - 剖面：切面穿过一个特征，剖面发光、旁边挂真实回波的带尺寸图表——适合堤坝高度、桥梁净空、道路切方
  - 测量窗：测区是未测点云里的一座舞台——适合地块、走廊、场地边界
  - 复原：被移除的层以幽灵形式回到所发现之物上——适合结尾、空地前后对比、街道下的埋管
- **避坑**：
  - 为新地点找数据：USGS 3DEP（Entwine Point Tiles）、OpenTopography、AHN 与各国官方门户；按框和深度取子集，别整块下载
  - 许可：公有领域/CC0/CC BY/仅署名政府许可可用并在 CREDITS 署名；ODbL、CC BY-SA、非商业条款先问用户；绝不用商业扫描或 Google 3D 瓦片，绝不用生成或虚构的点云冒充真实证据
  - 事实：项目文件夹放 FACTS.md（主张、来源 URL、引用原文或测量方法）随片交付
  - 坐标：EPT 常是 Web Mercator，先转到局部东/北/上坐标，并用已知地面核对垂直基准
  - 落叶季与长叶季要说明；点太密远看像地毯要贴近低飞；扫描条是真实纹理别用掠射角做揭示；追踪特征属解读要标 traced、吸附数据；裁掉房屋院落保护隐私

**适用场景**：文化遗产 / 环境 / 场地测绘
