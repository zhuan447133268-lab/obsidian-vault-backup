# 51 · 流水线图解 / Assembly-Line Diagram

> 分类：线稿图解
> 参考片：拆解流水线
> 原片一句话：把人体剖成一座倒着开的工厂：12:30 的一份三明治被一站一站拆开，六小时后变成追公交车的力气。

```text
用流水线图解风格：一个剪影（人体/机器/城市）被剖成一层层房间的正立面工厂，每间有机器、编号牌和小工人，彩色管道送货物、管色即图例，相机跟着一件货物走完整条线、货到即开工；纸外深底内、浅墙厚身墙、Holmes平影与轻微套印偏，三四种专色全片一义、线宽随相机变并做LOD；编号圆到达填实、牌子链条垂下落弹、重复即笑点；平面正立面相机横跟、穿门推入、沿槽下倾、舷窗POV、沿管甩镜、大拉回全亮；配120BPM进行曲逐工位加声部与机器拟音；避免等距透视、白板手绘、爆炸3D、蓝图与文字成团。
```

## 配方拆解

- **本质**：把一个流程讲成剖开的工厂正立面：一个剪影（人体/机器/建筑/城市）像娃娃屋一样被切成一层层房间，每间是一个工位，有机器、编号牌和小工人；彩色管道把货物在工位间输送，管道的颜色就是图例。相机跟着一件货物走完整条线，每件货物到达时该工位立刻开工。
- **不是什么**：不是等距信息图（无等距或透视视角：一切是平面正立面）、不是白板讲解（无手、无现场画）、不是爆炸拆解图（无3D零件飞散）、不是蓝图（是纸上的全彩而非蓝底白线）、也不是主题演讲（无幻灯片、居中标题页、页眉）。
- **配色**：纸＋墨＋一种底色＋三四专色。剪影外是纸、剖面内是深色底、房间是浅墙、墙与楼板是物件色，然后三四种专色即图例，别无他色。每种专色全片只表一义（回收厂里：赭=纸、朱=塑料、青=玻璃），房间边框可按工位轮换专色、货物自身颜色固定。底色要深到能框住画面、但绝不纯黑：深靛蓝或酒红读作"内部"并让专色立在其上，须检查每个专色与底色和墙都分得开。编号工位圆是一种色（赭填墨边）、未到时是空心、到达时填实。示例（夜班）：纸#F2ECE0、墨#1D2030、底#24345A、墙#FBF7EE、物件#EE9F87、朱#E04A2F、赭#F3B23A、青#2E8D87。
- **材质渲染**：全矢量、代码绘制：逐帧由形状与路径生成SVG，干净墨线圆头圆角、平涂、无渐变。轻微印刷感：每个色版按各自1–1.6px套印偏移、全画同向（墨/纸/墙不动），其上叠淡淡纸纹与纤维（multiply）；仅此而已，无做旧/撕边/黄渍/斑驳墨。平影（Holmes影）：同一形状向右下偏移一个浅平色（牌5–6px、大形14–18px），无软影、除甩镜运动模糊外无模糊。剖面：剪影是深色底＋厚 Body 墙（约56px宽、两侧有墨），货物入口（进料口/舱门）处断开、两端加墨帽；房间有彩色边框、浅墙、地板条，楼层间是带铆板的厚板，钢架与龙门架托住机器。管道：墨边(宽+6px)＋颜色＋高光条(0.2×宽、偏左上、遮在管内)、圆角弯头、间隔的法兰；宽度编码重要性（主管/动脉/支管）。任何距离都是一张印好的纸：线宽随相机变化（拉远约按z^-0.6变细、推近略粗）、低于某尺度就不画小工人/牌/小字而保留大机器，画面绝不变成发丝乱麻或字团。
- **字体字幕**：三种面三项工作（皆OFL）：压缩工业展示体做牌、图例签与标题（Big Shoulders Display 800–900，像刷在厂墙上）；grotesque做小标签、字幕与署名（Archivo 600–800）；CJK无衬线做每块牌上的一句中文（Noto Sans SC 700，≥34px）。牌：奶油板＋2.6px墨框＋3px角＋平影，格式[编号圆][ENGLISH隐喻 | 中文名]，贴在房间上沿或机器上、绝不贴在引线上。图例签挂在其管道上方：色片＋中英名（GLASS 玻璃）。引线（Holmes）：点→竖→直角→粗字，只给动态主角、每帧至多一条。每帧文字约至多七块、每块二到四词。标题是画中的物件（进料口上方的龙门招牌、机器铭牌）挂在所命名之物上，绝不在页边、绝不居中、绝不做页眉；尾卡是同一物件：立在地面线上的铭牌。字幕是工票：奶油票＋墨框、左侧存根显示当前工位号（无号时是钟）、中文34px在上英文28–30px在下各一行、置左下；标题或尾卡占左的镜头就移到右下，每镜构图留出那个角。
- **运动质量**：传送带永不停：货物匀速行进、进站时缓入。工位随到达启动：货物落定的那一拍机器开始（滚筒转、喷淋落、冲压砸）、工人做一个两帧动作、编号圆填实并弹出（0.9→1带回弹）。牌子用链条垂下并弹一次、第二语言的牌晚半拍摆入。重复即笑点：门卫举起STOP、放一份过去、再举STOP；机器按音乐网格重复循环。时间压缩在钟与表盘上：指针飞转、灯渐暗、工人打盹，绝不出现写着"后来"的标题卡。大人物按程序运动且脚踩地面线、随地面移动，膝由两骨求解且始终向前弯，绝不滑行、漂浮或在定帧上剪刀腿交叉。24fps。
- **镜头语法**：永远是平面正立面：相机只在画面平面内摇、倾、推、拉，绝不旋转成透视。跟货物横移（流动/跟随一件，开场/同层工位间移动）；穿过一个门形推入（进入系统/进料/进入某零件内部）；沿滑槽下倾、楼板擦过（下降一层）；从零件拉回整层（协同工作/分选分流站/定格对比）；跟随一种颜色（某产物去哪，其余离画）；舷窗POV（圆形遮罩，外部世界伸进来：触发/警报/顾客/事件）；沿管道甩下（紧迫）；大拉回（整条线同框，结尾：全部工位点亮的完整剪影）。转场在画内发生：穿过一个形状、楼板擦过画幅、同一件货物的匹配切、颜色跟随、圆形舷窗遮罩、沿管道甩镜（由相机速度产生的方向性运动模糊＋速度线，只渲一次，绝不叠鬼影）；无翻页、无淡到纸、无白闪。
- **声音配乐**：配乐像生产线：固定速度的进行曲（约120BPM），工位不断往上加声部；每条线或机器带来自己的音色（大管、单簧管、长笛…），冲压与盖章用木鱼与大鼓，工位点亮用钢片琴或钢片琴。停止即声音：闸门关闭或警报一响，整个乐队骤停、在下一次放开时重启。每个可见动作都有机器拟音：料斗、链条、牌子弹跳、卷帘、冲压、喷淋、滚筒、哨子、勺、钟、警铃、点火、门；程序化、短、落在帧上。旁白（可选）：平静讲解、一句一意、说画面说不了的（反转、某物变成什么、为何等待）；到达、大点亮与尾卡留白；压缩后高于音乐约9–10dB、音乐的300Hz–4kHz在其下让路、句间音乐抬起。−14LUFS、真峰≤−1dB，冲压与点火的瞬态要限幅。
- **招牌技法**：
  - 工位启动：货物落定、机器启动、工人动作、编号填实——适合制造流程每一步/数据管线每阶段/请求经过的部门
  - 拆成颜色：一团货物进分选层、出来成三股不同色的零件流各进其管、图例签 dropping——适合邮袋分邮编/原油分馏/营收分成本/矿石分金属
  - 门卫：举STOP的工人一次放一份过去——适合阀门/限流/队列/海关/水坝
  - 仓库与钟：货物上架、钟飞转、灯渐暗、工人打盹直到警报——适合储能/库存/电池/储蓄
  - 舷窗警报：圆形POV看外部世界、展示让生产线启动的事件——适合需求到来/订单/传感器触发
  - 跟随颜色：相机按颜色挑一条管道骑到终点、其余转弯离画——适合某产品去向/某信号路线/某顾客的旅程
- **避坑**：
  - 做成逐步流程图而非故事→给一个钩子（反转/期限/问题）和收尾画面、每工位只说一件事
  - 文字蔓延：牌/签/引线/字幕累加很快→每帧约七块、让颜色承担意义；无相机相关线宽与LOD时拉回变成灰色线网与不可读标签
  - 剪影消失（房间把剖边填得满满的）→房间与外墙之间至少留30px深色底；专色在底或墙上消失→先对两者测试
  - 人体装太多房间变成木桶→全身镜头交叉淡化到比例正常的人形示意图，而非把剖面吹大；程序化腿按正弦摆会浮/沉/滑→对地面线求解、末帧停在可读的相位
  - 隐喻撒谎（一进一出、本应是梯度的阀门）→每个简化都写进FACTS.md，旁白不声称画面只是暗示的事；引线每帧至多一条，其余都是贴物件的牌

**适用场景**：流程原理讲解 / 生物与医学 / 供应链与流水线
