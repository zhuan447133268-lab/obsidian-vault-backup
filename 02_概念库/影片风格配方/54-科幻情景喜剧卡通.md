# 54 · 科幻情景喜剧卡通 / Sci-Fi Sitcom Toon

> 分类：卡通动画
> 参考片：跑腿买咖啡
> 原片一句话：厌世天才开传送门只想买杯咖啡，却穿过越来越离谱的平行宇宙。

## ⭐ 可直接复制的提示词

```text
用【科幻情景喜剧卡通】风格：2D成人科幻情景喜剧，粗黑描边持续沸腾、平涂硬边阴影、大白眼小瞳、怪萌生物、科幻硬件当家用废品，一对反应不匹配的搭档用荒诞手段追琐碎目标；每个世界一套3–5色且与前一世界最大反差，线色眼白跨世界不变，辉光只属传送门；字幕底部中央白字黑描边配角色色药丸、12fps块状标题；角色12fps、镜头漩涡24fps、表演重于运动、落地挤压22%、口型由音频驱动、恐慌抖动随情绪增长；运镜中景双人→反应特写→冲门漩涡擦除→跨世界同构图→全景；配乐theremin主奏叠方波琶音复古鼓机、静默即笑点、双人对比嗓音、−14 LUFS；避免复制现存角色与传送枪、儿童卡通与切乐不切混响尾。
```

## 配方拆解

- **本质**：成人动画科幻情景喜剧：浓烈沸腾的粗黑描边、平涂硬边阴影、反应不匹配的一对搭档、发光的传送门，以及一个世界一套配色。类型引擎是「用荒谬庞大的科幻手段去追一个琐碎目标」，对白驱动、最后反转。
- **不是什么**：不是儿童卡通（干幽默、长停顿），不是日漫（无闪亮眼），不是矢量讲解（线会沸腾）。版权红线：绝不复制现存作品的角色、剪影、配色、名字、口头禅、打嗝梗、logo 或任何已有传送枪造型，必须自创角色、道具与装置。
- **配色**：每个世界一套3–5色，与上一世界在色相和明度上都拉开最大差距，让观众仅凭颜色就知道「跳了」；线色与眼白跨世界不变、其余皆可换；辉光色只属于穿越装置、任何世界别处不得使用；故意乏味的米色/棕色本身就是笑点（用于「可疑地正常」的世界）。
- **材质渲染**：线近黑（微紫黑最佳）、角色道具约7px、背景细节4–6px、圆角接点，线宽在屏幕空间恒定（特写按同重「重画」而非放大）；线沸腾——屏幕空间每约7px重采样、沿法线低频噪声位移≈1.7px、3张沸腾画以12fps循环，连静止姿势和背景都在沸；填充只用平色、阴影是裁在形内的硬边深色块、辉光为1–2层半透明平环而非渐变、天空为平色带；脸为大白眼（3/4视角相触）、4–5px瞳、重睑眼袋、参数化嘴、眉载情绪；剪影纯黑可读、每个主角一个荒诞服装点、避开白大褂+刺猬头；生物每个世界一只、既恶心又可爱、非语言（音效）以保对白是两个主角之间；传送门是唯一发光物——凹凸边缘粗描边、旋转螺旋臂、苍白核心、环绕火花、滴加、开启时场景覆半透明平洗、轻微过冲后柔和回缓；屏幕图形为按世界着色的复古终端标签（VT323）打字出现。
- **字体字幕**：字幕底部中央圆润粗无衬线（Baloo 2 ExtraBold ~50px）、白字约11px黑描边像卡通自带字幕、左侧角色色说话人药丸（带沸腾描边）；超约1300px折两行、重叠堆叠旧行淡至70%；旁白停留≥max(1.8s,语音+0.6s)、快对白max(音频+0.35s,0.9s+字/17)，在世界切换与静默拍前切以使静默落在干净画面；标题为12fps跳进的块状字踩乐点，避开酸绿+黏液滴+抖 bubble 字的特定组合；脸避开底部约170px字幕带、世界标签避开脸。
- **运动质量**：角色12fps（两帧），镜头/传送门漩涡/飞行道具/擦除24fps（逐帧）；表演重于运动——静止姿势的小变化（眼抽、瞳滑、吞咽、汗滴）、呼吸±1%挤压、随语音响度点头；每个手势前 anticipation→action；落地挤压拉伸（衰减余弦挤压≈22%）、飞出传送门拉伸、「吸入」=朝门心缩放并拉伸；口型由音频 RMS（开）与谱质心（宽/圆）24Hz驱动、12fps采样，尖叫嘴×1.5–1.9；紧张抖动为12fps随机3–6px加颤瞳、幅度随恐慌增长；冷场时除沸腾外全不动。
- **镜头语法**：中景双人（关系/谁怎么反应）；硬切特写（打断/表情崩坏）；插入物体极特写（荒诞细节）；反应特写（每个荒诞画面后必接）；单字紧特写+短抖（恐慌）；冲进传送门→漩涡擦除（离开世界）；跨世界重复同构图（蒙太奇/对比）；静止双人极缓推（冷沉默）；全景含装置与两人（整体处境）；越肩看屏幕（读坏消息）；两脸间甩镜（争吵/打赌/再看一眼）。转场经传送门漩涡或硬切，禁叠化。
- **声音配乐**：合成配乐无需采样：类 theremin 主奏（正弦+少量2/3谐波、约70ms滑音、起音约150ms后渐入颤音、弹簧混响）叠模拟贝斯、方波琶音、复古鼓机，小调与半音阶；每世界一个类型提示（冲浪吉他/波尔卡手风琴/玩具钢琴摇篮曲/电梯bossa/刷镲摇摆/大号+滑哨/暖Rhodes+啊声/颤音弦恐慌）；静默是笑点——揭示与冷场把音乐硬切（含混响尾）只留房间声（日光灯嗡/钟滴/冰箱）；foley全合成（门开、嗡、关fwump、漩涡whoosh、弹跳、湿glorp、啧、咬、眨眼blip、kazoo sting、吱叫玩具）；双人对比嗓音——面瘫主角低平慢（轻饱和+180Hz提升增厚）、紧张者高快（临场感提升），小生物升调说一两词，−7dB闪避对白，−14 LUFS。
- **招牌技法**：
  - 平行世界：每次跳跃换配色、换提示乐、换生物，适合产品各版本/本可拥有的人生/五个年代的同城
  - 双人对比：面瘫对恐慌、笑点在反应差，适合老手与新人/家长与青少年/AI与其用户
  - 三振变机关枪：两个慢的错误答案后按拍切一秒世界，适合失败的原型/糟糕的约会点子/税表
  - 硬件当废品：能扭曲世界的科技用于琐事，适合量子计算机列购物单/火箭送三明治/时光机改错字
  - 冷场反转：反转后长静默、再一句揭示角色价值观，适合报价/细则条款/不想要的礼物
- **避坑**：
  - TTS把连字符口吃读成词→写音节、改拼写、选扛得住低嗓的名字；Whisper误听极短片段→补约0.6s静音
  - 真打断要把被打断台词生成得更长、再在插入处截断音频；弹性过冲吞演员→用柔和回缓
  - 食物与液体需表面细节/滴/蒸汽提示否则读成别物；方波镲片混叠成8–20kHz嘶→带通噪声加少量FM
  - 40Hz以下持续低音在笔记本变隆隆→提高八度结束；切乐不切混响尾不算静默
  - ffmpeg fps=1 抽帧对照表最多偏0.5s→别误判镜头边界

**适用场景**：喜剧 / 科技品牌 / 社交短视频
