# 74 · 萤火光点 / Firefly Pointillism

> 分类：发光线条
> 参考片：你亮，我就亮
> 原片一句话：萤火虫闪一下就是在发问：女孩得到的回答是一只鹿，暴风雨吹灭了所有的光，她用最后一只问遍了整片黑夜。

## ⭐ 可直接复制的提示词

```text
用萤火光点风格：黑底占半幅以上，圆润柔和的光点组成人与万物；所有东西出自同一渲染器，只靠颜色、密度、虚实区分，清晰点小而锐、失焦点大而淡，形体是点状剪影靠动作辨认；一个温暖黄绿家族，角色独占一色贯穿变形，冷色只给星雨。点永不生灭：涌入、漩涡聚拢、阵风吹散后别处重组、熄灭、跃入星座——转场只在媒介内流动，不硬切或叠化。60fps 逐帧、呼吸脉动、曲线路径、180° 快门拖出光条；镜头用缓推、带视差横移、锁定远景、对焦拉取、快速拉远与全场重组。标题与字幕由点构成或用楷体压底部。配竖琴、钢片琴与玻璃琴，蟋蟀与风做环境。避免冷蓝科技感、粒子 logo、流体渐变、硬像素与绿色雾霭。
```

## 配方拆解

- **本质**：黑底上成千上万个柔和呼吸的光点组成人、动物、草、月亮、雨和文字。点永不生灭：它们散开、飞走、在别处聚成新的东西——这就是本风格讲故事的方式。画面是一幅会动的点彩画，也是一个夏夜的萤火虫。
- **不是什么**：不是数字雨、全息界面或暗色科技演讲（没有冷蓝、线框、科技感）、不是粒子 logo 片（这里有人物和故事）、不是流体渐变，也不是铁屑或硬像素。点始终是圆的、柔和的、温暖的。
- **配色**：线性颜色乘亮度，画面显示每种颜色的中间调与烧亮核心。一个温暖的黄绿家族；每个角色拥有一种颜色，并在每一次变形中保持它——散开重组后观众仅凭颜色就能认出谁是谁，颜色绝不互换。冷色只给星星和雨，占画面不到 5%；没有纯白，没有饱和红或蓝。参考：主角 中间调 #B2A076／核心 #F5ECC6，同伴 #A3B286／#EEF5D6，萤火与环境光 #A6B279／#F0F5C8，景物 #73965F→#96AA70，天气 #8A9893，冷星 #A6AAB2／#F0F2F5，标题 #B2AB92／#F5F2E2，背景 #050708→#060907。
- **材质渲染**：用五档模糊做 splatting：σ≈1.0／2.1／4.8／10.5／23 px，分别以 1／1／½／¼／⅛ 分辨率渲染；每个粒子带一个小数模糊层级并分配到相邻两档，因此可对焦连续拉取。每级能量增益 [1,1.55,2.7,5.2,10]/res²，让大散景同时更大更淡。光晕：每个点把约 16% 能量放到高两级的层，亮点因此发光。曝光与调子：线性光×曝光、1−exp(−x)、gamma 2.2，点核烧向白、边缘保持色相。动态模糊：180° 快门，每个点画成快门两端位置之间的采样，快速飞行自然变成光条；跨画面环绕的粒子（雨、流动）不能拖出贯穿屏幕的长条。颗粒极轻、暗部略多，加 1–2 LSB 抖动防色带。角色用 2D 骨骼（锥形胶囊与多边形），点绑定在各部位的归一化局部坐标上，姿势、缩放、镜像都不重采样；落在同层或更近层另一部位内部的轮廓点压暗到几个百分点（并集剪影），否则人看着像线框。位置是时间的函数：每组每场有状态函数，转场按粒子带错开延迟混合；任意帧可独立按任意顺序渲染（可并行、可复现），任意时刻粒子总数必须一致。
- **字体字幕**：标题与字幕都是点做的：文字渲染成遮罩后在抖动网格上采样（不是随机），每个采样一个粒子；140–170 px 的中文标题约需 3400 点、30–40 px 的拉丁行约 800 点，再稀笔画就读不出来。落定后文字绝对静止（只有亚像素微闪），落定时短闪一下；放在空旷天空、左对齐，绝不居中压在角色上，也绝不加底板。字幕是普通烧录文字（可读性优先），用手感柔和的楷体如 LXGW WenKai（OFL）：中文约 40 px 暖奶油色、英文约 28 px 略暗，居中在底部，无描边无底板，只有同色微光。所有主体保持在字幕带之上。
- **运动质量**：60 fps 逐帧（不抽帧）。粒子路径永远是曲线：直线飞行要加旋转或散开。呼吸：角色点缓慢脉动（±22%），少数点远亮于其余（点彩的闪光）；萤火大部分时间暗，用窄脉冲，任一时刻只有约四分之一亮着。用漂移代替物理：慢正弦之和（0.3–1.4 rad/s）做漂浮，缓动代替阻尼（落地 ease-out，其余 smootherstep）。表演只做大的剪影动作（抬头、伸手、低头、跳、跑、跌倒、跪、站、举手），眨眼和手指画不出来；大角色动作时要保持完整剪影：鞠躬或跃起时移动头、颈、腿，但背部线条和每条肢体都要读得清。三档速度：快（转场、高潮、点拖成光条）、中（表演、每拍换一个姿势）、静（阅读与情绪停顿：位置冻结 ≥1.5 s，只有亮度呼吸）。
- **镜头语法**：粒子世界上的 2D 摄影机，按深度层做视差（屏幕位移×(1＋0.38×深度)）。缓慢推进：亲近、注意——相遇、一束光定住；带视差的横向跟拍：一同行进——行走、乘车、时间流逝；锁定远景：渺小、安静、阅读时间——标题、告别、孤独身影；变焦（散景→清晰）：出现、「这是真的」——角色成形；快速拉远：尺度揭示——整条地平线上的人群；全场重组：不切镜换场景——旅行、时间跳跃、结尾画面。转场只发生在媒介内部：一股光流涌入、漩涡聚拢、阵风把场景吹散并在别处重组、灯光熄灭、世界向上重组。没有硬切、叠化或翻页。
- **声音配乐**：真实采样乐器：竖琴（流动用滑奏、聚拢用琶音、落定用和弦）、钢片琴、手铃、玻璃琴与颤音琴（单点光、触碰、闪光）、弦乐铺底与震音、长笛旋律、定音鼓与吊镲（成形与风）。大调带 Lydian 升四度的色彩：明亮神奇而非悲伤；失落时可用小调转折。粒子动作对应声音：聚拢＝上行琶音或滑奏加镲片渐强、正好落在和弦上；散开＝风声加下行钢片琴；落定＝竖琴拨弦或手铃；同步闪＝快速竖琴扫弦。程序化环境：蟋蟀（4–5 kHz 短脉冲串）、风、雨；动物脚步由步态相位生成。一束光可以承载动机：两音上行的「问」、下行到主音的「答」。
- **招牌技法**：
  - 涌入：一道光流从画外进入，逐点落定成世界与其中的人物——适合开场、万物生成
  - 引路光：全片最亮的那个点（强光晕）牵引视线，也可以变成角色的眼睛——适合跟随、寻找
  - 同步闪：按距离延迟的涟漪或整片同时闪——适合回答、连接、「世界听见了」
  - 漩涡聚拢：点一边飞行一边绕新形体的中心旋转并对焦——适合召唤、诞生、众合为一，从等身动物到比画幅还高的巨物都能用
  - 阵风换场：按屏幕 x 延迟（一侧先走）、加风矢量、吹散；光条来自动态模糊。风向即剧情方向——顺风是旅行，逆风是暴风雨
  - 熄灭：被吹散而不再重组、亮度降到 1–2%、地上只剩余烬——适合失去
- **避坑**：
  - 绿雾：背景散景、失焦的草和萤火叠成一片霾、黑色没了→让萤火大多保持暗、背景散景 0.1–0.38、近处虚草约 0.2
  - 光墙：远处点排在同一水平线像一堵亮墙→给它们离地高度和随机深度，并柔化涟漪前沿
  - 分布硬边：均匀随机的带状分布会画出可见边界→改用幂律的垂直分布
  - 角色读不出：只有填充点是云、轮廓需要约每像素 0.7 点并做遮挡剔除；侧面站立的动物远腿被近腿挡住→错开四蹄让四条腿都读得出
  - 高潮时形体溶解：对大角色逐粒子散开会把形体变成一根点柱→英雄动作要移动整套骨骼、保住形状

**适用场景**：绘本故事 / 众合为一 / 夜与自然抒情
