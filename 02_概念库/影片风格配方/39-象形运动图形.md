# 39 · 象形运动图形 / Pictogram Motion

> 分类：平面排版
> 参考片：被落下的伞
> 原片一句话：一把被落在公交车上的黄伞，晴天里在失物招领的货架上等了一整天，暴雨回来时和另外 312 把一起撑开：物件、交通、天气和标识，都是卡着节拍的几何象形符号。

## ⭐ 可直接复制的提示词

```text
用象形运动图形风格：画面只由三样构成——整行错位滑动的方格核心图形（圆/半圆/小母题）、由圆头杆与圆盘构成的几何象形图与无脸小人、从遮罩滑出的900字重双语巨字；一章一色每色五阶、浅底深字深人、字下图案低对比；每镜起于拍、每个动作落整数拍、字从遮罩上滑、象形图横条套准、转场贴网格滑行落列翻砖；多锁定平帧、HUD角落等宽文字加N格进度条、字幕是章节最深色实带左下；配鼓族为脊＋每章一击＋按剪辑表对点；避免卡通表意、3D深度、真实活动标志、叠化与字图重叠。
```

## 配方拆解

- **本质**：踩拍的片子，只由三样东西构成：方格"核心图形"（圆、半圆与小图案单元，整行错位滑动）、几何象形图（物件/车/天气/标志，及需要时的无脸圆头小人，由圆头杆、圆盘、胶囊构成）、以及从遮罩里滑出的粗体双语字。每个剪辑都落在鼓点上。
- **不是什么**：不是等距信息图（无深度无3D）、不是瑞士动态图形（象形图与图案承载和字体一样多）、不是卡通（象形图绝不表意、人物无脸）、也不是数据片（数字是标签不是图表）。
- **配色**：一组五色＋一深中性，每色五阶（最暗→最亮，中间为基色）；一章一色，多色章每卡在色组中轮换。文字下面的图案低对比、章节卡满对比。浅色底配深字深人物、其圆盘用较亮一阶；深色底配奶油；深中性上圆盘要用较亮阶否则消失、其强调色是一暖色。一奶油一墨服务所有色相；无描边，除那道光扫外无高光。按题材选色组并自创色名，绝不借用真实活动的色名。示例：暖节庆（红/紫/森绿/金/赭）、海岸（海军蓝/青绿/珊瑚/沙/天蓝）、厨房（番茄/罗勒/藏红/茄紫/面粉奶油）。
- **材质渲染**：平Canvas2D净渲染、颗粒只在合成时加。一个方格（单元≈画高的1/6）统管带、转场与墙。图案模型：中暗色填充、在网格节点随机放置单元半径的圆盘与盘中盘、再让一部分单元放置通用几何母题（四分之一圆/鱼鳞波/点与三角鳞/同心弧/太阳轮/棋盘/月牙）并按90°倍数旋转，画得比屏幕宽以便任一行都能移一格；绝不放吉祥物/地标/logo。象形图一笔粗（圆头）、实填、每图至多两阶（较深的暗部、远侧），物件在图标尺寸保持剪影、60px读不出的就砍掉。人物（可选）：单位为身高、原点在髋，先画远肢（向背景混约40%）、再躯干、近肢、头，第二人混约60%在其后；人也可以只通过痕迹出现（脚印/一排脚）。主角（任意物件或人物）站在一块邻色的大太阳盘上、被一道淡光扫过。环境（水/网/坡/轨/雨）活在主角自己的buffer里、在文字列之前渐变遮到0。24fps，仅在转场、甩镜与快速运镜内做子帧平均的运动模糊。
- **字体字幕**：标题用900字重grotesk（Inter Tight）150–330px、字距紧、自动适配；第二语言用其下粗体；meta用等宽（DM Mono）约22px宽字距，标签做成等宽chip。每张卡都有HUD：角落等宽文字＋一条N格进度条（当前高、已过暗、其余淡），N由条目数导出。双语规则：一种语言永远是大标题，第二语言由一个开关按版本选择、绝不手改卡片。卡片文字即文字层；有旁白时字幕是章节最深色实带上的两行（浅色底用墨带）、置左下、绝不压标题：第二语言粗体在上、英文等宽在下；停留≥max(1.8s,语音+0.6s)，必读卡（规格/数字）≥1.6s；从剪辑表导出标题卡的.srt。
- **运动质量**：时间的网格：全片定一个速度、每镜起于拍、每个关键姿势（释放/接触/落地）落在整数拍上。节奏阶梯：常规卡持续一小节、相关子项变半长快射；第二个速度来自分拍而非变速。缓动：入场指数out、甩镜与擦镜指数in-out、回弹全片至多一次。字从遮罩上滑入：标题先、第二行晚约0.08s、标签再后、meta逐字打出且无光标；短卡压缩全部时间。象形图组装：主角与其舞台以横条从交错的两侧滑入套准。背景呼吸：行朝交替方向漂移、章节卡在拍上跳四分之一格。转场全贴网格：滑行、落列、推、从格角长出的四分之一圆、从最后人物做出的虹膜、翻砖；轮换使用，各持续绕切点几帧。运动模糊只在运动处（转场与甩镜窗口），静止帧只渲染一次。
- **镜头语法**：多为锁定平帧，能量来自行移、转场与人物动作；相机若动则沿网格而动。锁定平帧（清晰、卡如海报，适合任一物件或必读规格）；沿轨横移、每拍一屏甩镜（一列站点/生产线/路线）；沿一行慢漂（画廊/菜单/较慢的章节）；按方格行垂直滚动（排名/楼层/深海）；推入一个母题格直到它成为下一帧（菜里的配料/地图里的城市）；拉回到贴满条目的墙（全体汇总/"全部"/对比）；砖块塌向一点（合并/共同目标/数归零）；沿格线分屏（对决/前后/两版本）。构图：文字与人物不重叠（一列文字、一个舞台），横向姿势把舞台外移；HUD留在角落。允许的转场只有§5的网格转场，绝不叠化/3D运镜/手持抖/景深。
- **声音配乐**：文字与音乐可独立撑起全片、旁白可选（平静，每章一两句）。打击乐是脊梁：按题材选鼓族（框鼓/太鼓/行进军鼓/钢盘/身体打击/电子套件）加边击、拍手、沙锤、镲。其上叠色乐器：Karplus-Strong拨奏（任何类似鲁特/古筝/竖琴、带弯音）、槌击乐器（马林巴/钢片琴）、失谐锯齿和弦刺、合成贝斯、pad、riser与drone。按家族加重音：每个镜头起点按章选一击（splash/pok/clank/crack/whoosh/sizzle），拟音读出该章的材质。配乐读剪辑表的镜头时间并在那里放重音、每个onset校到±15ms。静音作工具：大击前半拍鼓与贝斯静音，或一整小节只留一记tick的计数声。总线胶水压缩＋限幅、−14LUFS、≤−1dBTP。
- **招牌技法**：
  - 一卡一物：数量即钩子（ALL N）——适合车间每件工具/地铁每站/地方菜每道
  - 章即颜色：家族变成色相、观众始终知道身在何处——适合管弦乐器组/食物类别/公司部门
  - 一物一动词：一记杆可读的身体动作或道具动作（齿轮转/杯倒）——适合瑜伽姿势/厨房技法/工地工种
  - 节奏阶梯快射：一个子族双倍速——适合四种刀法/手的骨骼/工作日例行
  - 沿轨长镜：站距一屏、每次切换甩镜——适合食谱步骤/马拉松关卡/火箭发射阶段
  - 计数砸入：大数字在条上滚到落定值——适合回收吨数/会员数/公司年数
- **避坑**：
  - 人物环境溢进文字列→把人物层渲进独立buffer、在文字前用渐变遮罩淡出
  - 浅色底上奶油字对比失败→浅底用深字深人物、其盘用较亮阶；深中性上太阳盘消失→用较亮阶
  - 图案canvas很大且每卡带seed→用有界的LRU缓存；无界缓存在并行渲染时会耗尽内存
  - 横向姿势（游/躺/爬）压过标题→舞台外移并收窄文字列
  - 模仿真实活动形象太像→用格子母题自创色板、标志与口号；同屏文字与人物不重叠、HUD守在角落

**适用场景**：公共服务与城市故事 / 品牌与活动形象片 / 以符号与物件讲述的解说
