# Skill 判定标准

## 核心原则

**只要一件事重复出现三次，就应该考虑沉淀成 Skill。**

Skill 的本质：把你反复使用的方法论、判断标准、工作步骤，写成 AI 可以调用的操作说明。

## 适合做 Skill 的特征

| 特征 | 例子 |
|---|---|
| 有固定触发条件 | 用户说「写周报」 |
| 有固定步骤 | 先读规则 → 再筛选项目 → 再生成草稿 |
| 有明确输出格式 | 周报必须包含状态标签、本周进展、下周计划 |
| 有禁止项或边界 | 个人私活不写进周报 |
| 重复出现三次以上 | 每周都要写、每个项目都要检查 |

## 不适合做 Skill 的情况

- 一次性任务
- 结果依赖大量即兴判断、没有固定模式
- 仍在快速变化、没有稳定下来

## Skill 文件应该包含什么

1. **触发条件**：什么时候调用
2. **输入源**：需要读取哪些文件或信息
3. **执行步骤**：第一步、第二步、第三步……
4. **输出格式**：结果长什么样
5. **禁止项 / 注意事项**：什么不能做
6. **相关链接**：关联的概念卡或其他 Skill

## 示例 Skill 类型

- 周报 Skill
- 选题判断 Skill
- 写作风格 Skill
- 会议纪要 Skill
- 项目复盘 Skill
- 去 AI 味 Skill
- 财务项目开工检查 Skill
