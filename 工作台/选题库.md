# 选题库

> 所有创作想法的统一入口。一个选题进来，可以长出：文章、教程图、口播脚本、小红书封面、后续系列选题。

---

## 🆕 新建选题

复制 [[Templates/选题模板\|选题模板]]，或者配合 **Templater** 插件自动套用。

必填 frontmatter 字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `status` | 选题状态 | `idea`（灵感）, `todo`（待写）, `writing`（写作中）, `done`（已发）, `archived`（已放弃） |
| `source` | 来源 | `读者提问`, `小红书评论`, `公众号留言`, `扣子推送`, `自己冒出` |
| `type` | 内容类型 | `文章`, `教程图`, `口播脚本`, `小红书封面`, `系列选题` |
| `date` | 记录日期 | `2026-07-31` |
| `tags` | 标签 | `topic`（必填）, `writing`, `idea` |

## 🔥 写作中

```dataview
TABLE WITHOUT ID
  file.link AS "选题",
  source AS "来源",
  type AS "类型",
  date AS "记录日期",
  file.mtime AS "最后修改"
FROM #topic
WHERE status = "writing"
SORT file.mtime DESC
```

## 🗂️ 按来源分布

```dataview
TABLE WITHOUT ID
  source AS "来源",
  rows.file.link AS "选题",
  length(rows) AS "数量"
FROM #topic
WHERE source != ""
GROUP BY source
SORT length(rows) DESC
```

## 📝 使用工作流

```
灵感出现 → 新建选题笔记 → 状态设为 idea
    ↓
确定要写 → 状态改为 todo
    ↓
开始写作 → 状态改为 writing
    ↓
发布完成 → 状态改为 done
    ↓
两周后回看：放弃的选题改为 archived
```

## 💬 让 AI 帮你拆选题

对一个选题，可以让 AI 做这些：

1. 拆标题：起 5 个候选标题
2. 拆开头：用 3 种不同的钩子写法
3. 拆结构：列出文章大纲
4. 拆情绪：判断读者现在的痛点和期待
5. 拆可复用：这个选题还能产出什么？（图、脚本、封面、系列）
