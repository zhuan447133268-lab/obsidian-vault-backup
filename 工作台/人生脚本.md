## 今日记录

```dataview
TABLE WITHOUT ID
  file.link AS "日期",
  work AS "工作",
  writing AS "写作",
  reading AS "阅读",
  family AS "家庭",
  exercise AS "运动",
  sleep AS "睡眠",
  entertainment AS "娱乐"
FROM #journal/daily
WHERE date = date(today)
```

---

## 最近 7 天

```dataview
TABLE WITHOUT ID
  file.link AS "日期",
  work AS "工作",
  writing AS "写作",
  family AS "家庭",
  exercise AS "运动",
  sleep AS "睡眠"
FROM #journal/daily
WHERE date >= date(today) - dur(7 days)
SORT date DESC
LIMIT 7
```
